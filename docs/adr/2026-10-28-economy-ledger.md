# 경제 원장과 거래소

- 상태: 확정 (일부 대체됨: 경제 코어 `2026-10-31-economy-core.md` 확정 2026-11-08)
- 날짜: 2026-10-28
- 관련: PLAN 4.7, 독립 검토 12·23

## 배경
EVE식 통합 경제와 HTS급 거래창이 목표다. 잔고는 거래소뿐 아니라 시뮬레이션, NPC, 급여도 바꾼다. 쓰는 주체가 여럿이면 이중 지출과 잠금 경합이 생긴다.

## 결정
- 금액은 최소 단위 정수: DB `int8`, JS `BigInt`, 전송 시 문자열. 실수 금지.
- 모든 잔고 변동은 복식부기 원장 항목으로만 한다.
- 주문 접수 시 자금·물품을 묶어둔다(에스크로).
- 시장마다 쓰는 주체(매칭 엔진)는 하나다. 체결 묶음을 한 트랜잭션으로 커밋한 뒤 아웃박스로 발행한다.
- 부팅 시 미체결 주문으로 호가창을 복원한다. 요청에는 중복 방지 키를 쓴다.
- 시세는 순번 + 변경분, 누락 시 스냅샷.

## 이유
- JS `number`는 2^53을 넘으면 정밀도를 잃는다. Drizzle의 숫자 모드는 큰 값을 조용히 자를 수 있다(독립 검토, Assumed).
- 단일 작성자 + 에스크로는 잠금 없이 정합성을 지키는 가장 단순한 방법이다.

## 결과
- 주문 응답 목표(서버 내부 p95 ≤ 50ms)는 NAS 디스크 동기화 지연을 측정한 뒤 확정한다.
- 거래소 구현은 경제 기획이 정해진 뒤로 미룬다(PLAN 11장). 원장과 에스크로 구조는 먼저 만든다.
