# 편집기·배치 엔진·대량 작업

- 상태: 확정
- 날짜: 2026-10-28
- 관련: PLAN 6장, DECISION_LOG Round 4·5·6·7·8

## 배경
행성 편집기는 핵심 기술이다(사용자, Round 6). 자원·크리쳐 배치는 넓은 맵에서 자동 분포가 중요하고, 희귀한 것은 수동 배치가 필요하다. 관리자 화면은 같은 앱에 통합하기로 했다(Round 4, Round 9에서 별도 주소·2단계 인증은 쓰지 않기로 함).

## 결정
- 모든 칸이 환경 값을 갖고, **규칙 기반 배치 엔진**(규칙은 데이터)을 생성기와 운영 도구가 함께 쓴다.
- 자원: 배치 가능 영역 히트맵 → 자동 분포 미리보기(다시 돌리기, 시드 고정, 확정) → 수동 배치·금지 구역.
- 크리쳐: 서식 적합도로 조우 테이블 자동 생성, 2차맵·지역 덮어쓰기, 희귀 수동 배치.
- 선택 영역 통계(평균, 조우 구성), 행성 전체 비율(%)과 이상치 경고.
- 편의: 되돌리기, 명령 팔레트, 인스펙터(값 + 근거 규칙), 비교, 북마크, 이력, CSV·JSON 입출력(초안에만).
- **임의 코드 실행(스크립트 콘솔)은 두지 않는다.** 정해진 대량 작업만 미리보기 → 차이 → 실행 → 감사 기록 → 되돌리기.
- 편집은 초안에서. 공개 시 플레이어 소유 지역이 걸리면 운영자 승인.
- 단계: 1단계(파라미터·미리보기) → 2단계(영역 선택·조각·자원/크리쳐) → 3단계(항성계 편집기).

## 이유
- 스크립트 콘솔은 관리자 세션 탈취나 XSS 하나로 서버 전체가 위험해진다(독립 검토 17).
- 관리자 화면이 플레이어 앱과 같은 주소라서 서버 권한 검증·감사 기록·CSP가 더 중요하다.

## 결과
- 편집기 2·3단계는 자원·크리쳐 규칙이 정해진 뒤에 만든다.
