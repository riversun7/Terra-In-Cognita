# 연산 분담과 서버 권위

- 상태: 확정
- 날짜: 2026-10-28
- 관련: PLAN 4.3, DECISION_LOG Round 6·7·8·9

## 배경
사용자는 "로그인 중에는 유저 기기가 자기 유닛을 계산하고, 로그아웃하면 단순 행동으로 바꿔 서버 부하를 줄이자"고 제안했다(DECISION_LOG Round 6·7).

## 선택지
1. 기기 권위: 유저 기기가 자기 유닛을 계산하고 결과를 서버에 보고
2. **서버 권위 + 기기는 표현·제안**
3. 완전 서버 계산(기기는 화면만)

## 결정
- 결과에 영향을 주는 판정(자원 획득량, 전투 승패·피해, 거래·잔고, 아이템 생성, 조우, 소유권)은 **서버만** 한다.
- 기기: 렌더링, 보간, 연출, 경로 제안(서버는 검증만), 내 명령 즉시 반영(거절 시 되돌림), 판정과 무관한 장식용 생명체·군중·날씨.
- 접속 중에는 유닛이 풍부하게 행동하고, 로그아웃 후에는 설정된 시간까지만 단순 행동을 한다. 하루 1회 접속을 유도한다.

## 이유
- 접속하지 않은 유저의 유닛도 정해진 시간 동안 움직여야 한다. 기기 계산은 폰을 끄면 멈춘다.
- 통합 경제에서 조작된 기기 보고를 막을 수 없다. 검증 비용이 직접 계산과 비슷하다.
- 유저끼리 유닛이 마주칠 때 판정 주체가 모호해진다.
- 서버 부하는 이벤트 예약·상세도 단계·지연 정산으로 줄인다(시뮬레이션 모델 ADR).

## 결과
- 서버 계산량이 기기 계산 방식보다 많다 → 검증 단계 S3에서 유닛 10만 개 부하를 측정한다.
- 판정 코드(`packages/sim`)는 게임 앱 번들에 들어가지 않게 모듈 경계로 막는다.
