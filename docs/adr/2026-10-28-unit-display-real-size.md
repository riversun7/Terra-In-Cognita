# 유닛 표현: 과장 없이 실제 크기, 대형 유닛 최대 약 12m

- 상태: 확정
- 날짜: 2026-10-28
- 관련: docs/PLAN.md 5.7·14장, `2026-10-28-map-delivery-and-rendering.md`(유닛 중간 단계를 이 ADR이 대체), 기획 GDD v4 D-068·D-095(AntiGravt01 `claude/sweet-wright-4ubb2u`, bf30012), 조사 `docs/research/2026-10-28-gdd-v4-tech-crosscheck.md` C1

## 배경
- 맵 ADR은 유닛을 중간 확대에서 "최대 약 3배 과장 + 외곽선"으로 그리기로 했다. 아트 방향상 괜찮은지는 PLAN 14장 질문으로 기획에 넘겼다.
- 기획 세션에서 사용자가 답했다(사용자 선택).
  - D-068: 유닛을 실제보다 크게 그리는 과장 표현을 쓰지 않는다. 유닛은 항상 실제 크기로 그린다. 외곽선·선택 링은 쓴다.
  - D-095: 유닛 크기는 일반 0.5~3m, 보스·전설·신수는 최대 약 12m다.

## 선택지
1. 과장을 그대로 둔다. 사용자 결정과 어긋난다.
2. 실제 크기로 그리고, 외곽선·선택 링으로 보이게 하고, 너무 작아지는 거리부터 아이콘·묶음으로 바꾼다.

## 결정
- 2번.
- 근접·중간 확대 모두 실제 크기다. 중간 확대에서는 외곽선·선택 링을 붙인다.
- 실제 크기로는 알아보기 어려운 거리부터 아이콘·부대 묶음으로 바꾼다. 바꾸는 거리는 S1에서 휴대폰으로 재서 정한다.
- 유닛 크기 범위는 0.5~12m로 넓힌다. 3m보다 큰 유닛의 표현·충돌 반경·경로탐색 통과 폭·카메라는 S1에서 다룬다. 대형 유닛이 도로·건물 사이를 지나갈 수 있는지는 기획 질문(B16)으로 넘겼다.

## 이유
- 사용자 결정이다(D-068).
- 근접 화면(가로 약 40m, 393px)에서 0.5m 크리쳐는 약 5px, 12m 크리쳐는 약 118px이다(Assumed: 계산). 작은 유닛은 외곽선이 없으면 놓친다. 과장이 없으므로 아이콘으로 바꾸는 거리가 예전 계획보다 가까워진다.

## 결과
- `2026-10-28-map-delivery-and-rendering.md`의 "중간 최대 약 3배 과장 + 외곽선"을 대체한다. 나머지는 그대로다.
- S1 측정 항목이 늘어난다: 아이콘 전환 거리, 대형 유닛 표현, 묶음 표시.
