# 시작 국가 설정 편집기(/dev/nations): 국가 프리셋 덮어쓰기, 가상 이름·이름 만들기, 국가 마크(만들기·올리기), 국가마다 씨앗 값, 이 세계에 반영

- 상태: 제안
- 날짜: 2026-11-10
- 관련: ADR `2026-11-01-skill-editor.md`(덮어쓰기 층)·`2026-11-01-item-editor.md`·`2026-11-02-building-editor.md`, `2026-11-09-faction-profiles.md`(세력 정체성·화폐 표시), `2026-11-01-npc-brain-r5.md` 7절, `2026-11-07-play-flow.md` WP1·WP5·WP-NPC2, `2026-11-07-world-layout.md`, `2026-11-02-dev-ui.md`, 기획 30 §5.3·§9(D-076·D-078·D-086), 50 §9 이름 규칙(D-5046), D-518(시작 국가·이름은 팩 프리셋에서 고르고 개발자 페이지에서 바꾼다), D-461(바로 든다)

## 배경
- 사용자 요청(2026-11-10, 원문): "시작 기본 npc국가세팅 에디터추가하고 반영하라. 임시국가, 임시화폐같은 명칭을 제대로 생성하나, 국가마크도 생성 및 유저는 업로드하여 일정 사이즈를 크롭?자를수있게 그외 사이보그나 유닛 수 등등 디테일한 조정".
- 그전: 팩 `nation_presets`(16개)의 이름이 "임시 국가 N"·"임시 화폐 N"·"임시 지도자 N"이었고, 고치려면 팩 파일을 손으로 고쳐 배포해야 했다. 국가 마크는 없었다. 시작 도시의 주거·처음 인구·기본 시설 수는 모든 국가가 같은 설정 칸(49 worldSeed) 하나였다.
- 세력 정체성(이름·약어·색)·화폐 표시는 세력이 처음 보일 때 한 번 정해지고 그 뒤 프리셋을 바꿔도 그대로다(ADR `2026-11-09-faction-profiles.md` 2절).

## 선택지
1. 프리셋 편집을 운영자 콘솔(세력·화폐 탭)에 붙인다 — 세계마다 정해진 값만 고친다. 새 세계·새 씨앗에는 들지 않는다.
2. 새 표·새 저장 길을 만든다 — 판·검사·감사·내보내기를 다시 만든다.
3. 스킬·아이템·건물·크리처 편집기와 같은 팩 항목 덮어쓰기 층에 분류 `nation_presets`를 더한다. (고름)

## 결정

### 1. 어디서 고치나: 덮어쓰기 층에 `nation_presets`
- `@terra/shared` `CONTENT_EDIT_CATEGORIES`에 `nation_presets`. 표 `content_overrides`·`content_retired_ids`의 분류 검사를 넓힌다(마이그레이션 `20261110123352_nation_editor`, 넓히기만 — 직전 판 앱은 모르는 분류의 줄을 잠든 줄로 둔다).
- tRPC `nations.list·check·save·history`(권한 = 설정 칸 패널과 같은 `tuning:read·write`, dev·admin). 담기 → 검사 → [적용] 한 묶음, baseHash, 감사 기록, 내보내기(`terra-tuning-diff`의 `entries`) → `pnpm tuning:apply`가 `nation_presets.json`에 넣는다.
- 받지 않는 것: 프리셋 만들기·지우기, `enabled` 바꾸기, 화폐 코드(`currency.code`) 바꾸기. 고정 국가의 차례는 "켜진 프리셋의 차례"라서(`npc/nations.ts nationCode`·`presetOfCode`) 끄거나 더하면 이미 선 세계의 국가 코드가 어긋난다. 화폐 코드는 원장 자산 이름(`cur:<코드>`)이다.
- 팩 검사(`@terra/content` `checkNations`): 켜진 프리셋 사이에서 약어(대소문자 무시)·화폐 약어·화폐 코드가 하나씩이어야 하고, 도시 직무의 레시피는 그 시설의 것이어야 한다(코드 `nation_short_taken`·`nation_ticker_taken`·`nation_currency_code_taken`·`nation_job_facility`).

### 2. 국가마다 씨앗 값(선택 칸)
- 프리셋 `personality`에 선택 칸 여섯: `startHousing`·`startPopulationPm`·`startFarms`·`startLumberCamps`·`startMines`·`startStorehouses`. 칸이 없으면 설정 칸 값(49 worldSeed: `npc_seed_housing`·`npc_seed_population_pm`·`npc_seed_farms`·`npc_seed_lumber_camps`·`npc_seed_mines`·`npc_seed_storehouses`), 범위는 그 설정 칸과 같다(`@terra/shared/nationEditor` `NATION_SEED_LIMITS`).
- 읽는 곳(`npc/nations.ts nationSeedOf`): 새 시작 도시의 주거(`ensureTestNations`), 시작 도시 기본 시설 수(`facilities/npcSeed.ts` `seedOfFaction`), 처음 인구(`npc/runtime.ts` — 그 도시 주인이 따르는 나라의 칸).
- 이 수들은 앞으로 서는 시작 도시·모자란 기본 시설·아직 채우지 않은 처음 인구에만 든다(씨앗은 모자란 것만 더한다). 이미 선 도시는 바뀌지 않는다. 화면이 그렇게 알린다.
- 새 규칙은 만들지 않았다: NPC 사이보그·경비 유닛을 세우는 규칙은 지금 없다(국가마다 지도자 유닛 하나, 도시마다 행정 건물 하나가 고정). 화면은 "지금 세우는 규칙 없음"으로 보이고 질문 903으로 묻는다.

### 3. 가상 이름과 이름 만들기
- 팩 16개 프리셋의 국가·화폐·지도자 이름을 가상 이름으로 바꾸고 도시·사람 이름 목록을 다시 채웠다(`core@61`). ID(`placeholder_nation_NN`)와 화폐 코드(`placeholder_cur_NN`)는 그대로다(팩 ID는 바꾸지 않는다).
- 규칙(기획): 이름은 가상(D-076 — 실제 국가·지명·인물·국기를 쓰지 않는다), 길이 한글 2~8자·영문 3~16자(D-5046), 도시·사람 이름은 번역하지 않는다(D-476). 16개 프리셋은 문화 모티프 16개(30 §5.3)라서 프리셋 차례대로 모티프를 하나씩 맡겼다 [임시](질문 901).
- 화폐 기호는 실제 화폐 기호(₩·€ 등)를 피하고 획을 그은 로마자 16개(Ⱥ Ƀ Ȼ Đ Ɇ Ǥ Ħ Ɨ Ɉ Ł Ø Ɍ Ŧ Ʉ Ɏ Ƶ)로, 화폐 이름 첫 글자와 맞췄다. 화폐 약어는 3글자, 세력 약어도 3글자로 서로 다르다.
- 이름 만들기(`@terra/shared/nameGen`): 말씨 16개(모티프마다 음절 표 — 로마자 = 한글 짝, 끝말은 닿소리로 시작), 종류 여섯(국가·화폐·지도자·도시·이름·성). 같은 (말씨, 종류, 시드)면 같은 후보(`createRng`). 길이 규칙 밖·욕설처럼 들리는 한글 조합·막은 영어 이름은 내지 않는다. 후보는 사람이 고른다(음절 표가 실제 지명과 우연히 겹칠 수 있다). 프리셋 칸 `nameStyle`이 말씨를 든다(게임 규칙은 읽지 않는다).

### 4. 국가 마크
- 만든 마크: 프리셋 칸 `emblem` = 틀 6(방패·원·마름모·깃 모양·육각·둥근 네모) × 나눔 8 × 상징 16 × 색 짜임 3. `@terra/shared/nationEmblem`이 사양 + 시그니처 컬러 → SVG 조각(바탕·나눔·상징·테두리, 정사각 100칸)을 낸다. 색은 시그니처 컬러에서 내고 상징은 바탕과 대비 3 이상이다. 칸이 없으면 프리셋 ID 해시로 정해지는 기본 마크. 실제 국기를 쓰지 않는다(30 §9): 틀 안에 상징 하나를 두는 문장 모양이고 줄무늬만으로 된 깃발 모양은 없다.
- 그리기: `apps/game/src/ui/NationEmblem.tsx` 하나(16~256px). 편집기 목록·미리 보기와 세력 화면(`/faction`)의 세력 카드가 쓴다(`FactionSummary.emblem`).
- 올린 마크: 편집기에서 그림 파일(PNG·JPEG·WebP)을 고르고 정사각으로 잘라(끌기·확대·화살표 키, 24·48·128px 미리 보기) 기기가 256 × 256 PNG로 만들어 올린다. 새 의존성 없음(canvas). 바이트 상한을 넘으면 색 단계를 줄여 다시 만든다.
- 서버: tRPC `nations.uploadEmblem`(JSON base64 — tRPC 길은 multipart를 받지 않는다) → PNG 서명 8바이트·첫 청크 IHDR·가로세로 256 × 256·20만 바이트 이하만 받는다(그림을 풀지는 않는다). 표 `nation_emblems`(프리셋 ID마다 한 장: bytea·sha256·올린 사람·시각). 감사 기록 `nation.emblem_upload`·`nation.emblem_remove`(바이트는 싣지 않는다).
- 그림 길: `GET /api/nation-emblems/<sha256>.png` — `content-type: image/png`, `x-content-type-options: nosniff`, `cache-control: public, max-age=31536000, immutable`(해시가 주소). 로그인 없이 읽는다(게임 화면의 국가 이름 곁에 누구에게나 보이는 그림이고 주소가 해시 64자다).
- 올린 그림이 있으면 그 세계에서 만든 마크 대신 보인다. [생성 마크로 되돌리기]가 지운다. 올린 그림은 담지 않고 바로 들며 팩 내보내기에 들지 않는다. 표는 개발 도구 자료라 시험 세계 새로 시작에서 남긴다(`WORLD_RESET_KEEP`).
- 권한: dev·admin만(설정 칸 쓰기 권한). 사용자 원문의 "유저는 업로드"는 편집기를 쓰는 사람으로 읽었다. 플레이어가 자기 세력 마크를 올리는 것은 검수 규칙이 필요해 질문 905로 묻는다.

### 5. 서버가 실효 프리셋을 읽는다
- `main.ts`가 실효 국가 프리셋 목록(`npc/presets.ts createLivePresets`)을 하나 만들어 세계 씨앗·NPC 사회·세력 이름·운영자 콘솔에 넘긴다. 덮어쓰기를 싣거나 저장할 때마다(`ContentEditState.subscribe`) 그 배열의 내용을 제자리에서 바꾼다(읽는 쪽은 쓸 때마다 배열을 다시 읽는다 — 바로 든다, D-461). 랭킹 판의 세력 이름 표, 경제 목록의 나라 화폐 이름도 같이 따른다.
- 세계 씨앗(국가·시작 도시)은 덮어쓰기를 처음 실을 때까지 기다린다(`WorldConfig.npc.presetsReady`). DB가 없으면 기다리지 않고, 싣지 못하면 90초 뒤 팩 값으로 차린다.
- 그래서 게임 화면의 나라 이름·지도자 이름·도시 이름 후보·사람 이름·도시 직무는 저장한 다음 조회부터 새 값이다(세력 화면·지도·랭킹은 프리셋 이름을 읽는다).

### 6. 이 세계의 NPC 국가에 반영
- 이미 정해진 세력 정체성(`faction_profiles`)·화폐 표시(`currency_profiles`)는 편집기의 [이 세계의 NPC 국가에 반영]으로만 다시 넣는다(tRPC `nations.applyToWorld`). 먼저 미리 보기(`dryRun`)로 줄마다 앞 값·뒤 값·할 일을 보이고, [반영]을 눌러야 쓴다.
- 대상: 자기 국가 프리셋이 있는 세력(세력 코드 = 프리셋 ID, 시험 NPC 세력 = 16번째 프리셋)과 프리셋 화폐(`cur:<코드>`).
- 건너뛰는 줄: 운영자가 손으로 고친 줄(`source = 'admin'` — 운영자 콘솔이 고칠 때 다는 표시), 약어·티커가 다른 줄과 겹치는 줄, 프리셋 값이 규칙에 안 맞는 줄. 정체성 줄이 아직 없는 세력은 건드리지 않는다(처음 보일 때 지금 프리셋 값으로 정해진다).
- 바꾸는 것은 두 표의 표시 값뿐이다(유닛·도시·잔고는 그대로, 세계를 새로 시작하지 않는다). 바꾼 줄마다 감사 기록 `nation.apply_faction`·`nation.apply_currency`(앞·뒤 값, 프리셋 ID).
- 국가 마크는 프리셋(실효 값)과 올린 그림에서 바로 읽으므로 따로 반영할 것이 없다.

### 7. 화면
- `/dev/nations`("시작 국가 설정", dev·admin, 개발 화면 층 — 네온 다크·라이트). 왼쪽 국가 16줄(마크·색·이름·약어·시작 수·표지), 오른쪽 편집 판: 미리 보기(마크 크기 넷, 이름, 지도 이름표 밝은·어두운 바탕, 화폐 보기 "Ⱥ 1,234 ALD", 시작 수) + 구역 다섯(정체성·화폐·시작 조건·인구·유닛·성격).
- 입력 칸·담은 변경 막대·견주기는 공용 부품(`editor/content/`)을 그대로 쓴다. 색은 읽기 쉬운 색 20개 고르기 판 + 색 값 칸(지도 바탕 두 가지와의 대비를 보이고 낮으면 알린다 — 막지는 않는다).
- 조각 이름 `NationEditorScreen-*`는 미리 캐시하지 않는다(`[Nn]ationEditor`).

## 이유
- 덮어쓰기 층을 쓰면 판·baseHash·팩 검사·감사·켤 때 고르기(팩이 바뀌면 팩이 이김)·내보내기를 그대로 얻는다(Verified: `apps/server/src/nationEdit/nationEdit.db.test.ts`가 저장 → 실효 프리셋·경제 목록·내보내기·다시 켜기를 본다).
- 국가마다 씨앗 값을 선택 칸으로 두면 직전 판 앱·팩이 그대로 돈다(칸이 없으면 설정 칸 값 — Verified: `apps/server/src/facilities/npcSeed.db.test.ts` "국가마다 씨앗 값").
- 올린 그림을 서버가 풀지 않아도 되는 까닭: 기기가 캔버스로 다시 그린 PNG만 받고(크기·서명·IHDR 확인), 내줄 때 형식을 고정하고 nosniff를 단다. 그림 풀기 도구(새 의존성)가 필요 없다.
- 반영을 명시적 동작으로 둔 까닭: ADR `2026-11-09-faction-profiles.md`의 "한 번 정한 값은 다시 정하지 않는다"를 지키면서, 임시 이름으로 이미 정해진 세계(NAS)를 고칠 길이 필요하다.

## 결과
- 좋은 점: 시작 국가의 이름·화폐·마크·시작 수를 배포 없이 고치고, 팩에 넣을 차이를 내보낼 수 있다.
- 감수할 점: 실효 프리셋 목록은 "같은 배열을 제자리에서 바꾸는" 방식이다(서버 곳곳이 배열을 들고 있어 접근자로 다 바꾸지 않았다). 켤 때 한 번 읽어 둔 값(예: 운영자 콘솔 밖에서 이미 만든 파생 자료)은 다시 켜야 바뀐다.
- 감수할 점: 지도(1차맵·2차맵)의 도시 이름표·정부 판 머리에는 아직 마크를 넣지 않았다(조회 모양과 첫 화면 크기를 봐야 한다). 운영자 콘솔 표에도 넣지 않았다.
- 감수할 점: 올린 그림은 세계 DB에만 있고 팩 내보내기에 들지 않는다. 새 서버에는 만든 마크로 뜬다.
- 다시 볼 조건: 플레이어가 세력을 만들고 마크를 올리게 되면 검수·신고·크기 제한을 정한다(질문 905). 이름 말씨·모티프 차례는 기획 답(질문 901)에 따라 고친다.

## 구현하며 정한 것
- `ContentEditState.subscribe(listener)`: 스냅숏을 바꿔 끼운 뒤 부른다(듣는 쪽이 던져도 저장은 그대로).
- 마크 색: 색 짜임 0 = 시그니처 컬러 바탕, 1 = 밝은(또는 어두운) 바탕에 시그니처 컬러 상징, 2 = 짙은 바탕. 밝기 셈은 WCAG 식의 지수 2.4를 2.5로 근사한다(그림 색 고르기에만 쓴다, 판정 아님).
- 팩의 화폐 기호 16개는 Latin Extended-B 글자다. 기기 글꼴에 없는 글자가 있는지는 재지 않았다(Unknown).
