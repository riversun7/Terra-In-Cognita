# 인벤토리 화면·2차맵 가방·채집 진행바와 휘두르기 자세

- 상태: 확정
- 날짜: 2026-11-14
- 관련: `docs/adr/2026-10-29-app-shell.md` 1절(주소 표)·"구현하며 정한 것 (경제·거래창 화면)", `docs/adr/2026-11-03-item-holdings.md`, `docs/adr/2026-11-07-gather-objects.md` 결정 7(채집 화면), `docs/adr/2026-11-07-buildings-runtime.md` "바뀜 (창고·직무)", 기획 D-117(물건마다 자리)·D-121(다중 창고)

## 배경

사용자 요청(2026-11-14, NAS 2차맵 사진과 함께):

- "채집시 진행바 ui표시", "채집 모션추가".
- "인벤토리 시스템 추가. 하단 메뉴에도 유닛이 보유한 아이템 리스트 볼수있는 버튼. 첫 페이지에도 통합으로 유닛별, 창고별, 건물별, 전체적으로 보유한 아이템을 볼수있게해라".

물건 저장은 이미 있다(Verified: 코드).

- 쌓이는 물건·화폐: 원장 `ledger_accounts`(주체·자산·위치). 위치 = 도시 창고·건물 창고·유닛 화물(`@terra/shared/goodsPlaces`).
- 장비·식품 묶음: `item_holdings`(유닛·자리·칸).
- 조회: `economy.holdings`(자리별 잔고), `holdings.list`(유닛 물건), `facilities.overview`(창고 시설), `units.list`(유닛·화물).
- 명령(WebSocket): `storage_move`(창고 시설 넣기·꺼내기), `item_equip`·`item_unequip`·`item_use`.

빠진 것은 한곳에서 보는 화면이었다. 옛 경제 [창고] 칸이 자리별 목록을 보였지만 경제 메뉴 안에 있었고, 유닛별·전체 합계는 없었다. 채집은 서버가 이번 캐기의 끝 시각(`nextAt`)만 보내고 화면이 쓰지 않았다. 캐릭터 모델은 걷기 자세만 있었다.

## 선택지

통합 보기를 어디에 둘지(사용자에게 물음):

1. 홈 카드 + 새 화면(추천안)
2. 옛 창고 화면 넓히기

사용자 답: "새화면, 기존 창고도 이전 후 제거. 경제페이지에는 자산가치 합계 등의 정보를 보여주는 방식".

나머지 답:

- 아래 버튼은 "고른 유닛의 물건"(추천안)을 보인다.
- 범위는 "보기 + 옮기기·장착"이다.

## 결정

### 1. 인벤토리 화면 `/inventory`(주소 표 `inventory`, 부모 `home`, search `tab`·`unit`)

칸은 넷이다(`tab`: 없음 = 전체, `units`·`warehouses`·`buildings`).

- **전체**: 지갑(화폐), 한눈에(물건 종류 수·자리 수·추정 가치), 가진 물건 합계(같은 자산을 자리마다 더하고 몇 곳에 있는지).
- **유닛별**: 내 세계 유닛 줄. 펼친 유닛 하나만(`unit`) 화물과 장비·지닌 물건 판을 연다(`holdings/UnitHoldings.tsx` 그대로 — 칸 고르기·장착·해제·사용). 유닛마다 `holdings.list`를 따로 받지 않기 위해서다.
- **창고별**: 도시 창고 + 내 창고 시설(`facilities.overview`의 `storage`) + 자리 없는 물건. 창고 시설 카드에 넣기·꺼내기 폼(`economy/StorageParts.tsx`의 `StorageMoveForm` 그대로, `storage_move`)을 붙인다.
- **건물별**: 그 밖의 건물 창고(생산 시설 창고·임대 몫).

자료와 명령은 그대로 쓴다. 새 서버 조회·프로토콜·DB 표는 없다. 화면 계산은 `apps/game/src/inventory/inventoryModel.ts`(순수 함수, 시험)에 둔다.

### 2. 옛 경제 [창고] 칸 이전·제거

- 화면 코드(`economy/WarehouseView.tsx`)를 지운다. 자리 카드·지갑 판은 `inventory/PlaceCard.tsx`로 옮겼다.
- 경제 칸 띠에서 [창고]를 뺐다.
- 주소 표의 `economy_warehouse`(`/economy/warehouse`)는 옛 링크·책갈피를 위해 남긴다. 열면 인벤토리 [창고별]로 주소를 바꾼다(replace).

### 3. 자산 요약(경제 한눈에·홈)

- 경제 한눈에의 [창고] 카드는 [자산] 카드로 바꿨다: 추정 가치, 자리·물건 종류, 지갑 첫 화폐. 누르면 인벤토리로 간다(쌓기 — 경제 칸이 아니다).
- 홈 [자산] 카드는 서버 카드 상태(늘 not_ready) 대신 경제 원장 잔고로 그린다(실제 잔고 — 가짜 숫자 없음). 머리 링크와 [인벤토리 열기]는 인벤토리로 간다.
- 추정 가치 [임시]: 물건마다 기준 도시의 마지막 체결가(묶음당)를 쓰고, 없으면 팩 시작 시세(기준 통화, 묶음당)를 쓴다. 그 값에 묶음 수(버림)를 곱해 화폐마다 따로 더한다. 값이 없는 물건(경매 장비·문서 등)은 세지 않고 수를 알린다(`inventory/inventoryValue.ts`).

### 4. 2차맵 아래 탭 [가방]

- 아래 판 자리 하나(`useBottomSheet`)의 판 종류에 `bag`을 더한다. 우선순위는 도시 화면 다음, 내 유닛 목록 앞이다.
- 판 내용:
  - 고른 유닛(기본 내 사이보그)의 화물(`economy.holdings` cargo 자리, 열 때 다시 받음).
  - 장비·지닌 물건 판(`UnitHoldings`).
  - [인벤토리에서 보기] — 그 유닛을 펼친 [유닛별] 칸.
- 내 유닛이 아니면 안내만 보인다.

### 5. 채집 진행바

- `GatherLoopView`에 `phaseAt`(지금 단계를 시작한 서버 시각)을 더한다. 선택 칸이라 옛 서버면 진행바가 없다. 캐는 중이면 [phaseAt, nextAt]가 이번 한 번 캐기다.
- 머리 위 이름표 아래와 아래 판 채집 줄에 막대를 둔다.
  - 판의 막대는 둘이다: [이번 캐기]·[화물 kg/상한].
  - 막대는 CSS 움직임으로 채운다: 0 → 1 선형, 길이 = 전체 시간, 음수 지연 = 지난 시간. 그래서 자료가 몇 초마다 와도 부드럽고, 엔진 프레임을 깨우지 않는다.

### 6. 휘두르기 자세

- 캐릭터 자세(`CharacterPose`)에 `chop`(일하는 팔 각도)을 더한다.
  - 오른팔이 그만큼 앞으로 들리고 왼팔은 0.6배 든다.
  - 1.1초에 한 번 휘두른다: 70%는 천천히 들고 30%는 빠르게 내려친다. 내려칠 때 몸을 조금 낮춘다.
- 엔진 API `setWorkingUnits(ids)`: 화면이 캐는 중인 내 유닛을 넘긴다(채집 덧그림, `gatherOverlay.ts`).
  - 서 있고 모델로 그리는 유닛만 이 자세다. 걷는 중이면 걷기가 먼저다.
  - 그리는 동안 엔진이 계속 그린다(걷기와 같다).

## 이유

- 사용자 답이 위치·범위를 정했다(위 "선택지").
- 서버 자료가 이미 자리별로 있어(D-117 "물건마다 자리") 화면만 묶으면 된다. 새 서버 조회를 만들면 판정 코드와 겹친다. 전체 합계·가치는 화면이 더해도 값이 같다(원장 잔고 합) — Verified: 단위 시험 `inventoryModel.test.ts`.
- 장착·넣기·꺼내기는 이미 시험된 부품(`UnitHoldings`·`StorageMoveForm`)을 그대로 붙여 새 명령 경로를 만들지 않는다.
- 진행바는 서버가 이미 끝 시각을 갖고 있어 시작 시각 하나만 더하면 된다(보기 값, 판정과 무관). 선택 칸이라 PWA 기기·서버 판이 엇갈려도 깨지지 않는다.
- 휘두르기 자세는 기존 걷기 자세 행렬(팔 묶음의 x축 돌림)에 각도만 더해, 셰이더·지오메트리를 바꾸지 않는다.

## 결과

### 좋은 점

- 물건을 한 화면에서 유닛·창고·건물·전체로 본다.
- 2차맵에서 고른 유닛의 물건을 바로 본다.
- 채집 진행과 화물이 막대로 보이고, 캐는 동작이 보인다.

### 감수할 점

- 추정 가치는 [임시] 규칙이다. 기준 도시 하나의 마지막 체결가이고, 화폐를 바꿔 더하지 않는다. 기획 경제 가치 규칙이 정해지면 바꾼다.
- 다른 플레이어 유닛의 채집 자세는 보이지 않는다. 채집 줄은 보는 사람 자기 것만 받는다(지도 자료에는 "움직임"만 있다).
- 휘두르기 자세는 가까이 모델로 그린 유닛만이다. 캡슐·아이콘 단계는 그대로다.
- 앱 메뉴: 사용자 결정(2026-11-14 "당연")으로 메뉴 항목 `inventory`를 `NAV_ITEM_IDS` 끝에 더했다(아래 "구현하며 정한 것").
- `packages/engine/src/secondMapEngine.ts`가 998줄로 1,000줄 상한 직전이다. 다음 엔진 기능 전에 나눈다.
