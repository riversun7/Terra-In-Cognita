  - D-551(다른 줄기가 나중에 한다): 꼭 필요한 레벨 0 건물(처음 행정·자원 채집소·기본 창고 등)은 맨손으로 캔 원자재만으로 짓고, 나머지는 가공품이 든다. 이 줄기는 건물 비용을 바꾸지 않는다.

  - 시뮬(NPC 경제)은 오브젝트가 없다. 시설 레시피가 사다리를 굴리고, 배후지가 산지 막기(`oreTierCap`)·물 종류 범위(`fishTierRange`)를 준다.

## 결정
1. **확률표 하나.** 팩 `gather_tiers`에서 `ladder` 칸을 지운다(스키마에서 뺌). 광석 전용 표 14줄(`ore_band_*`)을 지우고 `id-changes.json`에 적는다. 남는 표 = 지금 기본 표(옛 값). 코드에서 `gatherLadderBands`·`gatherBandLadders`를 지우고 모든 곳이 표를 그대로 쓴다(시뮬 생산·서버 채집 직무·NPC 경제·아이템 편집기 미리 보기·사이보그 판·생산 편집기·채집 띠 표 편집기·오브젝트 굴림).
2. **오브젝트 = 원자재 종류 + 양 + 티어 범위.**
   - 종류(사다리) = 대표 아이템 `item`의 중분류. 맡는 시설(`facility`)에 채집 칸이 있고 그 사다리 중분류(주 + 함께 내는 것)에 든 아이템이면 그 시설 사다리(목장 = 축산물 + 부산물). 양 = `lots`(그대로).
   - `tierRange {min, max}`(T0~T9, min ≤ max)를 굴림표가 아닌 모든 오브젝트에 쓸 수 있다(굴림표와 함께면 2단계 오류 `gather_tier_range_table`). 없으면 [대표 아이템 티어, 같은 티어] — 옛 결과와 같다.
   - `ladder` 칸은 지운다(모든 오브젝트가 티어를 굴린다). 검사 `gather_ladder_facility`·`gather_table_ladder`·`gather_tier_range_ladder`도 지운다.
   - 굴림표(`table`, 난파선·고래 무리)는 그대로다(가공품·특수 전리품, D-540 1222 나).
3. **한 번 캐기 규칙(직접·일꾼 같은 함수 `@terra/sim rollGatherOutputs`).**
   - 티어 = 확률표에서 유효 스탯 구간으로 뽑고(맡는 시설이 선택 방식이면 해금 티어), 오브젝트 범위로 자른다(아래는 min으로 올리고 위는 max로 내린다, 난수를 더 쓰지 않는다). 선택 방식에도 범위를 건다(지금까지는 어류 물 종류 범위만 있었고 선택 방식은 접지 않았다).
   - 아이템 = 그 티어에 대표 아이템이 있으면 대표 아이템(새 칸 `prefer`, 난수 없음), 아니면 그 티어 켜진 아이템 가운데 고르게. 그 티어가 비면 더 낮은 티어로(옛 규칙).
   - 굴림표 오브젝트는 같은 함수 안에서 가중치로 하나(새 칸 `table`). 필요 진행은 나온 아이템의 사다리 티어(사다리 밖이면 T0).
   - 유효 스탯: 직접 = 오브젝트 주 + 보조 + 맡는 시설 반경 안이면 레벨 보너스(지금 그대로), 일꾼 = 시설 주 + 보조 + 컨디션 + 레벨 보너스(지금 그대로).
4. **일꾼 채집도 오브젝트 규칙.** 채집소(`objects` 종류) 정산은 이미 묶음마다 반경 안 오브젝트 번수를 가까운 것부터 쓴다. 이번 정산의 k번째 묶음이 쓸 오브젝트의 규칙(사다리·범위·대표·굴림표)으로 그 묶음을 굴린다(`StationPlan.lotRoll(k)` → `gatherLots`). 오브젝트를 맡지 않는 `facility` 채집소(덮어쓰기·시험 팩)는 시설 사다리 그대로다.
5. **흡수(플레이어).** 플레이어 광산의 칸 산지 막기(`gatherSiteOf` `tierCap`)와 플레이어 낚시터의 물 종류 범위(`tierRange`)를 지운다. 산지 = 바위 지표 광맥(`ore_vein`) 범위 T2~T9, 평지 노두는 위가 낮다(구리 노두 T2~T3 — 표의 T3 몫이 옛 "산지 밖 높은 티어 드물게 50‰" 자리를 맡는다). 물 종류 = 어군 범위(민물 T0~T2·연안 T0~T4·대륙붕 T2~T6·심해 T4~T8, 그대로)와 물터 범위.
   - NPC·시뮬의 배후지 모델(오브젝트 없음)은 산지 막기·물 종류 범위를 그대로 둔다(설정 칸 `ore_flat_high_pm`·`ore_low_tier_max`·`fish_tier_*`도 그대로) — 질문 1562.
6. **시작 값(팩 core@98, 모두 [임시]).** 원칙: ① 아래 끝 = 대표 아이템 티어(오늘보다 낮은 물건이 나오지 않음, 어군은 D-541 값 그대로). ② 대표 아이템이 레벨 1 건물 재료(소나무 원목·석재·잡석, Verified: 팩 `facilities` build 레벨 1)인 오브젝트는 위 끝 ≤ 1 — 늘 T0~T1(D-552 "레벨 0 건물은 T0~T1"). ③ 그 밖은 지형이 드물수록 위가 높다. 자연 채집물(물·소금 등)은 T0 하나(같은 사다리 위 티어에 다른 물건이 있어 넓히면 그것이 나온다 — D-556 뒤 조개 → 어류 사다리, 베리 → 작물 사다리 등).

   | 사다리 | 오브젝트 → 범위 |
   |---|---|
   | 목재 | 침엽수·야자수·쓰러진 나무·잔가지 더미·표류목·오아시스·맹그로브(소나무) T0~T1, 활엽수(자작나무) T1~T5, 바오밥 T1~T6, 거대목(편백) T2~T9 |
   | 광석 | 바위·석재 노두·이끼 바위·사암·갯바위·물가 바위(석재) T1~T1, 낙석 더미(잡석) T0~T1, 광맥 T2~T9, 구리 노두 T2~T3, 동토 광맥 T2~T5, 운석 조각(철) T3~T7, 열수구(은) T4~T8 |
   | 약초 | 약초 덤불 T0~T4, 버섯 군락·극지 약초·늪 약초 T0~T5, 빈터 약초 T1~T5, 약용 선인장 T1~T6, 열대 약초 T1~T7, 고산 약초 T2~T9 |
   | 작물·축산(선택 방식) | 밭·목초지 T0~T9(일꾼 해금 티어 그대로), 야생 곡물 T0~T4, 순록이끼(맡는 시설 없음 — 추첨) T0~T2 |
   | 어류 | 물터 T0~T2, 어군 넷 그대로 |
   | 자연 채집물(D-556 뒤 각 분류) | 물·소금·식물 섬유·이탄·베리·과일·조개·화석 여덟 모두 T0~T0 |
   | 굴림표 | 난파선·고래 무리 — 범위 없음 |

7. **채집 오브젝트 편집기 `/dev/gather-objects`**(개발 화면 층, 새 지연 조각 `GatherObjectsScreen-*`, 미리 캐시 밖).
   - 목록: 오브젝트 49종(자리 종류·사다리로 거르기), 줄마다 이름·종류·아이템·범위·양.
   - 고르면 판: 3D 모델(소품 그림 이름 — prop은 여러 그림, outcrop·site·school은 하나), 대표 아이템(원자재 중분류별 목록 → 사다리를 보인다), 양(`lots`), 티어 범위(아래·위, 한 끝을 고치면 다른 끝을 민다), 나오는 2차맵 지형(site = 바이옴마다 천분율, school = 바이옴마다 어군 수, plot·outcrop·site = 지표, rock·outcrop = 천분율). 미리 보기: 유효 스탯 하나(0~260)에서 확률표 → 범위 → 대표 아이템 순으로 센 아이템별 확률.
   - 차이 내보내기: 바뀐 항목만 `terra-tuning-diff` entries(분류 `gather_objects`, 이미 적용 스크립트가 받는다) → `pnpm tuning:apply`. 바로 적용(덮어쓰기)은 없다(지형 오브젝트 편집기와 같다 — 서버를 다시 켜면 든다).
   - 자료: 행성 편집기 정의 조회(`planetEditor.definitions`)에 원자재 아이템 요약(`gatherItems` — ID·이름·중분류·티어)·채집 시설 사다리(`gatherFacilities`)·확률표(`gatherTiers`)를 더한다(선택 칸, 옛 서버면 없음).
   - 지형 오브젝트 편집기의 티어 범위 칸은 굴림표가 아닌 모든 채집 오브젝트 줄에 보인다(어군만이던 것).
8. **판.** 팩 core@98. `SIM_VERSION` 45(확률표 하나 — 광석 사다리가 기본 표로 굴러 경제 시나리오 결과가 바뀐다). 프로토콜은 그대로(조회 `gather.objects`의 `ladderName`·`ladderTiers`는 모든 굴림 오브젝트에 싣는다 — 선택 칸이라 옛 기기도 읽는다).

## 이유
- 표 하나(1): 사용자 "표 하나". 광석 표는 "기본 재료 바닥 보장"(D-537, 석재 T1 350‰)을 위한 것이었다. 이제 석재 오브젝트가 늘 석재를 내고(범위 T1~T1), D-551이 레벨 0 건물에 T0~T1을 받게 하면 잡석도 쓴다. 기본 표는 0~39·40~59 두 구간 모두 T0+T1 몫(850·870‰)이 광석 표(850·850‰)보다 작지 않아 "T0~T1이 귀해지지 않는다"를 지킨다(Verified: 팩 값). 섞은 새 표(3)는 근거 없는 수를 새로 만든다.
- 범위 없음 = 대표 아이템 티어(2): 팩 검사·앞 판 팩·시험 팩이 그대로 옛 결과를 낸다.
- 대표 아이템 우선: 빈터 약초(캐모마일, T1)처럼 같은 티어에 아이템이 셋이면 고르게 고를 때 그 오브젝트의 아이템이 1/3로 준다. 오브젝트 이름이 그 아이템을 말하므로 그 티어가 나오면 그 아이템이 맞다(Assumed — 질문 1561).
- 일꾼 = 오브젝트 규칙(4): 산지 막기·물 종류 범위를 플레이어에게서 지울 수 있는 길이다. 묶음과 오브젝트 번수가 이미 1:1이라 새 상태가 없다.
- NPC는 그대로(5): NPC 경제는 오브젝트를 캐지 않는 추상 배후지 모델이라 오브젝트 범위를 직접 쓸 곳이 없다. 끌어내는 규칙(질문 1562 나)은 지형 → 오브젝트 대응을 새로 정해야 해서 이 줄기 밖이다.
- 시작 값(6): 직접 채집에서 석재 오브젝트는 지금과 같고(석재 100%), 소나무 오브젝트는 낮은 스탯에서 소나무 700‰·자작나무 300‰(T0~T1 100% 그대로). 채집소 일꾼은 옛 사다리 굴림(낮은 스탯 소나무 700·자작 150·편백 100·단풍 50)보다 T0~T1이 늘어난다(침엽수 곁 일꾼 850 → 1000‰, 바위 곁 광산 일꾼 850 → 1000‰). 높은 티어는 드문 지형 오브젝트(광맥·거대목·고산 약초)와 어군에서 나온다.

## 결과
- 좋은 점: 티어 규칙이 표 하나 + 오브젝트 범위로 줄었다. 직접·일꾼이 같은 함수다. 특수 규칙 둘(플레이어 산지 막기·물 종류 범위)이 지워졌다. 편집기에서 오브젝트마다 모든 칸을 고친다.
- 감수할 점
  - D-551 전까지 건물 비용은 소나무·석재를 따로 본다: 소나무 오브젝트 직접 채집은 낮은 스탯에서 소나무가 30% 준다(자작나무로) — 질문 1563.
  - NPC 경제(시뮬): 광석이 기본 표로 굴러 석재가 줄고 잡석이 는다(T0+T1 합은 같다) — 측정은 작업 기록, 질문 1564.
  - 일꾼 묶음이 쓰는 오브젝트는 정산하는 때의 반경 안 상태(가까운 것부터)로 정한다. 같은 (유닛, 묶음 차례)라도 그 사이 오브젝트가 바뀌면 다른 규칙으로 굴릴 수 있다(옛 "나눠 정산해도 같다"는 오브젝트가 그대로일 때만).
  - 바다 물터(물터 하나가 모든 물 지표에 선다)는 민물 범위 T0~T2다. 바닷가 낚시터의 바닷고기는 반경 안 어군에서만 나온다 — 질문 1566.
- 다시 볼 조건: D-551이 합쳐질 때(레벨 0 건물이 T0~T1을 받으면 시작 값 ②를 다시 본다), NPC가 오브젝트를 캐게 될 때(질문 1562), 사용자가 시작 값을 정할 때.
