## 선택지
1. 조약 기록 표 + 외교 서비스(새 모듈 `apps/server/src/diplomacy/`)가 제안·맞제안·받기를 맡고, 투표는 기존 의결 안건 틀에 새 종류 `treaty`(비준)로 얹는다. 집행은 세력·사회 규칙(강화·불가침·선포)과 원장 이체.
2. 조약 하나하나를 의결 안건 종류로(동맹 안건·보호 안건 …) — 협상(맞제안·판)을 담을 곳이 없고 안건 종류가 카드 수만큼 는다.
3. 시뮬(`packages/sim`)에 조약 상태를 넣는다 — 판정이 바뀌어 SIM_VERSION·골든을 고쳐야 하고, 플레이어 지도자 협상은 시뮬에 필요 없다.

## 결정
선택지 1. 시뮬 판정은 그대로(SIM_VERSION 그대로 — 세력·사회 규칙 함수만 부른다).

- **조약 = 조항 카드 묶음 + 기간**(표 `diplomacy_treaties`): 처음 제안한 나라·받은 나라, 지금 조항을 쓴 나라(`author_nation` — 맞제안이면 바뀐다), 판(`revision`), 조항(jsonb), 기간(날 1~`dip_treaty_max_days`),
  상태 proposed | negotiating | active | expired | broken | declined | lapsed, 지은이가 받아들였나(`author_ready`), 열린 비준 투표(`agenda_id`·`agenda_nation`), 답 기한, 맺은 때·끝 시각·공물 다음 시각.
- **집행하는 조항 카드**(`@terra/shared/treaty` `TREATY_CLAUSE_KINDS`): 휴전·강화(`ceasefire` — 전쟁 중이면 꼭, 전쟁이 아니면 못 넣음), 불가침, 동맹, 보호(보호하는 나라·공물 ‰ ≤ `dip_tribute_max_pm`).
  다른 카드는 받지 않는다(질문 2551).
- **받아들이기(동의)**: 두 나라가 모두 받아들여야 맺는다. 지은이가 먼저, 상대가 다음. 나라마다 길 = `treatyPathOf(카드, 체제)`(D-444 167): 투표 필요 카드가 있고 독재가 아니면 비준 투표(의결 안건
  `treaty` — 휴전·강화만이면 전쟁 묶음 짧은 기간, 아니면 지도자 묶음 기간, 정족수 지도자 묶음, 문턱 기본, NPC 가문 표 = 만족도 [임시]), 아니면 지도자가 바로. 지은이가 받아들이면 상대에게 간다(답 기한
  `gov_peace_offer_ms` 재사용 3일). 지은이 나라 투표 부결 → 거절, 받는 나라 투표 부결 → 기한 안에 다시 받기 가능 [임시 2554].
- **제안(가)·협상(나)**: WebSocket `dip_propose`(지도자, 두 나라 사이 열린 조약은 하나), `dip_counter`(받는 쪽 지도자가 조항·기간을 고쳐 되돌림 — 판 + 1, 지은이 바뀜, 다시 받아들이기부터),
  `dip_respond`(받기 = 받는 쪽 동의 / 거절·거두기 = 열린 조약이면 어느 쪽 지도자든, 열린 비준 투표는 취소). 제안·답은 지도자만 [임시 2552].
- **받는 쪽 NPC**(D-588 "NPC 규칙"): 상대에게 갈 때 NPC가 이끄는 나라면 `npcTreatyAnswer`가 바로 답한다 — 휴전·강화 = 기존 NPC 강화 규칙식, 불가침·동맹 = 차분함(1000 − 공격 성향) ≥
  `dip_npc_calm_pm`, 보호 = 힘(휴먼 수) 비교 [임시 2553]. NPC는 맞제안·먼저 제안하지 않는다.
- **맺음 = 서버가 바로 집행(D-292)**: 휴전·강화 → 세력·사회 `makePeace`(전쟁 끝 + 불가침 `d292_truce`). 불가침·동맹·보호 → 조약 기간 끝까지 두 나라 `truces`(NPC 판단이 거른다, 저장 = NPC 런타임
  `faction_wars` truce 줄, 틱마다 다시 건다). 보호 공물 → 봉신 공물 주기(`tributeEveryMs` 7일)마다 보호받는 나라 국고의 ‰ → 보호하는 나라 국고(원장 `treaty_tribute`). 끝: 기간 지남(expired), 두 나라가
  전쟁 상태가 됨(broken — 조약은 공격을 막지 않는다 D-329 86, 누가 어겼는지 기록 없음 [임시 2558]), 답 기한 지남(lapsed).
- **동맹·보호 효과(2498 기술 기본값 — 질문 2559에 전부 적음)**: 동맹 = 불가침 + 참전 요청·수락(양쪽), 보호 = 불가침 + 공물 + 보호받는 쪽이 전쟁에 들면 보호국에 참전 요청이 저절로(조약·적마다 한 번 [임시 2555])

  (`declareWar`)을 무명분 비용 없이 불러 그 적과 전쟁 참가자가 된다(D-291 "악명 없이"). NPC 참가국 = 힘이 적 이상이면 참가 [임시 2556].

  조약(기간 = 강화 불가침 날 수)을 상대에게 보낸다. 옛 길(두 나라가 서로 강화 안건을 정하면 맺음)은 그대로 남긴다. NPC가 이끄는 상대는 그대로 NPC 강화 규칙식(질문 2560).
- **잇기**: 의결 서비스에 고리 둘 — 비준 안건 집행(`leaderAgendas.enactTreaty` → 외교 서비스 `enact`)과 `run`(의결 사슬 — 외교 명령·틱이 의결 틱·명령과 겹치지 않게). 외교 틱은 의결 틱 뒤(1분).

## 이유
- 협상(나)은 조항이 판마다 바뀌어 안건 하나로 담기지 않는다 — 조약 기록이 조항·판·차례를 들고, 투표는 판 하나를 비준한다(판이 바뀌면 그 안건은 취소, Verified: DB 시험).
- 167 다(카드마다 투표 필요)는 이미 `@terra/shared/faction` 표로 있다 — 같은 표로 조약 하나의 길을 정해 화면 시안(조약 제안 목록)과 서버가 같은 답을 낸다.
- 집행은 이미 있는 세력·사회 규칙(`makePeace`·`truces`·`declareWar`)과 원장 이체만 쓴다 — NPC 판단이 불가침을 이미 거르므로 동맹·보호의 "서로 치지 않음"이 NPC 쪽에서 바로 듣는다(Verified: 코드 읽기 `npcRun.rivalView` truce).
- 동맹·보호 효과는 D-291(요청·수락·참가자 등록)과 D-255 카드 설명(동맹 = 공동 방어·참전 요청, 보호·속국 = 공물) 안에서 가장 작게 골랐다. 자동 합류·시야·통행·영토 보호는 결정이 없어 넣지 않았다(D-584).

## 결과
- 좋은 점: 플레이어 지도자끼리 조약을 내고 고치고 받는다(가·나). NPC가 이끄는 나라는 바로 답한다. 맺은 조약은 서버가 집행하고 끝(기간·위반·기한)도 서버가 정한다.
- 감수할 점·빈틈: 영토·배상·포로·관세·시야·통행 카드 없음(2551), 위반한 쪽·신뢰·제재 명분 없음(2558), 관계 점수 체계가 없어 참전 거절 벌칙 없음(2556), 해지·갱신 없음(2557), NPC 먼저 제안 없음(2553),
