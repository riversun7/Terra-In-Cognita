# 반응형 화면 틀 밀도 개편: 슬림 상단·사이드·플랫 하단바, 컬러 시그니처 아이콘, 다채널 채팅 도크

- 상태: 확정
- 날짜: 2026-11-24
- 관련: `docs/PLAN.md` 4.2·4.8·9.8장, `docs/adr/2026-10-28-design-system.md`, `docs/adr/2026-10-29-app-shell.md`, `docs/adr/2026-11-01-ui-visibility.md`, `docs/adr/2026-11-21-tap-target-relax.md`, 기획 `docs/design/02_Decision_Log.md`(D-265, D-480, D-6004~D-6010, D-6046)

## 배경
- 사용자 요청(2026-11-24): 모바일 전략 게임 화면 예시(STARFORGE)를 기준으로 모바일 UI의 상단바·사이드 메뉴·하단 탭 크기, 글자 크기와 정보 배치를 한층 촘촘하고 세련되게 개편하고, 다채널 채팅바를 넣으며, 태블릿·PC 화면과 2차맵(`/map`) 화면도 함께 확장·정돈한다.
- 기존 앱 틀(`2026-10-29-app-shell.md`)의 문제(**Verified**: `tokens.css`·`shell.css`·`tabbar.css`):
  - 위 띠 `56px` + 하단 탭 `64px` + 가운데 지도 돌출 원 `24px`(`88px`)이 스마트폰 세로 화면을 과하게 가렸고, 본문 기본 글자(`15px`)와 조작부(`40px`)가 커서 한 화면에 들어오는 전략 지표가 적었다.
  - 모바일 `☰` 서랍이 왼쪽에서 화면 대부분(`min(280px, 85vw)`)을 덮어 한 손으로 오른쪽 위 `☰`를 눌러 빠르게 여닫기 불편했다.
  - 단색 선 아이콘만 써서 좁은 하단 탭·사이드 메뉴에서 메뉴 성격을 한눈에 구분하기 어려웠다.
  - 다채널 채팅(기획 D-480 시장·장소·세력·파티, D-6046 번역 단추)을 놓을 반응형 자리가 앱 틀과 2차맵 HUD에 아직 없었다.

## 선택지
1. 하단 탭 모양: 기존 `64px` + 가운데 돌출 원(`88px`) 유지 / 돌출 없는 `48px` 슬림 플랫 바 + 상단 활성 표시선
2. 모바일 `☰` 메뉴 위치: 왼쪽 전체 높이 서랍 / 오른쪽 위 `☰` 단추 바로 아래에 뜨는 컴팩트 드롭다운(`216px`)
3. 다채널 채팅 배치: 별도 전체 화면으로만 분리 / 모바일·2차맵은 하단 탭 바로 위 `30px` 1줄 바(누르면 시트 펼침), 태블릿은 하단 인라인 바, PC는 우측 `280px` 고정 열

## 결정
1. **컴팩트 타이포그래피·조작부·틀 치수**(`apps/game/src/styles/tokens.css`)
   - 글자 크기: `11 / 12 / 13.5(본문) / 15 / 17 / 20 / 24px`, 탭·보조 라벨 `--tab-label-size: 10.5px`(`0.65625rem`). 입력칸 글자(`--font-size-input`)는 iOS 자동 확대를 막으려 `max(16px, 0.875rem)`을 유지한다.
   - 조작부·틀 크기: `--control-h: 34px`, `--control-h-sm: 28px`, `--tap-size: 32px`(`--tap-min: 24px` 유지), `--topbar-h: 40px`, `--status-strip-h: 36px`, `--tabbar-h: 48px`, `--rail-w: 64px`, `--sidebar-w: 216px`, `--chatbar-h: 30px`, `--chat-dock-w: 280px`.
2. **상단 상태 요약 띠(`StatusStrip.tsx`)와 옆 슬라이드 서랍 · 지도 가로 분할**
   - 일반 게임 화면(`!devSurface`)의 `40px` 위 띠 바로 아래에 자금·물자·유닛·시설·알림 5열 요약 띠를 지연 조각(`React.lazy`)으로 그린다. 모바일은 5열 핵심 숫자만, 태블릿·PC(`≥ 37.5em`)는 가로 한 줄에 통화 단위·가동 분모를 함께 편다.
   - 위 띠와 사이드바 머리는 원래 게임 로고(`/favicon.svg`)와 전체 제목(`TERRA IN-COGNITA`)을 함께 쓴다.
   - 모바일(`narrow`)에서는 `☰` 단추를 위 띠 오른쪽 끝에 두고, 누르면 기존처럼 전체 높이 사이드 서랍(`<dialog class="frame-drawer">`)이 오른쪽에서 옆으로 슬라이드 인(`translateX(100%) → 0`)한다. 태블릿(`medium`)은 `64px` 접이식 레일, PC(`wide`)는 `216px` 고정 사이드바를 쓴다.
   - 사이드바와 모바일 서랍의 지도 항목은 `2차맵 | 1차맵`을 한 줄에 가로 2분할(`.side-split`)로 배치해 세로 줄 수를 줄인다.
3. **슬림 플랫 `48px` 하단 탭과 메뉴별 컬러 이미지 아이콘(`SignatureIcon.tsx` · `public/icons/nav/*.png`)**
   - 배치 C·A 모두 위로 솟는 원형 단추 없이 균일한 `48px` 플랫 바로 통일하고, 현재 화면은 상단 `2px` 주색 표시선과 은은한 세로 빛 번짐으로 나타낸다.
   - 탭 칸 최소 폭을 `3.375em`(`54px`), 가운데 지도 칸을 `3.5em`(`56px`)으로 줄여 `380px` 이상 표준 스마트폰(`390px` 등)에서 배치 C 5칸(+지도=6탭), `432px` 이상에서 6칸(+지도=7탭)이 한 줄에 들어간다.
   - 홈·2차맵·1차맵·유닛·경제·세력·사이보그·인벤토리·도시·주변·처리함·우편·편집·설정·개발·관리·운영·로그아웃·채팅·자금·시설 21종에 항목별 고유 색·실루엣을 가진 96×96 투명 PNG 게임 아이콘(`apps/game/public/icons/nav/*.png`)을 적용해 다크·라이트·개발 네온 테마 어디서나 즉시 구분되게 한다. 2차맵 하단 내비게이션(`MapBottomNav.tsx`)도 같은 `48px` 플랫 바·이미지 아이콘 규격을 함께 쓴다.
4. **반응형 다채널 채팅 도크(`ChatDock.tsx` · `chatStore.ts`)**
   - 기획 D-480의 4개 기본 채널(`시장` · `장소` · `세력` · `파티`)과 외국어 메시지 `[번역]` 토글(D-6046 미리 보기)을 갖춘 프론트엔드 채팅 UI를 앱 틀(`variant="shell"`)과 2차맵(`variant="map"`)에 넣는다(실시간 WebSocket 서버 연동 전까지 `[UI 시안]` 배지를 표시한다).
   - 모바일(`< 37.5em`)과 2차맵(`< 64em`)은 하단 탭 바로 위에 `30px` 1줄 바로 붙고 누르면 채널 시트가 펼쳐진다. 태블릿(`37.5em~63.99em`) 앱 틀은 하단 인라인 입력 바, PC(`≥ 64em`) 앱 틀은 `.frame` 격자의 우측 `280px` 고정 열(`aside`, 접기 가능), 2차맵 데스크톱은 우하단 컴팩트 도크로 동작한다.
   - 개발·관리자 화면(`devSurface`)에서는 상단 상태 요약 띠와 채팅 도크를 숨긴다.
5. **테마 유지 및 다크 팔레트 정돈**
   - 기본 테마(`DEFAULT_THEME = "pastel"`)는 바꾸지 않는다. `dark` 테마는 심우주 슬레이트 네이비(`#070d14` 바탕, `#0d1622` 표면, `#26e0b8` 청록 강조)로 대비와 시인성을 높인다.

## 이유
- `40px` 상단바 + `36px` 상태 띠 + `30px` 1줄 채팅바 + `48px` 플랫 하단바를 합쳐도 옛 위아래 고정 영역(`56px + 88px = 144px`)과 비슷하면서, 실시간 자산·유닛 지표와 다채널 채팅 한 줄이 추가로 상시 노출된다(**Verified**: `tokens.css`·`layout.test.ts`).
- `StatusStrip`을 지연 조각으로 분리해 첫 화면 묶음에 `@trpc/client`·`net/api.ts`가 정적으로 섞이지 않는다(**Verified**: `firstScreen.test.ts`·`check-bundle.mjs` 규칙).
- 모든 테마(게임 4종 + 개발 2종)의 WCAG 대비 검사와 화면 CSS 원시 색·`px` 금지 규칙을 그대로 통과한다(**Verified**: `check-contrast.mjs`).

## 결과
- 모바일·태블릿·PC 앱 틀과 2차맵(`/map`)이 같은 밀도·아이콘·채팅 체계를 공유한다.
- 실시간 채팅 서버 프로토콜(WebSocket 채널 구독·전송·스팸 제한·자동 번역 API)을 붙일 때 `chatStore.ts`의 메모리 상태만 서버 스트림으로 교체하면 화면 배치는 그대로 쓸 수 있다.
