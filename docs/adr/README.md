# ADR (Architecture Decision Records)

결정 하나당 파일 하나. 파일명: `YYYY-MM-DD-<영문-슬러그>.md`.

규칙:
- 상태: `제안` → `확정` → (필요 시) `대체됨: <새 ADR 파일명>`.
- 확정된 ADR은 본문을 고치지 않는다. 바꾸려면 새 ADR을 쓰고, 옛 ADR의 상태만 `대체됨`으로 바꾼다.
- 새 런타임 의존성을 추가할 때도 ADR을 쓴다.

## 템플릿

```markdown
# <제목>

- 상태: 확정 | 제안 | 대체됨: <파일명>
- 날짜: YYYY-MM-DD
- 관련: docs/PLAN.md <절>, <다른 ADR>

## 배경
무엇이 문제였고 왜 지금 정해야 하는가.

## 선택지
1. ...
2. ...

## 결정
무엇으로 정했는가.

## 이유
왜 그 선택인가. 확인한 사실은 Verified, 추정은 Assumed로 표시하고 출처를 적는다.

## 결과
이 결정으로 생기는 일(좋은 점, 감수할 점, 나중에 다시 볼 조건).
```
