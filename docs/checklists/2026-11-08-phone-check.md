# 휴대폰 확인표 (ADR 8개, 2026-11-08)

사용자가 휴대폰으로 직접 보고 확정할 ADR 8개의 확인 항목이다. 항목은 각 ADR의 확정 조건·다시 볼 조건·측정 항목과 지금 앱 주소에서 뽑았다.

읽는 법
- `<NAS 게임 주소>` 자리에 평소 여는 게임 주소를 넣는다. 관리자 계정으로 들어간다(개발자 화면은 관리자·개발자 계정만 열린다).
- 지도 화면의 숫자는 왼쪽 위 작은 글씨 판에 늘 나온다(따로 켜는 주소는 없다). "60 fps · p95 16ms"처럼 보인다. p95는 느린 프레임 쪽 시간이라 작을수록 좋다.
- 숫자를 읽는 항목은 그 화면을 캡처해서 보내 주면 된다. 서버도 기기 성능 기록을 따로 모은다.
- 중가 안드로이드폰이 따로 있으면 같은 항목을 한 번 더 본다(기준 기기가 사용자 휴대폰과 중가폰 둘이다).

## 1. S1 2차맵 (`2026-10-28-s1-second-map.md`)
- [ ] 와이파이를 끄고(4G) 홈 → 아래 가운데 [지도] → 2차맵이 3초 안에 뜨면 통과. 판의 "준비 Nms"도 적는다.
- [ ] 지도에서 [뒤로] → 다시 [지도] → 1초 안에 다시 뜨면 통과.
- [ ] `https://<NAS 게임 주소>/map?key=312905547382793` → [운영자 모드] 켬 → 봇 1,000개가 걷는 시험 2차맵이 보임 → 20분 켜 둔 뒤 판의 "p95 Nms"가 33 이하이면 통과(판의 "유닛 N"도 함께 캡처).
- [ ] 같은 주소 끝에 `&pixel-ratio=1.5`를 붙여 열고 p95를 한 번 더 적는다(선명도 기본값 2와 견줌).
- [ ] 다른 앱으로 갔다가 돌아옴 → 지도가 다시 움직이기까지 걸린 느낌(초)을 적는다.

## 2. 앱 뼈대 (`2026-10-29-app-shell.md`)
- [ ] `https://<NAS 게임 주소>/` → 로그인 → 홈(카드 화면)이 보이면 통과.
- [ ] 아래 탭(홈·유닛·[지도]·경제·세력)을 차례로 누름 → 누른 화면이 열리고 그 탭이 강조되면 통과.
- [ ] 홈 → [유닛] → 휴대폰 뒤로 버튼 → 홈으로 돌아오면 통과. 한 번 더 뒤로 → 앱을 나가면 정상.
- [ ] 위 띠 [☰] → 메뉴 서랍이 열림 → 뒤로 버튼 → 서랍만 닫히고 화면은 그대로면 통과. 서랍에서 [경제]를 누르면 경제가 열리고 서랍이 닫혀야 한다.
- [ ] 홈 아닌 화면에서 새로고침 → 같은 화면에 남으면 통과. 홈이 1초 안에 뜨는지도 느낌으로 적는다(이 화면은 숫자 판이 없다).

## 3. 행성 편집기 1단계 (`2026-10-29-planet-editor-stage1.md`)
- [ ] `https://<NAS 게임 주소>/dev/planet-editor` → 지구본 미리보기가 뜸 → 위 상태 줄 "F7 N초"의 N이 3 이하이면 통과.
- [ ] [설정] 탭 → 프리셋 하나(예: 기온 [더움])를 누름 → 지구본이 하얗게 비는 시간이 거의 없이(0.2초 안) 새 모습으로 바뀌면 통과.
- [ ] [행성] 탭 → [새 행성] → 시작할 행성 고르고 [만들기] → [저장] → "저장됨 · 판 1"이 보이면 통과. PC에서 같은 주소를 열어 같은 행성이 목록에 있으면 더 좋다.
- [ ] 지구본에서 칸 하나를 누름 → [칸] 탭 → [2차맵 미리보기] → 2차맵 그림이 뜨면 통과(처음 한 번은 오래 걸린다).

## 4. 1차맵 하늘 (`2026-10-29-primary-map-sky.md`)
- [ ] `https://<NAS 게임 주소>/map/planet` → 지구본에 낮·밤 경계, 구름이 보이면 통과(달은 가끔만 보인다).
- [ ] 같은 화면의 "N fps · p95 Nms"를 적는다 → `https://<NAS 게임 주소>/map/planet?planet-sky=off`(하늘 끔)로 열어 같은 숫자를 적는다 → 하늘 켬이 114 fps 이상이고 p95 차이가 0.2ms 안이면 통과(120Hz 휴대폰 기준. 60Hz 중가폰은 p95 33 이하).
- [ ] `…/map/planet?pixel-ratio=1.5` 와 `…/map/planet?planet-sky=off&pixel-ratio=1.5` 로 한 번씩 더 적는다(선명도 기본값 2와 견줌).
- [ ] 두 번 눌러 가장 가까이 간 뒤 밤이 일하기에 너무 어둡지 않은지, 구름이 너무 안 움직이는지 의견을 적는다.
- [ ] (선택) `https://<NAS 게임 주소>/map/planet?planet-sky-bench=1` 과 `…?planet-sky-bench=1&planet-sky=off` → 판의 "GPU Nms" 차이가 2ms 이하이면 통과.

## 5. S2 행성 LOD (`2026-10-29-s2-planet-lod.md`)
- [ ] 와이파이를 끄고(4G) `https://<NAS 게임 주소>/map/planet` → 판의 "첫 표시 Nms"가 3000 이하이면 통과. 누른 때부터 뜰 때까지 걸린 느낌(초)도 적는다.
- [ ] 손가락으로 돌리고 확대하는 동안 판의 "p95 Nms"가 33 이하이면 통과.
- [ ] 판의 "타일 a/b"에서 a가 b를 넘지 않으면 통과.
- [ ] `https://<NAS 게임 주소>/map/planet?planet-debug=cracks` → 두 번 눌러 가까이 간 뒤 둘레를 돌려 봄 → 땅 사이로 자홍색 점(틈)이 안 보이면 통과.
- [ ] (선택, 셰이더 방식 고르기용) `https://<NAS 게임 주소>/dev/gpu-bench` → [측정 시작] → 끝나면 [복사]한 글을 개발 세션에 붙여 넣는다.

## 6. 대륙 모양 (`2026-10-31-continent-layouts.md`)
2026-10-31에 "대륙모양 이정도면 오케이"라고 답했다. 이번에는 휴대폰에서 한 번 더 보고 닫는다.
- [ ] `https://<NAS 게임 주소>/dev/planet-editor` → [설정] 탭 → 대륙 모양 [초대륙] → 큰 땅 하나(초승달 모양)가 보이면 통과.
- [ ] [대륙 몇 개] → 큰 대륙 2~4개와 섬이 보임 → 아래 [대륙 수]를 1이나 2로 옮기고 [적용] → 큰 땅 수가 그만큼이면 통과.
- [ ] [여러 대륙·군도]는 중간 대륙 여럿·섬 많이, [한쪽 반구]는 땅이 한쪽에 몰려 보이면 통과.
- [ ] 보기 방식 [평면]으로 바꿔 전체를 보고, 초대륙의 사막(갈색)이 너무 넓지 않은지, 반구 몰림이 충분한지 의견을 적는다.

## 7. 항성계 편집기 (`2026-10-31-star-system-editor.md`)
행성 편집기 보관함에 저장한 행성이 하나 이상 있어야 한다(3번 확인을 먼저 한다).
- [ ] `https://<NAS 게임 주소>/dev/star-system` → [새 항성계] → [만들기] → 항성 종류 고르기 → [궤도 더하기] → 천체 목록에서 행성 편집기에서 만든 그 행성 이름 고르기 → 그림에 점이 생기면 통과.
- [ ] 궤도 거리(AU)를 0.7과 2로 바꿔 봄 → 점 색이 초록 띠 안·밖에 따라 바뀌고 카드의 "제안 기온"이 바뀌면 통과.
- [ ] [저장] → "저장됨 · 판 1"이 보이면 통과. PC에서 같은 항성계가 목록에 보이면 더 좋다.
- [ ] 행성 점을 누름 → 카드 [제안 적용] → 확인 창 [행성 편집기에서 열기] → 행성 편집기의 적도·극 기온이 카드의 제안 값과 같으면 통과.

## 8. 첫 접속 사이보그 만들기 (`2026-11-01-first-login-cyborg.md`)
사이보그가 없는 새 계정이 있어야 한다. 로그인 화면에서 새 아이디를 넣고 [가입]을 누른다. "지금은 새 아이디를 만들 수 없습니다"가 뜨면 GitHub Actions `account-admin`으로 시험 계정을 만든다.
- [ ] 새 계정으로 `https://<NAS 게임 주소>/` → "사이보그 만들기" 화면으로 바로 넘어가면 통과.
- [ ] 이름 → 외형([무작위]도 눌러 봄) → 초기 스탯([굴리기], [다시 굴리기 (N번 남음)]의 숫자가 줄어듦) → 속성 → 세력 → 시작 도시 → 강하, 7단계가 끊김 없이 넘어가면 통과.
- [ ] 초기 스탯 단계에서 새로고침 → 남은 다시 굴리기 횟수가 되돌아가지 않으면 통과.
- [ ] [강하] → 홈으로 옴 → [지도] → 2차맵이 까맣지 않고 내 사이보그가 보이면 통과. 위 띠 얼굴도 고른 외형이어야 한다.
- 지금은 세력·도시가 적어 세력·도시 단계가 비어 보일 수 있다(ADR이 알고 있는 점).
