> 이 문서가 새 기획서(GDD v4)의 정본이다. 본문 문서와 충돌하면 이 문서를 따른다.
> 결정을 바꿀 때는 기존 항목을 지우지 않는다. 새 ID를 만들고 `대체: D-00X`로 표기한다.

## D-005
- **날짜**: 2026-10-27
- **단계**: Step 1-1
- **결정 (사용자 원문 요지)**: **높은 자유도.** 원하는 대로 모두 플레이할 수 있다.
  - **육성은 모든 플레이의 공통 요소**다.
  - 핵심 콘텐츠는 다음과 같다.
    - 힘과 군사력으로 **영토 확장**
    - 다양한 크리쳐를 포획해 **유전자 교배로 강력한 크리쳐 만들기**
    - **경제 강국** 만들기
    - **높은 기술력** 만들기
    - "등등"으로 열어 둔 추가 경로가 있다.
  - 각 핵심 콘텐츠는 모두 중요하다.
- **해석 (Step 1-2에서 확인 필요)**
  - 플레이어 판타지를 하나로 좁히지 않는다. 여러 **성장 경로(Path)** 중 원하는 길을 고르고 섞을 수 있는 샌드박스다.
  - 미결 1: 한 캐릭터가 모든 경로를 동시에 최상위로 키울 수 있는가? 기존 기둥 3번(분업·반독점)과의 관계가 여기에 걸려 있다.
  - 미결 2: "등등"에 해당하는 추가 경로 목록.
- **기각한 대안**: 단일 판타지 3안(개척 사령관 / 모험가 / 경영자).
- **영향**
  - 경로마다 독립적인 핵심 콘텐츠 깊이가 필요하다. 1인 개발(D-003)에서 **범위 위험이 가장 큰 요인**이다.
  - 그래서 MVP에서 경로를 어떤 순서로 열지 Step 8에서 반드시 정해야 한다.
  - 기존 다원화 랭킹(장인/거상/브리더/개척자/투사)과 연결된다. (출처: 기존 Consolidated_GDD Step 1 §3)

    - 늦게 합류한 유저의 진입 경로: NPC 영토 획득 또는 월드 확장
  - 단일 서버의 동시 수용 한계는 미확인(Unknown)이다. Step 8에서 기술 검토한다.

## D-007
- **날짜**: 2026-10-27
- **단계**: Step 1-1
- **결정 (사용자 원문 요지)**: **월드는 영구**다. **인플레이션 방지가 매우 중요**하다.
  - 채집한 자원을 정제, 가공, 생산하면서 생기는 **소실량은 월드로 회귀**한다.
  - 아이템을 사용하면 **내구도가 감소**하고, 강화 등으로 **파괴**되면 그 양도 **회귀**한다.
  - **회귀된 양만큼 채집 가능량이 증가**한다.
  - 이 구조를 "자원 보존 순환" 원칙으로 부른다.
  - → D-112로 일부 수정 (2026-10-28): 총량 보존은 화폐 가치가 걸린 총량 자원(금·은·다이아몬드·에너지 자원 등)에만 적용한다. 일반 자원은 총량 제한 없이 다시 자란다.
- **기각한 대안**
  - 영구 거점 + 시즌 원정 행성
  - 전체 시즌제
- **영향과 미결 사항** (Step 4 경제·생산에서 결정)
  1. 화폐에도 보존 순환을 적용할지
  2. 사재기 시 채집 가능량이 고갈되어 신규 유저가 불리해지는 문제의 대응책
  3. 유저 수가 늘어나면 1인당 자원이 줄어드는 문제. 월드 총량 확장 규칙이 필요한지
  4. 회귀한 양이 어느 지역·노드로 돌아가는지, 얼마 뒤에 돌아가는지
- ♻️ 재사용 후보
  - 기존 ECO-1 축4의 "금·은 월드 총매장량 고정, 소비 시 매장량 회귀" 아이디어를 전체 자원으로 일반화한 것이다.
  - 기존 제련 수율(30%)과 주조 손실(10%)은 회귀량을 만드는 장치로 재활용할 수 있다.

## D-010
- **날짜**: 2026-10-27
- **단계**: Step 1-2
- **결정**: 핵심 타겟은 **직장인 코어 게이머**다.
  - 20~40대이며 전략, 시뮬레이션, 수집 장르를 해 본 사람이다.
  - 평일: 하루 2~3회, 10~20분. 모바일로 정산과 지시를 한다.
  - 주말 또는 주 1~2회: 1~2시간. PC로 전투, 전쟁, 경영을 한다.
- **근거**
  - 기존 기둥 1번(비동기 자율 생태계 + 짧은 밀도의 액티브 플레이)과 일치한다.
  - D-004(PC 메인 + 모바일 보조)와도 일치한다.
- **기각한 대안**
  - 하드코어 샌드박스 유저: 콘텐츠 소모가 빨라 1인 개발에 부담이 크다.
  - 라이트 캐주얼: 깊은 경제·전쟁 시스템과 충돌한다.
- **영향**
  - **장시간 접속하지 않아도 불리하지 않아야 한다.** 이것이 설계 원칙이 된다.
    - 오프라인 보호
    - 자율 유닛
    - 예약 명령
  - 실시간 동시 접속을 강제하는 콘텐츠(예: 정해진 시각의 전쟁)는 최소화하거나 예고제로 운영해야 한다.

## D-011
- **날짜**: 2026-10-27
- **단계**: Step 1-2
- **결정**: 성장 경로 카탈로그는 **6대 영역, 18개 경로**로 확정한다.
  - ✅ 표시는 사용자가 제시한 경로, 💡 표시는 기획 제안을 채택한 경로다.

  | 영역 | 경로 | 핵심 행위 |
  |---|---|---|
  | ⚔️ 무력 | ✅ 정복자 | 군대 편성, 영토 확장, 공성 |
  | | 💡 용병·투사 | 영토 없이 전투로 성장한다. 의뢰, 현상금, 던전, 투기장 |
  | | 💡 무법자 | 밀수, 분쟁지대 상단 습격 |
  | | 💡 현상금 사냥꾼 | 무법자를 추적하고 체포한다. 무법자와 짝을 이루는 경로다 |
  | 🧬 생명 | ✅ 브리더 | 크리쳐 포획, 유전자 교배, 혈통 관리, 크리쳐 판매 |
  | | 💡 유전공학자 | 휴먼 혈통 개량, 수명 연장, 유전자 시술 |
  | 💰 부 | ✅ 무역상 | 지역 시세차 교역, 세력 간 대외경제와 관세 |
  | | ✅ 기업가·투자가 | 회사 설립, 시설 지분, 상장과 투자 |
  | | 💡 운송업자 | 정기 노선 개설·운영, 호위 계약, 도로·항로 건설 |
  | | 💡 대지주 | 농장·광산·목장을 대규모로 경영한다. 원자재 공급원이다 |
  | 🔬 기술 | ✅ 연구자 | 테크트리 해금, 기술 라이선스 판매 |
  | | ✅ 장인 | 명품 장비 제작, 제작자 서명 브랜드 |
  | | 💡 공학자 | 안드로이드 제작, 사이보그 개조 |
  | 🧭 개척 | ✅ 탐험가 | 최초 발견, 지도 제작·판매, 정착 후보지 발굴 |
  | | 💡 고고학자 | 유적 발굴, 고대 기술품 해독, 세계 미스터리 해금 |
  | 🏛️ 영향력 | ✅ 정치가 | 동맹·연방, NPC 세력 관계 조종, 선거·의회 |
  | | 💡 성직자 | 가상 교단 창시·포교, 환생 의식 집전. 실존 종교는 배제한다 |
  | | 💡 명소 경영자 | 맛집 식당, 호텔·사우나, 명의 병원 (코지 허브) |

- **근거**

  - 세금은 기존 7종(거래세, 재산세, 소득세, 관세, 입장세, 토지세, 전쟁세)을 바탕으로 다양하게 둔다.
  - 세율은 정부(도시·세력의 통치자)가 정한다.
  - 세율이 높으면 유닛의 만족도 같은 수치가 나빠진다.
  - 만족도가 크게 떨어지면 시민 반란군 같은 것이 생길 수 있다 (D-105의 반란·독립과 이어진다).

- **해석** (정정 가능)
  - 시스템 세율 상한은 두지 않는다. 높은 세율의 대가는 만족도와 반란으로 돌아온다.
  - 필지 세금(D-111)은 재산세·토지세에 들어간다.
- **근거**: 세금이 정치 콘텐츠가 된다. 세율이 너무 높으면 세수가 오히려 줄어든다 (기존 ECO-6의 래퍼 곡선 설명).
- **기각한 대안**
  - 핵심 3종으로 단순화
  - 7종 + 시스템 세율 상한
- **영향**
  - 만족도의 정의와 반란 조건은 Step 4-6에서 정한다 (D-105, D-110의 치안·만족도).
  - 세금은 세력 화폐로 낸다 (D-124). 화폐 발행 제도(Step 4-4 다음 결정)와 이어진다.
  - NPC 세력의 세율은 세력 AI가 정한다 (P0, Step 4-6).
  - 탈세와 밀수는 무법자 경로의 콘텐츠다. 기존 기획: 거래소·상점의 정규 거래는 자동으로 징수해 탈세할 수 없다 (ECO-6 "탈세 메커닉").

## D-131
- **날짜**: 2026-10-28
- **단계**: Step 4-4
- **사용자 요청 (원문)**: "경제시스템의 중요한 시작. 금본위제를 하여 발행량을 한정할수있으나 초기 세력창설에 필요한 금확보가 어려움 은 본위제는 조금 나을 수 있으나 역시 진입장벽이 있진 않을지? 동본위제까지 가는건 어떤지? 자유발행은 시스템 문제가 심해질 수 있으나 추후 금본위제를 폐지하는 등의 경우 어떻게 해야할지? 실제 경제학에 따라 현재 게임에 적합한 통화발행 시스템을 제시해라"
- **결정**: 세력 화폐는 **단계형 통화 제도**로 발행한다 (기획자 제안, 사용자 선택).

  | 단계 | 화폐 | 발행 한도 | 진입 장벽 | 위험 |
  |---|---|---|---|---|
  | 0. 빌려 쓰기 | 다른 세력 화폐나 금·은을 그대로 쓴다 | 발행하지 않는다 | 없음 | 남의 통화 정책에 끌려간다 |
  | 1. 주화 | 구리·은·금 주화를 찍는다 | 가진 금속만큼 | 낮음 | 무겁고 금속값에 묶인다 |
  | 2. 준비금 지폐 | 세력 지폐 | 준비자산 시가 × 배수 | 중간 | 교환 요구가 몰리는 뱅크런, 투기 공격 |
  | 3. 신용 통화 | 세력 지폐 (금으로 바꿔 주지 않음) | 세력이 정한다 | 신뢰 | 인플레이션 → 만족도 하락 → 반란 |

  - 단계는 세력이 고르고, 앞으로도 뒤로도 옮길 수 있다.
  - **준비자산은 묶음이다**: 금·은·다이아몬드·희귀 광물·다른 세력 화폐를 거래소 시세로 평가한다. 금속끼리 고정 비율을 두지 않는다 (그레셤 법칙 회피).
  - **구리는 주화로만 쓴다**: 구리는 총량 제한이 없는 일반 자원(D-112)이라 준비자산이 되면 사실상 무한 발행이 된다. 주화로만 쓰면 값이 채굴 노동에 묶인다.
  - **세금은 그 세력 화폐로만 받는다**: 그 화폐를 찾는 수요가 생긴다.
  - **남발하면 시장이 벌한다**: 환율(D-125)이 떨어지고 사람들은 금·은·다른 화폐로 갈아탄다. 그 화폐로 급여를 받는 휴먼·NPC의 만족도가 떨어져 반란·이주가 생긴다 (D-128과 같은 경로).
  - **금본위 폐지(닉슨 쇼크)**: 폐지 선언 → 유예 기간 → 교환 중지. 유예 중에는 뱅크런이 날 수 있다. 준비자산은 국고에 남고 환율은 자유 변동한다. 다시 돌아가려면 준비금을 다시 쌓는다. 기존 규칙(국민투표 2/3 또는 지도자 직권, 7일 유예, 전환 직후 3일간 환전 수수료 2배)을 쓴다 (♻️ ECO-1 축1).
  - **실패 처리**: 디노미네이션, 땅(필지, D-111)이나 준비자산을 담보로 한 새 화폐, 화폐 폐지 후 0단계로 복귀
  - **게임 보호 장치**: 발행은 정해진 통로(국고 지출, 대출, 준비자산 매입)로만 하고 모두 원장에 남긴다. 하루 발행 상한을 둔다. 관리자 감시(D-113)에 세력별 통화량을 넣는다. 기본 NPC 국가는 공식대로 움직이는 중앙은행(테일러 준칙)으로 운영해 기준 통화 역할을 한다 (P0).
- **근거** (Verified: 서브에이전트가 검색 엔진 요약으로 확인. 원문 페이지는 네트워크 정책으로 열지 못함)
  - 그레셤 법칙: 1558년 그레셤이 설명하고 1857~58년 Macleod가 이름 붙였다 (https://www.britannica.com/money/Greshams-law)
  - 티에르 법칙: 변동 환율의 고인플레이션에서는 양화가 악화를 구축한다. Bernholz가 이름 붙였다 (https://ideas.repec.org/a/bla/perwir/v6y2005i2p131-150.html, 2005)
  - 미국 복본위제: 1792년 15:1, 1834년 약 16:1로 바꾸자 은화가 빠져나갔고, 1873년 은의 자유 주조를 끝냈다 (https://www.encyclopedia.com/social-sciences-and-law/economics-business-and-labor/money-banking-and-investment/bimetallism)
  - 고전 금본위제: 1870년대~1914년 (https://www.gold.org/history-gold/the-classical-gold-standard)
  - 닉슨 쇼크: 1971년 8월 15일 달러의 금 교환을 정지했다. 금 1온스 35달러는 1934년부터다 (https://history.state.gov/milestones/1969-1976/nixon-shock)
  - 홍콩 연계환율제(통화위원회): 1983년 10월 17일 시행, 2005년부터 7.75~7.85 (https://www.hkma.gov.hk/eng/key-functions/money/linked-exchange-rate-system/milestones-of-monetary-reform/)
  - 렌텐마르크: 1923년 11월 15일 발행, 1 렌텐마르크 = 1조 마르크, 토지·산업 자산 담보 (https://www.britannica.com/topic/Rentenmark)
  - 표권설: Knapp(1905)은 국가가 공공 수납처(세금 포함)에서 받아 주는 것을 국가 화폐로 보았다. "세금이 화폐 가치를 받친다"는 후대 차탈리즘·MMT의 해석이다 (https://historyofeconomicthought.mcmaster.ca/knapp/StateTheoryMoney.pdf, 1905 독일어, 1924 영역)
  - 경쟁 화폐: Hayek, 화폐의 탈국가화 (1976) (https://iea.org.uk/publications/denationalisation-of-money)
  - 달러화: 에콰도르 2000년, 엘살바도르 2001년 (https://www.fedinprint.org/item/fedaer/30412, 2006)
  - 디노미네이션: 터키 2005년 100만 리라 → 1 신리라 (https://www3.tcmb.gov.tr/ytlkampanya/ytlsitedokuman/tcmb/5228ING.htm), 짐바브웨 2006·2008·2009년 (https://www.cato.org/sites/cato.org/files/serials/files/cato-journal/2009/5/cj29n2-8.pdf, 2009)
  - 테일러 준칙: 1992년 발표, 1993년 출판 (https://www.kansascityfed.org/documents/540/pdf-rwp10-05.pdf)
  - 투기 공격: 1992년 9월 16일 검은 수요일, 영국 ERM 탈퇴 (https://niesr.ac.uk/blog/six-lessons-black-wednesday-todays-central-bankers, 2022)
- **기각한 대안**
  - 준비금 지폐까지만 (신용 통화 없음)
  - 처음부터 신용 통화 + 규칙 상한
- **영향**
  - D-124의 세력별 화폐를 구체화한다. 금·은 주화를 만들 때의 주조 손실은 매장량으로 돌아간다 (D-112, 기존 주조 손실 10% ♻️).
  - 투기 공격과 뱅크런은 금융가 경로의 콘텐츠다.
  - 은행·대출은 Step 4-4 다음 질의에서 정한다.
  - 준비금 배수, 유예 기간, 하루 발행 상한, 첫 발행 기준선은 Step 5에서 정한다 (`♻️ 재사용 후보: 기존 초기 발행량 K_mint = 인구 × 1인당 하루 거래액 × 7`).
  - NPC 기본 국가의 중앙은행 공식은 NPC AI 단계(기술 N1)에서 다룬다.
- **기술 전달**
  - 세력 화폐는 정해진 통로로만 발행하고 모두 원장에 남긴다. 하루 발행 상한이 있다.
  - 준비자산은 거래소 시세로 평가한다.
  - 디노미네이션은 통화 단위를 바꾸는 사건이다. 원장의 금액을 한꺼번에 환산하되 최소 단위 정수를 지킨다. 반올림 규칙이 필요하다.

  - **보험은 두지 않는다.** 보험 사기 문제가 있고 규칙이 복잡해진다.
  - 위험에는 **용병을 고용**해 대비한다. 직접 운반의 호위(D-117), 프런티어 방어가 여기에 들어간다.
- **기각한 대안**
  - 기존 운송·건물 보험 + 금융가 운영 (추천안)
  - 운송 보험만
- **영향**
  - 금융가 경로(`20_Core_Loop.md` §7)는 은행·대출·환전이 된다. 보험을 뺀다.
  - 무역상·운송업자와 금융가의 관계 문장("금융가의 보험을 이용한다")과 프런티어 대비 문장("예약 방어와 보험")을 용병·호위로 바꾼다.
  - 용병·투사 경로의 수요가 는다. 고용 계약 방식은 Step 4-5·4-6에서 정한다.
  - 기존 ECO-4의 보험 요율 공식은 쓰지 않는다.

## D-152
- **날짜**: 2026-10-28
- **단계**: Step 4-2 보완 (기술 세션 질문 B5의 나머지)
- **결정 (사용자 원문)**: "마지막 모습/정보. 지도 판매는 좀 애매하다 구현이 복잡해질것같다. 제거하자"
- **정리**
  - 시야 밖의 아는 건물은 **마지막으로 본 모습과 정보**로 보인다. 실제와 다를 수 있다.
  - **지도 판매는 없다.** D-103의 "지도 거래" 기각을 그대로 둔다.
  - 탐험가 경로에서 "지도 제작·판매"를 뺀다. 탐험가는 최초 발견이 중심이다.
- **기각한 대안**
  - 마지막 모습 + 탐사 기록 판매 (추천안)
  - 실시간 + 지도 판매
- **영향**
  - 탐험가 경로의 지표와 수익원은 최초 발견 보상, 정찰·길안내 의뢰(D-036) 쪽으로 다시 본다 (Step 4-6, 기획자 제안).
  - 정보상 경로(정찰·정보 판매)는 지도가 아니라 정보(보고서)를 판다. 지도 판매와 겹치지 않게 Step 4-6에서 정한다 (기획자 제안).
- **기술 전달**: 유저마다 아는 건물의 마지막 관측 상태(모습·정보·관측 시각)를 저장한다. 탐사 기록은 거래하지 않는다.
