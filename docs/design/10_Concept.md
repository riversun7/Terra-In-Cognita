## 2. 한 줄 컨셉 (D-016)

- **외부용 (서사형)**
  > 플레이어가 없어도 역사가 흐르는 미지의 행성. 한 명의 사이보그로 내려앉아 정복자, 상인, 브리더, 학자 중 무엇이든 되어 그 역사에 이름을 새겨라.
- **내부용 (시스템형)**
  > 모든 물질이 순환하는 살아있는 행성에서, 개인에서 국가까지 27개의 길로 성장하는 비동기 샌드박스 전략 RPG. (D-048로 18 → 27 갱신)

※ '사이보그'와 '미지의 행성'은 Step 3(세계관) 확정 후 다듬는다.

## 3. 플레이어 판타지와 정체성

- **고자유도 샌드박스** (D-005)
  - 정해진 주인공 역할이 없다. 27개 성장 경로 중 원하는 길을 고르고 섞는다. (D-048로 18 → 27 갱신)
  - **육성은 모든 길의 공통 기반**이다.
- **개인에서 세력, 세력에서 국가로** (D-009)

  ```
  NPC 세력 소속 개인 (시민·용병)
        │  동료와 자산을 축적한다
        ▼
  ┌─ 독립 세력 창설 ──┐      ┌─ NPC 세력 안에서 출세 ─┐
  └────────┬─────────┘      └──────────┬───────────┘
           ▼                           ▼
                국가 (연방 / 동맹 맹주)
  ```

  - 어느 단계에 머물러도 정식 플레이다. 예를 들어 평생 떠돌이 용병이나 NPC 도시의 명장으로 살 수 있다.
- **모두 가능, 최상위는 선택** (D-008)
  - 모든 경로를 중급까지는 즐길 수 있다.
  - 최상위는 1~2개 경로만 가능하다. 유닛 유지비, 시설 슬롯, 지역 특산물 같은 기회비용이 이를 제한한다.
  - 그래서 최상위 플레이어끼리는 거래하거나 동맹해야 한다.

## 4. 월드 구조

- **단일 서버**와 **다수의 중립 NPC 세력** (D-006)
  - 신규 유저는 NPC 세력을 스타팅 포인트로 고른다.
- **살아있는 월드** (D-006, D-013)
  - 유저가 없어도 NPC 세력이 영토를 나누고, 개척하고, 교역하고, 전쟁한다.
  - 27개 경로의 역할을 모두 NPC도 수행한다. (D-048로 18 → 27 갱신)
- **영구 월드와 자원 보존 순환** (D-007, D-112로 일부 수정)

  ```
  채집 ──▶ 정제·가공 ──▶ 생산품 ──▶ 사용 (내구도 감소) / 강화 실패 (파괴)
   ▲          │ 소실분                          │ 소멸분
   │          ▼                                 ▼
   └────────── 월드 자원 풀로 회귀 ◀─────────────┘
              (회귀한 만큼 채집 가능량 증가)
  ```

  - 무한 발행이 없으므로 인플레이션이 구조적으로 억제된다.
  - → D-112로 일부 수정 (2026-10-28): 위 그림의 총량 보존은 화폐 가치가 걸린 **총량 자원**(금·은·다이아몬드·에너지 자원 등)에만 적용한다. 목재·광물·식재료 같은 **일반 자원**은 티어(T0~T9)별로 있고 총량 제한이 없다. 제작·건축·유지보수로 빨리 소비되고, 채집한 자리에서 다시 자란다.
  - 미결 사항(화폐 적용, 사재기, 인구 증가, 회귀 위치)은 D-112·D-113·D-116에서 정했다. 총량 자원의 총량은 행성마다 고정이고, 남은 매장량이 적을수록 채굴량이 급격히 준다. 도시 화폐는 Step 4-4에서 정한다.

## 5. 성장 경로 카탈로그 — 7대 영역, 27개 경로 (D-048, D-011 대체)

> **정본은 [20_Core_Loop.md](20_Core_Loop.md) §7이다.** 여기에는 요약만 둔다.

| 영역 | 경로 |
|---|---|
| ⚔️ 무력 | 정복자, 용병·투사, 무법자, 현상금 사냥꾼 |
| 🧬 생명 | 브리더, 유전공학자, 사냥꾼 |
| 💰 부 | 무역상, 기업가·투자가, 운송업자, 대지주, 금융가 |
| 🔬 기술 | 연구자, 장인, 공학자, 건축가, 연금술사 |
| 🧭 개척 | 탐험가, 고고학자, 정보상 |
| 🏛️ 영향력 | 정치가, 신관, 교육자, 예술가 |
| 🏡 생활 | 셰프, 호텔리어, 의사 |

### 5.1 경로 설계 원칙 (D-012)

- 경로는 아래 **공통 시스템 9개 위에서 맡는 역할**이다 (D-046에서 ⑨ 생활 추가). 경로 전용 미니게임이나 독립 시스템은 만들지 않는다.

  ```
  공통 시스템: ① 육성 ② 전투 ③ 생산·제작 ④ 시장·물류 ⑤ 세력·영토 ⑥ 탐험·맵 ⑦ 연구 ⑧ 사회(외교·신앙·명성) ⑨ 생활(의식주·회복)
  경로       = 공통 시스템 조합 + 전용 핵심 행위 1~2개 + 랭킹·칭호
  ```

### 5.2 역할 NPC 대체 원칙 (D-013)

- 모든 경로를 NPC도 수행한다. 유저가 없어도 각 경로의 생태계가 돌아간다.
- NPC는 유저와 같은 규칙을 따른다. 특혜 금지 원칙의 정확한 정의는 Step 4에서 정한다.

### 5.3 경로 간 상호의존 예시

| 경로 | 다른 경로와의 관계 |
|---|---|
| 정복자 | 장인(장비), 브리더(전투 크리쳐), 셰프·호텔리어·의사(회복), 운송업자(보급), 연구자(군사 기술)가 필요하다 |
| 무역상 | 운송업자의 노선을 이용한다 |
| 운송업자 | 노선이 무법자의 습격 대상이 된다 |
| 무법자 | 무역상이 고용한 용병과 현상금 사냥꾼이 무법자를 막는다 |
| 기업가 | 대지주와 장인의 시설에 투자한다 |
| 탐험가 | 지도를 대지주와 정복자에게 판다 |
| 고고학자 | 고대 기술품을 연구자에게 판다 |

## 6. 디자인 기둥 (Design Pillars) — D-014, 잠정 확정·추가 가능

> **기둥이란?** 기획이 흔들릴 때 쓰는 판단 기준이다.
> - 새 기능이나 아이디어가 들어오면 "5개 기둥 중 무엇을 강화하는가?"를 묻는다.
> - 하나도 강화하지 않거나 기둥을 해치면 빼거나 고친다.
> - 기둥은 필요하면 추가할 수 있다.

| # | 기둥 | 정의 | 근거 |
|---|---|---|---|
| **P0** | 🧠 **시뮬레이션 우선 (근본 원칙)** | 이 게임의 목적은 **NPC만으로도 돌아가는 세계 시뮬레이션**이다. 유저는 이 시뮬레이션의 참여자다. 모든 시스템은 "유저 0명일 때도 작동하는가?"를 먼저 검증한다. P1~P5의 상위 원칙이다. | D-044 (2026-10-28 추가) |
| P1 | 🌍 **살아있는 행성** | 플레이어가 없어도 NPC 세력이 개척하고 교역하고 전쟁하며 역사가 쌓인다. 모든 역할은 NPC도 맡는다. 플레이어는 이 역사에 뛰어드는 한 사람이다. | D-006, D-013 |
