## 2. 세계의 진실 (작가 설정, 플레이어 비공개)

> 플레이어에게는 시즌마다 조각으로 공개한다 (D-081, D-082 ②). 공개 단계는 Step 7에서 정한다.

### 2.1 구성 요소

| 요소 | 진실 | 결정 |
|---|---|---|
| 스타게이저 (정원사의 본체) | 우주와 행성을 지키는 초고도 문명. 지금도 존재한다. 오래전 지구에 정원을 설치했다. 행성에서는 그들이 보낸 존재를 "정원사"라고 부른다 | D-073, D-083, D-088 |
| 정원 | 모든 물질과 생명을 분해해 다시 순환시키는 행성 관리 장치. 고대 유적은 그 일부다 | D-073 |
| 마법 | 생명체가 정원의 순환 흐름에 접속하는 힘. 흐름은 12갈래이고, 이것이 12속성이다 | D-073, D-056 |
| 세계전쟁 | 강대국이 정원의 핵을 병기로 쓰다 폭주했다. 정원의 '가지치기'가 문명을 쳐냈다 | D-073 |
| 책임 | 둘 다 책임이다. 인간의 병기화가 방아쇠였고, 정원은 설계된 대로 가지치기를 했다 | D-081 |
| 회복 | 정원이 지구를 다시 키웠다. 지역마다 그 땅에 남은 신화·동화를 설계도로 크리쳐와 신격을 만들었다 | D-073, D-082 ① |
| 정거장 | 정원의 정체를 알고 탈출한 사람들이다. 정원을 다시 쥐려고 사이보그를 보낸다 | D-052, D-073 |
| 정원사 | 위기의 행성에 모함으로 파견된다. 인간은 이들을 외계인·UFO로 안다. 인간의 오염과 전쟁 때문에 인간에게 적대적이다. 세력이 강해질수록 더 강한 정원사가 온다 | D-083, D-085 |
| 다른 행성 | 정원사가 만든 다른 정원들이다 | D-082 ④ |

### 2.2 진실이 설명하는 게임 규칙

| 게임 규칙 | 세계관상 이유 |
|---|---|
| 사라지지 않는 세계 (P3, D-007) | 정원이 모든 것을 분해해 다시 순환시킨다 |
| 환생 (D-021, D-026) | 휴먼·크리쳐는 정원의 순환으로, 사이보그는 정거장의 의식 백업과 몸 교체로 돌아온다 (D-058) |
| 신화 크리쳐와 귀여운 화풍 (D-066) | 동화와 신화가 설계도였다 |
| 지역마다 다른 크리쳐 | 그 지역의 신화가 설계도였다 (D-082 ①) |
| 속성 아종과 시그니처 컬러 (D-071) | 정원의 흐름이 12갈래다 |
| 프런티어의 위험 (D-029) | 정원은 사이보그를 외래종으로 본다 (D-073). 정원사는 인간에게 적대적이다 (D-083) |

## 3. 역사 (순서만, 기획자 정리)

> 각 사건의 연대(몇 년 전인지)는 아직 정하지 않았다.

1. **아주 먼 과거**: 정원사 문명이 지구에 정원을 설치했다 (D-073, D-083).
2. **인류 문명**: 인류가 정원 위에서 자랐다.
3. **세계전쟁**: 강대국이 정원의 핵을 병기로 썼다. 정원이 폭주했고, 가지치기가 문명을 쳐냈다 (D-073, D-081).
4. **탈출과 잔류**
   - 정원의 정체를 아는 사람들은 지구 궤도의 거대 정거장으로 떠났다.
   - 가난한 인류는 지구에 남았다 (D-052).
5. **회복**: 정원이 지구를 다시 키웠다. 신화 크리쳐가 생겼다 (D-073).
6. **정원사 파견**: 위기에 빠진 지구에 정원사의 모함이 왔다. 언제 왔는지는 미정이다 (D-083).
7. **현재**: 정거장이 회복된 지구로 사이보그를 보낸다. 플레이어는 그중 하나다 (D-052).

### 5.2 관계

| 관계 | 내용 | 결정 |
|---|---|---|
| 정거장 ↔ 잔존 인류 | 복잡한 긴장. 기술이 필요한 세력은 협력하고, 원한이 깊은 세력은 적대한다 | D-057 |
| 정원 ↔ 사이보그 | 정원은 사이보그를 외래종으로 본다 | D-073 |
| 정원사 ↔ 인류 | 오염과 전쟁 때문에 적대한다. 세력이 강해질수록 오염·전쟁 지표가 커지고, 더 강한 정원사·크리쳐가 나오며 공격 웨이브가 오른다. 외교는 중립에 가깝고 동맹은 거의 불가능하다. 나중에 정원사 안에서 파벌이 생길 수 있다 | D-083, D-085 |
| 국가 ↔ 국가 | 실제 국가 관계를 따르지 않는다. 시뮬레이션이 만든다 (P0) | D-076 |
| 신앙 ↔ 신앙 | 진실의 다른 조각을 믿어서 서로 다툰다 | D-082 ② |

### 5.3 NPC 국가

- 기본 국가 프리셋은 문화 모티프 16개다 (D-078, D-086).
  - 미국, 중국, 일본, 한국, 영국, 독일·북유럽
  - 프랑스, 인도, 브라질·남미, 중동·이집트, 지중해·그리스, 동남아·인도네시아
  - 멕시코·중미, 슬라브·동유럽, 튀르키예·페르시아, 아프리카·오세아니아
  - 고정 목록이 아니다. 행성 편집기에서 프리셋을 고르고, 더하고, 뺀다.
- 국가 이름은 가상이다 (D-076).
  - 모티프로 쓰는 것: 문화, 건축, 의복, 음식, 신화
  - 쓰지 않는 것: 국기, 실제 정치 체제, 실제 역사 분쟁, 실존 지도자
- 국가마다 그 나라를 대표하는 신화·전설 캐릭터와 역사 인물을 대표 유닛으로 둔다 (D-075, D-079, D-087). 역사 인물은 살아 있는 사람만 빼고 쓴다 (D-089).
- 세력의 형태와 규모는 다양하다. 예(미확정): 대국·연방, 도시국가, 부족·유목, 상단·해상 세력, 교단 국가, 군벌·용병단 (D-076)
- 행성 편집기로 기본 세력을 배치하거나 무작위로 생성·배치한다 (D-076, 기술 전달).
- 유저가 없어도 NPC 국가끼리 개척하고 교역하고 전쟁한다 (D-006, D-044).

## 6. 마법·속성·상성

- 물리·마법·기술 세 계열이 공존한다. 상성은 **물리 < 마법 < 기술 < 물리**다 (D-054). 이유는 §2.2.
- 마법은 속성 체계 위에서 작동한다. 속성은 기본 6종이고, 각각 강화형이 있어 모두 12종이다 (D-056).

  | 기본 | 강화형 | 특수효과 |
  |---|---|---|
  | 💧 물 | 🧊 빙결 | 감속, 빙결 |
  | 🔥 불 | 🌋 폭렬 | 화상, 범위 |
  | 🌪️ 바람 | ⚡ 번개 | 감전, 쉴드 관통 |
  | 🪨 땅 | 💎 크리스탈 | 아머 무시, 방어 강화 |
  | ✨ 빛 | 🌟 성(聖) | 정화, 회복 |
  | 🌑 어둠 | 💀 사령 | 저주, 흡수 |

- 피해 계산에는 속성 상성만 쓴다. 계열 상성(물리 < 마법 < 기술)은 세계관 장르로만 남기고(D-181), 크기는 스탯 분포에 나타낸다(D-182). 속성값은 12속성마다 0~10이다(D-182).

| 정원 신앙 | 정원과 자연의 순환 | 자연, 환생, 크리쳐 교감 |

- 각 신앙은 빛·어둠 분파로 나뉘어 모두 6교단이다 (D-074).
- `♻️ 재사용 후보: 기존 REL-1의 공통 규칙` — 신앙도 0~100, 행동에 따른 빛·어둠 분기, 신앙도 구간 혜택, 사후 신격 형태 (D-074)
- 교단별 특화 배분은 Step 4에서 정한다. 참고 초안은 D-080에 있다.
- 신관 경로의 최상위는 신흥 교단을 세울 수 있다. 유저와 NPC 모두 할 수 있다 (D-082 ③).
- 신격화하면 그 지역 신화의 모습으로 환생한다 (D-021, D-082 ①).
- 세 신앙은 같은 진실을 서로 다르게 해석한다 (D-074, D-082 ②).

## 8. 크리쳐

- 정원이 신화·동화를 설계도로 만들었다. 지역마다 그 땅의 신화를 따른다 (D-073, D-082 ①).
- 필드 크리쳐는 귀엽고 둥글다. 보스와 전설종은 위엄 있다. 화풍은 하나다 (D-066).
- 같은 기본 종이라도 속성이 다르면 다른 종(속성 아종)이고, 속성마다 시그니처 컬러가 있다. 개체마다 속성값에 따라 색 비율과 무늬가 다르다 (D-071).
- 교배 결과가 색·무늬·크기·일부 부위로 겉모습에 드러난다 (D-070 ④).
- 희귀 개체
  - 이로치·특수 개체: 사냥꾼 보너스 대상 (D-049)
  - 출현 한도가 있다 (D-050)
  - 정원사도 희귀 크리쳐로 나온다. 포획과 교배는 최상위 콘텐츠다 (D-083, D-085)
- 크리쳐는 이동 중에 조우한다. 자동 분포 + 희귀종 수동 배치 (D-059)
- 12지신과 신수, 그리고 유명한 몬스터 유형(거상온라인 같은 게임의 유명 몬스터)은 필수 소재다. 가장 중요하다 (D-089). 분류 체계는 Step 4-1에서 정한다.
