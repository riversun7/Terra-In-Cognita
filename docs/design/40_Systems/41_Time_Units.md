## 1. 게임 시간 (D-091, D-5030)

| 실제 시간 | 게임 시간 |
|---|---|
| 1시간 | 1일 |
| 7시간 | 계절 1개 (7일) |
| 28시간 | 1년 (계절 4개, 28일) |
| 평일 짧은 접속 15분 | 6시간 (아침 → 정오) |
| 주말 긴 접속 2시간 | 2일 (낮·밤 2번) |
| 오프라인 24시간 (D-061. 모든 기기 연결이 끊긴 때부터 센다, D-136) | 24일 (거의 1년) |
| 기존 수명 2~3개월 | 약 51~77년 |
| 1년 | 약 313년 (세계 연대기) |

- 시간 기준은 서버의 UTC다 (기술 PLAN §4.6). 게임 시각은 서버 시각에서 계산한다.
- 지역 시각은 경도에 따라 다르다. 한 지역이 낮이면 지구 반대편은 밤이다.
- 밤은 어두운 분위기의 시간대다 (P5, D-063). 조명 규칙은 D-070 ①을 따른다.
- 알려진 단점: 계절이 실제 하루에 3~4번 바뀐다.
- `♻️ 재사용 후보: 기존 낮·밤 주기 "실시간 1시간 = 게임 24시간"` (`docs/GDD/Map/Consolidated_Map.md` 1285행)
- → **D-5030 (2026-10-29)**: 모든 규칙의 시간은 실제 시간으로 정하고 실제 시간으로 보인다. 이동 명령·운송 시간도 같다. 위 표의 주기(낮·밤 1시간, 계절 7시간, 한 해 28시간)는 그대로다. 그래서 "게임 N일"은 "실제 N시간"으로 읽는다 (해석). D-168(세계는 게임 시간)은 대체되었다.

## 2. 유닛 종류

| 유닛 | 보유 | 성장 | 수명·끝 | 결정 |
|---|---|---|---|---|
| 사이보그 | 계정당 1기 (플레이어 본체) → D-470: 본체 1기 + 사이보그 유닛(아래 행) | 공통 레벨, 인공장기로 스탯·스킬 변화 | 수명 없음. 의식 백업으로 즉시 돌아온다(2초 연출, D-351). 환생 때 외형을 다시 고른다(D-352) | D-018, D-058, D-096, D-351, D-352 |
| | → D-453: 사이보그도 인공장기 내구도가 닳아 수리가 필요하고 주거비 등 생활비가 든다. 없으면 비효율로 돌아간다 | | | |
| 사이보그 유닛 | 소유. 휴먼을 바탕으로 안드로이드·기계 부품을 융합해 만든다. 기수 상한은 없다 | 본체처럼 공통 레벨 + 인공장기 | 수명 없음. 유지비가 비싸다(생필품 + 테라코인 유지) | D-470 |
| | → D-516 (2026-11-07, 기획 정리, 질문 370~373): 융합의 부품 쪽은 안드로이드 유닛과 기계 부품 둘 다다. 융합한 유닛은 바탕 휴먼과 같은 유닛이라 지닌 것·계약이 따라온다. 레벨 1, 속성은 휴먼 값을 남기고 환생 횟수는 버린다 | | | |
| 휴먼 | 소유 (이적 가능, §3) → D-469: 정부기관 구인 카드로 고용, 출생 없음 | 공통 레벨, 유전 기반 초기 스탯, 교육 → D-478: 혈연 없음. 스탯 유전자는 인큐베이터에서 쓴다 | 수명이 있다. 신앙으로 환생·신격화 | D-018, D-020, D-021, D-097 |
| | → D-517 (2026-11-07, 사용자): 수명이 다하면 비활성 상태가 되고, 종교 시설에서 환생하거나 생명과학 연구소에서 유전자 조각으로 변환한다(§7) | | | |
| 안드로이드 | 소유 | 레벨 없음, 부품에 의존. 코어 이식·펌웨어. 성장은 부품 업그레이드, 피로 대신 배터리 (D-416) | 부품 파괴 | D-018, D-021, D-032, D-416 |
| 크리쳐 | 소유 (포획·교배) → D-481: 교배 없음. 포획·알 뽑기·유전자 조합 | 공통 레벨, 종족별 스탯 분포·고유 스킬 | 수명이 있다. 환생으로 수명 리셋 | D-018, D-020, D-026 |

- 레벨·경험치·환생·스킬 합성은 `../20_Core_Loop.md` §2를 본다.
- 모든 유닛은 강화할 수 있다. 사이보그·안드로이드는 기계 개조, 휴먼·크리쳐는 생명공학(고비용)이다 (D-025).
- NPC 세력의 유닛도 같은 규칙을 따른다 (P0).

## 3. 휴먼의 소유와 이적 (D-097)

| 항목 | 규칙 |
|---|---|
| 소유 | 휴먼은 소유 유닛이다 |
| 이적 | 축구·야구 선수처럼 이적료를 받고 다른 소유자에게 넘길 수 있다 |
| 부양 | 소유자는 필수 요소(주거·식량 등)를 제공하거나, 화폐로 지급한다 |
| 사유재산 | 휴먼이 경제활동으로 번 화폐는 휴먼 자신의 것이다 (기존 개인 지갑 재사용 후보) |
| 가치 | 육성, 특수 스킬, 유전자의 가치가 오르면 이적료가 오른다 |
| 계속 육성 | 생명공학과 환생으로 계속 키울 수 있다 |

- 휴먼의 가치를 키우는 경로: 교육자, 의사, 신관, 브리더 (D-048)
  - → D-481 (2026-11-01): 브리더는 유전공학자에 합쳤다.
- 이적 시장의 거래 방식과 이적료 평가는 Step 4-4 경제에서 정한다.
  - → D-129: 공개 이적 시장(경매) + 1:1 협상. 이적료의 일부는 수수료·세금으로 사라지고, 휴먼의 지갑은 휴먼을 따라간다.
    - → D-7023·D-242 (2026-10-29): 1:1 협상은 없앤다. 휴먼 거래소에서 공개 경매(즉시 구매가 가능)만 한다.
- 재산은 휴먼만 갖는다. 크리쳐·안드로이드의 노동 보상은 소유자가 받고, 소유자가 먹이·연료·수리비를 댄다 (D-127).
  - → D-470 (2026-11-01): 사이보그 유닛도 재산이 없다. 융합할 때 휴먼의 지갑은 상속처럼 처리한다(상속세 + 소유자).
- 휴먼은 출생하지 않는다. 정부기관(행정 건물)의 구인 카드로 고용한다. 주기마다 카드 여러 장 가운데 고른다. NPC 세력도 같다 (D-469).
  - 행정 건물(거점) 레벨 Lv1~5가 오르면 카드 수와 평균 스탯이 오른다. 카드 수·평균 스탯·주기는 설정값이다 (D-469).
  - 후반에는 생명공학연구소 인큐베이터 모듈에서 유전자로 스탯·스킬을 유도해 새 휴먼을 만든다. 비용과 기술 요구가 높다 (D-469, D-478).
    - → D-516 (2026-11-07, 사용자): 스탯 유전자에는 총합 스탯·스탯마다의 분포·속성값이 담겨 유전자 하나하나가 다른 물건이다. 인큐베이터에서 총합이나 주력 스탯 등을 골라 적용한다. 유전자끼리 합성할 수 있고, 끝없이 오르지 않고 확률에 따라 오르거나 내리거나 그대로다. "조각마다 무작위 스탯 +1"은 쓰지 않는다.
    - → D-516 (2026-11-07, 기획 정리, 질문 376~378): 유전자는 유닛 종류(휴먼·크리쳐)마다 쓴다. 크리쳐의 종은 바탕 개체가 정하고 유전자는 스탯·속성만 바꾼다. 스킬 유전자는 스킬마다 종류가 있고 주입하면 그 스킬을 배운다(확인 대기). 시설이 생기면 그 시설 도시 창고의 재료로 그 시설에서만 쓴다.
    - → D-478 (2026-11-07, 기획 정리, 질문 398~401): 인큐베이터 적용은 총합 적용(총합을 여섯 칸에 고르게, 바탕보다 작으면 바탕)과 주력 적용(분포가 가장 큰 칸 하나만)이고, 속성은 늘 유전자 값이다. 합성은 둘 → 하나다. 스킬 유전자 주입 대상은 고용 휴먼이고 등급 1로 배운다. 인큐베이터는 생명공학 시설에서 그 도시 창고 재료·화폐로 쓴다(D-311 기획 정리 질문 459: 연구소 Lv1부터, 새 휴먼은 연구소 도시에 산다).
- 휴먼이 죽으면 상속세를 내고 지갑은 소유자에게만 간다. 유닛에게는 자녀·배우자가 없다 (D-469).

## 4. 크리쳐

### 4.1 6축 도감 분류 (D-092)

| 축 | 값 예 (목록은 Step 5에서 확정) |
|---|---|
| 계통 | 짐승 · 조류 · 용 · 수생 · 곤충 · 식물 · 정령 · 기계 · 신령 |
| 기원 | 자연종(실제 동물) · 신화종(지역 신화) · 정원사종(스타게이저) |
| 등급 | 일반 · 희귀 · 보스 · 전설 · 신수 |
| 속성 | 12속성마다 0~10 값 → 속성 아종과 색 (D-071, D-182) |
| 크기 | S · M · L · XL |
| 성향 | 공격 · 방어 · 기동 · 탑승 · 마법 · 생산 |

- → 계통과 성향은 고정 값 대신 **태그**로 바꾼다. 태그는 크리쳐 생성기에서 계속 늘린다. 등급·크기·속성·기원은 규칙이 쓰는 고정 칸으로 남긴다 (D-5022·D-5026, 해석). 정본은 `../50_Content_Rules.md`.
- 종 = 계통 + 기원의 조합이다. 아종 = 속성이다. 개체 = 속성값·무늬·유전이다. 색 비율은 속성값을 그 합으로 나눠 구한다 (D-182, 해석).
- 예: 백호 = 짐승 / 신화종(동아시아) / 신수 / 땅 7·빛 3 / L / 공격
- 재사용 후보 (D-092)
  - `♻️ 크리쳐 데이터 필드 category·size_class·rarity`
  - `♻️ 원소 점유 비율별 시각 강도 60%·40%·20%·미세`
  - `♻️ 크리쳐 스킬 4칸: 선천 고유기·성장 해금기·특성 훈련기·탑승/조력기`
    - → D-427 (2026-10-31): 4칸 고정은 쓰지 않는다. 스킬 슬롯은 종마다 다르고(초반 약한 크리쳐는 많게), 최대 10이다 (`48_Stats_Formulas.md` §6.2).

### 4.2 필수 소재 (D-089, D-093)

- 신화·환상 동물 세트를 도감에 필수로 넣는다. 가장 중요하다.
  - 12지
  - 사신·사흉 같은 동아시아 신수
  - 국가 모티프 16개의 신화 속 환상 동물 (D-086)
  - 거상온라인처럼 유명한 몬스터 유형. 다른 게임 고유의 디자인은 복제하지 않는다 (D-067)
- **12지 계열**: 12지 동물마다 일반 → 희귀 → 보스 → 전설(12지신)로 이어진다.
  - 예: 들쥐(일반) → 은빛쥐(희귀) → 코리별 쥐왕(보스) → 자신(子神, 전설)
- → 세트 구성 (D-5025·D-5027·D-5028): 12지는 동양 공통 세트다. 서양은 황도 12궁 세트(12지와 짝)와 서양 환상 동물 세트를 둔다. 국가 세트의 종 수는 나라마다 자유다. 그 밖에도 최대한 많이 찾아 넣는다.

### 4.3 6스탯 분포 (D-094)

- 크리쳐 계열과 세트마다 주력 스탯이 6스탯(STR·DEX·AGI·VIT·INT·WIS)에 고르게 퍼지게 한다.
- 예시(미확정): 12지를 스탯마다 2계열씩 나눈다. STR 소·호랑이, DEX 쥐·원숭이, AGI 말·토끼, VIT 돼지·뱀, INT 용·양, WIS 닭·개
- → 크리쳐 생성 에디터 (D-5024): 개발자가 특성을 고르면 나머지를 자동으로 만들고, 고른 특성이 스탯 분포에 영향을 준다.

### 4.4 희귀와 정원사 크리쳐

- 이로치·특수 개체는 사냥꾼 보너스 대상이다 (D-049). 출현 한도가 있다 (D-050).
- 정원사 크리쳐는 신격화된 존재이거나 기계화 공룡 같은 모습이다 (D-083, D-084).
  - 포획과 교배는 최상위 콘텐츠다 (D-085).
    - → D-481 (2026-11-01): 교배 없음, 유전자 조합.

## 6. 보유 규모 (D-098)

- 모든 유닛은 개별 유닛이다. 집계 인구는 없다.
- 보유 규모는 유지비로만 조절한다 (D-019). → D-153: 보유 규모의 상한은 주거 수용이다.
  - 유지비는 누진이 아니다. 유닛마다 필요한 생필품(주거 등급·식료품·치료 등급)의 합이고, 등급·스펙이 높을수록 많이 든다. 유닛마다 선호가 다르다 (D-150, D-126 대체).
  - 유닛 예산은 유저 + NPC 합쳐 10만 개다 (기술 세션의 사용자 결정, terra-in-cognita ADR `2026-10-28-npc-scale-and-stage.md`). 유닛 상한은 주거 수용이고(D-153), 서버 전체 보호 장치는 기술 쪽 ADR `2026-10-28-unit-cap-housing.md`가 맡는다.
- 큰 세력일수록 유지비가 가파르게 올라야 한다. 기술 목표(동시접속 1만 명, 자율 유닛 10만 개 이상, D-059) 안에서 유저와 NPC가 유닛 예산을 나눠 쓰기 때문이다. → D-150으로 대체: 누진은 없다. 큰 세력은 주거·땅(D-153), 정원사 압박, 반란, 영토 유지비가 견제한다.
- 세력이 커질수록 정원사의 압박도 커진다 (D-085). 유지비와 함께 성장을 견제한다.

## 7. 부상과 사망 (D-099)

| 상황 | 결과 |
|---|---|
| 전투에서 HP 0 | 전투불능 → 부상(3단계) → 치료가 필요하다 → D-514: 병원이 없어도 자동 회복하되 부상 단계만큼 느리고 불이익, 병원 회복도 필요 |
| 수명이 다함 | 사망. 유전자 조각이 떨어진다 (환생 재화, 거래 가능) → D-478: 스탯 유전자(속성 포함)·스킬 유전자 두 종류가 남는다. 한 번 쓰면 사라진다 → D-517: 사망 대신 비활성 상태가 되고, 환생(종교 시설) 또는 유전자 조각 변환(생명과학 연구소) 중 하나. 유전자는 저절로 남지 않는다 |
| 신앙이 있는 유닛 | 사망 뒤 환생·신격화할 수 있다. 신격화하면 그 지역 신화의 모습이 된다 (D-021, D-082 ①) |

- 재사용 후보: `♻️ 기존 부상 3단계`, `♻️ 기존 유전자 조각` (D-099)
- 긴장감은 위험 지역의 장비·화물 손실로 보완한다 (D-029). 세부는 Step 4-5 전투에서 정한다.
- 치료는 의사 경로와 이어진다 (D-046).
- → D-478 (2026-11-07, 기획 정리, 질문 395~397): 395의 "안 고르면 떠난다"는 D-517(비활성으로 남음)로 바뀌었다. 남은 물건은 그 휴먼이 살던 도시의 내 창고로 간다. NPC 휴먼은 지금 유전자를 남기지 않는다(밸런싱 때 다시 봄). 환생 재료에 유전자 조각이 드는지의 확인 대기는 D-517이 닫았다(들지 않음).
- → D-311 (2026-11-07, 기획 정리, 질문 451·452): 비활성 상한이 지나면 값 없이 유전자로 변환한다(상한 출발값 = 없음). 비활성 휴먼은 이동은 되고 전투·일은 막힌다(신전·연구소로 걸어감).
