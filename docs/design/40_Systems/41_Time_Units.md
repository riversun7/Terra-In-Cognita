## 1. 게임 시간 (D-091)

| 실제 시간 | 게임 시간 |
|---|---|
| 1시간 | 1일 |
| 7시간 | 계절 1개 (7일) |
| 28시간 | 1년 (계절 4개, 28일) |
| 평일 짧은 접속 15분 | 6시간 (아침 → 정오) |
| 주말 긴 접속 2시간 | 2일 (낮·밤 2번) |
| 오프라인 24시간 (D-061) | 24일 (거의 1년) |
| 기존 수명 2~3개월 | 약 51~77년 |
| 1년 | 약 313년 (세계 연대기) |

- 시간 기준은 서버의 UTC다 (기술 PLAN §4.6). 게임 시각은 서버 시각에서 계산한다.
- 지역 시각은 경도에 따라 다르다. 한 지역이 낮이면 지구 반대편은 밤이다.
- 밤은 어두운 분위기의 시간대다 (P5, D-063). 조명 규칙은 D-070 ①을 따른다.
- 알려진 단점: 계절이 실제 하루에 3~4번 바뀐다.
- `♻️ 재사용 후보: 기존 낮·밤 주기 "실시간 1시간 = 게임 24시간"` (`docs/GDD/Map/Consolidated_Map.md` 1285행)

## 2. 유닛 종류

| 유닛 | 보유 | 성장 | 수명·끝 | 결정 |
|---|---|---|---|---|
| 사이보그 | 계정당 1기 (플레이어 본체) | 공통 레벨, 인공장기로 스탯·스킬 변화 | 수명 없음. 의식 백업과 몸 교체로 돌아온다 | D-018, D-058, D-096 |
| 휴먼 | 소유 (이적 가능, §3) | 공통 레벨, 유전 기반 초기 스탯, 교육 | 수명이 있다. 신앙으로 환생·신격화 | D-018, D-020, D-021, D-097 |
| 안드로이드 | 소유 | 레벨 없음, 부품에 의존. 코어 이식·펌웨어 | 부품 파괴 | D-018, D-021, D-032 |
| 크리쳐 | 소유 (포획·교배) | 공통 레벨, 종족별 스탯 분포·고유 스킬 | 수명이 있다. 환생으로 수명 리셋 | D-018, D-020, D-026 |

- 레벨·경험치·환생·스킬 합성은 `../20_Core_Loop.md` §2를 본다.
- 모든 유닛은 강화할 수 있다. 사이보그·안드로이드는 기계 개조, 휴먼·크리쳐는 생명공학(고비용)이다 (D-025).
- NPC 세력의 유닛도 같은 규칙을 따른다 (P0).

## 3. 휴먼의 소유와 이적 (D-097)

| 항목 | 규칙 |
|---|---|
| 소유 | 휴먼은 소유 유닛이다 |
| 이적 | 축구·야구 선수처럼 이적료를 받고 다른 소유자에게 넘길 수 있다 |
| 부양 | 소유자는 필수 요소(주거·식량 등)를 제공하거나, 화폐로 지급한다 |
| 사유재산 | 휴먼이 경제활동으로 번 화폐는 휴먼 자신의 것이다 (기존 개인 지갑 재사용 후보) |
| 가치 | 육성, 특수 스킬, 유전자의 가치가 오르면 이적료가 오른다 |
| 계속 육성 | 생명공학과 환생으로 계속 키울 수 있다 |

- 휴먼의 가치를 키우는 경로: 교육자, 의사, 신관, 브리더 (D-048)
- 이적 시장의 거래 방식과 이적료 평가는 Step 4-4 경제에서 정한다.

## 4. 크리쳐

### 4.1 6축 도감 분류 (D-092)

| 축 | 값 예 (목록은 Step 5에서 확정) |
|---|---|
| 계통 | 짐승 · 조류 · 용 · 수생 · 곤충 · 식물 · 정령 · 기계 · 신령 |
| 기원 | 자연종(실제 동물) · 신화종(지역 신화) · 정원사종(스타게이저) |
| 등급 | 일반 · 희귀 · 보스 · 전설 · 신수 |
| 속성 | 12속성의 비율 → 속성 아종과 색 (D-071) |
| 크기 | S · M · L · XL |
| 성향 | 공격 · 방어 · 기동 · 탑승 · 마법 · 생산 |

- 종 = 계통 + 기원의 조합이다. 아종 = 속성이다. 개체 = 속성 비율·무늬·유전이다.
- 예: 백호 = 짐승 / 신화종(동아시아) / 신수 / 땅 70%·빛 30% / L / 공격
- 재사용 후보 (D-092)
  - `♻️ 크리쳐 데이터 필드 category·size_class·rarity`
  - `♻️ 원소 점유 비율별 시각 강도 60%·40%·20%·미세`
  - `♻️ 크리쳐 스킬 4칸: 선천 고유기·성장 해금기·특성 훈련기·탑승/조력기`

### 4.2 필수 소재 (D-089, D-093)

- 신화·환상 동물 세트를 도감에 필수로 넣는다. 가장 중요하다.
  - 12지
  - 사신·사흉 같은 동아시아 신수
  - 국가 모티프 16개의 신화 속 환상 동물 (D-086)
  - 거상온라인처럼 유명한 몬스터 유형. 다른 게임 고유의 디자인은 복제하지 않는다 (D-067)
- **12지 계열**: 12지 동물마다 일반 → 희귀 → 보스 → 전설(12지신)로 이어진다.
  - 예: 들쥐(일반) → 은빛쥐(희귀) → 코리별 쥐왕(보스) → 자신(子神, 전설)

### 4.3 6스탯 분포 (D-094)

- 크리쳐 계열과 세트마다 주력 스탯이 6스탯(STR·DEX·AGI·VIT·INT·WIS)에 고르게 퍼지게 한다.
- 예시(미확정): 12지를 스탯마다 2계열씩 나눈다. STR 소·호랑이, DEX 쥐·원숭이, AGI 말·토끼, VIT 돼지·뱀, INT 용·양, WIS 닭·개

### 4.4 희귀와 정원사 크리쳐

- 이로치·특수 개체는 사냥꾼 보너스 대상이다 (D-049). 출현 한도가 있다 (D-050).
- 정원사 크리쳐는 신격화된 존재이거나 기계화 공룡 같은 모습이다 (D-083, D-084).
  - 포획과 교배는 최상위 콘텐츠다 (D-085).

## 5. 크기와 표현

| 항목 | 규칙 | 결정 |
|---|---|---|
| 크기 범위 | 사람·일반 크리쳐 0.5~3m. 보스·전설·신수는 최대 약 12m (2차맵 배치 칸 약 2칸) | D-095 |

| 크리쳐 표현 | 귀여움이 기본이고, 보스·전설종은 위엄 있게 | D-066 |

## 6. 보유 규모 (D-098)

- 모든 유닛은 개별 유닛이다. 집계 인구는 없다.
- 보유 규모는 유지비로만 조절한다 (D-019).
- 큰 세력일수록 유지비가 가파르게 올라야 한다. 기술 목표(동시접속 1만 명, 자율 유닛 10만 개 이상, D-059) 안에서 유저와 NPC가 유닛 예산을 나눠 쓰기 때문이다.
- 세력이 커질수록 정원사의 압박도 커진다 (D-085). 유지비와 함께 성장을 견제한다.

## 7. 부상과 사망 (D-099)

| 상황 | 결과 |
|---|---|
| 전투에서 HP 0 | 전투불능 → 부상(3단계) → 치료가 필요하다 |
| 수명이 다함 | 사망. 유전자 조각이 떨어진다 (환생 재화, 거래 가능) |
| 신앙이 있는 유닛 | 사망 뒤 환생·신격화할 수 있다. 신격화하면 그 지역 신화의 모습이 된다 (D-021, D-082 ①) |

- 재사용 후보: `♻️ 기존 부상 3단계`, `♻️ 기존 유전자 조각` (D-099)
- 긴장감은 위험 지역의 장비·화물 손실로 보완한다 (D-029). 세부는 Step 4-5 전투에서 정한다.
- 치료는 의사 경로와 이어진다 (D-046).
