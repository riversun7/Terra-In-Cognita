## 1. 기준 크기

| 항목 | 값 | 출처 |
|---|---|---|
| 지구 축척 | 약 1:12, 반지름 약 531km | PLAN §5.2 (D-055) |
| 1차맵 최소 칸 (= 2차맵 하나) | 한 변 약 1.5km | PLAN §5.2 |
| 2차맵 지형 칸 | 128×128칸, 약 11.7m | PLAN §5.2 |
| 2차맵 배치 칸 | 256×256칸, 약 5.9m. 건물·도로·충돌·경로탐색의 단위 | PLAN §5.2 |
| 게임 속 대한민국 | 약 697km², 1차맵 칸 약 310개 | D-100의 계산 |
| 고도 축척 | 수평과 같은 1:12. 에베레스트 8,849m → 약 737m. 1차맵 표시만 과장, 기후 계산은 실제 고도 | D-215 |

- 건물과 유닛은 실제 크기다. 지형은 1:12로 줄어 있다. 그래서 도시 크기도 1:12로 줄인다 (§2).
- 게임 규칙의 거리와 크기는 칸 수로 정한다. 미터는 표시용이다 (PLAN §5.2).
- 바이옴은 기술 세션의 임시 목록(빙상·툰드라·타이가·온대림·초지·사막·사바나·열대우림·습지·고산, 바다 3단계, 호수)에 특수 지형을 더한다. 지도가 단순한 패턴을 반복하지 않게 하고, 지형이 되는 조건을 보여 주는 정보창을 행성 생성기와 개발자 메뉴에 둔다 (D-214).
  - 특수 지형은 기술 제안의 18개(P1 화산·온천·맹그로브·산호초와 해조·바다 얼음·카르스트·사구·이끼 늪과 언 땅 호수, P2 소금 평원·오아시스·삼각주·협곡·피오르·빙하·갯벌, P3 바위 언덕·황토 고원·크리스탈 맥)와 예비 5개(범람원·열곡·운무림·고목림·크레이터)다 (D-258).
  - 나오는 양은 조건값으로 정해 행성마다 다르다. 한 종류가 땅의 5%를 넘지 않는지 자동 검사로 본다 (D-259).
  - 한 칸에 지형 1 + 생태 1 + 지점이 함께 있을 수 있고, 같은 층은 순위대로 이긴다 (D-260).
  - 생성기의 사실성 고침(말단 염호·열곡 호수·깊은 협곡)은 기후·지형 고침과 함께 지금 넣는다 (D-262).
  - 판타지 지형은 정원의 흐름으로 묶는다. 크리스탈 맥, 정원 유적·흐름의 샘·가지치기 흔적(지점), 뇌우 고원(번개 서식지), 정원 유적 둘레(성 서식지) (D-263).

## 2. 영토 = 도시의 영향권 (D-100, D-104)

### 2.1 크기

| 등급 | 실제 인구 | 게임 시가지 반경 | 게임 영향권 반경 |
|---|---|---|---|
| 마을 | 1천 | 47m | 141m (0.1칸) |
| 읍 | 1만 | 105m | 315m (0.2칸) |
| 소도시 | 10만 | 271m | 814m (0.5칸) |
| 도시 | 50만 | 526m | 1.6km (1.1칸) |
| 대도시 | 200만 | 940m | 2.8km (1.9칸) |
| 거대도시 | 1천만 | 1.8km | 5.3km (3.6칸) |

- 실제 도시 크기를 1:12로 줄였다. 영향권은 시가지 반경의 3배다. 배후 농지와 주변 마을을 포함한다 (밀도는 Assumed).
- 작은 마을 여러 개가 2차맵 하나를 나눠 쓸 수 있다.
- 등급의 기준은 실제 인구가 아니라 게임 속 발전도다 (§2.3). 표의 인구는 크기를 환산하기 위한 참고값이다 (해석).

### 2.2 경계

- 도시 사이의 경계는 도시 중심과 영향력으로 계산한다. 1차맵 칸보다 세밀하다.
- 2차맵 하나 안에 여러 세력의 영토가 있을 수 있다.
- 1차맵을 멀리서 볼 때는 칸마다 차지한 비율이 가장 큰 세력의 색으로 표시한다.
- 같은 세력 안에서도 도시마다 경계를 긋는다. 도시는 내정(세금·정책 등)의 단위다.

### 2.3 발전도 (D-110)

도시의 영향권은 발전도 점수가 오를수록 넓어진다.

| 요소 | 내용 |
|---|---|
| 인구 | 사는 유닛 수와 등급 |
| 건물·기반시설 | 건물의 수·등급·명소, 도로·철도 연결 |
| 경제 | 거래량, 세수, 생산량 |
| 문화·신앙 | 신전·축제·명성, 치안과 만족도 |
| 교육·연구 | 학교·연구소 |
| 보건 | 병원·위생 |
| 환경 | 오염이 낮을수록 점수가 오른다. 오염은 정원사의 적대를 높인다 (D-085) |

- 7요소를 모두 쓴다. 발전도 = Σ(요소 점수 × 가중치), 가중치는 설정값이다. 예시(잠정): 인구 25, 건물 20, 경제 20, 문화·신앙 10, 교육 10, 보건 10, 환경 5. 수치는 Step 5 (D-254).

## 3. 영토를 얻고 잃는 길 (D-101, D-105)

| 길 | 내용 |
|---|---|
| 거점 선언 | 빈 땅에 거점 건물을 세운다. 등급이 오르면 영향권이 넓어진다 |
| 영향력 자연 확장 | 영향력이 커지면 주인 없는 주변 땅이 자연스럽게 편입된다 |
| 전쟁 점령 | 다른 세력의 거점을 부수거나 점령한다 |
| 외교·구매 | 조약이나 거래로 넘겨받는다. 필지는 부동산처럼 사고판다 (§4) |
| 유지비·실효 지배 | 유지비를 내지 않거나 돌보지 않으면 줄어든다. 땅 투기와 독점을 막는다 |
| 반란·독립 | 내정이 나쁜 도시가 반란을 일으켜 독립한다. 예: 높은 세금, 치안 불안, 독점 불만. → 만족도가 낮으면 태업, 아주 낮으면 회유로 넘어감(낮을수록 싸고 주인에게 알림), 도시 평균 40(예시) 이하이면 낮은 유닛이 반란 전투 상태 (D-253, D-257). 정부가 소탕하고, 반란군이 시청을 점령하면 새 NPC 세력이 된다 (D-256) |
| 정원사 침공·폐허화 | 정원사 공격에 무너진 도시는 영토를 잃고 폐허가 된다. 폐허는 다시 개척할 수 있다 |

NPC 세력도 같은 길로 영토를 얻고 잃는다 (P0).

### 3.1 시장 위임과 공석 (D-105, D-109)

- 여러 도시 중 일부를 다른 유저나 유닛에게 시장으로 맡긴다.
- 시장이 수명으로 죽거나, 전쟁에서 부상·포로가 되거나, 도시를 잃으면 공석이 된다.
  - 부시장 같은 직위가 권한을 대행한다.
  - 포로는 몸값이나 포로 교환으로 돌아온다. 억류한 쪽이 주거·생필품을 대고, 몸값은 1:1 협상, 기한이 지나면 석방된다 (D-187). → 1:1 협상은 없앤다. 몸값은 억류자가 값을 건 원래 주인 전용 매물이고, 포로 교환은 강화 조약으로만 한다. 처형·회유도 할 수 있다 (D-242·D-244·D-269).
- 사망은 수명이 다했을 때만 한다 (D-099).
- 시장에게는 정해진 권한 묶음을 준다: 도시 세율, 필지 분양, 공공 건물, 도시 예산. 외교·전쟁·화폐는 지도자에게 남는다. 급여는 직위별 급여표대로 국고에서 나가고, 휴먼 시장은 효율점수 × 시장 단가다. 휴먼 시장은 태수처럼 자동 운영한다 (D-252, D-246).

## 4. 땅 소유 (D-111)

- 도시 영토 안에서도 개인·유닛이 필지(땅 구획)를 사고판다.
- 도시는 필지에 세금을 걷는다.
- 영토의 주인과 땅의 주인이 다를 수 있다.
- 도로와 공공시설의 땅은 도시가 소유한다.
- 대지주 경로의 무대다 (D-048).
- 필지의 크기·모양, 부동산 거래, 재산세는 Step 4-4 경제에서 정한다.

## 5. 건물 (D-102, D-133, D-5041, D-5042, D-5044)

- 크기: 실제 건물 크기를 배치 칸(약 5.9m)으로 환산한다.
- 모양: 직사각형만이 아니라 ㄱ자 같은 모양도 된다. 칸 조합 모양으로 정의한다.
- 90°씩 회전해서 놓을 수 있다 (D-133에서 확정).
- 건물 하나는 2차맵 하나 안에 들어가야 한다 (D-133에서 확정). 도로·철도(§6)와 활주로 같은 선형 시설은 경계를 넘을 수 있다 (D-133).
- 건물 목록은 **기능 분류 + 건물 에디터**로 만든다 (D-5044).
  - 대분류: 거점·행정, 생산 시설(4단계), 창고·물류, 주거·생활, 교육·훈련, 신앙·문화, 방어·군사, 교통, 선형 시설
  - 에디터에 칸 모양·레벨(Lv1~5)·직무·수용 인원·내구도를 넣고 계속 더한다. 수치는 개발자 패널 설정값이다 (D-5032).
- 건물은 레벨이 올라도 **차지하는 칸을 넓히지 않는다** (D-5041). 옆 칸이 남의 땅이거나 다른 건물이면 넓힐 수 없기 때문이다 (D-149).
  - 처음 지을 때 최종 크기의 칸을 차지하고, 레벨이 오르면 그 칸 안에서 겉모습과 성능이 바뀐다 (해석). 예: Lv1 작은 공방이 Lv5 공장 크기의 칸에 서 있다.
  - 거점 건물의 등급(§3)도 Lv1~5이고 같은 칸 안에서 오른다 (해석).
- 경계를 넘는 선형 시설은 **도로·철도·활주로뿐**이다. 운하·송전선·송유관·성벽은 2차맵 하나 안에서만 짓는다 (D-5042, 해석). 에너지·원유를 멀리 보내려면 운송(D-117)을 쓴다.
- 기존 건물 체계는 재사용 후보다: `♻️ 재사용 후보: 기존 건물 대분류(TERRITORY, HOUSING, PRIMARY, SECONDARY_REFINE, SECONDARY_CRAFT, STORAGE, LOGISTICS 등)` (`docs/GDD/Building/BLD-2_BuildingTree.md`)

## 6. 도로와 교통 (D-102, D-106, D-108)

### 6.1 도로 폭

| 종류 | 실제 폭(가정) | 칸 | 속도(예시) | 규칙 |
|---|---|---|---|---|
| 길 (자연 발생) | 약 2~4m | 1 | ×1.1 | 유닛이 자주 다니면 저절로 생긴다 |
| 마을길 (1차로) | 약 4~5m | 1 | ×1.2 | |
| 2차로 도로 | 약 9~10m | 2 | ×1.5 | |
| 4차로 도로 | 약 17~18m | 3 | ×1.8 | |
| 고속도로 | 약 23~26m | 4 | ×2.5 | 나들목에서만 진출입 |
| 단선 철도 | 약 5~6m | 1 | ×4.0 | 역에서만 승하차 |
| 복선 철도 | 약 10~11m | 2 | ×4.0 | 양방향 |
| 다리·터널 | 위와 같음 | 같음 | 같음 | 강·산을 건넌다 |

- 도로는 배치 칸을 차지한다. 도로 종류가 물류 이동 속도를 바꾼다.
- 대형 유닛(약 2칸)은 폭이 2칸 이상인 길·광장·들판으로만 다닌다. 골목과 건물 사이에는 들어가지 못한다 (D-135).
- 속도 배율은 예시다. 수치는 Step 4-3 물류에서 정한다.
  - → D-120: 속도는 실제 시간 기준이고 걷기는 실제보다 빠르게 한다. 배율과 수치는 구현 때 조정한다 (`43_Production.md` §7.2).

### 6.2 경계 연결

- 도로, 특히 철도는 이웃 2차맵으로 자연스럽게 이어져야 한다.

### 6.3 항공·해상

- 1차맵(행성 지도)에서 도시를 눌러 노선을 잇는다.
- 세부(공항·항구, 운송 수단, 비용)는 Step 4-3 물류에서 정한다.
  - → 실물 운송 2트랙(D-117), 시설 소유자가 운임을 정하는 운송 사업(D-122). `43_Production.md` §7. 운송 수단 목록은 Step 5.

## 7. 탐험과 시야 (D-103, D-107)

| 화면 | 보이는 것 (탐사한 곳만) |
|---|---|
| 1차맵 1~2단계 (대륙·지역) | 지형, 영토 경계, 아는 도시 이름 |
| 1차맵 3~4단계 | 위에 더해 아는 건물·도시 아이콘, 세력이 공유한 다른 유저의 건물 |
| 1차맵 5단계 | 위에 더해 시야 안의 부대 묶음 아이콘 |
| 2차맵 | 시야 반경 안의 유닛을 하나씩 표시 |
| 시야 밖 (탐사함) | 지형만 |
| 미탐사 | 검정 |

- 같은 세력 안에서는 다른 유저의 건물까지만 공유한다.
- 시야 반경은 유닛·건물·크리쳐마다 칸 수로 다르다. 망루와 조류 크리쳐는 넓다.
- `♻️ 재사용 후보: 기존 시야 확장 아이템 '오딘의 까마귀'` (D-107)

## 9. 기술 세션 전달

처리 현황은 `../00_README.md` §3-1에 있다.

- 영토 경계 계산 (D-104): 도시 중심과 영향력으로 계산하고, 칸보다 세밀하다. 2차맵 하나에 여러 세력이 있을 수 있다.
- 건물 (D-102, D-133): 칸 조합 모양, 회전 가능, 2차맵 하나 안. 활주로는 경계를 넘는 선형 시설. 칸 모양은 건설 때 고정, 레벨은 같은 칸 안의 상태 값 (D-5041). 경계를 넘는 것은 도로·철도·활주로뿐 (D-5042). 건물 데이터 = 기능 대분류 + 칸 모양 + 레벨별 값 + 태그, 건물 에디터 (D-5044)
- 도로 (D-102, D-106, D-108)
  - 배치 칸을 차지하고 종류별로 경로 이동 비용이 다르다.
  - 2차맵 경계를 넘어 끊기지 않게 잇는다.
  - 항공·해상은 1차맵의 노선 데이터다.
- 시야 (D-103, D-107): 3단계 안개, 확대 단계별 정보 층, 세력은 건물만 공유
