## 1. 우주의 큰 그림 (D-350, D-375, D-369, D-370, D-372)

### 1.1 4중 구조 (D-350, D-375)

맵은 **우주·하늘·육지·해상의 4중 구조**다. 우주를 실제로 구현한다 (D-350).

| 층 | 어디서 조작하나 | 결정 |
|---|---|---|
| 우주 | 항성계 전체를 보여 주는 **항성계 화면** (EVE Online 참고) | D-350 |
| 하늘·해상 | 1차맵에서 공항 도시·항구 도시(조선소)를 눌러 노선을 만들고 물류를 조작한다 | D-350, D-106 |
| 육지 | 유닛은 2차맵에서 활동한다. 이웃 2차맵으로 넘어가면 1차맵에서도 한 칸 움직인다 (기존 구조 그대로, 해석) | D-350, D-055 |

- 우주는 **행성 하나의 층**이다. 행성마다 우주층이 하나씩 있다 (D-375). 달·소행성대도 천체 하나로 자기 우주층과 소유권을 가진다 (D-375 해석, 정정 가능). 가스 행성은 우주층만 있다 (D-383).
- 하늘·해상 전투맵(D-202)에 우주가 더해져 이동·전투 영역이 넷이 된다 (D-350 해석).
- 개발 범위가 크게 늘어난다. D-058의 근거("개발 범위를 통제한다")와 부딪친다. 출시 범위는 D-372·D-407로 정했다: 우주층은 출시 뒤 후보, 순서는 운영 지표.

### 1.2 엔드게임 단계 (D-369, D-370)

- **우주는 엔드게임 단계**다. 최상위 세력의 후반 목표이고, 신규 유저에게는 멀다 (D-369, 추천안 아님).
- 기획자 해석 (정정 가능, D-369)
  - 새 경로는 만들지 않는다. 27경로 그대로다. 함선·우주 건물·우주 전투·모함 강습이 후반에 열린다. (→ D-481: 경로 목록은 언제든 바뀐다. 지금 26개, 정본 20 §7)
  - 신규 유저도 첫 접속에서 다른 행성으로 강하할 수 있다(D-365). 그것은 모항의 강하이지 우주 활동이 아니다.
- 우주는 **연구와 비싼 자재**로 열린다 (D-370).
  - 우주공항·함선 바디는 높은 연구 단계와 비싼 자재가 필요하다.
  - 큰 세력이 먼저 열고, 시간이 지나면 중간 세력도 닿는다.
  - 우주공항이 있는 도시는 남도 요금을 내고 쓴다 (§6.1).
- 공통 시스템 ⑦ 연구(`../20_Core_Loop.md` §7.1)에 우주 기술 단계가 생긴다 (D-370 해석).

### 1.3 출시 범위의 방향 (D-372)

| 시기 | 범위 |
|---|---|
| 출시 | 지구 하나 + 모항 강하·환생 연출 |
| 출시 뒤 큰 업데이트 후보 (순서는 운영 지표, D-407) | 우주층: 항성계 화면·함선·우주 건물·우주 전투. 새 행성(D-365)과 정기선(D-371)도 함께 연다 (해석) |
| 처음부터 | 데이터 구조: 행성 ID, 영역 4종 |

- Step 8에서 정했다: 우주층은 출시 뒤 후보이고 순서는 운영 지표로 정한다 (D-407, `../90_Roadmap.md` §6).

## 2. 규모와 천체 (D-360, D-366, D-367, D-383, D-365, D-368)

### 2.1 여러 항성계 (D-360, D-055)

- 계층은 은하 → 항성계 → 행성이다 (D-055). 우주는 **스타게이트로 잇는 여러 항성계**다 (D-360).
  - 처음에는 태양계와 몇 개로 시작한다. 운영자가 편집기로 항성계를 더한다.
  - 이동은 **EVE식 3층**이다 (D-385, EVE Online 참고).

    | 길 | 무엇 | 누가 놓나 |
    |---|---|---|
    | 함선 워프 | 항성계 안에서 함선이 스스로 워프한다 (추진기, D-362) | — |
    | 스타게이트 | 항성계 사이를 잇는 고정 게이트. 항성계 그래프의 연결선이다. 우주 건물이 아니다 | 운영자 (지도 데이터) |
    | 워프게이트 | 두 게이트 사이를 빠르게 잇는 지름길. 주인이 통행료·허가를 정한다. 우주 건물이라 공성 대상이다 | 유저·NPC (정거장 모듈, D-353) |

- 손으로 만드는 항성계마다 콘텐츠가 필요하다 (D-360 영향). 기술 첫 구현(우리은하 + 태양계)이 출발점이 된다 (해석).
- 은하지도 화면은 기술 기본안을 받는다: 점·연결선 그래프, 위에서 본 2D, 첫 구현은 개발자 도구 (D-381 100).
- 항성과의 거리는 편집기 편의 기능(궤도 거리·항성 밝기로 평균 기온 제안)에만 쓴다. 게임 중에는 계산하지 않는다. 거주 가능 구역 밖 행성의 별도 규칙은 없다 (D-381 101).

### 2.2 천체의 정체와 이름 (D-366, D-082 ④)

| 범위 | 정체 | 화면 이름 |
|---|---|---|
| 태양계 | 실제 천체(달·화성·금성 등)를 정원사가 꾸며 바뀐 모습 (D-082 ④ 다른 정원) | 별칭 + 실명. 예: "붉은 정원(화성)" |
| 다른 항성계 | — | 가상 이름 |

- 실존 지명 금지(D-015·R9)는 지구 위 지명의 범위다. 천체 이름은 예외다 (D-366 해석, D-055).
- 개척 이주 외계 행성(D-051 기각안)이 아니다. 정원사가 만든 정원이라는 틀을 지킨다 (D-366 해석).
- 편집기 샘플의 실명은 그대로 써도 된다 (D-381 102).
- 별칭 목록은 Step 5 2부(우주 콘텐츠)다.

### 2.3 행성 크기와 종류 (D-367, D-327, D-383)

- 행성 크기는 **편집기에서 면 레벨 4~9 가운데 자유롭게** 고른다 (D-367, 추천안 아님).
- 기획자 해석 (정정 가능, D-367)
  - 국가 수 표(S19)는 레벨 4~9 모두에 값을 둔다. 아주 작은 행성(레벨 4~5)은 국가 0~1개가 된다.
  - 시작 도시(기본 NPC 국가)가 없는 행성은 첫 접속 강하 목록(§2.4)에 뜨지 않는다. 함선으로만 가는 개척지가 된다.
- 국가 수는 행성 크기에 따르고, 성향은 행성마다 무작위다 (D-327, `46_Faction_Society.md` §9.3).
- **가스 행성**(목성·토성·천왕성·해왕성)은 **우주 자원 채취지**다 (D-383).
  - 정착할 땅이 없고 우주층만 있다(육지·하늘·해상 없음). 우주층은 영토 주장 건물로 다툰다 (D-378).
  - 그 위성(달)은 별도 천체이고, 행성처럼 정착할 수 있다.
  - 이름은 정원 별칭 + 실명 규칙(D-366)을 따른다 (D-383 영향). 채취 자원은 §7.3이다.

### 2.4 새 행성을 여는 방식 (D-365)

새 행성·항성계는 **운영자가 열고 추천 표시**를 한다 (D-365).

1. 운영자가 서버 지표(유저 수·땅 포화·유닛 예산)를 보고 연다.
2. 편집기로 NPC 국가를 배치해 공개한다. 공개하면 설정이 잠긴다 (D-156).
3. 세계 소식으로 알린다.
4. 첫 접속 강하 목록에 새 행성이 "추천·정착 지원금 높음"으로 뜬다.

- D-006의 미결 "늦게 합류한 유저의 진입 경로"를 닫는다. 월드 확장 = 운영자가 여는 새 행성이다 (D-365).
- 첫 접속 흐름(D-140)에 행성 고르기가 들어간다 (D-365 해석).
- 새 행성은 영구다. 시즌 행성은 없다 (D-007·D-7026).
- 공개 행성마다 기본 NPC 국가와 시작 도시(D-324·D-325)를 둔다 (D-365 해석). 시작 도시가 없는 작은 행성은 강하 목록에서 빠진다 (D-367 해석, §2.3).
- 정착 지원금 계수는 행성마다다 (D-365 기술 전달, D-218).

### 2.5 이동 시간 (D-368)

- 행성 간 이동은 **30분 이내**가 알맞다. EVE처럼 1~2분이면 은하가 아주 커야(항성계가 많아야) 거리감이 생긴다 (D-368 원문 "워프게이트이므로 단축하는게 맞으나 이브처럼 1~2분이면 은하계가 커야함 30분 이내가 적당할듯").
- 기획자 해석 (정정 가능, D-368)
  - 발사·워프·강하를 합쳐 한 행성에서 이웃 행성까지가 30분 이내다.
  - 다른 항성계는 게이트마다 시간이 더해진다.
  - 모두 설정값이다 (D-5032).
  - 물류 가속(D-7032)을 허용할지는 BM 규칙대로다.

## 3. 모항과 사이보그 (D-350, D-351, D-352, D-353, D-355)

### 3.1 모항 = 스타팅 정거장 (D-350, D-355, D-361, D-375)

- 모항은 사이보그가 출발하는 지구 궤도 정거장이다 (D-052). D-350의 "스타팅 모함"을 모항으로 읽었고(해석), 사용자가 이 해석을 적은 선택지를 골랐다 (D-355).
- 모항은 **우주층의 실제 건물**이고 우주 건물의 하나다. 걸어다니는 허브 맵은 아니다. 항성계 화면에서 조작하는 건물이다 (D-350 해석).
- 정거장 인류(고정 NPC) 소유다. **파괴·점령할 수 없다.** 시작 도시와 같은 원칙이다 (D-355, D-341).
- 파괴되지 않는 근거는 **고보안**이다 (D-361, §8.2).
- 지구 우주층의 주인은 정거장 인류이고 바뀌지 않는다 (D-375).

### 3.2 귀환 (D-351, D-173, D-381 108)

- 사이보그가 지거나 쓰러지면 **즉시 귀환**하고 짧은 연출만 둔다 (D-351).
  - 화면이 하얗게 바뀌며 "의식 백업 복원 중" 2초, 가까운 안전 도시로 돌아온다.
  - 우주나 안전 도시가 없는 천체(개척 행성·가스 행성 등)에서 지면 **모항**으로 돌아간다 (D-388).
  - 손실은 D-173(화물 일부·내구도)만이다. 대기 시간·재강하 비용은 없다.
- 평일 짧은 접속(D-010)에 맞는다. 귀환 대기를 줄이는 가속 상품은 생기지 않는다 (D-351 해석, D-7032).
- 패배한 다른 유닛도 사이보그와 같은 때 안전 도시로 바로 옮긴다. 전쟁이면 지금처럼 포로가 된다 (D-381 108, `45_Combat.md` §8·§10.5).

### 3.3 환생과 외형 (D-352)

- 환생할 때 **외형(얼굴·색 등)을 다시 고를 수 있다.** 무료다 (D-352).
- 그 밖의 때 외형을 바꾸는 것은 계정 서비스다 (D-7032).
- 인공장기는 그대로이고(D-026), 예비 몸은 없다(D-096).

### 3.4 정거장의 서비스 모듈 (D-353)

- 정거장은 **서비스 모듈을 설치하는 우주 건물**이다. 예: 우주선 유지보수·수리, 휴게소 같은 서비스, 다른 행성으로 가는 워프게이트(지름길, D-385) (D-353 원문 "우주선 유지보수 수리? 휴게소 처럼 다양한 서비스 모듈 설치가능. 다른 행성이동위한 워프게이트 등").
- 기획자 해석 (정정 가능, D-353)
  - 정거장은 모듈을 끼우는 틀이다. 어떤 모듈을 끼우느냐로 역할이 바뀐다 (EVE Online의 구조물 서비스 모듈 참고).
  - 서비스 요금은 시설 소유자 수입이다. NPC 시설이면 사라진다 (D-169·D-311과 같은 원리).
  - 환생·몸 교체도 모항의 서비스 모듈로 둘 수 있다.
  - 인공장기는 공학자가 만든다(D-114). D-052의 "인공장기 공급원" 제안은 쓰지 않는다.
- 우주 건물의 모듈은 **연료**를 태워 돈다. 연료가 떨어지면 서비스가 멈춘다 (D-387). 연료는 가스 행성에서 채취한다 (D-383).

## 4. 우주 건물 (D-350, D-353, D-355, D-361, D-375, D-378)

### 4.1 누가 짓고 무엇이 있나 (D-355)

- 우주 건물은 **유저·NPC 세력 모두** 짓고 갖는다 (D-355). NPC 세력도 같은 규칙으로 짓는다 (P0).
- 자재는 지상에서 올려 보낸다 (D-355). 오르내림은 우주공항으로 한다 (§6).
- 종류: 정거장, 창고, 영토 주장 건물, 워프게이트 등. 모항도 그 하나다 (D-350, D-355).
- D-058이 "별개의 게임 오브젝트"로 남긴 PLAN §5.1의 항성계 오브젝트 가운데 정거장·영토 구조물이 이 우주 건물들이다 (D-350 해석). 스타게이트는 운영자 지도 데이터다 (D-385·D-388).
- **지구 궤도에도** 유저가 창고·정거장·조선 모듈 같은 우주 건물을 짓는다. NPC에 임대료·세금을 낸다. 고보안이라 안전하게 우주를 시작한다. 영토 주장 건물만 지을 수 없다 (D-386).
- **우주 세금**: 우주 건물은 그곳 영토 주장 건물(행성 우주 정부)에 세금을 낸다 (D-386 사용자 덧붙임). 세금은 그 행성 우주층 영토 주장 건물 주인에게 가고, 지구는 정거장 인류(NPC)라 사라진다. 영토 주장 건물이 없는 우주층에는 세금이 없다. 세율은 주인이 정한다 (D-386 해석).
- 우주 건물은 모듈 칸을 가진다 (D-353 기술 전달). 건물 에디터(D-5044)의 대분류로 더한다 (D-355 해석).
- 우주 건물은 공성 대상이다 (D-354, §8.1).

### 4.2 영토 주장 건물 (D-361, D-375, D-378)

사용자 원문: "영토주장건물을 지어야 소유인것이다 행성마다 1개만 가능하다" (D-378)

| 규칙 | 결정 |
|---|---|
| 우주층은 **영토 주장 건물을 지어야** 소유가 된다 | D-378 |
| 영토 주장 건물은 **행성(천체)마다 1개만** 지을 수 있다 | D-378 |
| 세운 세력은 그 우주층의 채굴·건설·세금 권한을 갖고, 업그레이드 모듈을 끼운다 (EVE Online의 주권 허브 참고) | D-361 |
| 건물이 무너지면 주인이 없다 | D-378 기술 전달 |
| 지구 우주층은 정거장 인류의 건물이 있고 바뀌지 않는다. 고보안(지구)에는 지을 수 없다 | D-375, D-380 영향 |

- 기획자 해석 (정정 가능, D-378)
  - 새 행성의 우주층은 처음에 주인이 없다. 먼저 영토 주장 건물을 세운 세력이 갖는다.
  - 이미 건물이 있으면 다른 세력은 그 건물을 공성으로 무너뜨린 뒤에 세울 수 있다 (D-354).
  - 그 행성의 NPC 국가도 같은 규칙으로 경쟁한다 (P0).
- 저보안에서도 지을 수 있다 (D-380 영향, 해석, 정정 가능). D-361 원문은 "무법 구역에" 세운다고 적었다.
- 예: 새로 열린 행성의 우주층에 주인이 없다. 하늘세력이 먼저 영토 주장 건물을 세워 주인이 된다. 바다세력이 이 우주층을 가지려면 그 건물을 공성으로 무너뜨린 뒤 자기 건물을 세운다 (D-378 해석).

## 5. 함선 (D-356, D-358, D-362, D-363, D-370, D-377)

### 5.1 함급 (D-356)

- 우주선은 **EVE Online처럼 여러 함급**이 있다 (D-356 원문 "이브온라인 참고좀 하라고. 광물채집선이나 프리깃 DD CV 등등 다양한 전함급, 운송선도 당연히 있고").
  - 채집: 광물 채집선. 전투: 프리깃, 구축함(DD), 항공모함(CV) 등. 운송: 운송선.

- 함급은 데이터다. 함급마다 역할(채집·전투·운송·지원)과 크기가 있다 (D-356 해석, 정정 가능).

### 5.2 조종수 (D-358)

- 함선은 **운송 수단과 같이** 조종수가 몬다. 조종수는 사이보그, 휴먼, 안드로이드가 될 수 있다. **크리쳐는 안 된다** (D-358 원문 "운송수단과 동일하게 사이보그뿐만아니라 유닛이나 안드로이드가 조종수가 될 수있음. 크리쳐는 안됨").
- 기획자 해석 (정정 가능, D-358)
  - 함선은 운송 수단의 한 종류로 다룬다. 운송 수단 거래소(D-271)에서 사고판다.
  - 조종수의 스킬·스탯이 성능을 보정한다 (운송 수단 규칙과 같음).
  - 큰 함급의 승무원 수는 함급 데이터다.

### 5.3 조립식 (D-362)

- 사용자 원문: "조립식으로 가자 우선은 함급/외형을 제작하여 바디를 만들고, 모듈을 넣는 방식(무기나 쉴드, 아머, 특수장비, 창고, 유닛창고 등), 필수모듈은 추진기랑 cpu?같은거? 알아서 추천" (D-362)
- 함선은 **조립식**이다.
  1. 함급·외형을 정해 **바디(선체)**를 만든다.
  2. 바디에 **모듈**을 넣는다.
  3. **필수 모듈**이 있어야 한다.

**필수 모듈** (기획자 추천, 사용자 위임 "알아서 추천", 정정 가능)

| 필수 모듈 | 하는 일 | EVE 대응 (참고) |
|---|---|---|
| 추진기 | 속도와 워프 가능 여부. 없으면 움직이지 못한다 | 추진·워프 드라이브 |
| 동력로 | 동력 공급량. 모든 모듈의 동력 소비 합이 이 값을 넘지 못한다 | 파워그리드 |
| 제어 코어 (CPU) | 연산 공급량. 모듈의 연산 소비 합이 이 값을 넘지 못한다. 조종수가 함선을 다루는 자리 | CPU |

**조립 규칙** (기획자 추천, 정정 가능)

- 바디(함급)는 **모듈 공간**(부피)과 필수 모듈의 크기 한계를 정한다. 큰 함급일수록 공간이 크고 느리다.
- 모듈마다 {공간, 동력 소비, 연산 소비}가 있다. 세 한도 안에서 자유롭게 넣는다.
- 그래서 같은 구축함도 채굴용·전투용·운송용으로 달라진다.
- EVE의 칸 종류 구분 대신 공간·동력·연산 세 한도로 묶었다 (기획자 해석).

| 선택 모듈 | 예 |
|---|---|
| 무기 | 포·미사일·함재기 격납고 |
| 방어 | 방어막(쉴드), 장갑(아머) |
| 특수 장비 | 채굴기·전자전·수리·탐사 |
| 창고 | 화물 |
| 유닛 창고 | 사이보그·휴먼·안드로이드·크리쳐를 태운다 |

- 바디와 모듈은 생산품이다. 공학자·제작 경로가 만들고 거래소에서 사고판다 (D-362 해석, D-008).
- 모듈 교체는 정거장의 정비 모듈에서 한다 (D-362 해석, D-353).
- 함선 바디는 우주공항의 조선 시설이나 정거장의 조선 모듈에서 만든다 (D-363 해석, 정정 가능). 연구 단계·비싼 자재(D-370)와 우주 전용 광물(D-377, §7.3)이 필요하다.
- 함선은 정거장에서 수리한다 (D-356 해석, D-353).
- 수치는 모두 설정값이다 (D-5032). 모듈 목록은 Step 5 2부다.

## 6. 지상과 우주 (D-363, D-370, D-371, D-376, D-382)

### 6.1 우주공항 (D-363, D-370)

- 행성에 **우주공항**을 짓는다. 우주공항에서 유닛·자원을 **넣었다 뺐다** 하고, 우주정거장으로 **쏘아 올린다** (D-363 원문 "우주공항같은걸로 만들자 행성에서 유닛이나 자원같은걸 넣었다 뺐다하고 우주정거장으로 쏘아올리는 과정 존재.").
- 기획자 해석 (정정 가능, D-363)
  - 우주공항은 교통 대분류 건물이다 (D-5044).
  - 1차맵에서 우주공항 도시를 눌러 궤도 정거장과 노선을 잇는다 (D-106과 같은 방식).
  - 쏘아 올리기·내려오기는 예약 이동이다. 걸리는 시간은 설정값이다.
  - 우주공항이 없는 곳에서는 오르내리지 못한다. 그래서 우주공항 도시가 전략 요충지가 된다.
  - 우주공항은 공성 대상이고, 내구도가 낮으면 운행이 멈춘다 (D-198과 같은 원리, `45_Combat.md` §11).
- 우주공항이 있는 도시는 **남도 요금을 내고** 쓸 수 있다 (D-370). 요금은 시설 소유자 수입이다 (D-122와 같은 원리, 해석).

### 6.2 궤도와 지상은 우주공항으로만 (D-376)

- 궤도와 지상은 **우주공항으로만** 이어진다. 궤도에서 지상을 직접 치지 못한다 (D-376).
- **봉쇄**: 궤도를 쥐면 그 행성의 우주공항·정기선 통행을 막거나 허락한다 (D-376).
- 지상 전쟁은 지상에서 한다. 지상 전투 규칙은 그대로다 (D-376).
- 허가를 주는 쪽은 그 행성 우주층의 소유 세력이다 (D-376 기술 전달). 소유는 영토 주장 건물로 정한다 (D-378).
- 엔드게임 세력이 우주에서 강해도 지상 세력을 바로 짓누르지 못한다 (D-376 영향).
- 봉쇄는 행성 간 물류(D-357·D-371)를 끊는 전략이 된다 (D-376 영향).
- **NPC 정기선도 봉쇄 대상**이다. 사용자가 고른 문구대로다 (D-388, D-376 영향의 예외 해석을 정정). 지구 정기선은 지구가 NPC 소유라 늘 다닌다.

### 6.3 NPC 정기선 (D-371)

- 함선이 없는 유저는 **NPC 정기 여객·화물 노선**으로 다른 행성에 옮겨 간다 (D-371, 추천안 아님).
  - 정거장 인류가 운영한다. 누구나 유닛·화물도 옮긴다.
  - 요금은 사라진다(소멸처). 비싸고 느리다.
- 기획자 해석 (정정 가능, D-371)
  - "느리다"는 유저 함선보다 느리다는 뜻이다. 행성 간 30분 이내라는 느낌(D-368)을 크게 넘지 않게 설정값을 둔다.
  - 정기선의 화물도 총량 자원 이전 규칙(D-359, §7.2)을 따른다.
  - 정기선은 습격 대상이 아니다 (정규 노선 D-198과 같음). 봉쇄는 받는다 (D-388).
  - 정기선은 시작 도시가 있는 공개 행성의 시작 도시에 내린다 (D-388).
  - 우주가 엔드게임(D-369)이라는 것은 함선·우주 건물·우주 전투 이야기이고, 정기선은 그 밖의 공공 서비스다.
- 정기선 요금은 화폐 소멸처가 하나 더 생기는 것이다 (D-169). 유저 운송업자가 정기선보다 싸고 빠르면 시장이 생긴다 (해석).

### 6.4 해상 이동 도시 (D-382)

떠다니는 국가는 **이동 도시**다 (D-382, 사용자 아이디어 원문 "항공모함처럼 떠다니는 국가개념", 기술 질문 103 가).

| 항목 | 규칙 |
|---|---|
| 모습 | 바다 위의 거대 함선형 도시 1개. 건물은 정해진 칸 안에 짓는다 |
| 정박 | 일반 도시처럼 영향권·세금·생산이 있다 |
| 이동 | 영향권이 없고 생산이 제한된다. 느리게 움직인다 |
| 여는 길 | 후반 연구 |
| 전투 | 해상층에서 공성 대상이다 |

- 기획자 해석 (정정 가능, D-382)
  - 이동 도시도 도시라 세력·국가 규칙(46)을 그대로 따른다. 정박한 자리에 다른 도시의 영향권이 있으면 정박할 수 없다 (영향권 겹침 금지, D-104 원리).
  - 이동은 예약 이동이고, 오프라인에도 계속된다 (D-061).
  - 건물 칸 크기는 2차맵 하나 안이라는 원칙(D-102)을 따른다.
  - **우주의 함선·우주 건물과 따로다.** 우주에서 떠다니는 도시는 아니다.
- 도시·영향권 규칙은 `42_Map_Territory.md` §2, 세력 규칙은 `46_Faction_Society.md`가 정본이다.
- 기술 영향이 크다(움직이는 건물 묶음). 출시 뒤 후보다 (D-407). 이동 속도·칸 수·정박 규칙 값은 설정값이다.

## 7. 행성 간 이동과 자원 (D-357, D-359, D-377, D-383)

### 7.1 무엇이 넘나드나 (D-357)

- 워프게이트로 행성 사이를 오갈 때 **사이보그·유닛·화물이 모두** 넘나든다. 우주선에 실으면 모두 간다 (D-357).
- 행성 특산 교역·원정이 생긴다. 단일 월드 통합 경제(D-006)가 행성 사이로 넓어진다 (D-357 영향).
- 운송업자·무역상 경로의 무대가 커진다. 행성 간 힘의 불균형은 이동 시간·비용·위험으로 조절한다 (D-357 해석).

| 길 | 누가 | 결정 |
|---|---|---|
| 함선 | 함선을 가진 유저·NPC. 항성계 안은 워프, 사이는 스타게이트, 지름길은 워프게이트 (§2.1). 큰 함급은 항성계 사이 이동에 연료를 쓴다 (D-387) | D-357, D-360, D-385 |
| NPC 정기선 | 누구나 (요금 소멸, 비싸고 느림) | D-371 |
| 모항 강하 | 첫 접속 사이보그 (새 행성이 열리면 행성을 고름) | D-365, D-369 해석 |

### 7.2 총량 자원이 행성을 넘나들 때 (D-359)

- 사용자 원문: "A에서 B로 x만큼 운송됨. 총량은 모두 그대로 이나 B는 채굴된양이 x만큼 증가 A는 채굴량이 x만큼 감소하면 되는가? / 아주 극한의 상황에서 총량을 초과하거나 음수가 될수있어도 회귀되는 양과 채굴확률 보정으로 결국 정상범위로 돌아올듯." (D-359)
- 행성(천체)마다 총량은 **그대로** 둔다.
- 총량 자원이 행성 A에서 B로 x만큼 실려 가면 **B의 채굴된 양(보유량)이 x 늘고, A의 보유량이 x 준다.** 남은 매장량은 바뀌지 않는다.
- 극한 상황에서는 한 행성의 (남은 매장량 + 보유량)이 총량을 넘거나 음수가 될 수 있다. 소비되어 매장량으로 **돌아오는 양과 채굴 확률 보정**으로 결국 정상 범위로 돌아온다.
- 기획자 판단(사용자가 "되는가?"라고 물음): **된다.** 출처 꼬리표가 필요 없고, 서버 전체 합계는 늘 맞는다 (D-359).

**예** (D-359에 적은 예시. 수치는 예시다)

| 시점 | 붉은 정원 | 지구 |
|---|---|---|
| 처음 | 금 총량 1,000 = 남은 매장량 600 + 보유량 400 | 자기 총량 |
| 금괴 100을 지구로 실어 감 | 보유량 300. 합 900으로 총량보다 100 모자람 → 채굴 확률이 오른다 | 보유량 +100. 합이 총량보다 100 많음 → 채굴 확률이 내려간다 |
| 그 뒤 | — | 지구에서 쓰인 금은 지구 매장량으로 돌아온다. 지구는 채굴이 줄어 차이가 천천히 메워진다 |

- 소행성대·달도 하나의 천체로 자기 총량을 가진다 (D-359 해석).
- D-112·D-116의 행성마다 "총량 = 남은 매장량 + 모든 보유량"은 천체 단위로는 잠시 깨질 수 있고, 서버 전체 합계로 맞는다 (D-359 영향).
- 행성마다 금값이 다를 수 있고, 그 차이가 행성 간 무역의 동기가 된다 (D-359 해석).
- 채굴 확률 보정 곡선은 설정값이다. 49의 P3 근처에 칸을 더한다 (D-359 영향).
- 총량 자원의 기본 규칙(두 갈래, 채굴 감쇠, 회귀)은 `43_Production.md` §1, 총량 변경은 D-333이 정본이다.

### 7.3 우주에서 캐는 자원 (D-377, D-383, D-373)

- 소행성대·달에서 캐는 자원은 **기존 광물 + 우주 전용 광물**이다 (D-377).
  - 철·구리·금 같은 기존 광물도 나온다.
  - 함선 바디·고급 모듈·우주 건물에 꼭 필요한 **우주 전용 광물**이 있다. 우주에 갈 이유가 생긴다.
  - 단 작은 함급(채집선·운송선·프리깃 등)의 바디와 기본 모듈은 지상 재료로 만든다. 우주 전용 광물은 큰 함급 바디·고급 모듈·큰 우주 건물에 필요하다. 그래서 첫 함선을 만들 수 있다 (D-388).
  - 천체마다 총량을 가진다 (D-359).
- 채굴은 채집선 모듈(D-362)로 한다 (D-377 기술 전달).
- 가스 행성에서는 **가스 채집 모듈**로 우주 전용 자원(연료·고급 모듈 재료)을 채취한다 (D-383, EVE Online의 가스 채취 참고). 연료는 우주 건물 모듈 유지와 큰 함급의 장거리 이동에 쓴다. 작은 함선의 평소 이동에는 들지 않는다 (D-387). 우주 전용 자원에 가스가 들어가고, 가스 행성도 천체마다 총량을 가진다 (D-383 해석).
- 생산 단계(D-114)에 우주 원료가 들어간다 (D-377 해석).
- 1차맵 하늘의 달은 연출이고, 항성계 화면의 달은 채굴할 수 있는 천체로 따로 있다 (D-373).
- 우주 전용 광물의 목록·제련 단계는 Step 5 2부다.

## 8. 우주 전투·치안·영토 (D-354, D-361, D-375, D-378, D-380)

### 8.1 우주 전투 (D-354)

- 우주층에도 **전투가 있고, 지금과 같은 전투 규칙**을 쓴다 (D-354). 새 전투 체계를 만들지 않고 층만 늘린다.
- 우주는 하늘·바다처럼 하나의 영역이다. **우주를 다닐 수 있는 유닛(우주선)만** 우주의 대상을 습격한다 (D-202와 같은 원리).
- 자동전투·전투맵·개입 규칙은 `45_Combat.md`를 그대로 쓴다. 우주 전투맵은 그 위치의 우주 타일로 만든다 (D-354 기술 전달).
- 우주 건물은 공성 대상이다. 공성 규칙은 `45_Combat.md` §10이다 (D-354).
- 기획자 해석 (정정 가능, D-354)
  - 무법자 경로에 우주 해적이 생긴다.
  - 정규 노선은 습격 대상이 아니라는 규칙(D-198)은 우주 정규 노선에도 같다.
  - 공성 시각·예고(D-185·D-200)는 우주 건물에도 같다.
- 궤도에서 지상을 직접 치지 못한다 (D-376, §6.2).

### 8.2 보안 등급 (D-361, D-380)

우주는 **보안 등급 + 영토 주장**이다 (D-361). 보안 등급은 **모항에서 멀수록 낮아진다** (D-380). 사용자 덧붙임: "보안등급으로 스타팅 포인트가 파괴되지 않게 한다." (D-361)

| 등급 | 어디 | 경비 | 결정 |
|---|---|---|---|
| 고보안 | 지구 우주층 (모항 둘레) | 정거장 인류 경비가 공격자를 응징한다 (시가지 보호 D-146과 같은 원리) | D-361, D-380 |
| 저보안 | 태양계의 다른 행성 | 경비가 늦게 오거나 일부만 응징한다. 정도는 설정값 | D-380 |
| 무법 | 다른 항성계 | 개입 없음 | D-380 |

- 보안 등급이 모항을 지킨다 (D-361). 멀수록 위험과 보상이 커진다 (EVE Online처럼). 운영자가 행성마다 등급을 바꿀 수 있다 (D-380).
- D-361의 "모항 둘레·시작 항성계는 고보안"은 D-380이 지구 우주층만 고보안으로 좁혔다. 보안 등급의 단위는 천체다 (D-388).
- 정원사 우주 함대는 고보안에도 올 수 있고, 경비가 맞선다. 모항은 파괴·점령되지 않는다 (D-388, D-355).
- 신규 유저는 고보안에서 안전하게 시작한다 (D-307 신규 보호와 함께, D-361 해석).
- 악명(D-305)은 우주에서도 같다 (D-361 해석).

### 8.3 우주 영토 (D-375, D-378, D-361, D-376)

- 우주 영토의 단위는 **행성(천체)의 우주층**이다. 행성마다 소유권을 가질 수 있다 (D-375 원문 "우주는 행성 하나의 레이어로 하나의 행성마다 소유권을 가질수있음. 스타팅 행성 지구는 NPC 소유 불변").
- 소유는 영토 주장 건물(행성마다 1개, §4.2)로 정한다. 주인은 채굴·건설·세금 권한(D-361)과 봉쇄 권한(D-376, §6.2)을 갖는다 (D-378).
- 한 항성계에 여러 세력이 행성마다 나눠 가진다 (D-375 해석). 항성계 단위 소유는 없다 (D-381 100).
- **스타팅 행성 지구의 우주층은 NPC 소유로 바뀌지 않는다** (D-375).
- 땅 위 영토(도시의 영향권)는 `42_Map_Territory.md` §2가 정본이다.

## 9. 정원사 모함과 우주의 정원사 (D-364, D-379, D-321)

웨이브의 원인·빈도·예고·도착 규칙은 `45_Combat.md` §2.4, 정원사 세력 규칙은 `46_Faction_Society.md` §8이 정본이다. 이 절은 우주 쪽 규칙만 적는다.

### 9.1 모함 (D-364, D-379)

- 정원사 모함은 **정원이 있는 행성마다 1척**이다 (D-379). 항성계 화면에 보이는 거대 오브젝트다 (D-364).
- 그 행성의 웨이브·유목 부대·정원사 우주 함대가 그 모함에서 나온다 (D-379). 웨이브·유목 부대가 모함에서 내려오는 연출이 있다 (D-364).
- 판정은 지금처럼 오염·세력 규모를 쓴다 (D-364, D-188·D-192·D-322). 모함은 생성 위치의 연출이다 (D-379 기술 전달).

### 9.2 모함 강습 (D-364, D-379)

- 정원사 **모함도 강습할 수 있다** (D-364, 추천안 아님).
- 최상위 세력 연합이 모함을 강습하는 서버 사건이다 (EVE Online의 인커전 참고). 참가는 누구나 할 수 있고, 기여도로 보상을 나눈다. "최상위"는 강습이 어렵다는 뜻이다 (D-388).
- 이기면 일정 기간 **그 행성만** 웨이브가 줄어 편해진다 (D-364 → D-379).
- 엔드게임 목표다 (D-364 영향, D-369).
- 기획자 해석 (정정 가능)
  - 모함은 강습에 져도 사라지지 않고 일정 기간 약해진다. 정원사는 늘 남는 압박이다 (D-364, D-085·D-321).
  - 큰 세력이 유리한 위험은 참가자 기여도로 보상을 나눠 줄인다 (D-364 기획자 제안).
  - 지구 모함도 강습할 수 있다. 강습은 서버 사건이고 보안 등급과 상관없다. 정원사는 늘 적대다 (D-379, D-321).
  - 개인 스토리에서 모함 안으로 들어가는 장면(D-278)은 그대로 둘 수 있다 (D-364).
- 강습 규모·주기·보상은 Step 5 2부다.

### 9.3 정원사 우주 함대 (D-364, D-379)

- 오염·전쟁이 큰 항성계에는 **정원사 우주 함대**가 순찰·습격한다. NPC 적대다 (D-364).
- 함대는 오염·전쟁 지표로 생긴다. 상한은 모함 몫(S16) 안이다 (D-364 기술 전달).
- 모함 몫은 행성마다 나눈다 (D-379 해석, 기술 기본안 G2와 같음).
- 정원사와는 외교가 없다. 늘 적대다. 우주에서도 그대로다 (D-321, D-364).

- 영역·출시 (D-350, D-354, D-372): 이동·위치 영역 = {우주, 하늘, 육지, 해상}. 영역 4종과 행성 ID 구조는 처음부터 둔다. 출시 범위 = 지구 + 모항 연출. 항성계 화면 = 우주층의 조작 화면(PLAN §5.1의 가벼운 화면을 넘어섬). 항성계 오브젝트 타입에 건물(모항·영토 주장·창고·정거장 등)을 넣는다
- 항성계·행성 데이터 (D-360, D-365 ~ D-367, D-381, D-385): 항성계 = {항성, 천체 목록, 스타게이트 연결}. 이동 = {항성계 안 워프(함선 추진기), 스타게이트 통과(운영자 데이터), 워프게이트 통과(우주 건물 모듈, 주인 통행료·허가)}, 모두 예약 이동 사건. 항성계 편집기(PLAN 편집기 3단계). 행성 이름 = {별칭 ko·en, 실명 ko·en(선택)}, 첫 구현의 실명 데이터에 별칭 칸을 더한다. faceLevel 4~9, 레벨별 국가 수 표는 설정값, 시작 도시 없는 행성은 첫 접속 목록에서 뺀다. 행성 공개 = 편집기 공개 사건(설정 잠금) + 세계 소식 + 첫 접속 목록 갱신, 정착 지원금 계수는 행성마다. 은하지도 = 점·연결선 그래프(위에서 본 2D, 첫 구현은 개발자 도구). 항성 거리 = 편집기 편의 기능만, 게임 중 계산 없음
- 모항·사이보그 (D-351, D-352, D-355, D-375, D-381 108): 사이보그 패배 = 즉시 위치 이전(가까운 안전 도시, 우주·안전 도시 없는 천체면 모항, D-388) + 연출 사건, 대기 타이머 없음. 패배한 다른 유닛도 같은 때 안전 도시로(전쟁이면 포로). 환생 사건에 외형 재선택 단계(무료 1회), 평소 외형 변경 = 계정 서비스 상품. 모항 = 고정 NPC 소유 표시, 소유 이전·파괴 처리 안 함. 지구 우주층 = 고정 NPC 소유, 소유 이전 처리 안 함
- 우주 건물 (D-353, D-355, D-375, D-378, D-386, D-387): 우주 건물 = 건물 데이터(영역 = 우주, 소유 세력, 모듈 칸, 내구도), 건물 에디터(D-5044) 확장. 짓기 조건 = 그 천체의 보안 등급·소유(지구 = 영토 주장 금지, 그 밖 건물 허용). 우주 건물 세금 = 그 천체 영토 주장 건물 주인 계정으로(지구 = 소멸 계정). 모듈 = 연료 소비율, 연료 0 = 모듈 정지. 모듈 = 서비스 데이터(수리·휴식·워프 등). 우주 소유권 = 천체마다 {소유 세력, 영토 주장 건물}. 천체마다 영토 주장 건물 0~1개(서버 검증), 소유 = 그 건물의 세력, 건물이 무너지면 주인 없음
- 함선 (D-356, D-358, D-362): 함선 = 운송 수단 데이터의 영역 = 우주, 함급 데이터(역할, 크기). 조종수 조건 = 유닛 종류 ∈ {사이보그, 휴먼, 안드로이드}. 함선 = 바디(함급 데이터: 공간, 필수 모듈 크기 한계, 외형) + 모듈 목록. 모듈 데이터 = {종류, 공간, 동력 소비, 연산 소비, 효과}. 조립 검증 = 필수 모듈 3종 존재 + Σ공간 ≤ 바디 공간 + Σ동력 ≤ 동력로 + Σ연산 ≤ 제어 코어. 서버가 검증한다
- 이동·노선 (D-357, D-363, D-368, D-371, D-376): 워프 이동 = 함선의 예약 이동 사건(출발 게이트 → 도착 게이트), 실린 사이보그·유닛·화물의 위치가 함께 바뀐다. 우주공항 = 교통 건물(지상 영역), 발사 = 우주공항 → 궤도 정거장 예약 이동 사건(실린 유닛·화물 위치 이전), 1차맵 노선 데이터에 우주 노선 종류를 더한다. 발사·워프·게이트 통과·강하 시간 = 설정값, 출발값 합계가 이웃 행성 30분 이내. 정기선 = 고정 NPC 운송 노선(행성 간), 예약 이동, 요금 = 소멸 계정, 운행 주기·요금·시간 = 설정값. 우주공항 노선·정기선 운행 조건에 "그 행성 우주층 소유 세력의 허가"(정기선도 포함, D-388). 정기선 하차 = 시작 도시가 있는 공개 행성의 시작 도시. 궤도 → 지상 직접 공격 판정 없음
- 행성 종류 (D-383): 행성 데이터에 종류 {지면 행성, 가스 행성}. 가스 행성 = 우주층만(육지·하늘·해상 없음), 채취 자원 분포. 위성은 별도 천체
- 이동 도시 (D-382): 이동 도시 = 도시 데이터 + 위치가 바뀌는 건물 묶음(해상층). 상태 {정박, 이동}. 정박 = 일반 도시 판정(영향권·세금·생산), 이동 = 영향권 없음·생산 제한. 이동 = 예약 이동 사건
- 진입 조건 (D-369, D-370): 우주공항·함선 바디 건설 조건 = 연구 단계 + 자재 목록(설정값). 우주공항 이용 = 소유자가 정한 요금
- 자원 (D-359, D-377): 천체마다 총량 장부 {총량, 남은 매장량, 보유량}. 행성 간 운송 = 출발 천체 보유량 −x, 도착 천체 보유량 +x 원장 사건. 채굴 확률 = 곡선 하나(D-116 곡선과 D-359 보정을 합침, 입력·모양은 기술 기본안, D-388). 원장 경보 = 서버 전체 합계 불일치(천체 단위 차이는 설정 문턱 넘을 때만, D-6047 → D-388). 작은 함급 바디·기본 모듈 = 지상 재료, 우주 전용 광물 = 큰 함급·고급 모듈·큰 우주 건물(D-388). 서버 전체 불변식 = Σ총량 = Σ(남은 매장량 + 보유량). 천체 단위 값은 일시 초과·음수 허용. 천체 자원 분포 = 기존 자원 + 우주 전용 자원(데이터), 채굴 = 채집선 모듈
- 전투·치안 (D-354, D-361, D-380): 습격 가능 = 공격 유닛이 다닐 수 있는 영역에 대상이 있음. 우주 전투맵 = 그 위치의 우주 타일. 우주 건물 = 공성 규칙(45 §10) 적용. 천체마다 보안 등급 {고, 저, 무법}(운영자 변경 가능). 고보안 = 공격 판정 때 경비 NPC 개입 사건, 저보안 = 지연·일부 개입(설정값), 무법 = 개입 없음. 영토 주장 건물 = 구역 권한(채굴·건설·세금) + 업그레이드 모듈 칸
- 정원사 (D-364, D-379): 정원 행성마다 정원사 모함 오브젝트 1개(우주 건물과 같은 공성 틀, 고정 NPC, 파괴 대신 약화 상태와 기간). 웨이브·유목 부대·우주 함대 생성 위치 = 그 행성 모함(연출). 정원사 우주 함대 = 오염·전쟁 지표로 생성되는 NPC 함대(모함 몫 S16 안). 모함 몫 = 행성마다. 강습 사건 = 서버 사건, 참가자 목록과 기여도
- 하늘 (D-373, D-374): 하늘 연출 목록에 모항(이동하는 점광원)·정원사 모함(고리, 웨이브 사건 때 빛줄기)·강하 유성(강하 사건)·궤도 오브젝트 불빛(그 행성 우주층의 건물·함선 위치에서)·이웃 행성 점광원·우주 사건 섬광과 드문 이벤트를 더한다. 판정과 무관
