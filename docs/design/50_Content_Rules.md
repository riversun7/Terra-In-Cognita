## 1. 티어·등급 체계 (Step 5-1)

### 1.1 티어 (D-5001)

| 대상 | 척도 | 규칙 |
|---|---|---|
| 물건 (원자재·가공 재료·부품·완제품·요리·보석) | T0~T9 | 완제품의 티어 = 주재료의 티어 |
| 시설·건물 | Lv1~5 | 레벨별 최고 티어: Lv1 = T1, Lv2 = T3, Lv3 = T5, Lv4 = T7, Lv5 = T9 |
| 스킬 | 1~10등급 | 최대 등급 = min(3 + 사이보그 환생 횟수, 10). 합성 확률표는 D-030 |

- 상한(T9·Lv5·10등급)은 설정값이고 늘릴 수 있다.
- 실제로 만들 수 있는 티어 = min(시설 레벨의 최고 티어, 유닛 스탯이 연 티어) (해석, 정정 가능)
- `♻️ 재사용 후보: 1차 자원 T0~T9와 스탯 티어 해금` (`docs/GDD/Item/Consolidated_Item.md` ITM-10), `♻️ 같은 티어 규칙` (ITM-11)
- 이 티어와 다른 척도: 도시 등급(D-137), 크리쳐 등급(D-092), 랭킹 백분위 등급(D-041)

### 1.2 재료 품질과 완제품 성능 (D-5002)

- 재료(원자재·가공 재료·부품)는 품질 0~100(정수)을 가진다. 신선도는 식품 재료의 품질이 시간에 따라 떨어지는 것이다 (D-121, 해석).
- 완제품에는 품질 숫자가 없다. 아이템 프리셋마다 스탯 범위가 있다.
- 성능 위치 = 재료 품질의 가중 평균(레시피가 비중을 정함) + 시설·유닛 보너스 + 작은 난수
  - 예: T3 철검(물리 공격력 20~40), 철 70%·나무 30%, 철 78·나무 80 → 78.6 → 공격력 약 35

### 1.3 아이템 등급 (D-5003, D-5004)

- 등급은 제작 결과로 정해진다. 같은 프리셋 안에서 옵션이 서버 실제 백분위로 상위 몇 %인지가 등급이다.
- 티어와 등급은 따로다. T1 나무검도 최상급이면 신화다.
- 목표 등급을 고르지 않고, 제작 실패로 재료를 잃지 않는다.

| 단계 | 한국어 | 영어 (코드) | 색 | 예시 구간 (잠정) |
|---|---|---|---|---|
| 1 | 보통 | Common (`common`) | 회색 | 하위 50% |
| 2 | 고급 | Fine (`fine`) | 초록 | 상위 50% |
| 3 | 희귀 | Rare (`rare`) | 하늘 | 상위 25% |
| 4 | 영웅 | Epic (`epic`) | 보라 | 상위 10% |
| 5 | 전설 | Legendary (`legendary`) | 주황 | 상위 4% |
| 6 | 고대 | Ancient (`ancient`) | 금 | 상위 1% |
| 7 | 신화 | Mythic (`mythic`) | 무지개 | 상위 0.2% |

- 등급 점수 = 제작 직후 스탯마다 "범위 안 몇 %"의 평균 (D-5006). 수리로 줄어든 최대 내구도와 인챈트 옵션은 넣지 않는다.
- 실제 하루 1번 다시 매긴다. 새 물건은 직전 분포로 임시 등급을 받는다 (D-5007).
- 표본이 적을 때는 프리셋별 기준 분포(가상 표본)를 섞는다 (D-5007).
- NPC 장인의 물건도 표본에 들어간다 (P0, 해석).
- ⚠️ 위험: 남이 더 좋은 물건을 만들면 내 물건의 등급 표시가 내려간다 (D-5003).

### 1.4 소켓과 추가 장치 (D-5005, D-5008)

- 소켓 수는 만들거나 얻을 때의 등급으로 정해 끝까지 고정한다 (D-5008, 기획자 재량). 예(잠정): 보통·고급 0, 희귀·영웅 1, 전설·고대 2, 신화 3
- 옵션은 소켓에 보석을 인챈트해서 더한다. "등급별 추가 옵션 줄"은 쓰지 않는다 (D-5006).
- 제작자 각인 (유저·NPC 장인 이름)
- 낮은 티어 쓰임 보장: 높은 티어 레시피도 낮은 티어 재료를 일부 쓴다. 수리 재료(D-171)와 낮은 등급 유닛의 생필품(D-150)은 낮은 티어로 충분하다.
- 보석 인챈트 (D-5009): 기존 규칙 그대로다. `♻️ 후삽입 인챈트(소켓 보석)` (ITEM 2.5절)
  - 1·2·3번째 소켓의 성공률은 60·30·15%다.
  - 보석은 성공해도 실패해도 사라진다.
  - 실패하면 최대 내구도가 줄어든다. 강화와 같은 감소 풀을 나눠 쓴다.
- 보석은 T0~T9이고 어느 장비에나 넣는다 (D-5010). 보석의 티어·품질이 옵션 수치를 정한다 (해석).
- 🔄 미결: 옵션 목록, 보석 합성 규칙 (5-5)

## 2. 12속성 상성 (Step 5-2)

### 2.1 계열과 상성표 (D-5011, D-5013)

- 강화형은 기본형과 같은 계열이다.

  | 계열 | 기본형 (코드) | 강화형 (코드) |
  |---|---|---|
  | 물 | 물 `water` | 빙결 `frost` |
  | 불 | 불 `fire` | 폭렬 `blaze` |
  | 바람 | 바람 `wind` | 번개 `lightning` |
  | 땅 | 땅 `earth` | 크리스탈 `crystal` |
  | 빛 | 빛 `light` | 성 `holy` |
  | 어둠 | 어둠 `dark` | 사령 `necro` |

- 6×6 계열 상성표. 값은 rate다. +이면 방어자가 더 아프고, -이면 덜 아프다.

  | 공격 ↓ / 방어 → | 물 | 불 | 바람 | 땅 | 빛 | 어둠 |
  |---|---|---|---|---|---|---|
  | 물 | -0.02 | +0.05 | 0 | -0.05 | +0.05 | -0.05 |
  | 불 | -0.05 | -0.02 | +0.05 | 0 | +0.05 | -0.05 |
  | 바람 | 0 | -0.05 | -0.02 | +0.05 | +0.05 | -0.05 |
  | 땅 | +0.05 | 0 | -0.05 | -0.02 | +0.05 | -0.05 |
  | 빛 | -0.05 | -0.05 | -0.05 | -0.05 | -0.02 | +0.05 |
  | 어둠 | +0.05 | +0.05 | +0.05 | +0.05 | -0.05 | -0.02 |

  - 4원소 순환: 물 > 불 > 바람 > 땅 > 물. 큰 고리: 어둠 > 4원소 > 빛 > 어둠
  - `♻️ 재사용 후보: 기존 6속성 상성` (`terra-server/combat/constants.js` 194~225행, `formulas.js` 428~455행). "4원소 → 어둠 -0.10"만 -0.05로 바꿨다 (D-5013).
- 속성 항에는 하한이 있다(출발값 0.25배, 기존 "저항 75% 캡" ♻️). 수치는 2부.

### 2.2 계산 규칙 (D-182, D-5012, D-5014)

- 계열 값 = 기본형 값 + 강화형 값 × 2 (강화형 1점 = 기본형 2점). 계열마다 최대 30
- 공격 가산
  - 기본형 스킬은 기본형 값 × 스킬 계수
  - 강화형 스킬은 계열 값 × 스킬 계수
  - 예: 물 5 · 빙결 2, 계수 10%의 빙결창 → (5 + 4) × 10% = +90%
- 방어 상성 = 스킬의 공격 계열마다 Σ(rate × 방어자 계열 값)을 구한 뒤, 스킬 계수 비중으로 평균한다.
  - 예: "불 × 10% + 물 × 10%" 스킬로 바람 6 · 불 4인 방어자를 때리는 경우
    - 불 쪽 = +0.05 × 6 − 0.02 × 4 = +0.22
    - 물 쪽 = +0.05 × 4 = +0.20
    - 평균 +0.21
- 속성 항 = max(하한, 1 + 공격 가산 + 방어 상성). 다른 축(스탯 공격력·방어 감소·크리·스킬·버프)과 곱한다 (D-178).
- ⚠️ 위험: 계열 값이 최대 30이라 하한에 자주 닿을 수 있다. 예: 어둠 10 · 사령 10이면 4원소 공격에 -1.5다. 하한과 rate는 2부 수치에서 함께 맞춘다.

## 3. 크리쳐 데이터 규칙 ① — 아종·색·이로치·출현 (Step 5-3)

### 3.1 속성 아종 (D-5015, D-5021)

- 아종은 12칸 가운데 가장 큰 칸으로 정한다. 강화형 칸은 2배로 센다. 아종은 최대 12개다.
  - 예: 불 6 · 폭렬 1 · 바람 3 → 불 늑대
  - 예: 물 3 · 빙결 2 → 빙결 4 → 빙결 늑대
- 동점이면 종의 기본 속성을 고른다. 그래도 같으면 속성 코드 순서로 고른다.
- 종마다 허용 아종 목록을 둔다. 가장 큰 칸이 목록에 없으면 목록 안에서 고른다.
- 아종은 태어날 때 정해져 바뀌지 않는다.

### 3.2 시그니처 색 (D-5016, D-5019)

| 계열 | 기본형 | 강화형 |
|---|---|---|
| 물 | 하늘파랑 | 빙결: 얼음 민트·흰빛 |
| 불 | 주홍 | 폭렬: 진홍·노을빛 |
| 바람 | 연두 | 번개: 레몬노랑 |
| 땅 | 황토 | 크리스탈: 자수정 보라 |
| 빛 | 크림노랑 | 성: 백금·진주 |
| 어둠 | 라벤더 | 사령: 청록 유령빛 |

- 개체의 색 비율은 속성값 비율로 정한다(강화형 ×2).
  - `♻️ 원소 점유 비율별 시각 강도 60%·40%·20%·미세` (`docs/GDD/Consolidated_GDD.md` 160~165행)
- 정확한 색 코드는 화면 디자인 시스템과 아트 바이블에서 정한다.
- ⚠️ 사령의 청록은 기술 계열의 청록 금속(D-070 ②)과 비슷할 수 있다. 아이템 등급 색과 이로치 팔레트와도 겹치지 않게 맞춘다.

### 3.3 이로치 (D-5017)

- 모든 종·등급에서 태어날 때 낮은 확률(예: 1/500, 2부)로 나온다.
- 특수 팔레트(종마다 1개)와 반짝임 효과를 쓴다. 능력치는 같다.
- 교배하면 낮은 확률로 유전된다. 사냥꾼 보너스(D-049)를 받고, 도감에 따로 칸이 있다.

### 3.4 출현 분포 (D-5018, D-5020)

- 개발자 페이지에서 크리쳐·자원마다 분포를 정한다. 분포 하나 = 범위, 출현 확률, 포획 수량이다.
- 포획 수량을 다 쓰면 그 분포는 꺼진다. NPC 사냥꾼의 포획도 수량을 쓴다 (P0).
- 다시 켜지는 방식은 분포마다 개발자가 고른다. 예: 주기마다 리셋, 한 번만, 직접 켬, (제안) 다른 자리로 옮겨 켜짐
- 개발자 페이지는 개발자 친화적인 UI·UX로 만든다.
- ⚠️ P0: "한 번만"이나 "직접 켬"을 고르면 운영자가 없을 때 그 크리쳐가 사라질 수 있다. 편집기에 경고를 두는 안을 제안한다.

## 4. 크리쳐 데이터 규칙 ② — 분류·크기·생성·세트 (Step 5-4)

### 4.1 분류: 고정 칸과 태그 (D-5022, D-5026)

| 고정 칸 (규칙이 쓰는 값) | 값 | 쓰는 곳 |
|---|---|---|
| 등급 | 일반 · 희귀 · 보스 · 전설 · 신수 (D-092) | 출현 분포, 보상 |
| 크기 | S · M · L · XL (§4.2) | 통과 폭, 스탯 분포 |
| 속성 | 12칸 0~10 (D-182) | 아종(§3.1), 상성(§2) |
| 기원 | 자연종 · 신화종 · 정원사종 (D-092) | 정원사종의 적대(D-085) |

- 종류(계통)와 성향은 **태그**다. 한 종에 여러 개를 붙이고, 크리쳐 생성기에서 새 태그를 바로 만들어 넓혀 간다 (D-5026).
  - 예: 고양이과, 공룡, 슬라임, 동양 신화, 12지, 비행, 탑승
- 고정 칸과 태그를 나눈 것은 해석이다(정정 가능). 태그에는 한·영 이름이 있다.
- 다른 게임 고유의 디자인과 이름은 쓰지 않는다 (D-067). 유명한 몬스터는 유형만 쓴다.
- `♻️ 재사용 후보: 예전 크리쳐 편집기의 tags 칸과 태그 추가 UI` (`terra-client/src/app/admin/editor/creatures/CreatureFormTab.tsx`). 고정 카테고리 14개는 태그의 첫 목록으로 쓸 수 있다.

### 4.2 크기 등급과 통과 폭 (D-5023, 기획자 재량)

| 크기 | 키(몸길이) | 통과 등급 | 지나갈 수 있는 폭 |
|---|---|---|---|
| S | 1m 미만 | 일반 | 1칸 |
| M | 1~2m | 일반 | 1칸 |
| L | 2~3m | 일반 | 1칸 |
| XL | 3m 초과 (최대 약 12m) | 대형 | 2칸 이상 |

- ⚠️ 기술 PLAN의 격자·경로탐색 등급과 맞는지 기술 세션의 확인이 필요하다.

### 4.3 크리쳐 생성 에디터 (D-5024)

- 개발자가 특성(크기·성향 태그·주력 스탯·속성 등)을 고르면, 나머지는 자동으로 만든다.
- 고른 특성이 스탯 분포에 영향을 준다.
  - 예: 크기가 크면 STR·체력이 오르고 AGI가 내린다. 총합은 같다.
  - `♻️` `docs/GDD/World/Consolidated_World.md` 10-3
- 세트 단위로 주력 스탯이 6스탯에 고르게 퍼졌는지 검사하는 기능을 둔다 (제안, D-094).

### 4.4 필수 신화·환상 세트 (D-093, D-5025, D-5027, D-5028)

| 세트 | 범위 | 구성 |
|---|---|---|
| 12지 | 동양 공통 | 12계열 × 일반 → 희귀 → 보스 → 전설(12지신) |
| 황도 12궁 | 서양 공통, 12지의 짝 | 12계열 (같은 4단계, 해석). 사람 모습 별자리는 크리쳐로 다시 해석 |
| 서양 환상 동물 | 서양 공통 | 그리핀·유니콘·피닉스 같은 대표 환상 동물, 최대한 많이 |
| 국가 세트 | 국가 프리셋 16개마다 | 그 나라 신화 동물. 종 수는 나라마다 자유 |

- 사신·사흉 같은 동아시아 신수도 필수다 (D-093). 동양 공통 세트에 넣는다 (해석).
- 모든 목록은 편집 가능한 프리셋이다 (G15). 실존 종교는 직접 쓰지 않는다 (R9).
- 🔄 후보 목록 조사 (진행 예정): 12궁 재해석, 서양 환상 동물, 국가별 신화 동물

### 기술 전달 항목 (README §3-1)
- 물건 `tier` 0~9, 시설·건물 `level` 1~5와 레벨별 최고 티어 표, 스킬 `grade` 1~10. 상한은 설정값 (D-5001)
- 재료 `quality` 0~100 정수. 완제품은 스탯별 정수 값, 범위 안 위치는 천분율 (D-5002)
- 아이템 등급 = 프리셋별 점수의 서버 백분위 구간, 코드 7개 common·fine·rare·epic·legendary·ancient·mythic. 제작 난수는 서버 시드 (D-5003, D-5004)
- 등급 점수 = 제작 직후 스탯별 범위 위치 평균(천분율), 아이템에 저장 (D-5006). 하루 1번 분포 재계산(가상 표본 + 실제, NPC 포함) (D-5007)
- 장비 `socket_count` 0~3, 만들 때 정해 저장 (D-5008)

- 12속성 상성 (D-5011~D-5014): 속성 12칸 → 계열 6개, 6×6 rate 표(±50·같은 계열 -20, 천분율), 계열 값 = 기본형 + 강화형 × 2, 다중 속성은 스킬 계수 비중 평균, 속성 항 = max(하한, …), 하한 설정값(출발 250). D-182 기술 전달의 속성 항을 대체·보완

- 크리쳐 (D-5015~D-5021): 종에 `base_element`·`allowed_subspecies`, 개체 아종 = 허용 목록 안 argmax(기본형, 강화형 × 2), 동점 규칙. 개체 `is_shiny`(출생 때 시드 난수, 교배 유전 확률 설정값). 분포 = {범위, 출현 확률, 포획 수량, 남은 수량, 활성, 다시 켜지는 방식·주기}, 개발자 페이지

- 크리쳐 ② (D-5022~D-5028): 태그 사전(코드·ko·en)과 종의 tags, 생성기에서 태그 즉시 추가. 크기 경계 1·2·3m와 통과 등급 2개(일반 1칸, 대형 2칸+). 크리쳐 생성 에디터(특성 선택 + 자동 생성, 특성별 스탯 보정 설정값). 국가 프리셋마다 신화 동물 목록
- 기술 세션 확인 요청: D-5023 경계값이 PLAN 격자(배치 5.9m)·경로탐색 크기 등급과 맞는지

### 메인 결정과의 충돌
- `20_Core_Loop.md`의 "스킬 최대 등급 = 3 + 사이보그 환생 횟수"에 상한 10이 붙는다 (D-5001). 충돌은 아니고 보완이다.

- 장비 인챈트 = 소켓 순서별 성공률(설정값 60/30/15%), 보석 소모, 실패 시 최대 내구도 감소. 장비·보석 티어 비교 없음 (D-5009, D-5010)
