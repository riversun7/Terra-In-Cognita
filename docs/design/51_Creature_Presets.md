# 51. 크리쳐 프리셋 후보 (데이터 시트)

> - 상태: **후보(미확정)**. 크리쳐 에디터(D-5024)의 첫 입력 자료다. 목록은 편집 가능한 프리셋이다 (G15).
> - 관련 결정: D-5025·D-5027·D-5028(세트 구성), D-5047(민감 항목도 그대로 씀), D-5048(이 문서). 결정 로그가 정본이다.
> - 출처: 2026-10-29 서브에이전트가 일반 지식으로 만든 초안이다. 웹 확인을 하지 않았으므로 **모든 사실은 Assumed**다. 채택하기 전에 지역 귀속과 민감도를 확인한다.
>
> **이 시트를 읽을 때 주의** (Step 5 세션이 덧붙임)
> - ⚠️·⛔ 표시와 "쓰지 말 것", "제외", "대체 권장" 같은 문구는 서브에이전트의 권고다. 사용자는 D-5047에서 지금도 숭배되는 신화 존재도 **그대로 쓴다**고 정했다. 그래서 이 표시는 사용 금지가 아니다. 출시 국가를 검토할 때(Step 7·8) 참고하는 표시로 남긴다.
> - 아래 본문의 "신은 크리쳐로 쓰지 않는다는 원칙"은 프로젝트의 규칙이 아니다. R9는 "신화·전설의 신과 존재는 그대로 사용 가능"이다 (`03_Planning_Rules.md` §3).
> - 등급·속성 칸은 제안이다. 등급은 일반·희귀·보스·전설·신수(D-092)이고, 아래의 common·rare·boss·legendary·divine이 차례로 이에 대응한다.
> - 이름 규칙은 D-5045(자동 조합 + 덮어쓰기)와 D-5046(자연스러운 영어, 신화는 통용명)을 따른다.


> 용도: Terra In-Cognita 크리쳐 수집 기획용 **후보 풀**. 결정 사항 아님 — 채택/등급/속성은 기획 결정 로그(`docs/GDD_v4/02_Decision_Log.md`)에서 확정할 것.
> 톤 가정: 밝고 귀여운 파스텔 (라그나로크 온라인 / 메이플스토리 계열). 어둡거나 그로테스크한 원전은 "치비화/순화" 방향으로 시각 아이디어를 제시함.
> 작성일: 2026-10-29

## 0. 범례 / 근거 표기

| 표기 | 의미 |
|---|---|
| **A** | Assumed — 일반 상식 기반. 웹 검증하지 않음 |
| **V** | Verified — 웹 출처 확인 (URL 병기) |
| ⚠️ | 민감 항목 — 현존 종교의 신/신성 존재, 현존 공동체의 신성·의례 대상, 정치적 상징 등. 사유 병기 |
| ⛔ | 사용 비권장 (강한 민감성 또는 톤 불일치) |
| 🔁 | 다른 세트와 중복 (어느 세트와 겹치는지 표기) |

- **이 문서의 모든 신화·지역·설명 사실은 A(Assumed)이다.** 이번 조사에서는 웹 검색을 하지 않았다. 채택 전에 출처 확인을 권장한다(특히 ⚠️ 항목과 지역 귀속).
- 등급 후보: common / rare / boss / legendary / divine
- 속성 후보(12): water, frost, fire, blaze, wind, lightning, earth, crystal, light, holy, dark, necro
- 이름: 민속·신화 일반명(퍼블릭 도메인)은 그대로 사용 가능하다고 가정(A). 다른 게임 고유명(포켓몬, RO의 Poring 등)은 쓰지 않았다. 12궁 라인의 **창작명**은 출시 전 상표 검색이 필요하다.

## 7. 후속 확인 필요 (Open)

- 모든 항목이 A(웹 미검증)다. 특히 12궁↔지지 전통 대응(안 A), 『산해경』 세부 묘사, 용생구자 구성(판본 차이), 각 지역 귀속은 채택 전에 출처를 확인해야 한다.
