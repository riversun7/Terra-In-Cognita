## 2. 앱 뼈대 (6-1)

### 2.1 첫 화면 = 대시보드 (D-6001, D-6005)

- 로그인 직후 첫 화면이다. 내 사이보그·보유 유닛·자산·세력을 요약한다.
- 정보 요약 카드를 **유저마다 고르고 순서를 정해 저장**한다. 카드 종류는 늘릴 수 있다.
- 형태는 아직 하나로 정하지 않는다. 아래 템플릿을 보며 바꿔 가다가 하나 또는 몇 개로 통일한다 (D-6005).

  | ID | 이름 (ko / en) | 모습 |
  |---|---|---|
  | DT-GRID | 위젯 격자 / Widget Grid | 크기가 다른 칸(1×1·2×1·2×2)을 유저가 끌어 배치 |
  | DT-INBOX | 처리함 / Inbox | 처리할 일을 급한 순서로 쌓고, 처리하면 사라짐 |
  | DT-TIMELINE | 타임라인 / Timeline | 다가올 일을 시간 축에 (운송 도착, 웨이브 도착, 공성 시각, 오프라인 24시간 끝) |
  | DT-CITY | 도시 화면 / City View | 거점 화면 위 건물 말풍선 |
  | DT-BRIEF | 부관 브리핑 / Briefing | 휴먼 부관이 대화로 보고하고 답 버튼으로 처리 |
  | DT-HYBRID | 조합 / Hybrid | 처리함을 맨 위에 고정 + 아래 위젯 격자, 타임라인·브리핑은 위젯 종류 |

- 시안 페이지(2026-10-29): https://claude.ai/artifact/Fu4AYSAThT6jzX55MpP4YU (비공개, 소유자만 열람)
- ♻️ 재사용 후보: 기존 대시보드의 카드 구성과 경고 배너 (`terra-client/src/app/dashboard/page.tsx`)

### 2.2 처리할 일 (D-6006, D-6009)

| 순서 | 분류 | 항목 |
|:---:|---|---|
| 1 | 위협 | 내 도시로 오는 웨이브(D-196), 공성 선포·방어 시각 고르기(D-200), 내 운송·파티 습격 중(D-183) |
| 2 | 돈·생존 | 유지비 부족(D-150), 치료를 기다리는 부상 유닛(D-145), 곧 썩는 물건(D-121), 대출 만기·담보 처분 임박(D-138) |
| 3 | 멈춤 | 내구도가 낮아 멈춘 건물·도로(D-171), 직무 없는 유닛, 오프라인 24시간 뒤 대기 유닛(D-061), 재료가 없어 멈춘 시설, 가득 찬 창고 |
| 4 | 제안·결정 | 유닛 경매 입찰·낙찰(D-242, D-7023), 포로 처리(몸값은 원래 주인하고만·처형·회유, D-244), 맞는 의뢰(D-036), 걸어 둔 주문의 체결·만료(D-125), 세력 명령·투표(⏳ Step 4-6 뒤) |
| 5 | 완료 | 아이템 생산·제작 완료 등. 확인하면 사라진다 |

- 같은 분류 안에서는 마감(도착·만기·썩는 시각)이 가까운 순이다. 마감이 없는 항목은 분류의 끝이다.
- 같은 종류는 묶는다. 예: "명령 없는 유닛 6"
- 새 시스템이 생기면 중요한 일을 이 목록에 추가한다.

### 2.3 메뉴 (D-6004, D-6007, D-6008, D-6010)

| 층 | 모바일 | 태블릿 | 데스크톱 |
|---|---|---|---|
| 화면 위 띠 | 사이보그 얼굴(내 본체 화면) · 알림(종) · 우편 | 같음 | 같음 |
| 하단 탭 | 자주 쓰는 4칸 + 배치 A 또는 C | 폭에 따라 | 없음 |
| 사이드 메뉴 | ☰로 열기 (모든 항목) | 접었다 펼침 | 늘 펼쳐 둠 |

- 하단 탭 배치는 유저가 고른다. 기본은 C다.
  - A: 탭 4칸 + 끝칸 ☰ → 기본 `홈 · 지도 · 유닛 · 경제 · ☰`
  - C: 탭 4칸 + 가운데 큰 지도 버튼, ☰는 왼쪽 위 → 기본 `홈 · 유닛 · [지도] · 경제 · 세력`
- 메뉴 항목: 홈, 지도, 유닛(직무·파티), 경제(창고·거래·운송), 세력(도시·외교·전쟁), 사이보그. 유저가 하단 탭과 사이드 메뉴 사이에서 항목과 순서를 바꾼다.
- 연대기·세계 소식, 랭킹은 별도 메뉴 항목이 아니다. 다른 화면 안에 둔다 (해석, 해당 하위 단계에서 정함).
- ♻️ 재사용 후보: 기존 사이드 메뉴 항목 구성 (`terra-client/src/components/SystemMenu.tsx`)

### 2.4 화면 방향과 기기 (D-6002, D-6003)

- 모바일: 대시보드·경제 같은 메뉴 화면은 세로가 기본이다. 지도·전투에 들어가면 가로로 돌리라고 안내한다 (강제 아님). 세로 지도·전투도 최소 기능은 된다 (해석).
- 태블릿·데스크톱: 모든 화면이 가로로도 된다.
- 데스크톱: 화면 구성은 모바일과 같다. 카드 열을 늘리고, 지도·전투·거래창 옆에 패널(유닛 목록·호가창 등)을 하나 더 띄운다.

## 3. 지휘 루프와 알림 (6-2)

### 3.1 평일 지휘 루프의 화면 흐름 (D-028, D-6014, D-6015)

```
푸시(위협·돈과 생존) ─┐
                      ▼
[접속] → 복귀 요약 화면(없는 동안: 생산·습격·부상·세계 소식) → [확인]
       → 대시보드: 처리함 맨 위(위협 → 돈·생존 → 멈춤 → 제안·결정 → 완료)
       → 항목의 바로 처리 버튼 (수리 지시·자동 배치·판매·방어 배치·협상 수락/거절)
       → 더 고를 때만 유닛·경제 화면(세로), 위치가 필요할 때만 지도(가로 권장)
```

- 복귀 요약은 대시보드 템플릿과 상관없이 같다. 변화가 적으면 건너뛴다 (해석, 기준 Step 5).

### 3.2 알림 (D-6011~D-6013)

| 항목 | 규칙 |
|---|---|
| 통로 | 푸시 + 게임 안 처리함. 이메일은 쓰지 않는다 |
| 설치 안내 | 첫 접속 흐름 끝에 "홈 화면에 추가 + 알림 켜기"를 안내. 거절해도 진행 |
| 푸시 범위 | 처리할 일 분류별로 켜기. 기본은 위협·돈과 생존만 |
| 묶음 | 짧은 시간의 여러 건은 하나로 (간격 Step 5) |
| 방해 금지 | 유저가 정한 시간에는 보내지 않고, 끝나면 모아 보냄 |
| 오프라인 24시간 | 끝날 때 1회 (기본 켜짐, 끌 수 있음) |

- 사실 근거 (Verified, WebKit 블로그 2023-02 "Web Push for Web Apps on iOS and iPadOS"): iOS·iPadOS 16.4부터 홈 화면에 추가한 웹앱만 웹 푸시를 받는다. 허가 요청은 유저 동작 뒤에만 띄운다. iOS 18.4부터 Declarative Web Push (WebKit "Safari 18.4" 글).
- 설치하지 않은 iOS 유저는 처리함만 쓴다. 웨이브 최소 예고(D-196)가 길어 대개 접속 중에 본다 (Assumed).

### 3.3 자동화 (D-6016)

| 장치 | 내용 |
|---|---|
| 생활 자동 복귀 | 피로·포만 한계 → 스스로 먹고 쉰 뒤 하던 직무로 복귀. 접속 중에도 오프라인 규칙(D-144)과 같게 |
| 직무 프리셋 | 유닛 → 직무 배치를 이름 붙여 저장·적용 |
| 반복 예약 | 생산·운송을 주기·조건으로 반복 (예: 창고 ○○ 이하이면) |
| 휴먼 관리인 | 거점에 둔 휴먼이 대기 유닛 배치·수리 지시를 알아서 (시장 위임 D-105와 같은 방식, NPC도 같음) |
| 다중 선택 | 거점·종류·상태로 걸러 여러 유닛에 같은 직무 |

- 생활 자동 복귀의 규칙: 요금은 시설 주인이 정하고, 시설이 없으면 가까운 시설로, 그래도 없으면 노숙 (D-245). 휴먼 관리인은 시장 위임과 같은 틀의 자동 운영 (D-246).
- ♻️ 재사용 후보: 기존 작업 AI 상태와 피로 엔진 (`terra-server/ai/WorkerBrain.js`, `terra-server/game/movement/FatigueEngine.js`)

## 4. 지도 화면 (6-3)

### 4.1 진입과 전환 (D-6017, D-6018, D-139, D-197)

- '지도'를 누르면 2차맵의 **내 사이보그 위치**에서 연다.
- 2차맵을 끝까지 줄이면 1차맵 5단계로, 1차맵 5단계에서 한 곳을 키우면 그 2차맵으로 들어간다. 구석에 전환 버튼도 둔다.
- 2차맵 경계를 넘을 때는 화면이 짧게 바뀐다 (D-139).
- 1차맵은 좌표와 명령만 다룬다. 명령하면 유닛은 실제 2차맵을 지나간다 (D-197).

### 4.2 1차맵 명령 흐름 (D-6019, D-6021)

```
대상 누름 → 명령(이동·공격·운송·정찰) → 파티 고름 → 확인 화면 → 확정
```

| 확인 화면 항목 | 내용 |
|---|---|
| 경로·도착 시각 | 경로 후보 2~3개(빠른 길·도로 위 안전한 길), 실제 시간 도착 예정 |
| 경유지 | 지날 곳을 여러 개 찍는다 |
| 위험 구간 | 프런티어·분쟁 지대·시야 밖을 색으로. 습격 확률 숫자는 없음 |
| 호위·용병 | 위험 구간이 있으면 내 전투 유닛 호위 또는 용병 고용(D-151)으로 |
| 비용·소모 | 연료·피로 예상, 정규 운송과 직접 운반 비교(D-117) |
| 출발·반복 | 출발 시각 예약, 왕복 반복 |
| 도착 후 할 일 | 대기·귀환·채집 시작·공격 |
| 알림 | 이 명령의 도착·습격 푸시 여부 |

### 4.3 정보 층과 렌즈 (D-6020, D-6022)

| 층 | 내용 |
|---|---|
| 지형 (기존) | 고도·해수면, 기온·바이옴 (D-141), 3단계 안개 (D-103) |
| 영토 | 도시 영향권 경계, 시가지 안전지대, 공성 중인 도시 |
| 환경 | 오염, 온도·습도 |
| 자원·생산 | 아는 자원지, 내 시설·멈춘 시설, 창고 |
| 이동·물류 | 내 부대·운송 경로와 도착 시각, 정규 노선, 진군 중인 웨이브 |
| 외교 | 세력마다 나와의 관계 색 |
| 시세 | 같은 물건의 도시별 가격 |
| 사회 | 도시 만족도, 6교단 신앙 분포, 최근 습격·전투가 있던 곳(내가 보았거나 알림 받은 것) |

- 렌즈 묶음: 정착(빈 필지·자원·안전지대), 교역(노선·시세), 전쟁(경계·부대·웨이브) 등 목적별로 층을 한 번에 켠다.
- 지도 핀·메모: 개인 표시, 같은 세력·가문 안에서 공유 (D-247).
- 모든 층은 안개 규칙을 따른다. 시야 밖은 마지막 관측값이다 (D-103, D-152).
- 참고작 (Assumed): Civilization VI(2016) 렌즈·지도 핀, Europa Universalis IV(2013) 외교 지도, EVE Online(2003) 지역 시장, Crusader Kings III(2020) 종교 지도.

## 5. 전투 화면 (6-4)

### 5.1 흐름 (D-6023, D-6028, D-172, D-189)

```
전투 시작 → 어느 화면에서든 배너 "전투 중: ○○ [들어가기]"
   ├─ 들어감 → 전투맵 실시간 (배속·일시정지 없음, D-194)
   └─ 안 들어감 → 같은 규칙으로 빠른 계산 (D-189)
→ 결과 화면 (승패·얻은 것·잃은 것·부상·경험치) → [다시 보기] (참가자·같은 세력, 자기 편 시야)
```

### 5.2 화면 배치 (D-6024, D-6025, D-6027)

| 자리 | 내용 |
|---|---|
| 위 | 남은 시간과 승리 조건 (예: "남은 7:42 · 시간이 다 되면 수비 승", 공성은 넥서스 체력) |
| 가운데 | 전투맵. 퇴각 구역(가장자리 2칸)은 늘 연하게. 고른 유닛의 대기 명령 선과 목표 |
| 아래 | 파티 초상화 줄(최대 6). 누르면 스킬 버튼 → 전장의 목표를 누름. 초상화에 대기 명령 아이콘·1초 재입력 링 |
| 구석 | [퇴각] 버튼(파티 전원 "가장 가까운 퇴각 구역으로", 구역 안 인원 4/6), 명령 실행 기록 |
| 펼침 | 편별 남은 전력, 숨은 적의 마지막 위치 |

- 전장에서 유닛을 직접 눌러 고를 수도 있다. 군단은 초상화 줄을 파티별로 넘긴다 (해석).

### 5.3 전투 도움 장치 (D-6030)

| 장치 | 내용 |
|---|---|
| 스킬 범위·광역기 경고 | 고른 스킬의 사거리·범위, 적 범위 공격의 맞을 자리 (보이는 적만) |
| 지형 강조 | 수풀(숨음)·바위와 숲(시선 차단)·고지대(멀리 봄), 고른 유닛의 시야 범위 |
| 속성 상성 힌트 | 목표에 잘 듣는지 색·화살표 (숫자 없음) |
| 다중 명령 | 여러 유닛·파티 전체에 같은 명령, 1초 제한은 유닛마다 |
| 핑 | 같은 편끼리 정해진 신호 (여기 공격·위험·모여라) |
| AI 작전 성향 | 파티마다 공격적·균형·방어적·숨어 버티기, 대기 명령이 없을 때와 보지 않는 전투에 적용. 주인이 오프라인이어도 습격받은 전투 안에서는 성향대로 싸우고, 먼저 싸움을 걸지는 않음 (D-248) |
| 명령 실행 기록 | "궁수 A: 집중 사격 실행" |

- 훈련은 전투 화면 기능이 아니라 건물(시뮬레이션 훈련소)이다. 유닛을 넣으면 비용을 내고 경험치만 얻는다. 경험치는 실제 활동보다 적다 (D-6031, D-249).

### 5.4 참전·관전·리플레이 (D-6026, D-6036, D-6037, D-176, D-209, D-236)

- 2차맵의 전투 아이콘을 누르면 참전(근처에 있을 때만, D-209)하거나, 같은 세력의 전투면 그 편 시야로 본다.
- 시야는 세력 단위다. '같은 세력'은 같은 국가 전체(국가 안 가문·봉신 가문 포함, 독립 가문은 따로)다 (D-250). 세력이 다른 제3자는 자기 유닛 시야 안의 것만 보고, 두 편을 합친 관전은 없다 (D-236, D-6036).
- 리플레이는 참가자와 같은 세력 구성원이 보고, 각자 자기 편 시야로만 그린다 (D-6037).
- 볼 수 있는 사람이 전투 보고서(리플레이 포함)를 채팅·우편에 공유하면 누구나 본다. 공유된 것은 공유자 편의 시야로 그린다 (D-6038, 참고: EVE Online 전투 보고서 공유).

### 5.5 공성 방어 시각 고르기 (D-6029, D-200, D-233)

- 공성 선포는 처리할 일 '위협' 맨 위와 푸시로 온다 (D-6006, D-6012).
- 화면: 공격 쪽이 고른 공격 변, 우리 편 접속률 시간표(합계만)와 추천 시각, 구성원 참전 예약, 우리 쪽 준비 목록(성벽·넥서스 내구도, 주둔 유닛, 시민군 주민 수, 바로 처리 버튼), 시각은 각자의 기기 시간대로.

## 6. 거래창 (6-5)

### 6.1 흐름 (D-6032, D-117, D-148)

```
경제 → 거래 → 물건 고르기 → 도시별 목록(가격·거리·운임·관측 시각)
     → 도시 하나 → 호가창 + 주문표 → 주문
     → (내 창고 없는 도시에서 샀으면) 그 도시에 보관 / 운송 발주
```

- 누구나 어디서든 원격 주문한다. 시야 밖 도시는 마지막 관측값이다.

### 6.2 화면 배치 (D-6033, D-6034)

| 자리 | 내용 |
|---|---|
| 위 | 차트 (접기) |
| 왼쪽 | 호가창 (매도·매수 단계별 잔량). 동시호가 상품은 다음 체결까지 남은 시간·예상 체결가 |
| 오른쪽 | 주문표: 주문 종류·가격·수량·매수/매도, "남은 주문 7/10" (누르면 늘리는 법) |
| 데스크톱 옆 패널 | 차트 크게, 내 주문 목록 |

### 6.3 주문 종류 (D-6035)

| 종류 | 내용 |
|---|---|
| 지정가 | 가격을 정해 걸어 둠, 만료 기간 선택, 오프라인에도 체결 |
| 시장가 | 지금 호가로 바로 (물자만), 최대 가격 안전망 |
| 조건 | 가격 도달·재고 조건으로 자동 주문, 주문 한도를 씀 |

- 유닛 거래(종류별 경매소 + 즉시 구매가, D-242)와 필지(D-149)는 호가창이 아니다. 화면은 6-7 화면 목록에서 자리만 정한다 (해석).
