## 1. 수익 모델 (D-7001)

- **부분 유료 + 프리미엄 구독**이다.
  - 게임은 무료로 시작한다.
  - 테라코인 상점과 월 구독을 함께 둔다.
- 구독 (D-7007)
  - 혜택: 편의 + 작은 시간 단축·버프. 효과는 아래 §2 상한 안에 들어간다.
  - 구매: 현금, 또는 테라코인(세력 화폐로 산 것 포함).
  - 혜택 목록은 콘텐츠·화면이 정해진 뒤 정한다.

## 2. 공정성 원칙 (D-7002)

- 테라코인 상품은 밸런스에 영향을 줘도 된다. 시간 단축과 버프를 팔 수 있다.
- 효과는 과하지 않게 **10~20%** 안으로 둔다. 사용자가 말한 범위다.
  - **같은 효과끼리 합계**에 상한을 건다 (D-7005). 다른 종류끼리는 따로 센다.
  - 예: 생산 속도 +15%와 건설 시간 -15%는 둘 다 적용된다. 생산 속도 +15%를 두 개 쓰면 상한까지만 적용된다.
  - 상한값은 효과 종류마다 10~20% 안에서 정한다 (Step 5).
- **무과금 유저도 테라코인을 벌어서** 같은 상품을 살 수 있다.
  - 게임에서 번 세력 화폐로 거래소에서 테라코인을 산다 (D-7006).
- "P2W 금지"는 안티-필러가 아니다 (D-015 미결을 이것으로 닫는다).

## 3. 테라코인과 게임 재화 (D-7003, D-7006)

화폐 3층(D-124) 가운데 테라코인은 **거래소에서 세력 화폐로 직접** 사고판다 (D-7006이 D-7003의 교환 아이템 방식을 대체).

```
현금 ──결제──→ 테라코인 ──상점──→ 유료 상품·구독
                 ↕ 거래소 (유저끼리, 세력 화폐마다 환율)
             세력 화폐 ←── 게임 활동
                 ↓
     기본 NPC 국가가 테라코인을 사들여 소각 (D-7008)
```

- 게임 화폐 → 현금 경로는 없다.
  - 한국 게임산업법 제32조 제1항 제7호(게임 결과물을 업으로 환전하는 것 금지)의 직접 대상이 아니라고 본다 (Assumed, 법률 검토 아님. 출시 전 자문 필요).
  - 거래로 얻은 테라코인은 현금으로 환불하지 않는다. 결제분과 거래 취득분을 원장에서 나눈다 (기획자 정리, D-7006).
- 시스템이 세력 화폐를 만들지 않는다 → D-170과 맞는다.
- 차선책: 법 검토에서 직접 거래가 막히면 정액권·유료 아이템 형태의 교환(D-7003의 원래 방식, ♻️ 기존 ECO-1 축3)으로 돌아간다.
- 세력 화폐마다 테라코인 환율이 서고, 그 환율이 화폐 가치의 지표가 된다 (D-131, 해석).
- 테라코인/세력 화폐 거래는 **환율처럼 동시호가**로 체결한다 (메인 D-241).

### 3.1 NPC의 역할: 회수·소각 (D-7008)

- 기본 NPC 국가(D-086)가 거래소에서 세력 화폐로 테라코인을 사들여 소각한다.
- 테라코인 매출이 낮으면 더 높은 값에 사들여 가치를 올린다.
- 매입은 공식을 따르고 운영자가 개입할 수도 있다.
- 매입 자금은 **국고 잔액으로만** 낸다. 새로 발행하지 않고, 모자라면 운영자 부여(D-220)로 보정한다 (메인 D-240).
- NPC도 **테라코인을 벌어 사서 유료 효과를 쓴다** (메인 D-239). D-7008의 해석("NPC는 유료 버프를 쓰지 않는다")을 대체한다.

## 4. 확률 요소와 유료 재화 (D-7004)

- 확률 요소에 유료 재화를 쓸 수 있다. 확률은 모두 공개하고 상한으로 관리한다.
- 대상: 스킬 합성(D-030), 생산시설 투자(D-166), 이후 생길 확률형 상품
- 상한의 형태, 천장(보장) 여부, 유료로 할 수 있는 확률 행위의 목록은 7-2에서 정한다.
- 알려진 영향
  - 유럽 PEGI는 2026년 6월 이후 심사작에 유료 확률형 아이템이 있으면 기본 16세 등급이다 (Verified, 보도 여러 건, 2026).
  - 한국은 확률 정보 표시가 의무다 (2024-03-22 시행, Verified).

### 4.1 유료 확률 행위 (D-7011, D-7012)

- 하나로 좁히지 않는다. 다른 게임의 실제 BM 사례를 계속 참고해 더한다.

| 묶음 | 넣는 것 | 대상 (해석) |
|---|---|---|
| 강화·합성 | 확률 올리는 촉매 (상승 폭은 D-7005 상한 안) | 스킬 합성, 시설 투자, 보석 인챈트, 제작 난수(§4.3) |
| 강화·합성 | 하락·파괴 방지 | 합성 -1 결과, 인챈트 실패 때의 최대 내구도 감소 |
| 강화·합성 | 옵션 재설정(리롤) | 시설 특성, 장비 옵션(제작 때 정해진 것), 크리쳐 개체값 |

- 장비 강화(+단계)는 두지 않는다 (메인 D-275). 처음 표(D-7012)의 "장비 강화" 촉매와 "강화 실패" 하락 방지는 빠졌다. 장비 쪽 유료 확률은 보석 인챈트와 제작 난수뿐이다.
| 뽑기 | 꾸미기 뽑기 | 외형·장식·건물 스킨 |
| 뽑기 | 크리쳐 알·유전자 뽑기 | 종·속성 아종·이로치 |
| 뽑기 | 스킬석 뽑기 | 합성 재료가 되는 스킬 |
| 뽑기 방식 | 미리보기·박스형 | 위 뽑기에 입히는 방식 |

- **비용 대신 내기는 금지**한다. 테라코인으로 수수료·재료를 바로 내지 않는다. 테라코인 → 도시 화폐 → 재료 구매의 간접 경로만 쓴다.
- 확률 보조 아이템(촉매·하락 방지·리롤권)은 **계정 귀속**이다 (D-7014).
- 뽑기 결과물(꾸미기·크리쳐 알·스킬석)은 **모두 거래할 수 있다** (D-7015). ⚠️ 결과물이 유료 재화 가치를 가져 해외 도박법 위험이 있다 (출시 국가는 7-4·Step 8).
- **유료 상품은 별도 층**이다 (D-7016).
  - 시스템이 만들어도 된다.
  - 총량 자원과 세력 화폐는 절대 내지 않는다.
  - 버리거나 분해하면 일반 자원으로만 돌아간다.
- ~~크리쳐 알 뽑기의 희귀 결과는 야생과 같은 희귀 출현 한도를 나눠 쓴다 (D-7017)~~ → **알 뽑기는 수량 제한과 무관한 별도 BM 요소**다. 희귀 출현 한도는 조우에서 잡는 야생 포획만 통제한다. 뽑기 확률표는 고정이다 (D-7052). 이로치는 색만 다른 개체로 1% 이하 확률이고 한도 밖이다 (D-7053).

### 4.2 안전장치 (D-7013)

1. **실패 누적 확정**: 실패하면 게이지가 쌓이고, 가득 차면 다음은 확정 성공
2. **횟수 천장**: 정해진 횟수 안에 최고 등급 확정
3. **검증 가능한 확률**: 백분율로 모두 표시(천장·변동 확률 포함), 서버 시드를 나중에 공개해 검증, 개인 기록
- 보장 장치의 진행도는 화면에 늘 보여 준다.
- D-7004의 "상한"은 효과 상한(D-7005)과 천장이다. 지출 한도는 두지 않는다 (해석).
- 근거: 한국 확률 표시 의무(천장·변동 확률 포함), 거짓 표시 최대 3배 배상(2024-12 국회 통과), 숨은 0% 구간 제재(공정위 2025-11, 웹젠) — 모두 Verified(보도).

### 4.3 제작·인챈트 촉매 (메인 D-251, D-7031)

- 테라코인 촉매·하락 방지·리롤(D-7012)은 보석 인챈트와 아이템 제작에도 쓴다 (메인 D-251).
- 제작 촉매는 **작은 난수 부분에만** 건다. 재료·시설·유닛 실력이 결과를 정한다. 등급이 서버 백분위라 무과금 장인이 밀리지 않게 한다 (D-7031. Step 5의 D-5034도 같은 결정이다).
  - 메인 D-282로 재료 품질(D-5002)이 없어졌다. 성능의 몸통에서 재료 품질이 빠지지만 "촉매는 난수 부분에만" 원칙은 그대로다. 성능을 무엇이 정하는지는 메인이 D-282 해석을 확인 중이다.
- 인챈트는 성공률 촉매(상한 안)와 실패 시 최대 내구도 감소 방지다 (해석).

### 4.4 테라코인 쓰임 전체 (D-7032)

| 묶음 | 쓰임 | 조건 |
|---|---|---|
| 성장 | 훈련소 가속 | 상한을 더해도 실제 활동 경험치를 넘지 않음 |
| 성장 | 회복 가속 (피로·부상) | ⚠️ 피로도 경제를 약하게 할 수 있어 상한을 낮게 잡는 것을 제안 |
| 성장 | 건설·생산·물류 가속 | 사람의 절차(D-168)·공성 시각·웨이브 예고는 줄이지 않음 |
| 편의 | 창고 탭·프리셋 슬롯·예약 주문 수·알림 | 주문 한도·주거 상한·창고 총용량은 늘리지 않음 |
| 꾸미기 | 외형·건물·유닛 스킨 (확정 구매) | — |
| 계정 | 이름 변경·외형 재설정·세력 이전 | 정착 지원금은 다시 주지 않음 |
| 사회 | 복원 기부·기념비 | 기부자 이름을 남김 |
| 사회 | 소통·홍보 (확성기·홍보·이모티콘) | 도배 방지 규칙 필요 |

- 여기에 유료 확률 행위(§4.1), 구독(§1), 패스(§7)를 더한 것이 테라코인 쓰임 전체다. 목록은 계속 늘린다.
- **테라코인을 내는 곳은 상점 한 곳**이다 (Step 6 D-6049). 합성·인챈트·제작의 유료 보조는 상점에서 보조 아이템을 사 두고 행동 화면에서 고른다. 거래소의 테라코인/세력 화폐 쌍은 상점이 아니라 거래다. "비용 대신 내기 금지"(D-7012)와 맞는다.
- 공통 조건: 같은 효과 합계 10~20%, 비용 대신 내기 금지, 총량 자원·세력 화폐를 내지 않음, NPC도 같은 길로 사서 씀.

## 5. 이용등급과 증권 (D-7009, D-7010)

- 한국 목표 등급은 **청소년이용불가 단일**이다. 청소년 버전은 따로 두지 않는다 (D-7009).
  - 근거: 유료 재화로 쓰는 거래소가 있으면 청소년이용불가로 분류된 2017년 사례 (⚠️ 2년 넘은 보도 출처).
  - 아트 수위는 등급과 무관하다 (D-069). 밝은 파스텔 톤과 성인 등급이 함께 간다.
  - 게임 안 첫 접속 흐름에는 성인 인증 단계를 두지 않는다. 법상 필요하면 게임 밖 로그인(계정) 웹에서 한다 (Step 6 D-6044, 사용자 원문 "없음. 필요시 로그인 웹에서"). 법상 필요한지는 7-5에서 확인한다.
  - 해외 등급은 해외 확장 때 본다 (D-7029).
- 주식·채권·지분은 **세력 화폐로만** 사고판다 (D-7010). 테라코인 거래 쌍은 "테라코인/세력 화폐" 하나다.

## 6. 운영 정책: 랭킹·다계정·매크로·현금 거래·감시 (D-7018~D-7025)

- **랭킹** (D-7018, D-7022): 유료 효과로 낸 **성과는 넣고**, 버프처럼 시간제로 붙는 **수치는 뺀다**.
  - 예: 생산 속도 +15% 버프로 밀을 115 수확하면 115가 점수다. 전투력·보유 스탯 같은 수치형 지표는 버프 없는 기본값으로 매긴다.
- **다계정** (D-7019): 허용한다. 계정 사이에 재화·유닛·정착 지원금을 몰아주는 패턴만 감시한다.
  - 감시 방법: 시장가와 크게 다른 가격, 같은 IP·계정 사이 반복 이동, 의심 거래 자동 표시 → 운영자 검토 (♻️ 기존 ECO "P2P 직거래 + RMT 탐지")
- **외부 매크로·봇** (D-7020): 약관으로 금지한다. 서버 규칙(명령 간격 D-180, 주문 한도 D-148, 피로도 D-039)으로 이점을 없앤다. 시장을 흔드는 봇은 감시한다.
- **운영자 개입** (D-7021): 테라코인 매입·소각(D-7008)과 NPC 부여(D-220)는 원장에 운영자 사건으로 남기고 관리자 화면에서만 본다. 유저에게 공개하지 않는다.
  - ⚠️ 시세가 움직이면 조작 의심을 받을 수 있다 (Assumed).

## 7. 라이브옵스·결제·출시 (D-7026~D-7029)

- **시즌은 없다** (D-7026). 유닛의 수명이 시즌 역할을 하고 강대국의 흐름이 계속 바뀐다. 🟡 이벤트 시즌은 둘 수도 있다.
  - 시즌마다 공개하려던 진실의 조각은 사이보그마다의 개인 스토리 퀘스트로 공개한다 (메인 D-272, D-276~D-279).
- **시즌 패스 = 무료 트랙 + 유료 트랙** (D-7027). 유료 보상은 꾸미기 + 상한 안 효과 + 체험형, 총량 자원·세력 화폐는 없다. **3달(분기)마다** 새로 연다 (D-7030).
- **결제는 처음부터 웹(PG)과 앱 마켓 둘 다** (D-7028). 결제분 테라코인에 결제 경로를 남긴다. ⚠️ 앱 마켓이 유료 재화 거래·유료 확률을 허용하는지는 출시 전 확인 (Unknown).
- **한국 먼저 출시**, 해외는 나라별 법 검토 뒤 같은 월드에 더하고, 법이 막는 나라는 접속·결제를 막는다 (D-7029).
- **복귀 패키지** (D-7034): 오래 쉬고 돌아오면 유닛·크리쳐 뽑기권 등을 준다. 유료 상품 층이라 총량 자원·세력 화폐는 주지 않는다. "유닛 뽑기"(휴먼·안드로이드)는 뽑기 목록에 새로 더한다 (해석).
- **계정 삭제** (D-7035 → 메인 D-268로 구체화): 그 **사이보그가 그대로 NPC가 되어** 자산과 유닛을 모두 이어받는다. 지도자였으면 NPC 지도자가 되어 세력이 이어진다. 영구 정지도 같다(기간 정지는 장기 미접속과 같음, D-243). 남은 테라코인의 처리는 D-7035대로 소멸로 둔다(환불은 법대로) — D-268이 "자산 전부 계승"이라 테라코인도 그 NPC가 갖는지는 7-5에서 확인한다.
