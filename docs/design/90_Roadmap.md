## 1. 한눈에 보기 (D-389, D-408, D-391, D-407)

### 1.1 단계

| 단계 | 이름 | 무엇을 확인하나 | 환경·참가 | 결정 |
|---|---|---|---|---|
| **P1** | 혼자 한 바퀴 | 지휘 루프와 원정 루프의 모든 단계가 한 번씩 돈다 | 내부 환경, 개발자 | D-408, D-390 |
| **P2** | NPC 세계 시험 | 유저 0명으로 NPC만 돌린다. 독점 없음·통합과 분열 반복·기술 발전과 후퇴를 본다 | 내부 환경, 헤드리스 | D-391, D-396, D-408 |
| **P3** | 무결제 공개 테스트 | 외부 유저가 같은 판을 쓴다. 결제는 끈다. 상점·확률 상품은 운영자가 준 캐시로 시험한다 | 공개 테스트 환경. 끝나면 세계를 지운다 | D-389, D-401 ~ D-403, D-405, D-406 |
| **P4** | 한국 정식 출시 | 새 세계를 연다. 웹 결제와 앱 마켓 결제를 함께 연다. 청소년이용불가 | 정식 환경 | D-389, D-401, D-403, D-7009, D-7029 |
| **U** | 출시 뒤 후보 묶음 | 금융(은행·증권·유저 화폐), 우주층, 이동 도시·바다 특수 지형. **순서 없음.** 운영 지표를 보고 고른다 | 정식 환경 | D-407 |

- 단계 이름은 기술 마일스톤(S·M·N)과 따로 둔다. 단계마다 필요한 마일스톤은 §4에 적는다 (D-408).
- D-389의 3단계와의 관계: "내부 플레이판" = P1 + P2, "무결제 공개 테스트" = P3, "한국 정식 출시" = P4 (기획자 해석, 정정 가능).
- 날짜는 정하지 않는다. 출시 시점은 P2 시험을 통과한 뒤 정한다 (D-391).
- 단계마다 사용자가 확정해야 다음으로 넘어간다 (D-001의 진행 원칙을 단계에도 쓴다, 기획자 해석).

### 1.2 흐름

```
P1 혼자 한 바퀴 → P2 NPC 세계 시험 → 법률 자문 → P3 무결제 공개 테스트 → P4 한국 정식 출시 → U 후보 묶음

```

## 2. 출시 판의 범위 (P4 기준)

### 2.1 두 루프를 같은 깊이로 (D-390)

| 루프 | 단계 |
|---|---|
| 지휘 루프 | 강하 → 채집 → 생산 → 거래소 판매 → 고용·직무 → 오프라인 정산 → 웨이브 방어 |
| 원정 루프 | 탐험 → 조우 전투 → 포획 → 교배 |

- 두 루프에 필요한 시스템은 모두 "필수"다 (D-390 해석).
- 범위를 줄이려면 시스템을 빼지 않는다. 콘텐츠 양에서 줄인다 (D-390 기획자 제안). 콘텐츠 양은 운영자가 개발자 페이지에서 정한다 (D-398).
- 1인 개발에 가장 큰 범위다 (D-390 선택지에 적은 위험, D-003).

### 2.2 등급의 뜻

| 등급 | 뜻 |
|---|---|
| **필수** | 출시 판에 들어가고 켜져 있다 |
| **잠금** | 출시 판에 데이터 자리와 잠긴 메뉴만 있다. 기능은 출시 뒤 U 묶음에서 연다 (D-393 기술 전달 "기능 잠금") |
| **U** | 출시 판에 없다. 출시 뒤 후보다 (D-407). 데이터 구조만 처음부터 둘 수 있다 (D-372) |
| **미정** | 결정이 없다. §7에서 다룬다 |

- "기술 상태"는 PLAN·ADR·작업 기록을 `7bec7cb`에서 읽은 것이다. 경제·전투·NPC 코드 폴더는 아직 없다 (V: `apps/server/src`, `packages/sim/src` 목록).

### 2.4 27경로 (D-392)

- → D-481 (2026-11-01): 경로 목록은 언제든 바뀐다. 지금 26개, 정본 `20_Core_Loop.md` §7.

- 행동은 모두 연다. 경로는 공통 시스템의 조합이라서다 (D-012, D-392).
- 랭킹·칭호·전용 행위는 묶음별로 공개한다. 지표가 원장·전투 기록에서 바로 나오는 경로부터 연다 (D-392 기획자 제안).
- 아직 열지 않은 랭킹은 화면에 "곧 열림"으로 보인다. 공개 여부는 데이터 표시다 (D-392 기술 전달).
- 금융가·투자가 랭킹은 뒤로 간다 (D-393 해석). 은행·증권이 잠겨 있어서다.
- 금융가(은행·대출)와 기업가·투자가(회사 상장·지분)의 핵심 행위는 잠금이다. 그래서 출시 때 "행동은 모두"에서 이 행위들은 빠진다 (D-393 영향 "얕다", 기획자 해석). §7 9번.
- 묶음의 순서와 경로 목록은 아직 없다. 경로별 참여 지표(D-407)와 함께 정한다 (기획자 해석, 정정 가능).

### 2.5 콘텐츠 양과 아트 (D-398, D-399)

- 콘텐츠 양은 묻지 않는다. 운영자가 개발자 페이지에서 정한다. 크리쳐 등 콘텐츠는 당연히 다 넣는다 (D-398).
- 출시 판의 콘텐츠 범위 = 개발자 페이지에 넣은 만큼이다. 기획은 틀(규칙·분류·데이터 칸)만 정한다 (D-398).
- 그래서 개발자 페이지(콘텐츠 에디터·편집기 2단계)가 P1부터 필요하다 (기획자 해석, 정정 가능).
- 아트는 몸 틀 몇 개에 부위·색을 조합한다. 아종은 색으로 나타낸다 (D-071). 아이템은 아이콘만이다 (D-399).
- 기존 이미지는 그대로 쓰지 않는다. 특징만 잇는다 (D-067).

### 2.6 출시 국가·등급·결제

- 한국 먼저 출시한다. 해외는 나라별 법 검토 뒤 같은 월드에 더한다 (D-7029).
- 데이터는 지금부터 여러 언어 칸으로 열어 둔다. 필수는 한국어·영어다. 다른 언어는 그 나라로 해외 확장할 때 더하고, 후보는 일본어·중국어 번체다 (D-484).
- 한국 목표 이용등급은 청소년이용불가 하나다 (D-7009). 성인·본인 확인은 게임 밖 로그인 웹에서 한다 (D-6044).
- 공개 테스트는 무결제다. 정식 출시 때 웹 결제와 앱 마켓을 함께 연다 (D-401, D-7028 유지).
- 상점·확률 상품은 공개 테스트 때부터 켠다. 테스트에서는 운영자가 캐시를 준다 (D-405).

## 3. 단계별 통과 조건

### 3.1 P1 → P2: 혼자 한 바퀴

결정은 P1의 이름만 정했다 (D-408). 아래 목록은 모두 **기획자 해석(정정 가능)**이다. 근거는 D-390과 D-404다.

- [ ] 같은 사람이 원정 루프 4단계를 끝까지 돈다 (D-390)
- [ ] 첫 접속 → 핵심 10분 튜토리얼(이동·채집·창고, 첫 전투, 첫 고용·직무)을 지난다 (D-140, D-6043)
- [ ] 두 루프를 휴대폰에서 끝낼 수 있다 (D-060)
- [ ] 크리쳐·아이템·건물을 개발자 페이지로 넣고, 배치하고, 켜고 끈다 (D-398)
- [ ] 판정은 서버가 하고 원장에 남는다. 원장 대조 경보가 울리지 않는다 (D-6047, D-359)
- 깊이와 양은 P1에서 보지 않는다. "모든 단계가 한 번 돈다"가 기준이다.

### 3.2 P2 → P3: NPC 세계 시험 (D-391, D-396)

시험 방식

- 유저 0명으로 NPC만 돌린다 (D-391 해석, P0 D-044).
- NPC는 유저와 같은 규칙을 쓴다 (D-013). 자동 특혜는 없고, 운영자 부여만 있다 (D-220). 부여 기록은 시험 결과와 함께 본다 (기획자 해석).
- **실제 시간으로 몇 달** 돌린다. 규칙·타이머·설정값을 바꾸지 않는다 (D-410). 그 사이 콘텐츠 넣기·화면·법률 자문을 함께 한다 (D-410 해석).
- 시험에 있어야 하는 규칙: 생산·거래소·NPC 화폐(D-393), 전쟁·공성·점령·반란·독립(D-397), 수명·환생(D-395), 웨이브(D-396), 세력 기술 단계 재계산(D-396) (기획자 해석).

통과 조건 (문턱은 모두 설정값, D-391)

| 조건 (D-391) | 지표 (D-391 기술 전달) | 이 조건을 만드는 규칙 |
|---|---|---|
| 1. 한 세력이 독점하지 않는다 | 세력별 점유율 최대값과 지속 기간 | 독점 불이익은 없다 (D-295). 만족도·반란·정원사 압박·유지비가 무너뜨린다 (D-295, D-391 해석) |

## 8. 기술 세션 전달

처리 현황은 `00_README.md` §3-1에 적는다 (03 §9.4).

- 단계·환경 (D-389, D-408): 기획 단계 = P1 혼자 한 바퀴 → P2 NPC 세계 시험 → P3 무결제 공개 테스트 → P4 한국 정식 출시, 출시 뒤 U(순서 없음). 환경 3개 {내부, 공개 테스트, 정식}. 공개 테스트 = 결제 끔. §4.2 대응표와 공백 칸의 크기·기간 의견을 요청한다
- 출시 판 필수 (D-390): 두 루프의 모든 단계(원장·생산·거래소·직무·오프라인 정산·웨이브·탐험·조우 전투·포획·교배)
- NPC 시험 (D-391, D-396): 헤드리스 NPC 시뮬레이션 + 지표 {세력별 점유율 최대값·지속 기간, 세력 생성·소멸 횟수, 세력별 기술 단계 오르내림}, 문턱은 설정값. 가속 실행(실제 며칠~몇 주 분량) 가능 여부와 점유율 기준을 N1 ADR에서 정해 달라. 세력 기술 단계 = f(보유 연구 시설 레벨, 도시 발전도), 시설·도시 변화 때 재계산, 설계도 보유 = 다시 오를 때 비용·시간 할인(설정값)
- 27경로 (D-392): 경로 랭킹·칭호 = 공개 여부 표시가 있는 데이터, 화면에 "곧 열림" (→ D-481: 경로 목록은 언제든 바뀐다. 지금 26개, 정본 20 §7)
- 경제 (D-393, D-409, D-411): 원장 + 물자 거래소(연속 체결, D-125) + NPC·유저 세력 화폐 고정 단계 + 환전 + 도시 지분(배당·1:1 양도·의결). 증권 거래소·은행·채권·상장·통화 제도 전환은 기능 잠금. 은행이 잠긴 동안 화폐 발행은 중앙은행 공식이 정한 양을 시스템이 직접 낸다
- 세력 (D-397, D-409): 46의 세력 기능 전체, 잠금은 조건 방식(D-5055). 유저 나라도 자기 화폐(고정 단계)·도시 지분(배당·1:1 양도·의결). 잠금은 증권 거래소·은행·채권·상장·통화 제도 전환.
- 수명 (D-395): 휴먼 수명(설정값) + 사망·상속(D-332) + 환생·신격화 시설 서비스
- 콘텐츠·아트 (D-398, D-399): 콘텐츠 데이터는 모두 개발자 페이지에서 추가·배치·켜고 끈다. 크리쳐·캐릭터 모델 = 몸 틀 + 부위 슬롯 + 색 팔레트 조합 데이터, 아이템 = 아이콘
- 결제·BM (D-401, D-405): P3 = 결제 끔 + 운영자 캐시 지급 도구(감사 기록) + 상점·확률 상품 켬. P4 = 웹 PG + 앱 마켓 결제(앱 껍데기, PLAN §14의 새 ADR)
- 법률 (D-402): 공개 테스트를 열기 전 체크리스트에 법률 자문 완료를 넣는다
- 테스트 세계 (D-403): 테스트 데이터는 정식으로 옮기지 않는다. 테스터 계정 표시 → 출시 때 꾸미기 보상
- 순서 제안 (D-404): 지금 단계 → 루프 최소판(원장·생산·거래소·조우 전투) → N1 → 나머지. 결정은 기술 ADR. P2 조건에는 전쟁·수명·기술 후퇴 규칙도 필요하다는 기획 해석을 함께 보낸다 (§7 4번)
- 대시보드 (D-406): 공개 테스트에서 템플릿별 사용 기록(선택·체류)을 남긴다
- 운영 지표 (D-407): 유저가 막히는 곳, 경로별 참여를 수집한다
- 출시 판 공백 (§4.2): 지구 ETOPO, 편집기 2단계, NPC 국가 배치, 콘텐츠 에디터, 첫 접속·튜토리얼, 관리자 경제 감시, 아트 제작은 마일스톤이 없다
- 미러: D-330 ~ D-408을 동기화해 달라 (03 §9.4)
