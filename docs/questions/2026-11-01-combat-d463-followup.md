# D-463 후속 질문: 속성 무기를 든 유닛의 물리 기반 스킬 (2026-11-01)

## 질문과 기술 추천(가)

### 226. 속성 무기(지팡이)를 든 유닛이 물리 기반 스킬을 쓰면 무엇으로 세는가?
- 장면: 불 지팡이를 든 유닛이 물리 기반 스킬 "강타"(물리 × 150%)를 쓴다.
- 기획 원문(D-463): "속성 기반 스킬은 늘 속성 공격력(m.atk)으로 센다 … 속성 무기를 들지 않았으면 '맨손 속성' 기본 무기 자료를 맨손 무기(D-436)처럼 쓴다 … 물리 기반 스킬은 든 무기를 쓴다." 든 무기가 속성 무기일 때는 적혀 있지 않다.
- 가(지금): 속성 기반과 짝으로 맞춘다. 물리 기반 스킬은 늘 물리 공격력으로 센다. 든 무기가 속성 무기면 맨손(타고난 무기, D-436)의 공격력·적정치와 물리 공격력으로 센다. 지팡이를 든 유닛의 강타는 맨손 강타와 같다.
- 나: 든 지팡이의 공격력·적정치에 물리 공격력을 쓴다(무기 종류와 상관없이 든 무기). 지팡이 공격력이 크면 강타도 세진다.
- 다: 속성 무기를 들고는 물리 기반 스킬을 쓸 수 없다(스킬 칸에서 막는다).
- 코드: `packages/sim/src/combat/unitSpec.ts` `specFromStats`의 `skillAttack.physical`(속성 무기면 `naturalWeapon`).
