## 화면 흐름 (지금 만드는 것)
이름 → 외형 → 초기 스탯 → 세력 → 시작 도시 → 강하 → 대시보드. 한 화면 안 6단계이고, 틀(위 띠·하단 탭)은 숨긴다. 사이보그가 없는 계정은 어느 주소로 들어와도 이 화면으로 온다(설정·로그아웃은 연다).

## 질문과 기술 추천(가)

### 168. 성향은 몇 개이고, 얼마나 치우치나?
- 장면: 초기 스탯 단계에서 성향 카드를 고르고 [굴리기]를 누르면 여섯 스탯(합 60, 칸 1~20)이 나온다.
- 기획 원문: D-6039 "성향 예: 전투형(STR·VIT), 기술형(INT·DEX), 교역형(INT·WIS). 목록은 Step 5", 49 N9 "성향 목록".
- 가(지금): 4개 — 균형(치우침 없음)·전투(STR·VIT)·기술(INT·DEX)·교역(INT·WIS). 고른 두 스탯의 평균 14, 나머지 넷 평균 8(균형은 모두 10), 흩어짐은 표준편차 약 3(옛 CHR §4.2 "평균 10, 표준편차 ~3"). [임시] 값은 설정값.
- 나: D-6039 예 3개만(균형 없음).
- 다: 스탯마다 하나씩 6개(한 스탯만 크게).
- 답(D-445): 가. 네 성향(균형·전투·기술·교역)이 D-6039의 "목록은 Step 5"를 채운다. 치우침 값(고른 스탯 가중치·나머지 가중치·흩어짐)은 설정값이다 → 팩 `tuning` `n9_initial_favor`(출발값 4000: 고른 두 칸 평균 14·나머지 8)·`n9_initial_spread`(3000, 표준편차 약 3). 굴리기는 환생과 같은 함수(`packages/sim/src/society/cyborgStats.ts`)다.

### 169. 다시 굴리기는 어떻게 세나?
- 장면: 굴린 값이 마음에 들지 않아 [다시 굴리기]를 누르거나, 성향을 바꿔 다시 굴린다.
- 기획 원문: D-6039 "다시 굴리기 횟수 예: 3번", 49 N9 "3번", D-444 164 "환생도 같은 횟수".
- 가(지금): 처음 굴림 1번 + 다시 굴리기 3번 = 모두 4번. 성향을 바꿔 굴려도 한 번으로 센다(바꾸기로 횟수를 늘리지 못하게). 늘 마지막 값을 쓰고 앞 값으로 돌아가지 않는다. 다 쓰면 마지막 값으로 만든다. 횟수는 서버에 남아 새로고침·재접속해도 돌아오지 않는다.
- 나: 성향 바꾸기는 공짜, 다시 굴리기만 3번.
- 다: 굴린 값 가운데 하나를 고른다(앞 값으로 돌아갈 수 있음).
- 답(D-445): 가. 서버가 처음 1번 + 다시 굴리기 3번을 센다(3 = 설정값 출발값, 팩 `tuning` `n9_initial_rerolls` — 환생과 같은 칸, D-444 164).

### 170. 이름 글자·길이·대소문자는?
- 장면: 이름 단계에서 사이보그 이름을 친다. 서버에서 하나뿐이어야 한다(D-134, D-443 159).
- 기획 원문: D-134 "쓸 수 있는 글자는 한글·영문·숫자, 길이 출발값 한글 2~8자, 영문 3~16자(구현 때 확정)".
- 가(지금): 한글 완성형·영문·숫자만, 빈칸·기호 없음. 길이는 한글 1자 = 2칸, 영문·숫자 1자 = 1칸으로 3~16칸(한글만이면 2~8자, 영문만이면 3~16자, 섞어도 된다). 숫자만은 안 된다. 대소문자는 같은 이름으로 본다(Kim = kim). 보이는 이름은 친 모양 그대로.
- 나: 섞기 금지(한글만, 또는 영문·숫자만).
- 다: 가 + 비슷한 글자(0·o, 1·l·I)도 같은 이름으로 본다(사칭을 더 막지만, 이미 있는 이름과 겹친다는 안내가 늘어난다).
- 답(D-445): 가. 길이는 D-134와 같다.

### 171. 금칙어·사칭은 무엇을 막나?
- 장면: "운영자", "GM" 같은 이름을 치면 막힌다.
- 기획 원문: D-134 "금칙어, 운영자 사칭, 모양이 비슷한 다른 나라 문자 섞기를 막는다. 금칙어 목록은 Step 5·7".
- 가(지금): [임시] 짧은 사칭 목록만 막는다(운영·관리자·시스템·admin·gm·moderator·system·terra 등). 욕설 목록은 Step 5·7이 정하면 같은 자리에 넣는다. 다른 나라 글자는 처음부터 받지 않으므로 혼동 문자 섞기는 생기지 않는다.
- 나: 출시 전 공개 금칙어 목록(외부 자료)을 들여온다(라이선스 확인 필요).
- 답(D-445): 가. 사칭 목록은 데이터로 두고, 욕설은 나중에 같은 자리에 더한다. 외부 목록을 들여오기 전에 라이선스를 확인한다.

### 172. 3D 모델이 없는 지금 외형은 무엇으로 고르나?
- 장면: 외형 단계에서 프리셋을 고르고 [무작위], 부위 넘기기, 색 고르기를 한다(D-6040 "전부다").
- 기획 원문: D-6040 "외형 = 부위 ID 묶음 + 색. 부위 수는 Step 8".
- 가(지금): 2D 그림 [임시]. 부위 4곳(머리·얼굴·몸통·팔다리) × 4개, 색 2칸(주색·포인트) × 8색, 프리셋 4개. 저장은 ID 묶음이라 3D 부위가 생기면 같은 칸에 모델을 붙이고, 옛 ID는 가까운 부위로 옮긴다.
- 나: 3D 모델 전까지 외형 단계를 빼고 프리셋 하나로 둔다.
- 다: 출시 목표 부위 수(Step 8)를 먼저 정하고 그 수로 2D를 만든다.
- 답(D-445): 가 + [무작위] 단추를 남긴다. 프리셋·무작위·부위 바꾸기·색 바꾸기가 한 화면(D-6040 "전부다"). 부위·색 수는 개발자 페이지 콘텐츠(D-398)라 싸면 콘텐츠 팩 자료로 둔다 → 이번 단계는 공용 상수(`packages/shared/src/cyborgLooks.ts`)로 두고, 팩 분류로 옮기는 일을 ADR "다음 단계"에 적었다.

### 173. 세력·시작 도시가 하나뿐인 지금은 어떻게 보이나?
- 장면: 세력 단계에 시험 NPC 세력 하나, 시작 도시 단계에 도시 하나만 나온다.
- 기획 원문: D-140 "16개국 중 NPC 세력", D-6041 "세력마다 안전 도시 2~4곳", D-341 "시작 도시는 주인이 바뀌지 않음". 지금 세계에는 시험 NPC 세력(고정)과 시험 2차맵마다 시작 도시 하나만 있다.
- 가(지금): 세계에 있는 것을 그대로 보여 주고 고르게 한다(하나면 미리 골라 둠). 16개국·도시 2~4곳은 행성 편집기 세력 배치(D-076·D-154)·NPC 세력 돌리기(R5)가 채우면 화면이 그대로 받는다.
- 나: 시험 세계에도 [임시] 세력 2개·도시 2~4곳을 더 둔다.
- 다: 세력·도시가 하나뿐이면 두 단계를 건너뛰고 자동으로 정한다.
- 답(D-445): 가.

### 174. 추천 지역과 정착 지원금은 지금 어떻게 보이나?
- 장면: 세력 단계에서 "추천" 표시와 지원금을 본다.
- 기획 원문: D-163 "사이보그당 1회", D-218 "유저가 적은 NPC 세력일수록 지원금을 더 많이 → 추천 지역", 공식은 Step 5.
- 가(지금): 지원금 공식과 세력 화폐가 아직 없어 금액은 보이지 않고, 사이보그가 가장 적은 세력에 "추천"만 붙인다. 지원금은 아직 주지 않는다. 공식이 오면 금액을 보이고 강하 때 한 번 준다(받았는지 저장, D-163 기술 전달).
- 나: [임시] 금액을 시험 화폐로 보이고 강하 때 준다.
- 답(D-445): 가.

### 175. 시작 도시 카드에 무엇을 보이나?
- 장면: 시작 도시 단계에서 도시마다 주변 자원·기후·붐빔을 보고 고른다(D-6041).
- 가(지금): 붐빔 = 그 도시에서 시작한 사이보그 수와 띠(한산·보통·붐빔, 문턱 [임시] 20·50명), 기본 선택은 가장 덜 붐비는 곳. 자원·기후는 서버가 2차맵 바이옴·기온을 읽게 되면 더한다(지금 "곧 보임").
- 나: 자원·기후를 보일 수 있을 때까지 시작 도시 단계를 미룬다.
- 답(D-445): 가. 문턱 20·50은 설정값 출발값.

### 176. 튜토리얼은 이번에 넣나?
- 장면: 강하가 끝나면 곧바로 대시보드다.
- 기획 원문: D-6042·D-6043 "강하 직후 핵심 10분: 이동·채집·창고, 첫 전투, 첫 유닛 고용·직무".
- 가(지금): 이번에는 넣지 않는다. 채집·창고·전투·고용 화면이 생긴 뒤 튜토리얼을 만든다. 그때 정착 안내 목표 카드(처리할 일 종류)도 같이 만든다.
- 나: 지금 최소 튜토리얼(2차맵에서 사이보그 이동하기 하나)을 넣는다.
- 답(D-445): 가.

### 177. 사이보그가 없는 기존 계정(운영자·개발자)은?
- 장면: NAS의 기존 관리자 계정이 배포 뒤 처음 들어온다.
- 가(지금): 모든 계정이 다음 접속 때 생성창으로 간다. dev·admin 역할은 만들기 전에도 관리자 화면·개발자 도구·지도(전체 보기·시험 일꾼)·설정을 연다.
- 나: dev·admin은 만들지 않아도 모든 화면을 연다(만들기는 원할 때).
- 답(D-445): 가.

### 178. 사이보그 본체는 유지비·보유 유닛 수에 드나?
- 장면: 대시보드·유닛 화면의 "보유 유닛", 시간마다 내는 유지비.
- 기획 원문: D-150 "유지비 = 유닛마다 필요한 생필품의 합". 본체가 생필품을 쓰는지는 정한 곳이 없다.
- 가(지금): 본체는 보유 유닛 수에 세지 않고(유닛 화면은 부하 유닛, 본체는 사이보그 화면), 지금 시험 유지비도 내지 않는다.
- 나: 본체도 유닛 하나로 세고 유지비를 낸다.
- 답(D-445): 가. 본체는 계정당 하나이고 보유 유닛 수(주거 상한 D-153)에 세지 않으며 생필품 유지비(D-150)도 없다. 다만 피로 회복은 주거에 따른다(D-430) — 피로·주거 규칙이 서버에 들어올 때 본체에도 건다(메모).

### 179. 강하는 어떻게 보이나?
- 장면: 마지막 [강하]를 누른 뒤.
- 기획 원문: D-058 "모항 = 신규 강하 연출", D-372 "출시 = 지구 + 모항 강하".
- 가(지금): 2초 안의 짧은 화면 연출(정거장 → 지구, 움직임 줄이기 설정이면 없음) 뒤 대시보드. 모항에 머무는 단계는 없다.
- 나: 1차맵에서 강하 지점을 보여 주고 확대한 뒤 2차맵으로 들어간다.
- 답(D-445): 가.
