# 아이템 편집기 규칙 질문 2: 탄약은 어떤 물건인가 (2026-11-01)

- 받는 곳: 사용자(직접 결정). 답이 나면 기획 세션에 원문을 보낸다.
- PLAN 14장 번호: 291(292~299는 비워 둔다).
- 상태: 답 받음 = 사용자 직접 답(2026-11-01). 아래 "답" 줄.

### 291. 화살·탄환은 보조 칸에 끼우는 장비 하나인가요, 쌓이는 탄약 묶음인가요?
- 이미 정해진 것
  - 전투 중에 물건을 쓴다. 화살·탄약은 보조무기 칸(화살통·탄창)이고 원거리로 칠 때마다 1씩 쓰며, 떨어지면 원거리 공격을 못 한다(D-496 287) [V `docs/design/02_Decision_Log.md:8608`].
  - 대분류 표에는 탄약이 5번 식품·소모품에 있다("요리·음료·약·탄약·버프", 완제품) [V `docs/design/50_Content_Rules.md:232`].
  - 장비는 스택 상한이 1이다. 장비는 만든 물건마다 범위의 자리와 등급이 있어서다(D-5003) [V 팩 검사 `item_stack_equipment`].
- 엇갈리는 곳: "보조무기 칸의 장비"라면 스택 1인 장비 한 개이고, "1씩 쓴다"면 수가 줄어드는 묶음이다. 대분류 표는 탄약을 소모품에 둔다.
- 장면: 활을 든 휴먼이 화살 200발로 전투에 나간다. 보조 칸에는 무엇이 들어 있고, 다 쓰면 칸에는 무엇이 남는가?
- 가) **화살통(장비, 보조 칸, 스택 1) + 화살(소모품, 쌓임)**. 화살통은 담는 수(예: 200)를 정하는 장비이고, 화살은 화살통에 넣는 소모품이다. 원거리 타격마다 화살통 안 화살이 1개 준다. 다 쓰면 빈 화살통이 남는다.
- 나) **탄약 묶음 자체가 보조 칸 장비(쌓이는 장비 예외)**. 보조 칸에 "화살 ×200"을 그대로 끼우고 타격마다 1씩 준다. 다 쓰면 칸이 빈다. 탄약만 "쌓이는 장비"로 예외를 둔다(만든 물건마다 자리·등급 없음).
- 다) 탄약은 소모품이고 보조 칸 장비가 아니다. 원거리 무기가 파티 화물의 맞는 탄약을 쓴다. 화살통·탄창은 두지 않는다(D-496 287의 "보조무기 칸"과 다르다).
- 추천: 가
  - D-496 287("보조무기 칸")과 대분류 표(탄약 = 소모품)를 둘 다 지킨다.
  - 장비 스택 1과 만든 물건마다 등급(D-5003)을 깨지 않는다.
  - 화살통 크기·무게가 장비 값이 되어 편집기에서 바로 정할 수 있다.
- 지금 구현(이 질문과 상관없는 부분만): 무기 종류 표 `weapon_types`에 보조 칸 종류(방패·화살통·탄창)를 두고, 원거리 무기에 `equip.weapon.ammo` = 쓰는 보조 칸 종류를 적는다. 탄약 아이템 모양·소모 실행은 답 뒤에 정한다.
- 답이 없으면: 원거리 공격은 지금처럼 탄약 없이 돈다(전투 결과 그대로, SIM_VERSION 6). 편집기에는 `ammo` 연결만 보인다.
- 답(사용자 2026-11-01, 원문): "내구도" → 탄약은 보조 칸에 끼우는 장비 하나(쌓지 않음)이고, 그 장비의 내구도가 남은 탄 수다. 원거리로 칠 때마다 내구도가 1 준다. 0이 되면 원거리 공격을 못 한다(D-496 287). 장비 스택 1과 만든 물건마다 등급(D-5003)을 그대로 지킨다. 다시 채우기(수리·보충)의 규칙은 내구도·수리 줄기에서 묻는다.
