# 입은 장비·버프 → 스탯 질문: 1차 스탯 ‰ 버프, 전투 수치 버프의 화면, 꺼진 아이템을 입고 있을 때 (2026-11-07)

- PLAN 14장 번호: 353~355.
- 지금 코드(답 전): 입은 장비(굴린 값 + 지금 정의의 무기 사양, 내구도 > 0만)·인공장기는 사이보그 화면·유닛 상세·생명 수치 최대·세계 전투 시작 사양에 든다(같은 함수 `apps/server/src/roster/unitBody.ts`). 걸린 효과는 두 갈래다: 1차 스탯 버프·디버프(고정값)는 성장값 뒤에 더하고(48 §2.3 "쓰는 1차 = 성장값 + 장비 1차 보너스 + 버프"), 전투 수치 버프(공격 ‰·방어율·회피·관통·크리 배율·이동 속도·쉴드 재생)는 전투 시작 때 판정의 걸린 효과로 넣는다(효과 합 `modifiersOf`가 그대로 읽는다).

### 353. 1차 스탯 ‰ 버프(효과 사전 "바꾸는 수치" = STR~WIS, 값 방식 ‰)는 무엇에 곱하나요?
- 효과 사전은 1차 스탯 버프에 값 방식 ‰를 고를 수 있다(팩 형식 `effects` `valueMode`). 지금 팩에는 1차 스탯 버프가 없다(효과 7개 모두 전투 수치·회복·상태).
- 옛 규칙: 옛 요리 버프는 모두 고정값이다(옛 문서 `docs/GDD/Item/Consolidated_Item.md:748~751` "감자 구이 INT+2, WIS+2", "사슴 구이 STR+3, VIT+3", "붕어 찜 DEX+3, AGI+3", AntiGravt01 main `0ea5299`). ‰ 1차 버프는 옛 문서·코드에 없다. 옛 서버는 버프를 저장하지도 않았다(대조 `docs/research/2026-11-03-old-item-holdings.md` 사용 줄).
- 가) 성장값 × ‰를 더한다(장비 보너스는 따로). 나) (성장값 + 장비 1차 보너스) × ‰를 더한다. 다) 1차 스탯 버프는 고정값만(아이템 편집기 효과 사전 탭이 ‰를 막는다).
- 지금 코드: ‰ 1차 버프는 아무것도 주지 않는다(걸리기는 한다 — 효과 목록에는 보인다).
- 추천: 다 — 옛 요리 표가 모두 고정값이고, 곱하는 바탕을 고르지 않아도 된다.

### 354. 전투 수치 버프(공격 ‰·방어율 등)를 사이보그 화면의 스탯 줄에도 보여야 하나요?
- 지금 코드: 그 버프는 판정의 "⑥ 버프·디버프"(48 §4 6축 곱)라 2차 스탯 행 값을 바꾸지 않는다. 사이보그 화면 상세 전투 스펙의 실제 공격력·방어율 줄은 버프 없는 값이고, 걸린 버프는 같은 화면 보유 물건 판의 "걸린 효과"(남은 시간)에 보인다. 전투에서는 든다.
- 48 §3.1: 양 모양 행 = 기본 + 가중합 + 장비 + 버프, 확률 모양 점수에는 버프를 넣지 않는다. 그런데 효과 사전의 전투 수치는 2차 행 ID가 아니다(공격 ‰는 행이 없는 배율, 방어율·회피는 확률 모양의 끝 ‰에 더한다).
- 가) 지금대로(스탯 줄은 버프 없는 값, 버프는 효과 목록). 나) 스탯 줄 옆에 "버프 +n" 표를 붙인다(값은 판정과 같은 합). 다) 버프 든 값을 줄 값으로 보인다.
- 추천: 나 — 판정 값과 화면 값이 함께 보이고, 랭킹은 버프를 뺀 값(D-7022)이라 줄 값 자체는 그대로 두는 편이 맞다. 화면 줄기에서 한다.

### 355. 꺼진 아이템(D-398 켬·끔)을 입고 있으면 그 장비는 스탯을 주나요?
- 지금 코드: 전투 자료(`combatCatalogFrom`)가 켜진 장비만 싣기 때문에, 이미 입은 꺼진 장비는 칸에 남지만(보유 물건 목록·칸에 보인다) 스탯·무기 사양을 주지 않는다. 새로 생기지는 않는다(D-398 "끈 항목은 새로 나오지 않는다", 보유 물건 ADR 4절).
- 가) 주지 않는다(지금 코드 — 개발자가 끄면 바로 빠진다). 나) 준다(꺼짐은 새로 생기는 것만 막는다, 이미 가진 것은 그대로 — D-5008 "산 물건의 성능이 줄지 않는다"와 같은 뜻).
- 추천: 나 — 산 물건의 성능을 지키는 원칙(285 "새것부터", D-5008)과 맞다. 고르면 전투 자료에 꺼진 장비 정의도 싣는다(서버만, 시뮬 출력 그대로).
