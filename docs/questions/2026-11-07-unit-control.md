# 2차맵 유닛 조종 질문: 카메라·운영자 모드·목록 범위·여러 유닛·거절 코드·감사 기록·남의 유닛 정보·목록 차례 (2026-11-07)

- 받는 곳: 기획 세션(사용자에게 물을 것은 기획이 고른다).
- PLAN 14장 번호: 630~637.
- 상태: 열림(확인 대기, 모양만).
- 답(630~637, 기획 커밋 `4de8c68`, D-519 포인터 — 기획 정리): **630만 바뀜** — 플레이어 2차맵 카메라는 내 유닛·내 세력 시야 둘레로 묶고, 시야 자유 이동은 운영자 모드만(D-519 원문 "운영자는 다른 유닛 조종이나 시야 자유이동이 가능"). 나머지는 추천대로 — 631 다, 632 다, 633 다(파티가 생길 때), 634 나(쓰러짐·포로 흐름 때), 635 다(관리자 화면 줄기), 636 나, 637 나. 630·631·632·636·637은 다음 줄기.
- 지금 코드: 서버는 이동·멈추기 명령을 내 유닛(수호신 빼고)이거나 운영자(dev·admin)일 때만 받는다(남의 유닛·없는 유닛 `not_owner`, 내 수호신 `unit_stays`, 프로토콜 17). 2차맵 화면에 [내 유닛 N] 목록(사이보그 먼저, 상태 한 마디)이 있고, 줄을 누르면 고르고 카메라가 그 자리로 간다. 땅을 누르면 이동, 가는 동안 [멈추기]. 남의 유닛은 눌러도 번호·움직임만 보인다. dev·admin은 [운영자 모드]를 켜면 모든 유닛을 명령하고 안개 없이 2차맵 어디든 보며, 위 판에 "운영자"가 뜬다. 운영자가 남의 유닛을 옮기거나 세우면 감사 기록에 남는다.

### 630. 플레이어의 2차맵 카메라는 어디까지 움직이나요?
- 정해진 것: 모든 층은 안개 규칙을 따른다(D-103). 사용자 원문 "운영자는 … 시야 자유이동이 가능".
- 지금 코드: 플레이어도 그 2차맵 전체(경계 너머 이웃 2차맵 포함)를 끌어 볼 수 있다. 탐사하지 않은 곳은 검게, 시야 밖 남의 유닛은 보이지 않는다(서버가 거른다). 운영자 모드는 안개가 없다.
- 가) 지금대로(카메라는 자유, 안개가 가린다). 나) 플레이어 카메라는 탐사한 곳 둘레로만. 다) 내 유닛 시야 안으로만(유닛을 따라다님).
- 추천: 가 — 안개가 이미 정보를 가리고, 카메라를 묶으면 짓기 자리 고르기·도시 둘러보기가 불편하다. 원문의 "시야 자유이동"은 안개 없이 보는 것으로 읽었다.

### 631. 운영자 모드는 늘 켜져 있나요, 켜고 끄나요?
- 정해진 것: 없음(운영자 개입은 기록한다, D-7021).
- 지금 코드: dev·admin에게 [운영자 모드] 단추. 화면을 열 때마다 꺼진 채(플레이어처럼 보임), 켜면 모든 유닛 명령 + 안개 없는 전체 보기 + "운영자" 표시.
- 가) 지금대로. 나) dev·admin은 늘 켬. 다) 가 + 이 기기에서 마지막 상태를 기억.
- 추천: 다 — 운영 계정도 자기 사이보그로 플레이하므로 끌 수 있어야 하고, 운영 중에는 다시 켜는 수고를 던다.

### 632. 2차맵 화면의 내 유닛 목록에는 어느 유닛이 나오나요?
- 정해진 것: 데스크톱은 지도 옆에 유닛 목록 판(기획 60 §2.4). 유닛 화면은 모든 유닛(걸러 보기, D-6016).
- 지금 코드: 이 2차맵에 있는 내 유닛만(사이보그 본체 포함).
- 가) 지금대로. 나) 모든 2차맵의 내 유닛(다른 2차맵 유닛은 그 2차맵 이름과 함께, 누르면 그 2차맵으로). 다) 가 + "다른 곳에 N" 한 줄(누르면 유닛 화면).
- 추천: 다 — 지도 화면은 지금 2차맵에서 명령하는 곳이라 목록이 짧아야 하고, 다른 곳 유닛이 있다는 것은 알 수 있다.

### 633. 여러 유닛에 한 번에 명령하나요?
- 정해진 것: 자동화의 다중 선택(거점·종류·상태로 걸러 같은 직무, D-6016). 파티·진형 편성(기획 60 §9 유닛 화면).
- 지금 코드: 2차맵에서 한 유닛씩 고르고 명령한다.
- 가) 지금대로. 나) 목록에서 여러 줄을 고르면 같은 곳으로(서버가 둘레 칸에 나눠 세움). 다) 파티 단위로만(파티를 고르면 진형대로).
- 추천: 다 — 기획의 파티·진형과 맞고, 전투 화면(파티별 AI 작전 D-5039)과 이어진다. 파티 편성이 서버에 생길 때 넣는다(그 전엔 가).

### 634. 포로·중태 유닛에 명령하면 어떤 답을 주나요?
- 정해진 것: 중태는 활동 불가(D-145), 포로는 몸값 경매(D-310).
- 지금 코드: 목록은 "포로로 잡힘"·"중태"로 보이고 화면은 보내지 않는다. 서버에 보내면 `invalid_request`(전용 코드 없음).
- 가) 지금대로. 나) 전용 결과 코드(`unit_unavailable`) — 화면이 까닭을 문장으로.
- 추천: 나 — 전투 화면(L1)에서 쓰러짐·포로 흐름을 만들 때 함께 더한다.

### 635. 운영자가 한 일은 어디까지 감사 기록에 남기나요?
- 정해진 것: 운영자 개입은 원장에 운영자 사건으로 남기고 관리자 화면에서만 본다(D-7021, 경제 개입). 전체 보기를 켜면 감사 기록(S3).
- 지금 코드: 운영자 권한으로만 된 명령(남의 유닛·수호신 이동·멈추기, 된 것만)과 전체 보기 켜기를 감사 기록(`second_map.operator_command`·`second_map.observe`)에 남긴다. 내 유닛 명령은 남기지 않는다.
- 가) 지금대로. 나) 운영자 모드를 켜고 끈 때도. 다) 나 + 관리자 화면에 운영자 개입 목록.
- 추천: 다 — D-7021과 같은 "운영자 개입" 틀로 한 곳에서 본다. 관리자 화면 줄기에서 넣는다.

### 636. 남의 유닛을 누르면 무엇이 보이나요?
- 정해진 것: 시야 밖 이름이 새지 않는다(D-103), 위치는 내가 아는 도시 기준(D-476).
- 지금 코드: "다른 주인의 유닛 #번호(이동 중/서 있음)" — 명령 단추 없음.
- 가) 지금대로. 나) 가 + 주인 세력 이름·유닛 종류(시야 안일 때). 다) 나 + 정찰로 알게 된 스탯(정찰 명령 D-6019).
- 추천: 나 — 시야 안 유닛은 이미 보이는 것이라 세력·종류를 알려도 새지 않는다. 다는 정찰 규칙이 생길 때.

### 637. 내 유닛 목록은 어떤 차례인가요?
- 정해진 것: 유닛 화면 기본 정렬은 손이 필요한 순(질문 137 → D-443).
- 지금 코드: 사이보그 본체 먼저, 그다음 유닛 번호 차례.
- 가) 지금대로. 나) 사이보그 먼저 + 손이 필요한 순(포로 → 부상 → 대기 → 쉼 → 일함). 다) 사이보그 먼저 + 화면 가운데에서 가까운 순.
- 추천: 나 — 유닛 화면과 같은 규칙이라 익숙하고, 명령이 필요한 유닛이 위에 온다.
