# 계산식 식 조각판 질문 (2026-11-08)

- 받는 곳: 사용자(개발 도구 사용자) — 기획 세션은 참고만.
- PLAN 14장 번호: 880~881.
- 상태: 확인 대기(답이 없으면 지금 코드).
- 지금 코드 요약: 계산식 탭 식 칸 옆(좁으면 아래)에 칸 변수·중간값·함수·연산자 칩. 마우스는 끌어 놓은 자리에, 누르면 글자 위치에 넣는다. 함수는 자리표시 인자를 붙여 첫 인자를 고른다. 휴대폰은 누르기만.

### 880. 휴대폰에서도 칩을 끌어 놓게 할까요?
- 정해진 것: 사용자 원문은 "드래그해서 쓸수있게". 개발 화면은 휴대폰(390px)에서도 쓴다(개발 도구 공통 요구).
- 지금 코드: 손가락 입력이면 끌기를 끄고 누르기만 둔다(누르면 글자 위치에 넣고, 자판이 올라오지 않게 글 상자에 초점을 주지 않는다). 손가락 끌기는 화면 스크롤과 겹치고, 놓을 자리를 손가락이 가린다.
- 가) 지금대로(휴대폰은 누르기만). 나) 길게 누른 뒤 끌기(포인터 이벤트로 직접 만든다, 스크롤과 구분). 다) 휴대폰은 칩을 누르면 "넣을 자리 고르기" 모드가 되고 글 상자의 자리를 한 번 더 눌러 넣는다.
- 추천: 가 — 글자 위치를 먼저 눌러 두고 칩을 누르면 같은 결과이고, 손이 덜 가며 실수(스크롤하다 넣음)가 없다.

### 881. 함수 자리표시 인자를 영어 낱말로 둘까요?
- 정해진 것: 식 이름은 영어 대문자 변수·영어 함수다(ADR 1절). 자리표시는 채우지 않으면 담기가 막혀야 한다(오타 막기 D-488).
- 지금 코드: `clamp(value, lower, upper)`·`if(condition, whenTrue, whenFalse)`처럼 영어 낱말(모르는 이름이라 검사가 막는다, 어떤 변수와도 비슷하지 않아 "고치기" 권함이 붙지 않는다). 한국어 화면에서도 같다. 칩 풀이에는 한국어 모양(`clamp(값, 아래, 위)`)이 보인다.
- 가) 지금대로(영어 낱말). 나) 빈 자리(`clamp(, , )`, 문법 오류로 막힘 — 첫 자리만 알린다). 다) 한국어 낱말(`clamp(값, 아래, 위)`, 문법 오류 "알 수 없는 글자"로 막힘).
- 추천: 가 — 모든 자리를 한꺼번에 "모르는 이름"으로 짚어 주고, 고른 자리에 바로 변수를 넣으면 된다.
