# 채집소 기능 질문 (2026-11-08)

- 받는 곳: 기획 세션(사용자에게 물을 것은 기획이 고른다).
- PLAN 14장 번호: 750~757.
- 상태: 답함(D-523 포인터, 기획 정리 2026-11-08 — 모두 기술 추천, 사용자 결정 아님): 750~755·757 = 지금 코드, 756 = ②(농장도 채집소 창고·버프). 756은 가지 `work/farm-station`에서 넣음(ADR "바뀜 (756 ②)", 새 모양 질문은 `docs/questions/2026-11-08-farm-station.md` 810~813). 아래 "지금 코드"는 답 전 서버가 하던 일이다.
- 지금 코드: 벌목장·광산(오브젝트 종류가 맡는 채집 시설)을 누르면 채집소 판(레벨·반경 고리·버프·반경 안 원자재·채집소 창고·일꾼·레벨 올리기)이 열린다. 직무 배치·노동 계약 일꾼의 정산 산출이 묶음마다 반경 안 오브젝트 번수를 하나씩 쓰고(없으면 못 냄), 레벨 수확 버프를 곱해 채집소 창고에 넣는다. 정산 뒤 피로를 레벨 배율만큼 덜어 준다. 채집소 창고의 주인 몫은 10분([임시])마다 그 도시 창고로 자동으로, 또는 손으로 옮긴다. 레벨이 오르면 반경·수확·피로·다시 자람 버프가 커진다.
- 이미 정해져 묻지 않은 것: 채집 지점마다 다시 자라는 시각(D-112), 오염된 땅은 덜 자람(D-115), 채집 티어·옛 1차 생산 규칙(D-506·D-507), 작물·가축은 시설로만(D-519), 직무 위치는 같은 2차맵(D-518 522 ①), 수치는 밸런싱 단계(D-515).

### 750. 채집소 일꾼 산출은 반경 안 오브젝트가 있어야만 나오나요?
- 지금 코드: 그렇다(질문 664 ②를 넣음). 묶음 하나 = 반경 안 오브젝트 번수 하나. 반경 안에 오브젝트가 없거나 모두 떨어졌으면 일꾼이 있어도 내지 않는다(판에 "원자재 없음"). 그래서 오브젝트가 몰린 곳에 지어야 한다.
- 다른 모양: ① 오브젝트가 없으면 느리게라도 낸다(예: 절반), ② 오브젝트는 버프만 주고 산출은 예전대로.
- 추천: 지금 코드(사용자 답 "오브젝트가 몰린곳에"를 그대로 담는다).

### 751. 채집소 일꾼은 지도에서 실제로 걸어 다니며 캐나요?
- 지금 코드: 걷지 않는다. 정산(소유 주체 정산, 최대 1시간마다)에서 시설 안에서 일한 것으로 셈하고, 쓴 오브젝트가 지도에서 떨어진 것(회색 고리)으로 보인다. 내 유닛을 직접 보내 캐게 하는 것(채집 줄)은 따로 된다(판의 [고른 유닛으로 직접 캐기]).
- 다른 모양: ① 일꾼이 실제로 반경 안 오브젝트로 걸어가 캐고 채집소에 넣는다(채집 줄과 같은 꼴 — 서버를 다시 켜도 이어지려면 채집 줄 저장이 필요, 질문 670), ② 지금 코드.
- 추천: 지금 코드 → 채집 줄 저장(670)이 생기면 ①을 다시 본다.

### 752. 채집소 산출 아이템은 무엇인가요?
- 지금 코드: 시설 사다리 그대로(벌목장 = 목재 중분류 티어 추첨, 광산 = 광석 중분류 티어 추첨, 시뮬과 같은 규칙). 쓴 오브젝트 종류의 아이템(침엽수 → 소나무 원목 등)이 아니다.
- 다른 모양: ① 쓴 오브젝트 종류의 아이템을 낸다(티어 없음), ② 오브젝트 아이템 + 사다리 티어 덤.
- 추천: 지금 코드(시뮬 대응을 바꾸지 않는다).

### 753. 채집소 창고와 도시 창고로 옮기기는 어떤 꼴인가요?
- 지금 코드: 일꾼 산출·직접 채집 넣기·들어가기 넣기가 모두 채집소 창고(그 건물 창고, 상한 = 팩 storageKg × 레벨)에 모인다. 창고가 차면 묶음을 끝내지 않는다. 주인 몫은 10분([임시])마다 그 도시의 주인 도시 창고로 자동으로 옮기고, 판의 [도시 창고로 옮기기]로 바로 옮긴다(운송 시간·비용 없음). 도시 밖 채집소는 옮길 곳이 없다.
- 다른 모양: ① 예전처럼 도시 창고로 바로, ② 자동 옮김 없이 손·운송으로만, ③ 자동 옮김에 운송 시간·비용(운송 줄기, D-117).
- 추천: 지금 코드 → 운송 줄기 때 ③.

### 754. 레벨 버프는 어떤 꼴인가요?
- 지금 코드: 레벨마다 같은 걸음으로 — 반경 +4칸, 수확 +200‰, 피로 배율 −50‰, 다시 자람 배율 −50‰(둘 다 하한 200‰). 모두 설정 칸.
- 다른 모양: ① 레벨마다 정한 표(건물 편집기), ② 반경은 레벨과 상관없이 고정, ③ 어떤 버프는 특정 레벨부터.
- 추천: 지금 코드(수치는 D-515).

### 755. 채집소 일꾼의 피로는 어떻게 덜어 주나요?
- 지금 코드: 직무 규칙대로 쌓인 뒤 정산 끝에 일한 주기 × (1000 − 피로 배율)‰을 덜어 준다. 오브젝트·창고에 막혀 묶음을 하나도 못 끝낸 구간은 기다림이라 모두 덜어 준다.
- 다른 모양: ① 막혀도 피로가 쌓인다, ② 막히면 직무를 쉬게 한다(쉼 단계).
- 추천: 지금 코드.

### 756. 농장(오브젝트가 없는 채집 시설)도 채집소 창고·버프를 받나요?
- 지금 코드: 받지 않는다. 판(레벨·일꾼·레벨 올리기)만 보이고 산출은 예전처럼 도시 창고로 바로, 레벨 수확·피로 버프 없음.
- 다른 모양: ① 농장도 채집소 창고·피로·수확 버프, ② 목장·약초원(질문 665)과 함께 정한다.
- 추천: ②.

### 757. 일꾼 상태·끝낸 묶음 수를 저장하나요?
- 지금 코드: 메모리에만 둔다(서버를 다시 켜면 "정산 기다림"·0부터). 산출·오브젝트 상태·창고 물건은 저장된다.
- 다른 모양: ① 저장해 이어 보인다(작업 기록 표).
- 추천: 지금 코드(채집 줄 저장 670과 함께 본다).
