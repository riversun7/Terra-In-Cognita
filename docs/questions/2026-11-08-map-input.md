# 2차맵 지도 조작 질문: 채집 표시 보이기·배율 표시·누르기 차례·따라가기 (2026-11-08)

- 받는 곳: 기획 세션(사용자에게 물을 것은 기획이 고른다).
- PLAN 14장 번호: 720~725.
- 상태: 열림(확인 대기, 모양만 — 답이 없으면 지금 코드).
- 지금 코드: 2차맵 위 채집 오브젝트·건물 표시는 손가락을 받지 않아 표시 위에서도 지도가 끌린다. 짧게 누르면(움직임 10px 안) 유닛 → 표시(화면 거리 22px) → 땅 차례로 고른다. 땅을 누르면 건물 칸이면 건물 판, 아니면 고른 유닛을 보낸다(오브젝트 둘레 땅을 눌러도 오브젝트 판을 열지 않는다). 내 유닛(운영자 모드면 아무 유닛)을 고르면 카메라가 그 유닛을 따라가고, 손으로 끌면 끊겨 [따라가기]로 다시 붙는다. 확대 사다리는 "2차맵 3/5"(1~5단계)이고 [+]·[−]가 한 단계씩, 가장 멀리에서 [−]를 한 번 더 누르면 1차맵 5단계.

### 720. 2차맵 채집 오브젝트 표시는 언제 보이나요?
- 정해진 것: 오브젝트는 바이옴별 원자재(D-519), 표시는 화면 편의(서버가 채집을 판정).
- 지금 코드: 가까이 볼 때(목표점 1m가 1px 이상 — 휴대폰 세로로 화면 짧은 변 약 390m 안) 화면 가운데에 가까운 40개. 떨어진 것은 속 빈 회색 고리.
- 가) 지금대로. 나) 확대 4~5단계에서만(멀리서는 숨김). 다) 고른 유닛(또는 내 유닛) 시야 안의 것만.
- 추천: 가 — 끌기·잘못 누름의 원인은 표시가 손가락을 받는 것이었고(고침) 표시 수가 아니었다. 표시가 빽빽해 보기 어렵다는 지적이 다시 나오면 나.

### 721. 2차맵 배율은 어떻게 보이나요?
- 정해진 것: 1차맵은 "1차맵 3/5" + 점 다섯(ADR 2026-11-07-planet-view 1절, 질문 652 경계는 열림).
- 지금 코드: 2차맵도 같은 모양 "2차맵 3/5"(거리 한계를 로그 눈금으로 다섯 등분, 1 = 가장 멀리).
- 가) 지금대로. 나) 가 + 축척 막대(예: "100m" 막대). 다) 단계 대신 화면 폭 m 글자(예: "약 160m").
- 추천: 가 — 1차맵과 같은 사다리라 익숙하다. 거리를 재야 하는 규칙(사거리·시야 표시)이 생기면 나.

### 722. 유닛과 표시가 겹친 곳을 누르면 무엇을 고르나요?
- 정해진 것: 남의 유닛은 정보만, 내 유닛은 명령(기획 답 630~637).
- 지금 코드: 유닛 먼저(화면 22px + 몸), 없으면 표시(22px), 없으면 땅.
- 가) 지금대로. 나) 표시 먼저. 다) 화면 거리가 가장 가까운 것.
- 추천: 가 — 지적이 "오브젝트가 잘못 눌린다"이고 유닛은 적다. 채집 중인 내 유닛 바로 옆 오브젝트는 조금 떨어져 누르거나 키우면 된다.

### 723. 어떤 손짓이 유닛 따라가기를 끊나요?
- 정해진 것: 없음(사용자 원문 "화면은 선택된 유닛으로 고정되어야함").
- 지금 코드: 한 손가락 끌기(10px 넘게)와 다른 곳으로 옮기기([내 사이보그] 등)만 끊는다. 두 손가락·휠 확대·회전, [+]·[−]는 끊지 않고 그 유닛을 가운데에 둔 채 바뀐다.
- 가) 지금대로. 나) 끌기 + 두 손가락. 다) 끊지 않음(끌어도 놓으면 돌아감).
- 추천: 가 — 길 안내 지도와 같은 조작이고, 둘러보기는 끌기로 한다.

### 724. 어느 유닛을 따라가나요?
- 정해진 것: 플레이어 카메라는 내 유닛·내 세력 시야 둘레(630), 운영자 모드는 자유.
- 지금 코드: 내 유닛(명령을 못 하는 머묾·포로·중태 포함), 운영자 모드면 아무 유닛. 남의 유닛은 눌러도 따라가지 않는다.
- 가) 지금대로. 나) 남의 유닛도 시야 안이면 따라감(카메라 범위 안에서만).
- 추천: 가 — 남의 유닛은 시야 밖으로 나가면 사라져 따라가기가 자주 끊긴다. 정찰·추적 명령이 생길 때 다시 본다.

### 725. 2차맵을 처음 열 때 따라가나요?
- 정해진 것: 카메라는 지형이 서면 내 사이보그 자리에 맞춘다(D-6017).
- 지금 코드: 처음엔 내 사이보그 자리에 한 번 맞추고 고르지 않는다(따라가지 않음). 고르면 따라간다.
- 가) 지금대로. 나) 내 사이보그가 있는 2차맵이면 열 때 내 사이보그를 골라 따라간다.
- 추천: 가 — 원문은 "선택된 유닛"이고, 열자마자 고르면 땅을 누를 때 뜻하지 않게 사이보그를 보낸다.
