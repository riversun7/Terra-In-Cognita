# 세계 배치 2 질문: 사람이 놓는 국가 자리·자리가 드는 때·이미 선 국가 옮기기·NPC 수도·"시작 = 시작 세력" (2026-11-08)

- 받는 곳: 기획 세션(사용자에게 물을 것은 기획이 고른다).
- PLAN 14장 번호: 860~868.
- 상태: 확인 대기(답이 없으면 지금 코드).
- 지금 코드(이 줄기): 개발자·관리자 화면 `/dev/world-layout`(dev·admin)이 행성 평면 지도(1차맵 타일)에 고정 NPC 국가마다 자리(수도 2차맵 하나)를 놓는다(표 `world_nation_placements`, 세력 코드로 적어 세계 새로 시작 뒤에도 남는다, 감사 기록). 놓은 자리는 서버가 다음에 켤 때 든다: 시작 도시가 없는 국가는 그 자리에 서고, 시작 도시가 선 국가는 막는 것이 없을 때만 국가째 옮긴다. 자리를 놓지 않은 국가는 자동 배치(가장 먼 점 고르기, 화면의 [자동 제안]). 수도는 NPC가 하루 끝마다 발전도로 고르고, 다른 도시가 10점(설정 칸 `npc_capital_switch_dev`) 넘게 앞서면 옮긴다. 지도자는 수도를 따라간다. D-341 시작 도시 보호는 그대로(도시 표시 `start`).

### 860. 사람이 놓는 것은 국가의 수도 자리 하나인가요, 도시 하나하나인가요?
- 정해진 것: 고정 NPC 세력의 자리는 개발자·관리자 페이지에서 사람이 행성 위에 놓는다(D-528). 국가마다 시작 도시 2~4곳(D-6041).
- 지금 코드: 국가마다 수도 2차맵 하나만 놓는다. 시작 도시는 그 둘레(붙은 2차맵)에 세계 배치가 자동으로 고른다(질문 641과 같은 규칙).
- 가) 지금대로(국가 자리 하나). 나) 시작 도시마다 자리를 놓음(도시 수만큼 누름). 다) 가 + 화면에서 도시 하나씩 옮길 수도 있음.
- 추천: 다 — 처음엔 국가 하나 누르기로 빠르게, 필요하면 도시를 고쳐 놓는다.

### 861. 놓은 자리는 언제 세계에 드나요?
- 정해진 것: 없음.
- 지금 코드: 다음 서버 시작 때(세계 씨앗). 실행 중인 2차맵·NPC 사회 런타임·유닛을 그 자리에서 옮기지 않는다(옮길 2차맵을 띄우고 거울 세계를 다시 짜는 일이라 위험이 크다). 화면은 "다음 시작 때 듦"으로 보인다.
- 가) 지금대로(다음 시작 때). 나) 화면의 [지금 들이기] 단추로 서버가 그 자리에서 옮김(실행 중 옮기기). 다) 가 + 세계 새로 시작(reset-world) 때 반드시 놓은 자리로.
- 추천: 다 — 운영 중에 국가를 옮길 일은 드물고, 시험 세계는 새로 시작할 때 놓은 자리로 선다(지금도 그렇다).

### 862. 시작 도시가 이미 선 국가를 옮길 때 무엇이 막나요?
- 정해진 것: 플레이어 자료를 말없이 지우지 않는다(작업 지시). 시작 도시는 주인이 바뀌지 않는다(D-341).
- 지금 코드: 국가 단위로 모두 옮기거나 하나도 옮기지 않는다(한 국가가 둘로 갈라지지 않게). 막는 것 = 옛 자리 옮기기(질문 645, `world/relayout.ts`)와 같은 목록(돌고 있는 전투·플레이어 건물·시설 계약·직무·플레이어 작업·수호신·영토 비콘·2차맵의 플레이어 유닛·일·이동 중인 사이보그·NPC 휴먼 계약·NPC 건물 창고 물건) + 그 국가의 시작 도시가 아닌 도시(실행 중에 세운 마을) `other_cities`. 놓을 때 지금 막는 것을 미리 보이고, 켤 때 다시 본다. 옮기면 도시 ID 그대로(창고·주문·지분·이름이 따라감), NPC 시설은 새 자리에 다시, NPC 휴먼·그 도시가 시작 도시인 쉬는 사이보그·지도자는 새 도시 둘레로.
- 가) 지금대로(막히면 하나도 안 옮김). 나) 막힌 도시만 남기고 나머지는 옮김(국가가 갈라질 수 있음). 다) 가 + 마을도 함께 옮김(마을 둘레 자리를 새로 고름).
- 추천: 다 — 마을이 옛 자리에 홀로 남지 않는다.

### 863. NPC는 수도를 어떻게 고르고 언제 옮기나요?
- 정해진 것: 수도는 발전도가 높거나 알맞은 도시를 NPC가 정하고, 상황에 따라 옮길 수 있다(D-528).
- 지금 코드: 수도 = 그 세력 도시 가운데 발전도가 가장 높은 도시. 같으면 시작 도시 먼저, 그다음 작은 도시 ID [임시]. 하루 끝(UTC 0시)마다 다시 보고, 다른 도시가 지금 수도보다 발전도 10점(설정 칸 `npc_capital_switch_dev` [임시]) 이상 높으면 옮긴다. 수도를 잃으면(점령·폐허) 문턱 없이 남은 도시에서 바로 고른다. 모든 NPC 세력이 같은 규칙(고정 국가만이 아님).
- 가) 지금대로(발전도 + 문턱). 나) 발전도 + 둘레 안전(전선에서 먼 도시) + 인구를 섞은 점수. 다) 나 + 성향(공격 성향은 전선 가까이, 상업 성향은 거래소가 큰 도시).
- 추천: 다 — "알맞은 곳"(D-528)을 성향으로 읽는다. 수치는 설정 칸.

### 864. D-341 "시작 도시" 보호를 "시작 세력"으로 읽으면 무엇이 보호되나요?
- 정해진 것: D-528: "시작"은 도시가 아니라 세력이다(시작 세력을 고르고 그 안 도시를 고른다). D-341의 "시작 도시"는 "시작 세력"으로 읽는다(해석, 세부 확인 대기). D-341: 시작 도시는 주인이 절대 바뀌지 않는다(웨이브 폐허 없음·독립 투표 없음·반란 승리 = 만족도 회복). 46 §9.2: 나머지 도시·영토는 전쟁·반란으로 잃을 수 있다.
- 지금 코드: 바꾸지 않았다 — 고정 국가가 처음 세운 시작 도시(도시 표시 `start`)만 보호한다. 수도와는 다른 개념이다(수도는 시작 도시가 아니어도 된다).
- 가) 지금대로(처음 세운 시작 도시들만 보호 — 플레이어가 고르는 도시 목록과 같다). 나) 고정 국가(시작 세력)의 모든 도시를 보호(전쟁·반란으로 잃지 않음 — 46 §9.2 "나머지 도시는 잃을 수 있다"와 부딪침). 다) 고정 국가의 수도만 보호(수도가 옮겨 가면 보호도 따라감).
- 추천: 가 — 지금 규칙과 같고, "시작 세력을 고르고 그 안 도시를 고른다"의 도시 목록이 곧 보호 도시라 플레이어 안전 도시(D-140)가 그대로다.

### 865. 수도가 바뀌면 지도자는 어떻게 움직이나요?
- 정해진 것: 지도자는 수도 행정 건물 곁에 선다(질문 741·742, "WP-NPC").
- 지금 코드: 수도가 바뀌면 지도자가 새 수도 행정 건물 곁으로 바로 옮겨 선다(걷지 않음). 새 수도 2차맵을 띄우지 않았으면 그 자리에 두고 다음 켤 때 옮긴다.
- 가) 지금대로(바로 옮겨 섬). 나) 2차맵 사이 이동(WP9)으로 걸어서 감(가는 동안 습격받을 수 있음). 다) 나 + 처리할 일·소식으로 "수도 이전"을 알림.
- 추천: 다 — 수도 이전이 세계 사건으로 보인다.

### 866. 자리를 놓을 때 무엇을 검사하나요?
- 정해진 것: 다른 세력 범위에 도시를 세우지 않는다(사용자 지적 2026-11-07).
- 지금 코드: 누른 칸이 시작 도시가 설 땅(질문 642)이 아니면 12칸 안의 가장 가까운 알맞은 땅으로 옮겨 놓는다(없으면 거절). 다른 국가 자리(놓은 자리, 없으면 지금 수도)와 국가 간격(30칸, 설정 칸 `world_layout_nation_gap_cells`)보다 가까우면 거절, 시험 2차맵 줄 둘레 국가 간격 안이면 거절.
- 가) 지금대로. 나) 간격은 경고만(사람이 고른 것을 믿음). 다) 가 + 다른 NPC 마을·플레이어 도시 영향권도 봄.
- 추천: 다 — 켤 때 시작 도시 자리 고르기가 영향권을 보므로 미리 보이는 편이 맞다.

### 867. 자리를 놓지 않은 국가는 어떻게 하나요?
- 정해진 것: 고정 NPC 세력은 사람이 놓는다(자동 배치가 아님, D-528).
- 지금 코드: 자리를 놓지 않은 국가는 자동 배치(가장 먼 점 고르기)로 선다(뒷길). 화면의 [자동 제안 보기]가 같은 함수로 자리를 보여 주고 [제안 모두 놓기]로 한 번에 놓는다.
- 가) 지금대로(자동은 뒷길). 나) 놓지 않은 국가는 세우지 않음(서버 시작 때 경고). 다) 가 + 출시 전 점검표에 "모든 국가 자리를 놓았나".
- 추천: 다 — 개발·시험 세계는 바로 돌고, 출시 세계는 사람이 모두 놓는다.

### 868. 수도를 화면 어디에 보이나요?
- 정해진 것: 없음.
- 지금 코드: 정부(행정 건물) 판의 "수도" 표시와 지도자 자리만 수도를 따른다. 1차맵·세력 화면·시작 도시 고르기에는 수도 표시가 없다.
- 가) 지금대로. 나) 1차맵 도시 표시에 수도 별 표지. 다) 나 + 세력 화면에 수도·이전 기록.
- 추천: 나 — 나라를 한눈에 알아본다.
