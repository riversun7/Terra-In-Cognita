## 1011. 다시 굴리기 5번을 환생에도 쓰는가
설정 칸 N9 `n9_initial_rerolls` 하나를 만들 때와 환생 때가 같이 쓴다(기획 49 N9 "3번", D-444 164). 사용자 요청은 만들 때 5번이다.
- 가. 같은 칸 하나로 둔다 — 환생도 5번 **(추천: 지금 구현. 칸이 하나라 단순하고, 환생도 같은 굴리기 함수다)**
- 나. 칸을 나눈다 — 만들 때 5번(새 칸), 환생은 3번(옛 칸)
- 기획 49 N9 표 값(3번)도 5번으로 고칠지 기획 세션에 알린다.

## 1012. 추천 나라 규칙
[임시] 지금 규칙: 시작 도시 하나당 시작한 사이보그 수가 적은 차례 → 시작 도시가 많은 차례 → ID 차례로 앞의 3곳(열린 나라 3곳 이하면 1곳). 빈 세계에서는 시작 도시가 많은 나라(초강대국·강대국)가 추천된다.
- 가. 이대로 **(추천: 자리·지원금이 넉넉한 나라로 사람을 나눈다)**
- 나. 등급이 낮은 나라(소국·도시국가)를 앞세운다(작은 나라 살리기)
- 다. 추천 표지를 없앤다
