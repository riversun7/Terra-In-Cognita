# 가문 가입·귀화·도시 질문: 옛 나라 가문원·가문장 넘기기·다시 들기·도시 얻는 길 (2026-11-11)

- 받는 곳: 기획 세션(사용자에게 물을 것은 기획이 고른다).
- PLAN 14장 번호: 1001~1006.
- 상태: 1001~1006 답함(기획 정리 2026-11-11, D-216 포인터 — 사용자에게 묻지 않음, 모두 추천안, 각 질문의 "답" 줄). 이어진 질문 1036~1045는 `docs/questions/2026-11-11-house-3.md`. (옛 상태: 답 기다림.) "지금"은 기술이 [임시]로 넣은 기본안이다. 수치(인원 상한·대기 수·유효 시간)는 묻지 않는다(D-515 — 설정 칸 `house_member_max`·`house_pending_max`·`house_apply_max`·`house_request_ttl_ms`).
- 지금 코드 요약(Verified: 가지 `work/house-2`, DB 시험 `apps/server/src/factionIdentity/members.db.test.ts`): 가문장은 같은 나라 시민을 사이보그 이름으로 초대하고, 플레이어는 내 나라 가문에 가입을 신청한다. 초대와 신청이 맞으면 바로 든다. 가문원은 나가고, 가문장은 내보낸다. 가문장이 귀화하면 가문이 새 나라로 옮기고 옛 나라 시민인 가문원은 빠진다. 운영자는 신고된 가문 이름을 "가문 #ID"로 되돌린다.

### 1001. 가문장이 귀화해 가문이 옮길 때, 옛 나라에 남은 가문원은 어떻게 되나요?
- 정해진 것: 가문원은 소속 NPC 국가의 시민으로 남는다(D-216). 가문은 창설자를 따라 새 나라로 옮긴다(983 가). 같은 세력(시야·리플레이·핀) = 같은 국가 전체(D-250).
- 지금: 옛 나라 시민인 가문원은 그 자리에서 가문에서 빠지고 "나라가 달라져 가문에서 빠졌습니다" 소식을 받는다. 가문장은 빠진 수를 소식으로 받는다. 대기 중인 초대·신청은 모두 지운다.
- 가) 바로 빠진다(지금). 나) 며칠(설정 칸) 동안 가문원으로 남겨 두고 그 사이 같은 나라로 귀화하면 그대로, 아니면 빠진다. 다) 가문장이 귀화하려면 다른 나라 가문원이 없어야 한다(먼저 내보내거나 같이 옮김).
- 추천: 가 — "가문원 = 가문 나라 시민"이 늘 지켜져 시야 공유(D-250)와 어긋나는 때가 없다. 나는 그 며칠 동안 가문원끼리 다른 나라 시야를 보는 틈이 생긴다.

- **답 (기획 정리, 2026-11-11, D-216 포인터 — 사용자에게 묻지 않음, D-515)**: 가 — 바로 빠진다(지금 코드 그대로). 코드 바꿈 없음.

### 1002. 가문에서 나가거나 내보내진 사람이 다시 들기까지 기다려야 하나요?
- 정해진 것: 없음.
- 지금: 기다림 없음 — 나간 바로 뒤 다른 가문에 신청하거나 같은 가문의 초대를 받을 수 있다. 가문 창설도 바로 할 수 있다.
- 가) 기다림 없음(지금). 나) 설정 칸 대기(같은 가문만). 다) 설정 칸 대기(모든 가문).
- 추천: 가 — 지금은 가문에 얹힌 이익(국고·도시·지분)이 없어 옮겨 다녀 얻는 것이 없다. 가문 이익이 생기면 다시 본다.

- **답 (기획 정리, 2026-11-11, D-216 포인터 — 사용자에게 묻지 않음, D-515)**: 가 — 기다림 없음(지금 코드 그대로). 코드 바꿈 없음.

### 1003. 가문장이 나가고 싶으면 어떻게 하나요(넘기기·해산)?
- 정해진 것: 창설 인원 하한 없음(D-216). 가문장 넘기기·해산 규칙은 없다.
- 지금: 가문장은 나갈 수 없다(`leader_cannot_leave`). 넘기기·해산이 없다. 세력 행이 남는다.
- 가) 가문장 넘기기(가문원 한 명에게) + 혼자 남은 가문장은 해산(세력 행 `dissolved_at_ms`, 이름·약어는 풀림). 나) 해산만. 다) 지금처럼 못 나감.
- 추천: 가 — 가문장이 게임을 떠나도 가문이 이어진다. 해산하면 쓴 이름·약어를 다른 사람이 쓸 수 있다.

- **답 (기획 정리, 2026-11-11, D-216 포인터 — 사용자에게 묻지 않음, D-515)**: 가 — 가문장 넘기기(가문원 한 명에게) + 혼자 남은 가문장의 해산(이름·약어가 풀림). → 넣음: ADR `2026-11-11-faction-identity.md` "바뀜 (1001~1006 답)" 1절(WebSocket `house_handover`·`house_dissolve`, 프로토콜 24). 받는 사람 동의 없이 바로 넘김은 [임시](질문 1036), 도시 가진 가문의 해산 막기는 [임시](질문 1037).

### 1004. 가문원이 다른 가문원의 초대·신청을 볼 수 있어야 하나요? (권한 나누기)
- 정해진 것: 없음.
- 지금: 대기 중인 초대·신청과 초대·받기·내보내기는 가문장만 본다·한다. 가문원은 가문원 목록만 본다.
- 가) 가문장만(지금). 나) 가문장이 "부가문장"을 정해 초대·받기를 맡긴다. 다) 가문원 모두 초대만 할 수 있다(받기는 가문장).
- 추천: 가 — 가문 규칙(46 Step 5 2부)이 정해질 때까지 가장 단순하게 둔다.

- **답 (기획 정리, 2026-11-11, D-216 포인터 — 사용자에게 묻지 않음, D-515)**: 가 — 가문장만(지금 코드 그대로). 코드 바꿈 없음.

### 1005. 가문이 도시를 얻는 첫 길: 폐허 복원에 봉신·독립 고르기를 걸까요? (982 이어서)
- 정해진 것: 새로 세운 마을은 세울 때 봉신·독립 도시국가를 고른다(D-340). 유저 주인 폐허가 되살아나면 봉신·독립을 고른다(D-339 "D-340 틀"). 982 가 = 플레이어 마을 세우기를 다음 줄기로 열고 그때 고른다.
- 지금: 플레이어가 도시를 얻는 길은 폐허 복원(D-510)뿐이고, 복원한 도시는 복원한 사람의 사이보그 나라로 간다(질문 481 기본안). 고르기는 없다. 가문이 도시를 가지려면 가문에 소유 주체(국고·원장 계정)·봉신 관계(위 세력 = 나라, 공물)·독립 체제가 필요하다(ADR "바뀜 (2026-11-11, 981~986 답)" 3절).
- 가) 마을 세우기 줄기에서 둘(새 마을·폐허 복원)을 같은 고르기로 연다. 나) 폐허 복원에 먼저 건다. 다) 마을 세우기만, 폐허 복원은 지금처럼 나라 도시.
- 추천: 가 — 고르기·봉신 공물·독립 체제를 한 번에 만들어 두 길이 같은 규칙을 쓴다.

- **답 (기획 정리, 2026-11-11, D-216 포인터 — 사용자에게 묻지 않음, D-515)**: 가 — 마을 세우기와 폐허 복원을 같은 봉신·독립 고르기로 연다. → 넣음: ADR `2026-11-11-house-village.md`(WebSocket `house_village`·`house_ruin`, 고르면 가문 소유 주체·NPC 사회 거울 세계, 봉신 = 나라 공물, 독립 = 체제·따로 보는 시야). 남은 것은 질문 1038~1045.

### 1006. 운영자가 이름을 되돌린 가문이 또 나쁜 이름을 정하면?
- 정해진 것: 금칙어 운영자 관리는 다음 줄기(929 다). 운영자가 "가문 #ID"로 되돌리고 주인이 대기 없이 다시 정한다(986 가).
- 지금: 되돌린 횟수를 세지 않는다. 같은 사람이 또 나쁜 이름을 정하면 운영자가 또 되돌리거나 계정을 정지한다. 되돌릴 때 약어도 되돌릴지 운영자가 고른다("H<36진수 ID>").
- 가) 지금처럼(되돌리기·계정 정지). 나) 되돌린 횟수가 설정 칸에 이르면 이름 바꾸기를 운영자가 풀 때까지 막는다(마크 자동 막기 934 나와 같은 꼴). 다) 되돌린 뒤 새 이름은 운영자 승인 뒤에 보인다.
- 추천: 나 — 마크와 같은 꼴이라 운영 도구가 하나로 읽힌다.
- **답 (기획 정리, 2026-11-11, D-216 포인터 — 사용자에게 묻지 않음, D-515)**: 나 — 되돌린 횟수가 설정 칸(`house_name_reset_block`, 출발값 3)에 이르면 이름 바꾸기를 운영자가 풀 때까지 막는다(마크 자동 막기와 같은 꼴). → 넣음: ADR `2026-11-11-faction-identity.md` "바뀜 (1001~1006 답)" 2절.
