# 배후지 저장·마을 건물·가문 구인 질문 (2026-11-12)

### 1096. 마을(시작 도시가 아닌 도시)에는 어떤 건물이 서나요?
- 정해진 것: 1052 다(NPC가 나중에 짓는 건물·가문 마을도 도시 배치 함수를 쓴다). 마을 건물 수·값은 기획 몫이라고 질문 1052에 적었다.
- 지금([임시]): 행정 건물 하나 + 숙소(설정 칸 `npc_village_lodgings` 1). NPC 새 마을·가문 마을·되살린 폐허 모두 같다. 되살린 폐허처럼 이미 행정 건물이 있으면 숙소만.
- 가) 그대로(행정 + 숙소 1).
- 나) 마을에도 창고·채집 시설 하나(땅을 따라) — 주민이 일할 곳.
- 다) 마을 크기(주거)에 따라 숙소 수.
- 추천: 가 — 마을은 처음에 휴먼이 없고(구인으로 든다) 도시 경제는 건물이 없으면 도시 직무로 일한다. 일터 건물은 도시 발전 규칙(1101)과 함께 정하면 된다.

### 1097. 가문 국고가 비었을 때 첫 주민은 어떻게 들이나요?
- 정해진 것: 1041 다(자동 구인, 가문장이 끄고 손으로 산다), 1043(마을 비용 = 가문 국고, 없으면 가문장). D-469(인구는 구인 카드로만).
- 지금: 가문 국고에 돈이 들어오는 길이 없다(주민이 없으면 세금도 없다). 그래서 자동 구인(국고에서 냄)은 빈 마을에서 돌지 않는다.
- [임시]로 넣은 것: 가문장이 손으로 살 때 국고가 모자라면 **가문장 지갑(기준 통화)에서 같은 수**를 소각한다(1043의 "국고, 없으면 가문장"과 같은 결).
- 가) 그대로.
- 나) 가문장·가문원이 가문 국고에 넣는 명령(입금)을 만든다 — 지갑 대신 국고로만 산다.
- 다) 마을을 세울 때 마을 값 일부를 가문 국고 처음 돈으로.
- 추천: 가 + 나(나중 줄기) — 지금은 가문장이 첫 주민을 들일 수 있고, 국고 입금이 생기면 자동 구인이 스스로 돈다. 가문 화폐(나라 화폐)와 기준 통화를 1:1로 친 것은 환율을 무시한다(유저 구인과 같은 값).

### 1098. 자동 구인을 끄면 경비대 다시 채우기도 끄나요?
- 지금: NPC 구인 규칙식은 경비대 목표(국력 등급 값)를 먼저 채우는데, 가문은 등급이 없어 경비대 목표가 0이다 → 끄든 켜든 경비대를 사지 않는다.
- 가) 그대로(가문 경비대 없음).
- 나) 가문 도시도 경비대 목표(설정 칸)를 둔다 — 자동이면 채운다.
- 추천: 가 — 경비대는 공성·웨이브 규칙과 함께 정할 일이다.

### 1099. 마을 건물은 값·짓는 시간 없이 서나요?
- 지금([임시]): 세계 씨앗과 같이 재료·작업 없이 다 지은 채(레벨 1) 선다. 가문 마을도 같다(마을 값 5,000만 낸다).
- 가) 그대로.
- 나) 가문 마을은 행정 건물만 공짜, 숙소는 가문장이 짓는다.
- 다) 둘 다 가문장이 짓는다(빈 터만 준다).
- 추천: 가 — NPC 마을과 같은 규칙(D-212), 마을 값이 그 몫이다.

### 1100. "국가 땅이 버티는 도시 수"를 상한으로 쓰나요?
- 정해진 것: 1025 나(국가 땅의 배후지 수로 상한, 숫자 규칙은 기획).
- 지금: 세계 배치 화면 배후지 덮개에 어림을 보이기만 한다(수도 둘레 찾는 반경 안 알맞은 땅에 시작 도시와 같은 간격으로 놓을 수 있는 수). 측정(S2 시험 행성, 국가 16): 등급 표 1~6곳에 견줘 9~25곳 — 지금 등급 표는 모두 땅 안이다. 국가마다 혼자 세고 다른 국가 땅은 나누지 않는다(계획 도시만 피함).
- 가) 보이기만(지금).
- 나) 시작 도시 수 = min(등급 표, 버티는 수) — 땅이 좁으면 적게 세운다.
- 다) 실행 중 NPC 새 마을도 이 수를 넘지 않게 한다.
- 추천: 가 — 지금 등급 표가 모두 땅 안이라 자를 일이 없다. 섬 나라·작은 행성이 생기면 나.

### 1101. NPC 도시는 언제 건물을 더 짓나요?
- 지금: NPC 런타임은 시작 씨앗 뒤에 건물을 짓지 않는다(연구 레벨·행정 레벨은 수만). 부팅 씨앗만 설정 칸을 올렸을 때 모자란 것을 채운다(도시 배치 함수로).
- 가) 발전도 도시 등급(D-137)이 오를 때 그 등급의 시설 줄(등급마다 건물 표 — 기획)까지 도시 배치 함수로 세운다.
- 나) NPC 판단 행동에 "짓기"를 더한다(국고로 재료를 사고 일꾼이 짓는다 — 플레이어와 같은 규칙).
- 추천: 나 — D-212(유저와 NPC가 같은 규칙). 자리는 어느 쪽이든 같은 배치 함수다.
