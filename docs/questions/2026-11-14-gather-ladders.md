### 1301. 자연 채집물(1224)을 새 중분류에 두었습니다
- 정해진 것: D-540 1224 가 "물·소금·섬유·이탄·베리·과일·조개·화석 T0 원자재를 아이템 표에 더함". 중분류는 정하지 않았다.
- 지금([임시]): 새 원자재 중분류 `wild_goods`(자연 채집물)에 여덟 개. 이 중분류는 어느 시설 사다리에도 들지 않아 지금 농장·낚시터·광산의 산출 분포가 바뀌지 않는다. 지형 오브젝트에서 직접 캘 때만 나온다.
- 가) 지금(새 중분류 하나).
- 나) 맞는 사다리에 넣는다(베리·과일 → 작물, 조개 → 어류, 소금·화석 → 광석, 이탄 → 광석 …) — 같은 티어 아이템이 늘어 그 사다리 T0 몫이 나뉜다(예: 어류 T0 미꾸라지·피라미 반씩 → 셋이 ⅓씩, 작물 T0 건초·콩·보리 → 다섯이 ⅕씩).
- 다) 쓰임마다 중분류를 새로(식재료·연료·광물 …).
- 추천: 가 — 지금 사다리 분포(D-507 옛 규칙)를 흔들지 않고, 요리·제작(D-507) 레시피가 생길 때 중분류를 옮겨도 아이템 ID는 그대로다.

### 1302. 고래 고기·기름의 티어·무게
- 정해진 것: D-540 1231 다 "고래 고기·기름 아이템". 티어·값은 없다.
- 지금([임시]): 고래 고기 T6(무게 5kg), 고래 기름 T7(1kg), 시작 가격 1, 중분류 `wild_goods`(1301과 같은 까닭 — 어류에 넣으면 낚시 사다리 T6·T7에 들어 민물 어군에서도 고래가 나온다).
- 가) 지금.
- 나) 둘 다 어류 중분류(낚시 사다리 높은 티어에 고래가 든다).
- 추천: 가 — 고래 무리는 심해·배로만 닿는 오브젝트라 사다리와 따로 두는 것이 맞다.

### 1303. 고래 무리는 굴림표(고기 700·기름 300‰)입니다
- 지금([임시]): 고래 무리 = 고래 고기 700·고래 기름 300‰ 굴림표(대표 아이템 고래 고기). 고래상어(T9)는 더 나오지 않는다.
- 가) 지금.
- 나) 한 번 캘 때 둘 다(고기 n + 기름 m) — 새 칸(여러 산출)이 필요하다.
- 추천: 가 — 같은 굴림표 칸 하나로 된다.

### 1304. 난파선 굴림표 내용
- 지금([임시]): 구리 괴 450·철 괴 300·판자 150·은 괴 80·금 괴 20‰(대표 = 구리 괴, 다시 자람 24시간 그대로).
- 가) 지금.
- 나) 설계도·레시피(문서 대분류) 같은 희귀 물품을 섞는다(아이템이 생긴 뒤).
- 추천: 가 — 지금 있는 아이템만 쓴다. 숫자는 개발자 지형 오브젝트 편집기 내보내기로 고친다.

### 1305. 열수구는 은광석 하나 그대로입니다
- 지금: 열수구 → 은광석(광산이 맡음). 같은 굴림표 칸을 쓸 수 있지만 넣지 않았다.
- 가) 그대로.
- 나) 굴림표(예: 구리광석 500·은광석 350·금광석 150).
- 다) 광석 사다리 굴림(`ladder` — 광석 띠 표, 산지 티어 막기는 보지 않음).
- 추천: 가 — 배가 생기기 전에는 아무도 캐지 못해 지금 바꿀 까닭이 적다. 배(B3) 줄기에서 다시 본다.

### 1306. 어군 사다리 굴림의 유효 스탯과 성공 확률
- 정해진 것: D-540 1222 다 "어군도 낚시 사다리 티어 굴림".
- 지금([임시]): 직접 낚을 때 유효 스탯 = AGI + DEX(낚시터 반경 안이면 + 레벨 보너스 × (레벨 − 1)). 컨디션은 넣지 않았고, 낚시터 일꾼의 성공 확률(`catch`, 기본 300‰)은 굴리지 않는다(한 번 = 늘 한 마리, 앞 판과 같은 양).
- 가) 지금.
- 나) 낚시터 일꾼과 같게 성공 확률·컨디션도(직접 낚기 양이 약 ⅓로 준다).
- 추천: 가 — 직접 채집은 오브젝트 번수·일 시간이 이미 양을 막는다. 일꾼과 같은 셈을 원하면 나.

### 1307. 어군 종류마다 티어 차이가 없습니다
- 지금: 네 어군(민물·연안·대륙붕·큰 어군)이 모두 같은 낚시 사다리를 굴려, 스탯이 같으면 민물 어군에서도 바닷고기(꽁치·방어 등)가 같은 확률로 나온다. 대표 아이템(잉어·꽁치·고등어·방어)은 판 이름으로만 남았다.
- 가) 지금.
- 나) 어군 종류마다 티어 범위 칸(예: 민물 T0~T2, 연안 T0~T4, 대륙붕 T2~T6, 큰 어군 T4~T8)을 더해 밖으로 나온 티어를 범위 안으로 접는다(광산 티어 막기와 같은 꼴).
- 추천: 나 — 바다가 깊을수록 큰 고기라는 뜻이 살아난다. 칸 하나·시험 몇 개면 되어 답이 오면 바로 넣는다.

### 1308. 자연 채집물 자리는 장식 소품 위 오브젝트(prop)입니다
- 정해진 것: 1224 가 "이 오브젝트들을 채집 자리(site)로 바꾼다".
- 지금: site로 옮기지 않고, 이미 생성기가 놓는 장식 소품 그림(얼음덩이·소금 평원·소금밭·덩굴·이탄 더미·베리 덤불·과일나무·조개·해초 밭·얼음 속 화석)에 `source: "prop"` 채집 종류를 더했다. 생성기 판·지형 캐시가 그대로이고, 장식이 놓인 자리에서 바로 캔다. 양은 지형 오브젝트 편집기의 소품 규칙(map_props) 쪽에서 고친다.
- 가) 지금.
- 나) site로 옮긴다(장식 소품을 빼고 채집 자리 바이옴 천분율로) — 소품 규칙이 바뀌어 지형 캐시를 새로 만들고 골든 해시를 다시 적는다.
- 추천: 가 — 같은 결과(그 땅에서 자원을 캔다)를 생성기를 건드리지 않고 낸다.

### 1309. 자연 채집물 수치와 맡는 시설
- 지금([임시]): 한 번 일 15초(이탄 20초·화석 40초), 3번(화석 1번), 다시 자람 30분(화석 24시간), 묶음 1, 맡는 시설 없음(창고·도시 창고로 나름). 스탯 짝: 물·소금·이탄·화석 STR + VIT, 섬유 DEX + STR, 베리·과일 INT + WIS, 조개 AGI + DEX.
- 가) 지금.
- 나) 맡는 시설을 둔다(소금·이탄·화석 → 광산, 베리·과일 → 약초원, 조개 → 낚시터, 섬유 → 벌목장) — 채집소 반경 버프를 받는다.
- 추천: 가 — 시설 산출 사다리와 섞이지 않게 처음에는 직접 채집만.

### 1310. 띠 표 편집기는 있는 표만 고칩니다
- 지금: 생산 편집기 확률 분포·예상 확률 탭에 띠 표 고르기(기본 표·광석)를 두었다. 새 사다리 표 만들기·지우기는 없다(팩 `gather_tiers`에 `ladder` 줄을 더한다).
- 가) 지금.
- 나) 편집기에서 사다리 표 만들기(기본 표를 복사)·지우기.
- 추천: 가 — 표를 늘릴 일이 드물고, 만들기는 덮어쓰기 층에 새 항목을 더하는 일(지금 건물 편집기는 만들기 없음)이라 크다.

### 1311. 광석 표의 60 이상 구간은 기본 표의 복사본입니다
- 지금: 사다리 표는 구간 전체(0~260, 14줄)를 갖는다. 그래서 60 이상 구간을 고칠 때 두 표를 따로 고쳐야 한다.
- 가) 지금(표마다 전체).
- 나) 사다리 표는 고친 구간만 두고 나머지는 기본 표를 따른다(부분 표).
- 추천: 가 — 셈이 단순하고 편집기·검사(표마다 0부터)가 그대로다. 사다리마다 높은 구간도 달리 하고 싶어질 때 더 맞다.
