# 1차맵 영토 표시 2 — 질문 (2026-11-15, 줄기 `planet-ui-2`)

- 관련: 기획 D-544·D-546, ADR `docs/adr/2026-11-07-planet-view.md` "바뀜 (2026-11-15 D-546)", `docs/adr/2026-11-03-territory-layer.md` "바뀜 (2026-11-15)"
- 지금 구현은 각 질문의 [임시] 기본값이다(수치는 D-515에 따라 묻지 않고 [임시]로 둔다 — 아래는 모양만). 답이 오면 그대로 바꾼다.

## 1471. 비슷한 색 이웃 빗금 — 누가 받고, 얼마나 가까우면
- 지금 [임시]: 맞닿은 두 국가(받침 선이 있는 쌍)의 국가 색 OKLab 거리 < 0.12면 **국가 ID가 큰 쪽** 칠에 빗금(국가 색 바탕 + 검정·흰색 줄). 새 프리셋 16색에서는 같은 계열 14쌍이 걸린다.
- 가. 지금 그대로(큰 ID 한쪽만, 문턱 0.12) **← 추천**
- 나. 영토가 작은 쪽이 빗금(넓은 나라는 맨 색으로 남는다)
- 다. 내 국가는 늘 맨 색(빗금은 늘 상대 쪽)

## 1472. 도시 소유 비콘의 외곽선 여유
- 지금 [임시]: 외곽선은 비콘 밖으로 2칸(설정 칸 `planet_territory_beacon_cells`) 지나간다. 비콘 하나면 도시 원에서 비콘으로 가늘어지는 둥근 띠, 둘 이상이면 도시·비콘 사이가 채워진다.
- 가. 지금 그대로(비콘 둘레 2칸 여유 — 비콘이 외곽선 바로 안쪽) **← 추천**
- 나. 비콘 자리도 기준 도시 원만큼 넓힌다(외곽선이 비콘 밖으로 도시 원 반지름만큼 — 비콘 하나로 땅이 크게 는다)
