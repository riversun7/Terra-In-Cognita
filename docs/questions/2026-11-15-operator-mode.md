# 운영자 모드·시설 분류·개발 도구·옛 초상 정리 질문 (2026-11-15)

- 받는 곳: 기획 세션(사용자에게 물을 것은 기획이 고른다).
- PLAN 14장 번호: 1661~1680(이 문서는 1661~1669를 쓴다).
- 상태: 답 기다림. 아래 추천안은 모두 [임시]로 코드에 넣었다.

## 정해진 것 (다시 묻지 않음)

- **D-560 1236·1237**: 도시 화면 건물 무리는 시설 분류 칸으로, 분류표는 기획(9가지: 행정·채집·가공·제작·저장·물류·주거·공공·서비스·상업·교통·항만·군사·방어). 건물을 누르면 카메라 이동은 그대로. → 팩 `facilities.category`(core@102)로 넣었다.
- **D-560 1239·1241·1242**: 운영자 모드 1차맵 텔레포트, 건설 제한 없이. [주변] 탭 차례 건물 → 주변 유닛 → 자원, 처음 건물. 운영 메뉴는 누르면 닫힘. 데스크톱은 왼쪽 세로 띠.
- **D-560 1246~1248**: 운영자 유닛 속도 배율 조정 가능, 기본은 보통 유닛과 같다. 운영자 모드를 끄면 바로 해제.
- **D-560 1376·1380·1381**: 스탯 영향도 → 2차 스탯 화면, 전투 보고서 기록 상한 없음, A/B의 B에서 계산식도.
- **D-560 1421**: 옛 2D 외형 자료 바로 정리, 3D 외형 없는 옛 사이보그는 기술이 3D 외형으로 옮김(세계 새로 시작 없이 켤 때 옮겼다).
- **D-561**: 거래소는 건물(시설), 분류 "상업". 이 줄기에서는 만들지 않았다(다음 줄기) — 분류와 도시 화면 칩(0이면 숨김)만 둔다.
- 운영자 모드는 dev·admin의 시험 도구다(ADR `2026-11-07-unit-control.md`). 서버가 명령마다 권한을 본다.

## 남은 것

### 1661. 운영자 속도로 고를 수 있는 값과 기억 범위
- 지금 [임시]: 운영 메뉴 [운영자 속도] 칩 셋 1×·10×·100×(서버는 1~100 아무 정수나 받는다). 기본 1×. 기기에 기억하지 않는다 — 운영자 모드를 켤 때마다 1×.
- 가) 지금.
- 나) 칩을 더 둔다(1×·2×·5×·10×·100×).
- 다) 고른 값을 이 기기에 기억한다(운영자 모드 기억처럼).
- 추천: 가 — "기본은 그대로 동일하게"에 맞고, 켤 때마다 보통이라 헷갈리지 않는다.

### 1662. 1차맵 텔레포트로 옮길 수 있는 유닛
- 지금 [임시]: 1차맵 명령 판이 보내는 유닛(내 사이보그가 있는 2차맵의 내 유닛)만. 서버도 내 유닛만 옮긴다(수호신·봇 제외). 남의 유닛은 2차맵 운영자 모드로 조종한다.
- 가) 지금(내 유닛만).
- 나) 운영자는 아무 유닛이나(1차맵에서 남의 유닛을 고르는 화면이 더 필요).
- 추천: 가.

### 1663. 운영자 모드 "제한 없는 건설"에 남긴 검사
- 지금 [임시]: 재료·땅 규칙(다른 세력 도시 2차맵)을 보지 않는다. 그대로 보는 것: 2차맵 밖·다른 건물·막힌 지형·유닛과 겹침, 물가 조건(낚시터 등), 행정 건물은 주인 없는 폐허 자리에만(도시가 없는 정부는 만들지 않는다), 일꾼 유닛은 내 유닛.
- 가) 지금.
- 나) 물가 조건도 보지 않는다.
- 다) 행정 건물도 아무 자리에나(새 도시를 만드는 규칙이 더 필요).
- 추천: 가 — 놓을 수 없는 자리·도시 없는 정부는 세계 자료를 깨뜨린다.

### 1664. 배(조선소)의 운영자 모드 시간
- 지금(Verified: 코드, 바꾸지 않음): 운영자 모드에서 배 만들기·수리는 재료 없이, 시간 ÷ 100(고정 — 옛 운영자 빠르기 값).
- 가) 그대로.
- 나) 운영자 속도 배율을 따른다(기본 1 = 보통 시간 — 건물 짓기와 같게).
- 추천: 나 — D-560 "기본은 그대로 동일하게"와 건물 짓기에 맞춘다. 서비스 함수 칸을 바꿔야 해 다음 줄기에서 한다.

### 1665. 운영자 모드 건물 짓는 시간
- 지금 [임시]: 짓기·레벨 올리기 시간 ÷ 운영자 속도 배율(기본 1 = 보통 시간). 바로 끝내기는 건물 판 개발 시험 [완료](dev_facility_finish)로 한다.
- 가) 지금.
- 나) 운영자 모드는 늘 바로 짓는다(시간 0).
- 추천: 가 — 1246 답("기본은 그대로")과 같은 규칙.

### 1666. 데스크톱 왼쪽 세로 띠의 폭 경계
- 지금 [임시]: 64em(1024px) 이상이면 왼쪽 세로 띠(앱 틀 접은 레일 폭). 48~64em(태블릿)은 전처럼 아래 가운데 떠 있는 탭 띠, 그 아래는 아래 탭.
- 가) 지금.
- 나) 48em(768px)부터 세로 띠.
- 추천: 가 — 앱 틀이 사이드 메뉴를 늘 펼치는 폭과 같다.

### 1667. 전투 보고서 기록이 쌓이면
- 지금(Verified: 코드): 상한 없음(D-560 1380). 지우기 단추는 없다. 보고서 하나 약 60KB(ADR 측정) → 1만 개면 약 600MB(Assumed, 압축 전).
- 가) 그대로 두고 NAS 디스크를 지켜본다.
- 나) 기록 화면에 [지우기](고른 기록, 감사 기록 남김)를 더한다.
- 다) 오래된 기록의 보고서 본문만 지우고 목록 줄(점수·설정)은 남긴다.
- 추천: 나 — 상한 없음은 지키고 쓰는 사람이 치운다.

### 1668. 시설 분류 아이콘·색
- 지금 [임시]: 분류마다 아이콘(행정 기둥, 채집 곡괭이, 가공 톱니, 저장 상자, 주거 집, 공공 십자, 상업 동전, 교통 닻, 군사 방패)과 색(1차 스탯 색 여섯 + 상업 경고색·교통 시장 파랑·군사 위험색). 시설 줄이 없는 건물은 "그 밖"(회색 네모).
- 가) 지금.
- 나) 기획이 분류마다 색·아이콘을 정한다.
- 추천: 가.

### 1669. 옮겨 채운 옛 사이보그의 한 번 무료 외형 고르기
- 지금 [임시]: 3D 외형 없이 옛 2D만 있던 사이보그는 켤 때 옛 외형에서 넘긴 3D 외형을 받고, 질문 961 나의 "한 번 무료로 고르기"가 남는다(`look_auto`).
- 가) 지금(한 번 고르기 남김).
- 나) 옮긴 외형으로 굳힌다(다시 고르기는 환생·계정 서비스만).
- 추천: 가 — 961 나로 이미 준 기회를 옮기기 때문에 잃지 않는다.
