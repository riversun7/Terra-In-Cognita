## 2281. 이름 없는 1인 가문의 처음 이름과 이름 붙이는 길
- 지금: 서버가 1인 가문을 만들 때 저장한 정체성이 없거나 약어가 겹치면, **운영자가 되돌린 이름과 같은 자리표시**(이름 "가문 #ID", 약어 "H<36진수 ID>" —
  겹치면 Q·Z, 색 = 정체성 색 20개 가운데 가문 ID 차례, 마크 = 계정 씨앗)를 붙이고 **이름 대기 없이** 바로 바꾸게 둔다. 세력 화면 "내 가문" 칸에 안내 한 줄과
  [이름 정하기](정체성 화면 — 이름·약어 규칙·이름 바꾸기 막음 1006 나 그대로). 정체성 초안이 있으면 색·마크는 남기고 이름·약어만 바꾼다(초안 이름은 사라진다 —
  약어가 겹친 이름이라 그대로 쓸 수 없다).
- 가) **지금대로(자리표시 + 정체성 고치기 길).**
- 나) 가문은 이름 없이(세력 정체성 없음) 두고 세력 화면에 따로 [이름 정하기] 칸 — 그 사이 가문 표지·가문 도시 줄이 보이지 않는다(표지 조회가 정체성을 잇는다).
- 다) 정부를 지을 때(1인 도시를 고를 때) 이름·약어를 먼저 받는다(건축 시트에 입력 칸).
- 추천: **가** — 이미 있는 "되돌린 이름" 상태와 고치기 길을 그대로 써서 표·명령이 늘지 않고, 이름을 정하기 전에도 가문 도시·독립 선언이 보인다.

## 2282. [기다림]이 접는 범위
- 지금: [기다림]은 **그 멈춤 회차**(밀린 지급 시각)만 접는다. 같은 계약이 다시 돌다 또 멈추면 다시 보인다. 계약 상태는 바꾸지 않는다(이미 일시 중지).
- 가) **지금대로(회차마다).**
- 나) 그 계약이 끝날 때까지 다시 보이지 않는다.
- 다) 일정 시간(예: 하루 — 설정 칸) 뒤 다시 보인다.
- 추천: **가** — 2237 원안(기기 접힘)과 같은 뜻을 계정으로 옮겼다. 다시 멈추는 것은 새 사건이라 다시 알린다.

## 2283. 짓는 중 귀속·독립 고르기를 바꾸는 화면
- 지금: **경제 화면 내 시설 카드**(짓는 중인 알박기 정부 카드)에 "지금 고른 것" + 고르기 칸 + [고르기 바꾸기]. 2차맵 건물 판(정부 칸)에는 아직 없다 —
  짓는 중 정부 건물은 도시가 없어 정부 판 조회가 그리지 않는다.
- 가) **지금대로(경제 화면 시설 카드).**
- 나) 2차맵 건물 판에도(짓는 중 정부 건물을 누르면 같은 칸).
- 추천: **가**를 지금, 나)는 건물 판 줄기에서 — 판정·명령은 같고 화면 자리만 더한다.

## 2284. 가문 단위 독립의 범위(D-577 해석)
- 지금: 가문 도시 가운데 **알박기 도시가 하나라도 있으면** 가문장이 독립을 선언한다(위 나라가 독재여도). 선언하면 **알박기가 아닌 가문 도시도 함께**
  위 세력에서 떨어져 독립 나라 + 고른 체제가 된다(지분 그대로). 알박기 도시가 하나도 없는 가문은 막는다(`independence_blocked` — D-302·46 §3.2 몫).
- 가) **지금대로.**
- 나) 알박기 도시를 처음 세운 뒤 일정 기간 안에만 선언할 수 있다.
- 다) 알박기 도시를 잃으면(점령·폐허) 선언 권리도 사라진다 — 지금도 그렇다(그때 가문 도시에 알박기 도시가 없으므로). 이것을 그대로 두는지 확인.
- 추천: **가**(다는 지금 규칙의 결과로 그대로).

## 2285. 멈춘 정부 건물의 고르기
- 지금: 남의 도시가 먼저 서서 멈춘 정부 건물(2241 ② — 레벨 0인 채 남음)은 고르기를 바꾸지 못한다(`not_buildable` — 다시 지을 길이 없으므로).
  다 지은 정부 건물도 바꾸지 못한다(그때 이미 발효).
- 가) **지금대로.**
- 나) 멈춘 건물도 바꿀 수 있게 둔다(다시 짓기 길이 생길 때를 위해 — 지금은 쓸 데가 없다).
- 추천: **가**.
