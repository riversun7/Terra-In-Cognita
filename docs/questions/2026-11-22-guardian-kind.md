# guardian-kind: 수호신 = 휴먼의 상태 (2026-11-22)

- 받는 곳: 기획 세션 → 사용자.
- PLAN 14장 번호: 2631~2635(이번에 쓴 것 2631·2632, 2633~2635는 비워 둔다).
- 상태: 둘 다 **[임시]로 이미 만듦**(추천안 = 지금 코드). 규칙(머묾·방어 참전·버프·상한·일 안 함·수명 없음)은 D-311·기획 답 456·470~473 그대로다.

## 2631. 남이 보는 수호신 이름
- 배경: 수호신이 종류(6)였을 때는 남의 유닛 한눈 정보(시야 안 유닛을 눌렀을 때)가 "수호신"이라고 보였다. 이제 종류는 휴먼이다.
- 지금: 남에게는 "휴먼 #번호"로 보인다(한눈 정보는 종류만 보낸다). 내 유닛 목록·유닛 화면·1차맵 내 유닛은 "수호신 #번호"로 보인다.
- 가) **지금대로 — 남에게는 휴먼으로 보인다**.
- 나) 남에게도 "수호신"으로 보인다(한눈 정보에 상태 칸을 더한다).
- 추천: **가** — 상태를 남에게 알릴지는 정해지지 않았고, 가장 작은 바꿈이다. 나로 바꾸기는 칸 하나다.

## 2632. 유닛 화면 종류 거르기에서 수호신
- 배경: 유닛 화면의 종류 거르기(휴먼·크리쳐·안드로이드·사이보그·시험)는 종류를 본다. 수호신은 이제 휴먼이다.
- 지금: "휴먼"을 고르면 수호신도 보인다(줄 이름은 "수호신 #번호"). 정렬·상태 분류는 그 전과 같다(직무가 없어 "대기").
- 가) **지금대로 — 휴먼 거르기에 든다**.
- 나) 상태 거르기에 "수호신"을 더하고 휴먼 거르기에서는 뺀다.
- 추천: **가** — 수호신은 휴먼 종류이고(D-589), 화면 규칙을 새로 만들지 않는다.
