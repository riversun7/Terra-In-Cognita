  - 다만 지형을 "비밀"로 다루면 모두에게 같은 타일을 주는 방식과 맞지 않는다.
  - 어느 쪽인지 사용자가 정해야 한다 → 질문 A3.

**C3. 2차맵 경계 연결 (D-106 ↔ map-delivery ADR) — 기술 쪽을 고친다**
- 기획: "도로, 특히 철도는 이웃 2차맵으로 자연스럽게 이어져야 한다." (DL:2014)
- 기획: "2차맵 경계에서 도로·철도가 끊기지 않게 이어야 한다." (DL:2018)

- 기술: "2차맵 스트리밍은 검증 결과에 따라 조건부" (DLOG:171)
- 판단 (A)
  - 데이터의 연속(경계를 넘는 선형 오브젝트, 경계의 연결점)과 화면의 연속(이음매 없는 스트리밍)을 나눈다.
  - 데이터 연속은 필수로 하고, 화면 연속은 계속 조건부로 둔다.
  - S1 ADR에 이렇게 적으면 된다.
  - 사용자가 "화면도 끊김 없이"를 뜻했다면 그때 다시 묻는다.

**C4. S3 유닛 10만 개의 범위 (D-098 ↔ PLAN 11) — 사용자가 정한다**

**C5. 다계정 (D-096 근거·D-039 ↔ 인증 ADR) — 사용자가 정한다(강한 충돌은 아님)**

**C6. 콘텐츠 팩 ko 필수 (ADR 대기 항목 ↔ D-059) — 기술 쪽이 대기 항목을 닫는다(사용자 확인만)**

**C7. 건물은 2차맵 하나 안 (D-102 해석) — 사용자 확인 필요**

## 4. 진행 중인 작업과의 관계

### 4.1 인증·계정 (adr/auth-and-accounts, 상태: 제안) (V)

- **맞는 것**
  - 로그인 아이디는 사이보그 캐릭터 이름과 다르다(:12). 로그인 아이디는 남에게 보이지 않는다(:42).
  - 계정 삭제 경로는 닫혀 있다(:37). 영구 월드에서 삭제 정책이 정해지기 전이라 안전하다.
  - 키를 UUID로 둔 것(:33)은 사이보그 표를 참조키로 잇기에 좋다.
- **확정 전에 넣을 것** (코드 변경은 아니고 ADR 문구)
  - "사이보그는 계정당 1기(D-096). 캐릭터 표에 `user_id` 고유 제약을 둔다. 캐릭터 선택 화면은 만들지 않는다."
  - "사칭 방지 예약어는 사이보그 이름에 적용한다."
- **다계정**: 복구 이메일 공유 허용(:57)과 계정 생성 상한(:48)을 그대로 둘지 묻는다 → 질문 A2.
- **24시간 기준**: 나중에 할 일 "WebSocket 접속에 세션 연결"(:101)을 할 때, 계정별 마지막 접속 끊김 시각을 같이 기록한다 → 질문 A6.
- **지금 바꿔야 하는 것**: 코드에는 없다. ADR 문구만 보완한다.

### 4.2 PWA (adr/pwa-and-browser-baseline, 상태: 제안)

- D-060과 맞는다 (V). iOS 16.4 하한(:40)은 웹 푸시를 쓸 수 있는 하한이기도 하다(:56). D-028 ①·D-061에 필요하다.
- 앱 껍데기만 캐시한다(:32-33). 그래서 안개(C2)·2차맵 접근 제한과 부딪히지 않는다 (A).
- `generateSW`(:31)는 웹 푸시를 넣을 때 다시 본다(:67). Workbox의 `importScripts`로도 푸시 처리 코드를 붙일 수 있다고 알고 있다 (A, 이번에 확인하지 않음).
- 진행 중 변경(커밋 전, worktree `.claude/worktrees/agent-a04d1f673045e98d9/apps/game/messages/ko.json`)
  - manifest 설명이 "사이보그와 미니언을 이끄는 전략 게임"이다 (V).
  - GDD v4는 "미니언"을 쓰지 않고 "유닛(휴먼·크리쳐·안드로이드)"을 쓴다(검색 결과 01_Review_Report의 옛 기획 인용만 있음, V).
  - 이름·색·아이콘이 임시값이라는 규칙(:47)에 따라 지금 고치지 않아도 된다. 바꾸려면 en.json도 함께 바꾼다.
- **지금 바꿔야 하는 것**: 없다.

### 4.3 콘텐츠 팩 규칙 (adr/content-pack-format, 상태: 확정)

- ID 영어 snake_case, 이름 ko·en 필수(:35-38, `packages/content/src/schema/common.ts:55-56`)는 D-059 "모든 명칭에 영문"과 맞는다 (V).
- 이름과 ID가 따로 있어서 이름만 바꾸면 ID 변경 기록이 필요 없다. D-075 "문제 생기면 이름 교체"와 맞는다 (V).
- 수는 정수가 기본이다(:40). 합성 확률(D-030)과 속성 비율(D-071)을 정수 퍼센트로 담을 수 있다 (V).
- D-056 12속성을 넣을 때
  - 기본 6과 강화형 6을 참조(`ref`)로 잇는 분류로 둔다 (A).
  - 기획 표에는 한국어 이름만 있다(DL:1055-1060) (V).
  - 영어 이름이 없으면 1단계 검사에서 실패한다. 기술이 영어 이름을 지어 넣지 말고 기획에서 받는다 → 질문 B13.
- "ko 필수 유지 여부" 대기 항목(:115)은 C6대로 닫는다.
- **지금 바꿔야 하는 것**: 없다.

  1. 기획 세션에 terra-in-cognita 쓰기 권한을 준다.
  2. 기술 세션이 한 번 복사한다. 이 경우 `docs/PROTECTED.md`의 "`docs/design/` 이 세션에서 수정 금지"(:10)에 대한 사용자 승인이 필요하다.
- 그 전까지 기술 세션은 이 보고서처럼 AntiGravt01 브랜치를 직접 읽는다.
