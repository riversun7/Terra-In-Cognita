# 합의안 재검토 결과 (2026-10-28) — 계획서 반영용 메모

근거: 본인 검토 + 독립 검토(independent_review.md). 상태: Round 9 질문 답변 대기.

## 확정 수정(기술 위임 범위)
1. 마일스톤 재구성: M0(기반 2–3주) → S1 2차맵 폰(2–3주) → S2 행성 LOD(2–3주) → S3 서버 10만(2주) → M2 벌목→1차맵(2주). 거래소 피드·편집기 조건선택/통계는 뒤로. 스파이크마다 가설·수치·결론 ADR, 기간 상한 엄수, 스파이크 중 기획 동결. (Q8 승인 대기)
2. 격자: 2차맵 = 1차맵 셀 (u,v) N×N, 게임 규칙은 칸 수 단위, 탄젠트 투영(면적비 ~1.4), 자체 큐브-구면(회전으로 꼭짓점 8곳 바다 배치) + 꼭짓점 규칙 + 면 경계 변환표 테스트, 행성 크기 = 면 레벨. N=128 권장(Q2).
3. 전투 표현: 기기 재생 철회 → 서버 틱 이벤트 스트리밍 + 기기 보간. 개입은 서버가 적용 틱 지정. 판정 코드는 결정적 규칙(정수/고정소수점, 자체 PRNG, 표준 Math 초월함수 금지).
4. three-globe 제거 → 자체 쿼드트리 LOD + 데이터 텍스처 레이어 + 인스턴싱 선/아이콘, 카메라 기준 좌표(RTC).
5. 프로세스: v1 단일 Node 프로세스(메인=API·WS·상태, Piscina 워커=순수 계산), 버스 인터페이스+아웃박스, 지역 키 상태.
6. 배포: watchtower 미사용(개발 중단), 고정 태그 + git compose + deploy.sh(마이그레이션→헬스체크→롤백) + NAS self-hosted runner, 기존 watchtower는 새 스택 제외 라벨.
7. 기록: WORKLOG 작업별 파일 + 자동 목차 docs/WORKLOG.md, ADR 날짜-슬러그, 커밋 훅=포맷·시크릿만, 문서 검사=PR CI, ADR 의무=새 런타임 의존성, release-please GitHub App 토큰, 영문 파일명.
8. 관리자 스크립트 콘솔 → 타입 정해진 대량 작업(미리보기·차이·감사·되돌리기), 가져오기는 초안만.
9. 린트 oxlint+tsgolint, 포맷 Biome.
10. Zustand는 UI 요약만, 고빈도 상태는 엔진 내부 타입 배열.
11. Drizzle 1.0 RC로 시작, TS6 별칭(@typescript/typescript6) 준비, 정확한 버전 고정 + AGENTS.md API 요약표.
12. 금액 int8+BigInt(전송 문자열), 셀 ID는 53비트 이내 자체 압축 ID.
