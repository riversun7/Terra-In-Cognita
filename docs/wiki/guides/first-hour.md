# 길잡이: 처음 한 시간

처음 들어와서 무엇부터 할지 모를 때 읽는 글입니다. 낱말이 낯설면 [색인](../index.md)에서 찾아보세요.

> 아직 만들지 않은 기능이 섞여 있습니다. 항목마다 머리의 `지금` 줄을 보세요.

## 1. 몸 만들기 (5분)

[첫 접속](../pages/first-access.md) 순서대로 이름 → 외형 → 능력치 → 나라 → 시작 도시를 고릅니다.

- **능력치**는 다시 굴릴 수 있습니다. 하고 싶은 일에 맞춰 고르세요. 어떤 능력이 어떤 일에 쓰이는지는 [직무](../pages/job.md)에 있습니다.
- **나라**는 신입 지원이 많은 곳을 "추천"으로 보여 줍니다. 처음이면 추천을 고르면 됩니다.
- **시작 도시**는 주변에 무엇이 나는지 보고 고릅니다. 광물이 많은 곳과 숲이 많은 곳의 할 일이 다릅니다.

## 2. 지도에 익숙해지기 (10분)

지도가 두 겹입니다. 이것만 알면 길을 잃지 않습니다.

- [1차맵](../pages/primary-map.md) = 행성 전체. **어디로 갈지 고르는 곳.**
- [2차맵](../pages/second-map.md) = 내려간 한 조각. **실제로 움직이는 곳.**

가 보지 않은 곳은 검게 덮여 있습니다([시야](../pages/vision.md)). 걸어 다니면 벗겨집니다.

## 3. 먹고살 거리 만들기 (20분)

1. 2차맵에서 나무·바위 같은 것을 찾아 캡니다([자원](../pages/resources.md)).
2. 캔 것은 가까운 [창고](../pages/warehouse.md)로 알아서 들어갑니다.
3. 도시의 행정 건물에서 **구인 카드**로 사람을 하나 뽑습니다([휴먼](../pages/human.md)).
4. 그 사람에게 일을 맡깁니다([직무](../pages/job.md)). 능력치가 맞는 일에 넣으면 같은 월급으로 더 많이 생산합니다.

여기까지 하면 **접속하지 않아도 일이 굴러갑니다**([접속하지 않은 동안](../pages/offline.md)).

## 4. 끄기 전에 할 것 (5분)

- 홈 화면에 추가하고 알림을 켭니다([알림](../pages/notification.md)). 급한 일만 울립니다.
- [처리할 일](../pages/inbox.md)을 한 번 봅니다. 다음에 들어오면 여기부터 보면 됩니다.
