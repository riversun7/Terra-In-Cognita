# 발전도

> **한 줄**: 도시가 얼마나 잘 자랐는지를 하나로 모은 점수. 오르면 도시가 넓어진다.

**지금**: 만드는 중 — 서버가 도시마다 값을 들고 있다. 요소별로 보여 주는 화면은 아직이다.

## 쉽게 말하면

도시의 종합 점수입니다. 올리면 도시의 등급이 오르고, 시가지와 [영토](territory.md)가 넓어지고 안전한 범위도 커집니다.

일곱 가지를 봅니다.

| 요소 | 무엇을 보나 |
|---|---|
| 인구 | 사는 사람 수와 수준 |
| 건물·기반시설 | 건물 수와 등급, 도로·철도 연결 |
| 경제 | 거래량, 세수, 생산량 |
| 문화·신앙 | 신전·축제·명성, 치안과 [만족도](satisfaction.md) |
| 교육·연구 | 학교와 연구소 |
| 보건 | 병원과 위생 |
| 환경 | 오염이 적을수록 점수가 오른다 |

환경을 버려 두면 점수가 깎이는 데서 끝나지 않습니다. 오염은 [정원사](gardener.md)의 적대를 올립니다.

## 자세한 규칙

- 일곱 요소에 각각 가중치를 곱해 더합니다. 가중치는 개발자 설정값입니다 `[잠정]`.
- 도시 등급의 기준은 실제 인구가 아니라 이 점수입니다.
- 교육기관을 세우면 교육 요소가 오릅니다.
