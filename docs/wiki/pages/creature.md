# 크리쳐

> **한 줄**: 야생의 생물. 잡아서 데리고 쓸 수 있고, 종과 속성에 따라 색과 능력이 다르다.

**지금**: 만드는 중 — 크리쳐 편집기와 콘텐츠 틀은 있다. 포획과 도감은 갖춰지는 중이다.

## 쉽게 말하면

크리쳐는 여섯 가지로 나뉘어 도감에 들어갑니다.

| 축 | 예 |
|---|---|
| 계통 | 짐승, 새, 용, 물에 사는 것, 벌레, 식물, 정령, 기계, 신령 |
| 기원 | 실제 동물 / 신화 속 동물 / 이 세계의 것 |
| 등급 | 일반, 희귀, 보스, 전설, 신수 |
| 속성 | 12가지 속성을 0~10으로 가진다 |
| 크기 | S, M, L, XL |
| 성향 | 공격, 방어, 기동, 탑승, 마법, 생산 |

**속성값이 색으로 보입니다.** 땅 기운이 센 놈과 불 기운이 센 놈은 같은 종이어도 색이 다릅니다.

신화 속 동물이 많이 들어갑니다. 12지(쥐·소·호랑이…)는 일반 → 희귀 → 보스 → 전설(12지신)로 이어집니다.
서양 쪽은 황도 12궁과 환상 동물 세트가 있습니다.

능력치는 종마다 치우쳐 있습니다. 힘이 센 종, 민첩한 종, 머리가 좋은 종이 고르게 퍼져 있습니다.

## 자세한 규칙

- 아주 드문 색의 개체(이로치)가 있습니다. 잡으면 사냥꾼에게 보너스 점수가 됩니다. 세계에 나오는 수에 한도가 있습니다.
- **교배는 없습니다.** 대신 유전자를 조합해 능력치와 속성을 바꿉니다. 종 자체는 바탕 개체가 정합니다.
- 스킬 칸 수는 종마다 다릅니다. 초반에 만나는 약한 크리쳐가 칸이 많습니다 `[잠정]`.
- [정원사](gardener.md) 쪽 크리쳐는 신격화된 존재나 기계화된 공룡 같은 모습입니다. 잡는 것은 최상위 콘텐츠입니다.
- 다른 게임의 고유한 디자인은 쓰지 않습니다. 실제 종교·국가·인물도 그대로 쓰지 않습니다.
