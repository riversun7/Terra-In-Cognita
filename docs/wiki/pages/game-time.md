# 게임 시간

> **한 줄**: 실제 1시간이 게임에서 하루다. 그래서 하루에 계절이 몇 번 바뀐다.

**지금**: 지금 되는 것 — 행성 달력과 하늘의 낮·밤이 서버 시각으로 돌아간다.

## 쉽게 말하면

| 실제 시간 | 게임에서 |
|---|---|
| 1시간 | 하루 |
| 7시간 | 한 계절 |
| 28시간 | 한 해 |

그래서 점심시간에 15분 들어오면 게임에서는 아침부터 정오까지 지나갑니다. 주말에 두 시간 하면 이틀이 갑니다.
하루를 안 들어오면 게임에서는 거의 한 해가 지납니다.

**중요한 점**: 규칙에 나오는 시간은 모두 **실제 시간**으로 말하고 보여 줍니다.
"7일마다 배당"은 실제 7일입니다. 이동에 걸리는 시간도 실제 시간입니다.
바뀌는 것은 하늘과 계절뿐입니다.

행성은 공이라 지역마다 시각이 다릅니다. 내 도시가 낮이면 반대편은 밤입니다.

## 자세한 규칙

- 시간의 기준은 서버 시각(UTC)입니다. 내 기기 시계를 바꿔도 게임 시각은 바뀌지 않습니다.
- 사람의 수명은 게임 시간으로 재면 50~80년쯤 됩니다 `[잠정]`.
- 알려진 단점: 계절이 실제 하루에 세 번 네 번 바뀝니다.
