# 성장 경로

> **한 줄**: 무엇으로 먹고살지 고르는 길. 직업을 고르는 칸이 아니라, 하는 일이 쌓여 내 길이 된다.

**지금**: 기획만 있는 것 — 경로 목록과 원칙은 정해져 있고, 경로별 평가와 랭킹은 아직 없다.

## 쉽게 말하면

이 게임에는 "직업을 고르시오" 하는 화면이 없습니다. 하고 싶은 일을 하면 그게 내 길이 됩니다.
어느 길이든 누구나 갈 수 있고, 두세 가지를 같이 해도 됩니다.

길은 크게 일곱 묶음입니다.

| 묶음 | 예 |
|---|---|
| 무력 | 정복자, 용병, 무법자, 현상금 사냥꾼 |
| 생명 | 유전공학자, 사냥꾼 |
| 부 | 무역상, 기업가, 운송업자, 대지주, 금융가 |
| 기술 | 연구자, 장인, 공학자, 건축가, 연금술사 |
| 개척 | 탐험가, 고고학자, 정보상 |
| 영향력 | 정치가, 신관, 교육자, 예술가 |
| 생활 | 셰프, 호텔리어, 의사 |

**생활 쪽이 장식이 아닙니다.** 셰프는 배고픔을, 호텔리어는 피로를, 의사는 부상을 고쳐 줍니다.
싸우는 사람이 많아지면 이 세 길의 벌이가 늘어납니다.

**가장 높은 단계는 한두 가지만 할 수 있습니다.** 그래서 최상위끼리 서로가 필요합니다. 혼자 다 할 수는 없습니다.

NPC도 **같은 규칙으로 같은 길**을 갑니다. 사람이 없는 길은 NPC가 메웁니다. 그래서 세계가 멈추지 않습니다.
