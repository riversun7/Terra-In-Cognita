# 알림

> **한 줄**: 급한 일이 생겼을 때 휴대폰으로 알려 주는 것. 게임 안에서는 [처리할 일](inbox.md)로 쌓인다.

**지금**: 기획만 있는 것 — 규칙은 정해져 있고, 휴대폰으로 보내는 기능은 아직 없다.

## 쉽게 말하면

접속하지 않은 동안에도 세계는 돌아갑니다. 그래서 급한 일은 휴대폰으로 알려 줍니다.
기본으로 켜지는 것은 **위협**과 **돈·생존**뿐입니다. 사소한 것까지 울리지 않습니다.

메일은 쓰지 않습니다. 알림은 휴대폰 푸시와 게임 안 [처리할 일](inbox.md) 두 가지입니다.

알림을 끄거나 거절해도 게임은 그대로 할 수 있습니다. 처리할 일 목록은 그대로 쌓입니다.

## 자세한 규칙

- 처리할 일의 분류별로 켜고 끕니다.
- 짧은 시간에 여러 건이 생기면 하나로 묶어 보냅니다 `[잠정]`.
- 방해 금지 시간을 정하면 그동안 보내지 않고, 끝난 뒤 모아 보냅니다.
- 접속하지 않은 지 24시간이 되면 한 번 알립니다(기본 켜짐, 끌 수 있음).
- 아이폰·아이패드는 **홈 화면에 추가한 웹앱만** 알림을 받습니다(iOS 16.4 이상). 추가하지 않으면 처리할 일만 씁니다.
