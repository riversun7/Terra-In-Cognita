## 10분이면 아는 것

1. 당신은 **[사이보그](pages/cyborg.md)** 입니다. 계정에 하나뿐인 몸이고, 쓰러져도 돌아옵니다.
2. 세계는 행성입니다. **[1차맵](pages/primary-map.md)** 에서 갈 곳을 고르고, **[2차맵](pages/second-map.md)** 에 들어가 실제로 움직입니다.
3. 사람을 거느리고 도시를 키웁니다. 사람들의 기분이 **[만족도](pages/satisfaction.md)** 이고, 이게 낮으면 반란이 납니다.
4. 직접 도시를 세우지 않고 **[도시 주식](pages/city-stock.md)** 을 사서 몫만 받는 길도 있습니다.

> 이 글은 아직 뼈대입니다. 항목이 쌓이면 "처음 1시간" 길잡이로 늘립니다.
