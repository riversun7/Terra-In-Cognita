# 처음 오셨나요

**Terra In-Cognita**의 위키입니다. 게임 기획서를 쉬운 말로 풀어 놓은 곳입니다.
아직 만드는 중인 게임이라 **기획만 있는 기능도 함께** 적습니다. 항목마다 머리에 `지금` 줄로 밝혀 둡니다.

## 10분이면 아는 큰 그림

1. 당신은 **[사이보그](pages/cyborg.md)** 입니다. 계정에 하나뿐인 몸이고, 쓰러져도 돌아옵니다.
2. 세계는 행성 하나입니다. **[1차맵](pages/primary-map.md)** 에서 갈 곳을 고르고, **[2차맵](pages/second-map.md)** 에 들어가 실제로 움직입니다.
3. 혼자 다 하지 않습니다. **[휴먼](pages/human.md)** 을 고용해 **[일](pages/job.md)** 을 맡기면 접속하지 않아도 굴러갑니다.
4. **[실제 1시간이 게임의 하루](pages/game-time.md)** 입니다. 규칙에 나오는 시간은 모두 실제 시간입니다.
5. 사람들의 기분이 **[만족도](pages/satisfaction.md)** 입니다. 낮으면 일을 게을리하고, 심하면 **[반란](pages/rebellion.md)** 이 납니다.
6. 돈은 **나라마다 다릅니다**([화폐](pages/currency.md)). 나라를 잘못 운영하면 그 돈이 싸집니다.
7. 오염을 쌓으면 **[정원사](pages/gardener.md)** 가 떼로 찾아옵니다. 이쪽과는 외교가 없습니다.
8. **NPC도 똑같은 규칙으로 삽니다.** 사람이 없어도 세계가 돌아갑니다. 이게 이 게임의 중심 생각입니다.

## 읽을 때 알아 둘 것

- **숫자는 믿지 마세요.** `[잠정]`이 붙은 값은 밸런싱으로 바뀝니다.
- **아직 없는 기능이 섞여 있습니다.** 항목 머리의 `지금` 줄을 보세요(`지금 되는 것` / `만드는 중` / `기획만 있는 것`).
- 더 자세한 원본 규칙은 각 항목 맨 아래 "출처"의 기획서 링크에 있습니다.
