## 한 일
- 로그인 상태(`apps/game/src/auth/session.ts`): 화면 밖에 하나만 두고 화면은 `useSession()`으로 읽는다.
  - 앱을 켤 때 `GET /api/auth/get-session`을 부른다. 응답은 `{ user: { id, loginId, roles }, expiresAt }` 또는 `null`이다.
  - 화면이 다시 보일 때, 다시 온라인이 될 때, 켜 둔 채 30분마다 다시 확인한다(30분에 1번까지). 서버는 하루 넘게 쓴 세션이면 이때 연장하고 쿠키를 새로 준다.
  - 처음 확인이 실패하면 "확인하지 못했습니다" 화면과 [다시 시도]를 띄운다. 서버와 다시 연결되면(WebSocket `welcome`) 저절로 다시 확인한다.
  - 로그인한 채로 잠깐 실패하면 상태를 그대로 둔다. 서버가 세션이 없다고 하면 "로그인이 끝났습니다" 안내와 함께 로그인 화면으로 간다.
  - 로그아웃: `POST /api/auth/sign-out`(JSON `{}`). 모든 요청은 `fetch` + `credentials: "same-origin"`이다.
  - 판단 규칙은 순수 함수로 나눴다(`sessionState.ts`).
- 화면(주소·라우터 없이 상태로 바꾼다, `App.tsx`·`auth/AuthScreens.tsx`)
  - 로그인: 아이디(`username`, `autocapitalize="none"`, `spellcheck=false`, 안내 "영문·숫자·_ 3~20자")와 비밀번호(`current-password`). 보내기 전에 `@terra/shared`의 `parseLoginId`로 아이디를 검사한다.
  - 새 아이디 확인: 아이디를 크게 보여 준다. 비밀번호 확인(`new-password`), 이메일(선택), 이메일 안내 3줄, [가입]·[다시 입력]. `{ id, password, create: true, passwordConfirm, email? }`를 보낸다.
  - 로그인 화면에서 넣은 비밀번호가 8자 미만이거나 아이디와 같으면, 확인 화면에 들어가자마자 알리고 [다시 입력]을 안내한다. 흔한 비밀번호는 서버만 안다(누른 뒤 같은 안내).
  - 비밀번호 찾기: 아이디·이메일·새 비밀번호 2번. 성공하면 로그인 화면으로 돌아가 "비밀번호를 바꿨습니다…" 안내를 띄운다(아이디는 남긴다).
  - 로그인한 뒤: 계정 줄(아이디, admin에게만 [관리자], [로그아웃]) + 기존 상태 화면(연결·시계·성능·언어). 언어 고르기는 모든 화면 아래에 둔다(로그인 전에도 영어로 바꾸게).
  - 서버 거절 안내와 [새로고침]은 로그인 화면·관리자 화면에서도 보인다(`RejectedNotice`).
  - 관리자 화면(`admin/AdminPage.tsx`, `React.lazy`로 따로 내려옴): 아이디 찾기, 20명씩 쪽 나누기(`admin.users.list`), 사용자마다 역할 4개 고르기와 [저장](`admin.users.setRoles`, 배열). 본인 줄에는 "나", 정지된 계정에는 "정지됨"을 붙인다. 이메일은 서버가 보내지 않고 화면에도 없다.
  - 관리자 조각을 못 불러오면 앱 전체가 내려가지 않고 그 자리만 안내 + [다시 시도](강제 적용)로 바뀐다(`ui/ChunkErrorBoundary.tsx`).
- 접근성
  - 모든 칸에 보이는 이름표(`label`)가 있다. 안내·오류는 `aria-describedby`로 칸에 잇고, 오류 칸은 `aria-invalid`이다.
  - 오류는 `role="alert"`, 안내는 `role="status"`. 영역은 늘 두고 문구만 넣는다. 같은 오류가 다시 나도 다시 읽히게 상자를 새로 만든다.
  - 화면이 바뀌면 제목으로 초점을 옮긴다(앱을 켤 때는 옮기지 않는다). 검사에 걸리면 첫 오류 칸으로 옮긴다.
  - 누름 영역 44px 이상, 입력 글자 16px(iOS 확대 방지), 키보드 초점 3px 테두리.
  - 누르는 중에도 버튼 초점이 사라지지 않게 `disabled` 대신 `aria-disabled`를 쓴다.
  - 문서 언어(`<html lang>`)를 고른 언어로 맞춘다.
- 오류 문구
  - 서버 오류 코드(`ACCOUNT_ERROR_CODES`) 18개를 모두 메시지 키로 바꾼다(`auth/errorMessages.ts`). 코드가 늘면 타입 검사가 실패한다.
  - 429는 서버의 `retryAfterSec`(없으면 `Retry-After`, 그것도 없으면 60초)를 "30초", "12 minutes"처럼 보여 준다(`Intl.NumberFormat` 단위).
  - 관리자 tRPC 오류는 `error.data.code`로 고른다(`admin/adminErrors.ts`): UNAUTHORIZED·FORBIDDEN·BAD_REQUEST·NOT_FOUND·PRECONDITION_FAILED(`LAST_ADMIN`). UNAUTHORIZED면 세션을 다시 확인한다.
  - 모르는 코드는 일반 문구, 서버에 닿지 못하면 연결 문구. 서버·Zod 원문은 보여 주지 않는다.
  - 화면 문구는 `messages/{ko,en}.json`에 함께 넣었다(새 키 93개, 모두 111개).
- 디자인 값(토큰): 색·글자·간격·모서리·그림자를 `src/styles/tokens.css`의 CSS 변수로 옮겼다. `styles.css`와 `admin/admin.css`는 `var(--…)`만 쓴다. 나중에 `:root[data-theme="…"]`로 값만 바꿔 끼우면 모든 화면이 바뀐다. 테마 고르기는 넣지 않았다.
- 한국어 줄바꿈: `word-break: keep-all`(낱말 중간에서 줄을 바꾸지 않음), 긴 아이디만 끊는다.

## 건드리지 말 것
- 화면 스타일에 색·크기 값을 직접 쓰지 않는다. `styles/tokens.css`에 변수를 두고 `var(--…)`로 쓴다(나중 테마 바꾸기의 전제).
- 세션 토큰을 스크립트에서 읽거나 저장하지 않는다(HttpOnly 쿠키에만 있다).
- 서버·Zod 오류 원문을 화면에 보여 주지 않는다. `LAST_ADMIN` 비교에만 message를 쓴다.
- 관리자 화면을 첫 화면 묶음으로 끌어오지 않는다(`App.tsx`의 `lazy(() => import(…))`). 관리자 조각만 쓰는 코드(`net/api.ts` 등)를 첫 화면 코드에서 import하면 함께 끌려온다.
- 알림 영역(`LiveMessage`)의 역할(alert·status)을 한 영역 안에서 바꾸지 않는다. 오류와 안내는 영역을 따로 둔다.

- DB가 없는 서버(인증 꺼짐)에서는 `/api/auth/get-session`이 404라서 "확인하지 못했습니다" 화면에 멈춘다. DB 없이 `pnpm dev:server`로 화면을 띄우면 상태 화면을 볼 수 없다(로그인하려면 DB가 필요하다).
- 서비스 워커는 관리자 조각도 미리 캐시한다(admin이 아니어도 내려받는다, gzip 약 8.8KB). 권한은 서버가 보므로 보안 문제는 아니다(Assumed). 빼려면 `vite.config.ts`의 `workbox.globIgnores`.
- 확인 화면의 비밀번호 확인 칸은 `new-password`라서, 브라우저가 강한 비밀번호를 만들어 넣으면 로그인 화면의 비밀번호와 달라진다("두 비밀번호가 다릅니다"). 드문 경우라 그대로 뒀다.
- 권한을 잃은 관리자(FORBIDDEN)는 [관리자] 버튼이 다음 세션 확인(30분, 다시 열기)까지 남는다. 문구가 사라지지 않게 일부러 세션을 바로 다시 읽지 않았다.
- 비밀번호 길이 숫자(8·128)는 합칠 때 `@terra/shared`(`passwordRules.ts`) 한곳으로 옮겼다(메인 세션).
- 첫 화면 묶음이 약 37kB(압축 전) 늘었다. 대부분 문구(ko·en)와 로그인 화면 코드다.
- `pnpm dev:game`(Vite 개발 서버)으로는 확인하지 않았다. 빌드 결과만 확인했다.

## 정한 것(합칠 때, 메인 세션)
- 버튼 이름은 [로그인]·[가입]으로 둔다. 지시의 [들어가기]·[만들기]는 korean-writing 스킬 규칙("버튼은 짧은 동사, '~하기'를 붙이지 않는다")과 맞지 않는다. 제목 "로그인"·[로그아웃]과 짝도 맞는다. 바꾸려면 `auth_sign_in`·`auth_login_title`·`confirm_create` 문구만 고친다.
