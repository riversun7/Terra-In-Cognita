## 한 일
- 새 패키지 `packages/sim`(`@terra/sim`, `exports: { ".": "./src/index.ts" }`). 경계 표(`scripts/check-boundaries.mjs`)에는 이미 있었다.
- 단위(`units.ts`): 위치 = 배치 칸의 1/1024 정수(`CELL_UNITS`), 시각 = 서버 ms, 속도 = 단위/초 정수. 걷기 `WALK_SPEED` 437, 차 `CAR_SPEED` 4813(D-120 출발값).
- 정수 수학(`math/`): `isqrt`·`isqrtRound`(안전 정수 전 범위에서 정확), FNV-1a(골든 해시), lowbias32 정수 섞기(노이즈).
- 배치 격자(`grid/`): 256×256 타입 배열 — 지형 비용(천분율, 0 = 막힘), 도로 종류, 건물 ID, 통과 폭. 2차맵당 512KiB.
- 통과 폭(clearance): 칸을 왼쪽 위로 하는 열린 정사각형의 최대 변(3에서 자름). 크기 등급 s는 통과 폭 ≥ s인 기준 칸에 선다. 칸이 바뀌면 왼쪽·위로 2칸 넓힌 범위만 다시 계산한다.
- A*(`path/astar.ts`): 8방향, 모서리 뚫기 금지, 정수 비용, 옥타일 × 가장 싼 칸 비용 추정, (f, h, 칸 번호) 동점 처리, 노드 예산. 상태: found·no_path·budget_exceeded·start_blocked·goal_blocked·invalid_request.
- 꺾이는 점(`path/waypoints.ts`): 방향이 바뀌는 칸만 남기고 고정소수점 중심 좌표로. `planRoute`는 지금 위치에서 시작하고 목표 기준 칸 중심에서 끝난다. 시야선 다듬기는 하지 않는다.
- 경로 이동(`motion/motion.ts`): `createMotion`·`positionAt`·`positionAtDistance`·`distanceAt`·`arrivalAt`. 반올림 규칙은 아래 표.
- 이벤트 큐(`events/eventQueue.ts`): (시각, 예약 번호) 최소 힙, 지연 취소, 취소가 쌓이면 다시 만들기, `popNext`·`popDue`·`peekTime`.
- 건물 배치(`placement/placement.ts`): 직사각형, 90° 회전, 2차맵 안, 건물·도로·막힌 지형 겹침. 순수 `validatePlacement`, 점유와 통과 폭을 고치는 `applyPlacement`·`removeBuilding`.
- 임시 지형(`terrain/`): 칸 키 → 시드 → 정수 값 노이즈 높이(꼭짓점 129×129, cm) + 지표(물·풀·흙·바위, 128×128) → 배치 칸 비용(지형 칸 하나 = 배치 칸 2×2). `TEMP_TERRAIN_GENERATOR_VERSION` 1.
- 벤치마크(`bench/pathfinding.ts`, `pnpm --filter @terra/sim bench`, `pnpm test` 밖).
- 프로필을 보고 A* 열린 목록을 위치 기억 힙으로 바꿨다(같은 결과, 약 1.5배 빠름).

## 건드리지 말 것
- `src/` 판정 코드에 `Math.random`·`Date.now`·`new Date(`·초월함수(경계 검사가 막는다). `Math.sqrt`는 `isqrt` 첫 추정에만 쓰고 정수로 바로잡는다.
- 이웃 순서(`DX`·`DY`)와 힙 동점 순서를 이유 없이 바꾸지 않는다(같은 비용 경로 중 고르는 것이 바뀐다).
- 격자 배열을 직접 쓰지 않는다. `setTerrainCost`·`setRoad`·`applyPlacement`·`removeBuilding`을 거쳐야 통과 폭과 추정값 캐시가 맞는다.

- 건물을 놓은 뒤 그 칸을 지나는 경로를 가진 유닛을 다시 탐색하는 일은 서버가 해야 한다(지금은 아무것도 안 한다).
- 유닛은 칸을 차지하지 않아서 유닛 위 건물 배치를 막지 않는다. 출발 칸이 막히면 `start_blocked`이고 빠져나오는 규칙은 없다.
- 갈 수 없는 목표(다른 섬)는 출발 쪽 영역을 다 펼친 뒤에야 `no_path`다. 크기 등급별 연결 영역 번호를 두면 바로 알 수 있다(후보).
- 더 빠르게: 점프 포인트 탐색(JPS)·계층 탐색·영역별 추정값(ALT). 지금은 최적 A*만.
- 대형 유닛이 이전 경로 밖의 임의 위치에서 `planRoute`를 부르면 첫 반 칸 구간이 규칙을 어길 수 있다(유닛은 칸 중심에서 생기고 경로 위로만 움직인다고 본다).
- 이벤트 큐 예약 번호는 큐마다 1부터다. 서버를 다시 켤 때 같은 시각끼리 순서를 지키려면 정해진 순서로 다시 예약하거나 번호를 저장한다.
- 임시 지형은 이웃 2차맵과 경계가 이어지지 않는다. 높이는 해수면 기준 상대값이다(1차맵 고도 없음).
- `SIM_VERSION`이 `apps/server/src/config.ts`와 `packages/sim/src/version.ts` 두 곳에 있다(서버가 sim 값을 가져다 쓰게 바꿀 것).
- 커버리지 도구는 저장소에 넣지 않았다. 넣으려면 `@vitest/coverage-v8` 개발 의존성 + 설정.
- 일시: 자정을 넘겨 파일 이름이 `29-0020`이다(KST 기준).
