## 함께 바꿔야 하는 파일
- 속성 코드 차례는 셋이 같아야 한다: `packages/shared/src/cyborgElements.ts` `ELEMENT_IDS`, `packages/protocol/src/cyborg.ts` `CYBORG_ELEMENT_IDS`(서버 `gateway.test.ts`가 맞춰 본다), 전투 공식 칸 번호(`packages/sim/src/combat/formula.ts` 주석).
- 생성 분배 규칙(N36)은 기기·서버·환생이 같은 함수다. 칸 수·점수를 바꾸면 팩 tuning만 바꾼다(구조 값).
- 사이보그 화면(다른 줄기)이 `CyborgBody.elements`·`religion`·`faithPoints`·`living`을 보일 때 이 칸을 쓴다. 환생 화면 문구("신앙도를 씀", "종교 아이템은 추가 조건")는 D-451·D-452에 맞춰 고쳐야 한다(사이보그 화면 줄기 몫, 아래 TODO).
- 환생 명령(R5)을 만들 때 `rebirthCyborg`의 `spent.items`(종교 아이템 하나)·`grants.skill`을 원장·스킬 칸에 적는다. 휴먼 유닛 행이 생기면 같은 신앙 칸(`UnitFaith`)을 넣는다.

- 올라간 마이그레이션(`20261101025010_cyborg_elements_faith_upkeep` 포함)은 고치지 않는다.
