- 무기 자료: `kind`·`attack`·`attackAppropriate` → 공격력 칸 `physical?`·`elemental?`(`{ attack, attackAppropriate }`) + 기본 공격 칸 `basic?`. 나머지(명중·크리·간격·사거리·비용·옵션 계수)는 그대로 무기 하나에 하나.
- `specFromStats`: 기본 공격 = `basic` 칸(없으면 그 무기의 한 칸). `skillAttack.physical`/`elemental` = 든 무기에 그 칸이 있으면 그 칸, 없으면 타고난 무기의 물리 칸·맨손 속성 자료의 속성 칸. `skills.ts`(스킬 기반으로 `skillAttack`을 고름)는 그대로다.
- 팩 검사(`checkWeaponFields`): 칸 하나 이상, 두 칸이면 `basic` 필수, `basic`은 있는 칸만. 타고난 무기는 물리 칸 필수, 맨손 속성 자료는 속성 칸만(strict).
- 팩 옮김(기계적): `test_sword` → 물리 칸, `test_staff` → 속성 칸, 유닛 종류 넷의 타고난 무기 → 물리 칸, 맨손 속성 자료 → 속성 칸. core@17 → core@18. ID 바뀜 없음(`id-changes.json` 그대로). 두 칸 예시 무기는 팩에 넣지 않았다(시험은 인라인 자료로 충분, 팩에 넣으면 경제 목록에도 생긴다).
- 기본 공격(스킬 없음)의 칸은 기획에 없어 기술 추천 가(무기 자료가 `basic`으로 적음, 두 칸이면 필수)로 넣고 질문 235로 물었다. 두 칸 무기의 옵션 계수를 두 칸이 같이 쓰는지도 236으로 물었다(가 = 같이 씀).
- `@terra/sim`이 `basicFieldOf`·`AttackField`·`WeaponAttackField`를 내보낸다.
