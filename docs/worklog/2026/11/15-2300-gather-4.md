## 한 일
- **1721·D-567·D-568 건물 채집소**: 선택 방식(농장·목장, 팩 core@107부터 약초원도)은 건물 레벨의 최고 티어(2 × 레벨 − 1)를 기르고, 권장 스탯 합(20 × 티어) 미달이면 수확 효율 ‰ = max(300, 1000 − 25 × 모자란 합). 면적 모듈마다 수확 +200‰(겹침). 셈은 `@terra/shared/gatherMath`(`buildingGatherTier`·`buildingGatherEfficiencyPm`·`plotSlots`·`plotAreaPm`·`buildingYieldPm`), 판정은 `@terra/sim workerEffects`(티어·`yieldPm`)·`rollGatherOutputs yieldPm`(개수 × ‰, 나머지 난수 올림). 시뮬 NPC 시설·서버 채집 직무가 같은 함수. 설정 칸 5개(`building_gather_*`·`plot_module_*`).
- 건물 채집소는 2차맵 오브젝트를 쓰지 않는다: 서버 채집소는 선택 방식이면 "facility" 채집소(반경 번수 상한 없음), 시뮬 NPC는 선택 방식에 오브젝트 티어 규칙을 걸지 않는다. 직접 채집은 맡는 시설이 선택 방식이어도 확률표(옛 해금 티어 고르기 없앰). 밭·목초지 자리 설명 고침(질문 1766).
- **면적 모듈**: `world_facilities.plots` 열(마이그레이션 `20261115133024_facility_plots`), 명령 `facility_plot`(프로토콜 41, 코드 `plot_full`), 서버 `facilities/plots.ts`(자리 = 레벨 × 1, 재료 = 레벨 1 짓기 재료, 바로 붙음, 운영자 재료 없이). 채집소 조회에 `plots`(수·자리·면적·기르는 티어·권장 합·다음 재료).
- **1722 NPC 지형별 특수 자리**: `npcGatherTiers`가 site 오브젝트를 바이옴마다 모으고, 배후지 칸 바이옴(서버 `catchmentGeometry.biomeOf` → `catchmentPlaceOf biomes`)에 맞으면 평지·산지 묶음에 더한다. 셈할 때마다 끌어내 저장이 없다 → 이미 있는 세계 도시도 켤 때부터 그대로(멱등). 시뮬 평면은 바이옴이 없어 옛 그대로.
- **1723 레벨 0 재료**: `bareHandMaterials BARE_HAND_GROUPS` = 목재 중분류 전부 + 광석의 석재·잡석. 소금·이탄·화석은 석재 줄로 받지 않는다.
- 1724·1725 그대로.
- **화면**: 사이보그 판 채집 줄(Lv·기르는 티어·권장 합·수확 ‰·모듈 수, 기대 금액에 ‰), 2차맵 채집소 판(개요 기르는 티어, 관리 칸 면적 모듈·[모듈 하나 붙이기]), 경제 생산 카드 채집소 칸(티어·모듈 줄·[모듈 하나 붙이기]), 생산 편집기(미리 보기 = 레벨 티어·수확 효율, 예상 확률 칸 = 기르는 티어·K 범위 효율, 방식 이름·설명), 아이템 편집기 미리 보기(레벨마다 몫), 경제 화면(Lv1 T1). 문구 ko·en 함께.

## 리셋 필요 여부: 필요 없음
- DB는 열 더하기만(`plots smallint not null default 0` + 범위 검사) — 직전 판 앱은 열을 모른 채 넣고 처음 값 0을 받는다(Verified: 마이그레이션 SQL). 시설 줄을 다시 쓰는 직전 판 앱은 `plots`를 넣지 않으므로 그 사이 붙인 모듈은 지워지지 않는다(Verified: `world/persist/writer.ts` upsert는 열 목록의 열만 `do update set` — 직전 판 열 목록에는 `plots`가 없다).
- 기존 세계의 농장·목장·약초원 작업 줄(`unit_work` gather_points·gather_seq)은 그대로 이어지고 다음 정산부터 새 규칙(레벨 티어·효율)으로 묶음을 굴린다. 채집소 종류(objects → facility)·끝낸 묶음 수는 메모리라 저장할 것이 없다. 밭·목초지 오브젝트는 지우지 않아 오브젝트 번호·저장 상태가 그대로다.
