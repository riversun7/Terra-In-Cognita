## 함께 바꿔야 하는 파일
- 묶음이 판을 매길 때: `content/core/manifest.json`(245 → 묶음 판)과 `id-changes.json`의 `since` 245(같은 판으로), ADR league-3 절 머리의 판 줄.
- **no-teleport-b와 합칠 때(통합 메모)**: `apps/server/src/hospital/attach.ts`의 NPC `travel: () => undefined`를 `travel: () => npcTravelOf(p.travel)`(`../travel/npcTravel.ts`)로 바꾼다.
  `CareNpcTravel`(`labor/stewardCare.ts`)은 no-teleport-b(머리 0ce23b84ba)의 `NpcTravel.send(unitId, { mapKey, x, y }, onDone?)` → `{ ok: true, arriveAt } | { ok: false, code }`, `onDone({ unitId, state, stop, mapKey })`와 같은 꼴이다.
  닿았다는 알림에서 바로 치료하고 돌려보낸다(NPC 휴먼은 닿은 뒤 다시 스스로 걷는다). NPC 다녀오기 시험(가짜 NPC 이동 — `stewardCare.test.ts` 마지막 시험)은 그대로 돈다.
  no-teleport-b의 "플레이어 유닛이 일터로 걸어감"(`labor/walkToWork.ts`)과는 겹치지 않는다(돌아온 유닛을 관리인이 다시 일자리에 넣으면 그 길로 걸어간다 — Assumed).
- 프로토콜 판을 올리는 묶음이 오면 `house_league`의 `clause_on`·`clause_off`·`clause`·`HOUSE_LEAGUE_CLAUSES`를 뺄 수 있다(옛 판 기기가 더 없을 때).
- 표 `house_league_clauses`를 지우려면 다음 판 정리 마이그레이션(직전 판 앱이 그 표를 더 쓰지 않은 뒤 — 이 판부터 쓰지 않는다).
