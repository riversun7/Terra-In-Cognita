### 1. 유닛 목록·상세에 성장과 작업 상태

- **유닛 표**(유닛 탭·유저 상세·세력 상세 공용)는 칸 열 개다: ID, 이름, 종류, 주인, 위치, 레벨·경험치(이번 레벨 / 구간, 만렙이면 "만렙"), 스탯 여섯(STR·DEX·AGI·VIT·INT·WIS 차례 — 레벨 성장을 센 지금 값), 작업(직무 또는 도시 일꾼 · 일하는 중/쉬는 중 + 일하는 건물 번호), 피로, 상태.
  - **모든 유닛에 레벨·스탯이 보인다.** 저장된 스탯이 없는 유닛(NPC 지도자·규모 시험 봇·시험 유닛)은 세계가 실제로 쓰는 종류 기본 몸(레벨 1, 1차 스탯 모두 10)을 보인다. 이 유닛은 경험치를 받지 않아 경험치 칸은 "—"다.
  - **이름**: 사이보그 본체 이름, NPC 휴먼 이름(나라 이름 목록 규칙 — NPC 런타임 `humanName`), NPC 지도자 이름(국가 프리셋 `leaderName`). 이름을 눌러도 유닛 상세가 열린다.
  - **위치는 짧게**("맵 …끝 네 자리 · (칸)") 보이고, 누르면 그 아래에 전체 위치(행성·2차맵 키·칸)와 [이 2차맵의 유닛]이 펼쳐진다. 도시 표도 같다.
  - NPC 도시 일꾼(도시 경제가 일터를 준 휴먼 — 직무 상태가 없다)은 "도시 일꾼 · 일하는 중/쉬는 중"으로 보인다(일하는 때 = 움직임과 같은 셈 `bots.ts atWork`).
- **유닛 탭의 정렬·거르기**: 칸 머리(ID·레벨·피로)를 누르면 그 칸으로 정렬하고 다시 누르면 차례를 뒤집는다. [작업 상태] 고르기(일하는 중·쉬는 중·하는 일 없음·이동 중·부상·포로)로 거르고, 표의 작업·상태 표지를 눌러도 그 상태로 거른다. 정렬·거르기는 서버가 전체 유닛에 대해 한다(쪽 안에서만 하지 않는다).
- **유닛 상세**에 판 둘을 더했다.
  - 성장: 성장 자료(사이보그 본체·휴먼·사이보그 유닛·기본 몸), 레벨, 경험치, 환생, 지금 스탯, 처음 스탯, 성장 K(‰). 저장된 K가 없으면 "기준 1000‰로 성장"이라고 알린다. 기본 몸이면 "저장된 스탯이 없어 … 경험치를 받지 않습니다" 안내 한 줄.
  - 작업 상태: 직무와 단계, 이번 주기 진행(ms), 피로, 일터(건물 번호·시설 종류·직무 배치/임금형/임대형), 계약(임금·임대료와 화폐·상태), 생활 규칙(쉬러 가는 피로·다시 일하는 피로, 주인이 정했는지), AI 작전 프리셋, 가는 곳(이동 중일 때 도착 칸과 시각).
  - 앞에는 직무가 "코드 / 단계 / 진행 / 피로" 숫자 한 줄이었다. 그 줄을 없애고 이 판으로 옮겼다.
- 유닛 탭에 [유닛 번호로 열기]를 더했다(번호를 알면 목록을 넘기지 않고 상세를 연다).

### 2. 화면끼리 잇기

이름·수를 누르면 그 대상으로 간다. 모두 콘솔의 `open` 하나로 부른다.

| 누르는 곳 | 가는 곳 |
|---|---|
| 유저 표의 사이보그 이름 | 그 사이보그 본체의 유닛 상세 |
| 유저 표의 유닛 수 | 유닛 탭(그 유저의 유닛만) |
| 유저 상세의 사이보그 이름 | 본체 유닛 상세 |
| 유저·세력 상세의 [유닛 탭에서 모두 보기] | 유닛 탭(그 주인의 유닛만) |
| 유닛 표의 주인 | 유저 상세 또는 세력 상세 |
| 유닛 표·도시 표의 위치(펼친 뒤 [이 2차맵의 유닛]) | 유닛 탭(그 2차맵의 유닛만) |
| 유닛 상세의 주인 / [이 주인의 유닛] / [이 2차맵의 유닛] / 잡은 주체 | 유저·세력 상세 / 거른 유닛 목록 |
| 감사 기록의 한 사람·대상 | 유저·유닛·세력 상세 |

- 유닛 탭은 건너온 주인 거르기를 줄 위 표지("주인: …")로 보이고 [거르기 풀기]로 푼다. 2차맵 거르기는 거르기 줄의 2차맵 키 칸에 채워진다.
- 앞에도 있던 연결(유저 → 소속 세력, 도시 → 세력, 세력 → 소속 유저·전쟁 상대)은 그대로다.

- **경험치는 묶음을 실제로 수확한 유닛만 받는다**(플레이어 직접 채집·채집 직무 — ADR `2026-11-26-gather-exp.md`). NPC 도시 휴먼은 생산이 도시 경제 합계(일꾼 수)로 돌아 경험치를 받지 않는다. 그래서 NPC 휴먼은 모두 레벨 1·경험치 0으로 보인다(사용자 지적 2026-11-27 — 다음 작업).
