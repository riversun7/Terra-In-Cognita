# 운영자 콘솔: 경험치 없는 유닛 줄 없애기, 레벨 정렬이 경험치까지, NPC 일꾼 피로, 지금 하는 일 하나로

## 한 일

사용자 지적(2026-11-27, 운영자 콘솔 유닛 표 사진과 함께): "1. 왜 레벨만 있고 경험치는 아예 없는 유닛이 존재하냐? 2. 왜 전부 경험치가 0이냐?"

### 1. 레벨만 있고 경험치가 없던 줄

- 원인(Verified: 개발 DB `terra_dev` 읽기 — 사진의 95번 유닛은 종류 0 봇, 기본 빠르기 4,813): 앞 작업에서 탈것 빠르기 봇을 굴림 대상에서 빼 두어 기본 몸(레벨 1, 경험치 없음)으로 보였다.
- 고침: 탈것 빠르기 봇도 같은 봇으로 굴려 저장한다. 걷는 빠르기는 바뀌지 않는다(탈것 빠르기 봇은 AGI로 빠르기를 셈하지 않는다 — Verified: `world/walkSpeed.ts` `walksOnFoot`).
- 레벨을 두지 않는 유닛(배·줄 없이 세운 시험 유닛)은 표와 상세에서 레벨·경험치를 둘 다 "—"로 보인다.

### 2. 경험치가 전부 0으로 보이던 것

- 확인(Verified: 개발 DB 읽기, 서버를 다시 켠 지 몇 분 뒤): `unit_exp`에 경험치가 있는 유닛 1,052(10이 1,044 · 20이 8), 모두 NPC 나라 휴먼(유닛 ID 120 이상). NPC 일꾼 경험치는 돌고 있다.
- 사진의 줄(ID 90번대, 2차맵 …8457)은 규모 시험 봇(도시에 속하지 않고 걷기만 하는 봇 100)과 NPC 지도자다. 일하지 않아 경험치가 0이다.
- 화면에서 찾기 어려웠던 까닭: 레벨 정렬이 레벨만 봐서(모두 레벨 1) 경험치가 있는 유닛이 위로 오지 않았다.
- 고침: 레벨·경험치 칸 머리의 정렬이 레벨 다음에 경험치를 본다. 한 번 누르면 경험치가 많은 유닛부터 나온다.

### 3. NPC 일꾼의 피로가 0으로만 보이던 것

사용자 지적(2026-11-27, 레벨·경험치로 정렬한 사진과 함께): "1. 피로는 왜 안오르냐"

- 원인(Verified: 코드 읽기): NPC 도시 일꾼은 직무 상태가 없다(도시 경제가 일꾼 수만 센다). 표는 직무 상태의 피로(늘 0)를 보였다.
- NPC 일꾼에게는 어림 피로가 따로 있다(`world/bots.ts` `shiftFatiguePm` ‰ — 일하는 때 0에서 꼭대기 600‰로 오르고 쉬는 때 내린다. NPC 작업 중 부상 판정과 봇 판단이 쓰는 값).
- 고침: NPC 도시 일꾼은 그 어림 피로를 피로 상한(설정 칸, 120) 눈금으로 바꿔 보인다(꼭대기 72). 피로 칸 머리 정렬도 그 값을 쓴다. 어림값인 줄은 칸에 마우스를 올리면, 상세에는 글자로 알린다.

### 4. "쉬는 중"인데 "이동 중"으로 같이 뜨던 것

사용자 지적: "2. 왜 다 이동중이냐? 쉬는중 일하는중이랑 왜 다르냐"

- 원인: 작업 칸(일하는 때·쉬는 때 — 시각으로만 봄)과 상태 칸(걷는 중인가)을 따로 보였다. NPC 휴먼은 일터·집 둘레를 계속 걸어서 거의 늘 "이동 중"이었고, 일하는 때인데 아직 일터로 가는 중인 것도 "일하는 중"으로 떴다.
- 고침: **지금 하는 일을 하나로** 보인다. 봇의 움직임을 정하는 판단과 같은 값(`bots.ts` `botStatus` — 새 함수)에 "그 자리에 닿았는가"를 더했다.
  - 일하는 중 / 일터로 가는 중 / 운반 중 / 쉬는 중 / 쉬러 가는 중 / 볼일 보는 중(시장) / 순찰 중 / 피하는 중 / 이동 중(직무·일터 없는 유닛) / 하는 일 없음
  - 직무 유닛(플레이어)은 직무 단계(일·쉼) 그대로다.
- 상태 칸은 부상·포로만 보인다. [작업 상태] 거르기는 위 값 그대로(+ 부상·포로)이고, 줄에 보이는 값과 거른 결과가 늘 같다.

## 미검증·TODO·알려진 문제

- **NPC 일꾼의 피로는 어림값이다.** 플레이어 유닛처럼 쌓이는 진짜 피로(직무 상태)가 아니다 — NPC 휴먼은 직무 상태가 없고 생산은 도시 경제가 일꾼 수로 센다. NPC 휴먼에게 플레이어 유닛과 같은 직무 상태(묶음마다 피로 10, 피로 구간 불이익, 생활 규칙)를 주는 것은 하지 않았다(도시 경제의 생산 셈을 유닛 단위로 바꾸는 큰 일이다).
- "닿았는가"는 유닛 자리가 목적지 네모(일터·쉼터 둘레) 안인지로 본다. 네모 안에서 걷는 것은 일하는 중·쉬는 중이다.
- 규모 시험 봇·NPC 지도자는 일하지 않아 경험치를 받을 일이 없다(전투 경험치가 없다). 운영자 콘솔에서 이 유닛들은 계속 0으로 보인다.
- 개발 서버를 다시 켠 뒤 화면에서 직접 보지는 않았다(미실행 — DB 값과 화면 시험으로 봤다).
- 로컬 PostgreSQL에 지난 시험이 남긴 `terra_test_*` DB가 여럿 있다(누가 남겼는지 모른다 — 지우지 않았다).
